# Pygame Marp 슬라이드 작성 및 운영 가이드

## 1. 목적과 적용 범위
이 문서는 StepCode Pygame 코스(`lesson01~05`)의 실제 수업자료 관리 및 Marp 슬라이드 작성 원칙을 정의한다.

## 2. 폴더 구조와 역할
- `lessonXX/lesson/slide.md`: 수업 슬라이드 원본
- `lessonXX/assets/`: 해당 차시 전용 이미지/도식
- `lessonXX/src/`: 학생/교사용 코드 자료
- `shared/themes/pygame_theme.css`: 공용 테마

## 3. Marp 슬라이드 작성 표준

### 3.1. 기본 원칙
- **수업 진행 스크립트:** 설명서가 아닌, 수업의 흐름을 주도하는 대본처럼 작성한다.
- **Top-Down 구조:** 큰 그림을 먼저 보여주고 세부 코드로 내려간다.
- **클래스 기반 스타일링:** `slide-title`, `slide-section`, `slide-part` 클래스를 적극 활용한다.

### 3.2. 계층 번호 체계
- 파트: `1.1`, `1.2` (점 하나)
- 콘텐츠 슬라이드: `1.1.1`, `1.1.2` (점 두 개)
- **목차와 본문 제목은 100% 일치해야 함.**

### 3.3. 코드 블록 및 마커
- 핵심 실습 코드는 `<div class="code-window">`로 감싼다.
- 설명 텍스트와 매칭되는 위치에 `[A]`, `[B]` 마커를 사용한다.

### 3.4. SVG 자산 제작
- `viewBox="0 0 W H"` 원점 기준 설계.
- 텍스트 줄바꿈이 없으므로 `<text>` 태그 분할 사용.

### 3.5. Mermaid.js 활용 표준 (로직 시각화)
- **순서도(flowchart):** `graph TD` 또는 `graph LR`을 사용하여 로직의 흐름을 표현한다.
- **교육적 강조:** 학생이 작성해야 할 구간은 `style` 문법으로 강조색(예: 노란색)을 입힌다.
- **단순함 유지:** 한 슬라이드에 노드는 최대 5~6개로 제한하여 인지 부하를 줄인다.
- **Marp 호환성:** 코드 블록에 `mermaid` 언어 명시를 잊지 않는다.
