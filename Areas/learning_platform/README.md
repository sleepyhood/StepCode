# Areas - Learning Platform

이 폴더는 StepCode의 장기 운영 영역을 설명하는 PARA 래퍼입니다.

현재 1차 적용에서는 웹앱 상대경로를 보호하기 위해 아래 경로를 실제 이동하지 않습니다.

- `practice/`
- `scripts/`
- `docs/`
- `README.md`

운영 원칙:

- 웹앱이 직접 참조하는 자산은 기존 위치를 유지합니다.
- 장기 유지되는 기능/콘텐츠 운영은 `Areas` 관점으로 관리합니다.
- 실제 루트 정리는 느슨한 문서, 임시 산출물, 실험 스크립트부터 수행합니다.
