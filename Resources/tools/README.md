# StepCode 유틸리티 도구 상자 (Resources/tools)

이 디렉토리는 StepCode 프로젝트 운영 및 교육 콘텐츠 제작을 보조하는 파이썬 기반 자동화 도구들을 포함합니다. 모든 도구는 `[접두어]_[대상]_[방식].py` 명명 규칙을 따르며, 생산성 향상을 목적으로 합니다.

## 1. 크롤러 및 데이터 수집 (Crawler & Data)
외부 사이트의 정보를 수집하고 가공하는 도구들입니다.

| 파일명 | 주요 기능 |
| :--- | :--- |
| `crawler_baekjoon_gui.py` | 백준(Baekjoon) 문제 수집 통합 GUI. 대량 수집 및 실시간 로그 확인 지원. |
| `crawler_baekjoon_engine.py` | 백준 크롤링 핵심 엔진. 세션 관리, 데이터 파싱, 배지 패치 로직 포함. |
| `crawler_testcase_zip_export.py` | 수집된 문제의 테스트케이스를 ZIP 파일로 빌드 및 내보내는 유틸리티. |
| `util_open_data_loader.py` | 공공 데이터나 외부 데이터셋을 프로젝트 형식에 맞춰 로드하는 도구. |

## 2. 제작 및 미디어 지원 (Media & Capture)
콘텐츠 제작에 필요한 화면 캡처, 녹화 및 다이어그램 자동화 도구들입니다.

| 파일명 | 주요 기능 |
| :--- | :--- |
| `util_window_capture.py` | **타이머 기반 창 자동 캡처 도구**. 미리보기, 무제한 모드, 실시간 로그 지원. |
| `util_pdf_capture_gui.py` | PDF 페이지 영역 자동 감지 및 페이지 넘김 연동 전문 캡처 도구. |
| `util_pygame_recorder.py` | Pygame 실행 화면이나 미디어 출력을 기록/녹화하는 유틸리티. |
| `util_ai_automator_gui.py` | **Draw.io AI 통합 오토메이터**. 배경 이미지 설명 및 다이어그램 작업 자동화 지원. |

---

## 관리 가이드라인
1. **파일명 규칙**: 새로운 도구 추가 시 `[접두어]_[대상]_[방식].py` 형식을 유지합니다.
   - `crawler_`: 데이터 수집용
   - `util_`: 제작 보조 및 범용 유틸리티
2. **버전 관리**: 파일 이름에 날짜나 버전 번호를 넣지 않고 Git 히스토리를 활용합니다.
3. **한글 금지**: 파일 및 폴더명에는 프로젝트 규칙에 따라 한글 사용을 금지합니다.
