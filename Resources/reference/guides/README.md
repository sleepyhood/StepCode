## 문서 사용 규칙

- 새 운영/참고 문서를 추가하면 이 인덱스에도 링크를 추가합니다.
- 장기적으로 반복 참조하는 문서만 이 폴더에 둡니다.
- 단기 작업 메모는 `Projects/active/` 쪽에 둡니다.
- 재생성 가능한 산출물이나 임시 결과물은 `Archives/`로 분리합니다.
