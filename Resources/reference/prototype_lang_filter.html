문제: 1부터 20까지 출력하기

난이도: Bronze V

반복문을 사용하여 1부터 20까지 화면에 출력하는 프로그램을 작성하세요.

이 문제의 핵심은 반복문의 범위 설정입니다. [[lang:c]]C언어에서는 for(int i=1; i<=20; i++)와 같이 조건식을 명확히 작성해야 합니다.[[/lang]] [[lang:python]]파이썬의 range(start, end) 함수는 마지막 숫자를 포함하지 않으므로 range(1, 21)로 작성해야 함에 유의하세요.[[/lang]] [[lang:java]]자바에서는 System.out.println()을 사용하여 한 줄씩 출력할 수 있습니다.[[/lang]]

C언어 구현 팁:
줄바꿈을 위해 \n 서식 문자를 잊지 마세요. 
for (int i = 1; i <= 20; i++) {
    printf("%d\n", i);
}
Python 구현 팁:
파이썬은 print() 함수가 기본적으로 줄바꿈을 포함합니다. 
for i in range(1, 21):
    print(i)
Java 구현 팁:
정적 메소드인 main 안에서 로직을 구현하세요. 
for (int i = 1; i <= 20; i++) {
    System.out.println(i);
}

모든 숫자가 출력된 후에는 프로그램이 정상적으로 종료되어야 합니다.
