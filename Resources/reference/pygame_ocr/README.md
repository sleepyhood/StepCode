# pygame_ocr Reference

이 폴더는 `practice/data/Pygame`에서 분리한 OCR/PDF 원본과 중간 산출물을 보관합니다.

구성:

- `01_test1/`, `02_test2/`: OCR 테스트 결과와 이미지 덤프
- `python_ocr_game.pdf`: 원본 PDF
- `1차LLM교정_게임으로 배우는 파이썬OCR.md`: 교정 메모

운영 웹앱 자산은 아닙니다.
실제 운영용 Pygame 콘텐츠는 `practice/data/content/pygame/`와 `practice/data/generated/*.json`에서 관리합니다.
