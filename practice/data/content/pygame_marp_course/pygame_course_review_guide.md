# Pygame 수업 콘텐츠 검수 가이드 (Pygame Course Review Guide)

이 문서는 프로그래밍 초심자를 위한 Pygame 연습 플랫폼(StepCode)의 수업 콘텐츠(`interactive.md`)와 교사용/학생용 실습 코드 간의 정합성을 검수하고 보완하기 위한 가이드라인입니다.

---

## 📌 핵심 검수 체크리스트 (Review Checklist)

### 1. 함수 정의(Def)와 호출(Call)의 정합성
*   **체크 사항:** 수업 자료에서 학생이 직접 작성하도록 정의한 함수가 게임 엔진 및 메인 루프(`main()`) 내부에서 정상적으로 호출되고 있는지 확인합니다.
*   **주의 사례:** 2차시 운석 생성(`spawn_meteor`) 및 낙하(`update_meteors`)처럼 학생이 함수 자체를 구현한 뒤, 메인 루프 내의 알맞은 위치(타이머 이벤트 구역 및 프레임 업데이트 구역)에서 직접 호출하도록 가이드하는 내용이 누락되지 않았는지 확인합니다.

### 2. 변수명 및 객체명 일관성
*   **체크 사항:** 수업 자료의 텍스트 설명, MCQ 문제 보기, 실습 미션 코드 블록, 그리고 실제 파이썬 소스 코드(`src/step*.py`)에 쓰인 모든 변수명과 객체명이 완벽히 일치하는지 확인합니다.
*   **주의 사례:**
    *   `new_m` vs `new_meteor`
    *   `m` vs `meteor`
    *   약어와 정식 명칭이 혼용될 경우 초보 학습자에게 불필요한 인지 부하를 줍니다. 되도록 직관적이고 상세한 영어 단어로 통일합니다.

### 3. 알고리즘 구현 스타일 일치
*   **체크 사항:** 수업 자료에서 가르친 논리적 알고리즘과 교사용 완성본(`step*_teacher.py`)에 작성된 알고리즘이 완벽히 일치하는지 확인합니다.
*   **주의 사례:**
    *   수업 자료에서는 초보자용으로 리스트 복사본 순회 및 삭제(`for meteor in meteors[:]` 후 `remove()`)를 설명했으나, 교사용 예제에서는 고급 문법인 리스트 내포(List Comprehension)를 사용하는 등의 불일치가 없어야 합니다.
    *   부득이하게 두 코드가 다를 경우, 수업 자료에 추가 해설(예: 팁 박스)을 달아주거나 교사용 코드를 초보자용 표준 코드로 교체해야 합니다.

### 4. Pygame 좌표계 및 경계 값 일치
*   **체크 사항:** 화면 크기(예: `800x600`)에 따른 충돌 방지 조건식 및 경계 판단 값이 정확하고 일관된지 확인합니다.
*   **주의 사례:**
    *   `ship_rect.right > 800` 일 때 오른쪽 벽 고정은 `ship_rect.right = 800` 이어야 합니다. (`left = 800` 등으로 표기되는 오타 방지)
    *   화면 아래로 사라진 운석을 지울 때, `y > 600`과 `top > 600` 중 무엇을 기준으로 삼았는지 코드가 가리키는 실제 속성과 주석 설명이 동일한지 검수합니다.

### 5. 초보자용 개념 설명 보완
*   **체크 사항:** 파이썬 및 Pygame 기초 문법의 장벽을 해소할 수 있는 친절한 설명(Callout)이 포함되어 있는지 확인합니다.
    *   **`global` 선언:** 함수 내에서 외부 전역 변수(리스트, 객체)를 직접 수정/재할당할 때 왜 `global` 키워드가 필요한지 설명합니다.
    *   **`pygame.Rect` 속성:** `top`, `bottom`, `left`, `right` 등 Rect 객체가 가진 경계 속성들이 화면 좌표계에서 무엇을 의미하는지 도해와 함께 설명합니다.

## 🛠️ 검증 및 빌드 파이프라인 (Verification Pipeline)

수업 콘텐츠나 소스 코드를 수정한 후에는 반드시 아래 검증 명령을 차례대로 실행하여 인덱스가 정상 생성되는지, 정합성이 유지되는지 확인해야 합니다.

### Step 1. Pygame 구문 컴파일 테스트
수정된 교사용 완성본(`step*_teacher.py`)에 구문 오류가 없는지 검사합니다.
```bash
python -m py_compile practice/data/content/pygame_marp_course/lesson*/src/step*_teacher.py
```

### Step 2. 콘텐츠 인덱스 재생성
마크다운 문서와 메타데이터의 변경 사항을 웹 플랫폼 인덱스 파일에 반영합니다.
```bash
python scripts/generate_content_indexes.py
```

### Step 3. 정합성 자동 체크
생성된 인덱스 파일(`sets.index.json`)에 오류나 누락, ID 중복이 없는지 유효성을 검사합니다.
```powershell
powershell -ExecutionPolicy Bypass -File scripts/check_sets_index.ps1
```
*(출력 결과에 `OK: sets.index.json is consistent`가 표시되어야 성공입니다.)*
