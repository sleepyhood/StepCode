# Pygame 반완성형 Marp 코스 커리큘럼

## 방향

이 코스는 `완성된 설명 전달`보다 `선생님이 바로 수업할 수 있는 반완성형 진행`을 목표로 한다.

- 슬라이드는 설명서가 아니라 수업 진행 스크립트다.
- 학생은 슬라이드를 보며 교사와 함께 코드를 채우고 수정한다.
- `lesson01`부터 `lesson05`까지의 차시는 하나의 게임을 단계적으로 확장하는 실제 수업자료다.
- 차시별 산출물은 각 lesson 폴더의 자료를 기준으로 누적 관리한다.

## 현재 운영 차시

### 1차시. 우주선 좌우 이동하기

- 목표: 키 입력에 따라 우주선을 좌우로 움직이고, 화면 경계를 넘지 않도록 제한한다.
- 산출물: 방향키로 좌우 이동하는 우주선과 좌우 경계 제한이 적용된 기본 플레이 화면
- 교사 포인트: 좌표계, 입력 처리, 조건문을 `입력 -> 이동 -> 경계 제한` 흐름으로 설명한다.

### 2차시. 운석 생성과 낙하

- 목표: 화면 위에서 운석이 생성되고 아래로 떨어지는 반복 업데이트 구조를 만든다.
- 산출물: 주기적으로 생성되어 아래로 떨어지고, 화면 밖으로 벗어나면 제거되는 운석 시스템
- 교사 포인트: 리스트 상태 관리, 타이머 이벤트, 반복 갱신을 분리해서 설명한다.

### 3차시. 충돌 판정과 재시작

- 목표: 우주선과 운석의 충돌을 판정하고, 게임 오버 및 재시작 흐름을 만든다.
- 산출물: 충돌 시 게임 오버가 표시되고 `R` 키로 다시 시작할 수 있는 플레이 루프
- 교사 포인트: `colliderect`, 상태 전환, 조건에 따라 업데이트 흐름이 달라지는 구조를 보여준다.

### 4차시. 점수와 난이도

- 목표: 생존 시간에 따라 점수를 올리고, 점수에 비례해 게임 난이도를 높인다.
- 산출물: 점수와 레벨이 표시되고 시간이 지날수록 운석 속도가 빨라지는 게임 화면
- 교사 포인트: 누적 변수, 정수 나눗셈 기반 레벨 계산, HUD 표시를 연결해서 설명한다.

### 5차시. 선택형 확장 기능

- 목표: 기본 게임 구조를 바탕으로 확장 기능을 추가해 완성도를 높인다.
- 산출물: 운석 크기 랜덤, 목숨 시스템 등 추가 규칙이 반영된 확장 버전 게임
- 교사 포인트: 기존 구조를 재사용하면서 규칙을 하나씩 덧붙이는 확장 설계를 경험하게 한다.

### 6차시. 이미지로 만드는 진짜 게임 (Final Polish)

- 목표: 단순한 사각형 객체를 실제 이미지(Sprite)로 교체하고 배경을 입혀 게임의 시각적 완성도를 높인다.
- 산출물: 우주선, 운석, 배경 이미지가 적용된 최종 완성본 게임
- 교사 포인트: 이미지 로드, 크기 조절(Transform), 렌더링(Blit)의 개념을 배우며 리소스 관리의 중요성을 이해하게 한다.

## 운영 원칙

- 새 차시를 추가할 때는 `lessonXX_topic` 폴더를 만든다.
- 차시명과 lesson 폴더명은 실제 수업 흐름이 드러나도록 맞춘다.
- 공통적으로 반복되는 테마, 장식, 재사용 조각은 `shared/themes/`, `shared/assets/`, `shared/snippets/`에서 관리한다.
- 각 차시는 앞 차시의 산출물을 바탕으로 다음 기능을 누적하는 방식으로 설계한다.
