# Pygame 반완성형 Marp 코스

## 방향

이 코스는 `완성된 설명 전달`보다 `선생님이 바로 수업할 수 있는 반완성형 진행`을 목표로 한다.

- 슬라이드는 설명서가 아니라 수업 진행 스크립트다.
- 학생은 슬라이드를 보며 교사와 함께 코드를 채우고 수정한다.
- 차시별 산출물은 `slide.md`를 기준으로 누적 관리한다.

## 차시 초안

### 1차시. Pygame 시작과 화면 구성

- 목표: 실행 환경, 창 생성, 게임 루프의 큰 흐름 이해
- 산출물: 기본 창이 뜨고 종료되는 최소 구조
- 교사 포인트: 학생이 `왜 반복문이 필요한지`를 말로 설명할 수 있게 유도

### 2차시. 입력과 반복 업데이트

- 목표: 키 입력, 위치 갱신, 속도 개념 도입
- 산출물: 방향키로 움직이는 단일 오브젝트
- 교사 포인트: 이벤트 처리와 상태 갱신을 구분해서 설명

### 3차시. 스프라이트와 움직임 조합

- 목표: 이미지 자산, 스프라이트 위치, 간단한 충돌/애니메이션 감각 도입
- 산출물: 캐릭터 또는 오브젝트가 움직이는 장면
- 교사 포인트: 코드 완성보다 구조 분해와 수정 포인트 파악에 집중

## 확장 규칙

- 새 차시를 추가할 때는 `lessonXX_topic` 폴더를 만든다.
- 차시 제목, category id, concept id는 모두 새 namespace를 사용한다.
- 공통적으로 반복되는 슬라이드 장식, 코드 프레임, 안내 문구는 `shared/themes/`, `shared/snippets/`에서 관리한다.
