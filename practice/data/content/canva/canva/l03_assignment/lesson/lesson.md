# 3차시. 디자인 정돈 및 AI 창작 워크플로 체험

## 디자인 정돈하기: 레이어와 정렬, 그룹화

여러 요소가 겹치는 디자인에서는 정렬과 레이어, 그룹 기능이 필수입니다. 정렬·레이어·그룹 기능으로 디자인을 깔끔하게 정돈해 완성도를 높이는 노하우를 배워 봅니다.

캔바에서 디자인을 하다 보면 여러 요소(이미지, 텍스트, 도형 등)들이 작업 페이지 위에 겹쳐서 배치됩니다. 이때 각 요소의 위치를 정확하게 조절하고, 여러 요소를 한 번에 이동시키려면 레이어, 정렬, 그룹 기능을 활용해야 합니다. 이 세 가지 기능은 깔끔하고 완성도 높은 디자인을 만드는 데 필수적인 기본기입니다.

이번 레슨은 디자인을 정돈하는 실제 작업 순서 흐름대로, 요소 배치 ➔ 레이어 정리 ➔ 정렬/간격 맞추기 ➔ 그룹으로 구조 잡기 구성으로 정리해 볼게요.

### 요소의 보이는 순서 정돈하기: 레이어

**레이어 이해하기: 겹쳐진 종이들의 순서**
캔바의 디자인 화면은 여러 장의 투명한 종이가 겹쳐진 것과 같습니다. 이 투명한 종이가 ‘레이어’이고, 텍스트 상자, 그래픽, 사진 같은 모든 요소는 각각 한 장의 ‘레이어’에 올려져 있다고 이해하면 됩니다. 이 레이어가 어떤 순서로 쌓이느냐에 따라 디자인이 화면에서 다르게 보입니다.

**레이어 구조 이해도: 레이어가 쌓인 순서와 화면에서 보이는 디자인**

<!-- p.154 -->

![텍스트·자동차·배경 이미지가 층층이 쌓인 레이어 구조를 보여주는 도식](./data/theory/canva/Week03/images/p154_12.png)

텍스트가 사진 뒤에 숨어 보이지 않거나, 요소가 배경 위에 나타나야 하는데 뒤에 묻혀 있거나 등등 이런 문제는 대부분 레이어 순서가 정돈되지 않아서 생깁니다. 레이어만 잘 이해해도 복잡해 보이는 디자인을 쉽게 정리할 수 있답니다. 레이어 작업의 중심 도구는 에디터 툴 바의 위치 메뉴와 플로팅 툴 바입니다.

**에디터 툴 바의 레이어 패널에서 레이어 순서 바꾸기**
요소가 많아질수록 뭐가 어디에 있는지 헷갈릴 때에는 눈대중 대신 레이어 목록을 확인해 파악하는 게 정확하고 빠릅니다. 특히 복잡한 디자인 작업의 레이어들을 전체적으로 정돈할 때, 겹쳐진 요소가 많거나 작아서 클릭하기 어려울 때 유용합니다.

1. **[레이어] 탭 열기**: 에디터에서 페이지나 배경, 또는 아무 요소나 하나 선택하고 에디터 툴 바 - [위치] - [레이어] 탭을 클릭합니다. [레이어] 탭에서 모든 요소의 쌓인 순서를 볼 수 있어요. 가장 위의 레이어에 있는 요소가 페이지에서 맨 앞에 보이게 됩니다.

2. **레이어 순서 변경하기**: 여기서 각 레이어를 클릭하면 해당 레이어에 있는 객체가 선택됩니다. 레이어를 선택한 채로 위아래로 드래그하면 이동할 자리에 보라색 선으로 표시되어 직관적으로 조정할 수 있습니다.
   <!-- p.155 -->
   ![레이어 패널에서 항목을 드래그해 순서를 바꾸는 캔바 화면](./data/theory/canva/Week03/images/p155_12.png)

**플로팅 툴 바로 레이어 순서 바꾸기**
작업하는 과정에서 선택한 요소의 앞뒤 레이어 관계를 바로바로 정리하고 싶을 때에는 플로팅 툴 바를 활용하는 게 편리합니다. 또한 선택한 요소의 레이어 순서를 바로 바꿔 주는 단축키를 활용하면 더 빠르게 작업할 수 있어요.

**한 요소의 레이어 순서 바꾸기**
순서를 바꾸고 싶은 요소를 선택하고, 플로팅 툴 바 - [...] (더보기) - [레이어]를 선택하면 4가지 옵션이 나타납니다. 원하는 옵션(예: [앞으로 가져오기])을 클릭하면 해당 요소의 레이어가 이동한 것을 확인할 수 있어요.

**레이어 순서 변경 단축키 정리**
디자인 작업하면서 레이어 순서 바꾸는 기능은 정말 자주 사용하니 단축키를 기억해 두면 좋습니다.

| 기능                   | Windows              | Mac                    |
| ---------------------- | -------------------- | ---------------------- |
| **앞으로 가져오기**    | `Ctrl` + `]`         | `Cmd` + `]`            |
| **맨 앞으로 가져오기** | `Ctrl` + `Alt` + `]` | `Cmd` + `Option` + `]` |
| **뒤로 보내기**        | `Ctrl` + `[`         | `Cmd` + `[`            |
| **맨 뒤로 보내기**     | `Ctrl` + `Alt` + `[` | `Cmd` + `Option` + `[` |

![레이어 순서 변경 단축키를 정리한 표](./data/theory/canva/Week03/images/p156_03.png)

**여러 요소의 레이어 순서 바꾸기**
여러 요소를 다중 선택하면 한꺼번에 레이어 순서를 바꿀 수 있습니다. 작업 페이지 또는 레이어 패널에서 `Shift`를 누른 채로 레이어 순서를 바꿀 여러 요소를 클릭해 선택하고 레이어 순서를 바꾸면 됩니다. 또는 플로팅 툴 바나 단축키로 순서를 바꿀 수 있습니다.

### 요소와 구조 고정하기: 잠금

배경 이미지나 메인 그래픽 요소 등 위치가 고정돼야 하는 요소는 작업 중에는 실수로 움직이지 않게 잠그는 것이 좋습니다. 또한 복잡한 템플릿의 경우, 수정하면 안 되는 요소에 잠금을 걸어 두면 다른 사람이 작업할 때 실수를 줄일 수 있습니다.

1. **잠금 설정하기**: 고정하고 싶은 요소(예: 배경 그래픽)를 선택하고 플로팅 툴 바에서 [잠금] 아이콘을 클릭합니다. 잠긴 요소는 선택은 되지만, 위치를 움직일 수 없습니다. 이렇게 해두면 작업하는 동안 실수로 배경 그래픽 요소가 선택될 일이 없어 편리합니다.

![포스터 요소를 잠가 위치가 고정된 상태를 보여주는 화면](./data/theory/canva/Week03/images/p157_05.png)

2. **잠금 해제하기**: 잠금을 해제하고 싶다면, 잠긴 요소를 선택한 후 [잠금 해제] 아이콘을 클릭합니다.

### 요소의 위치 정돈하기: 정렬과 간격

정렬과 간격은 여러 요소를 일정한 간격으로 배치하거나, 페이지의 특정 위치에 정확하게 놓을 때 사용합니다.

**자동 가이드 선**
요소를 선택하고 드래그해 이동하면 페이지에 자주색의 가이드 선이 나타나, 페이지의 가운데나 안전 영역에 쉽게 맞출 수 있습니다. 또한 비슷한 간격을 두고 배치된 다른 요소와의 간격을 수치로 보여 줍니다.

![요소를 이동할 때 중앙 정렬 가이드 선이 표시되는 캔바 화면](./data/theory/canva/Week03/images/p158_02.png)

**요소 정렬**
에디터 툴 바의 [위치]를 클릭하면 정렬 메뉴가 나타납니다. 여러 개의 요소를 선택한 후 [가운데], [왼쪽], [오른쪽] 등 원하는 정렬 옵션을 클릭하면 요소들이 기준점에 맞춰 자동으로 정렬됩니다.

![여러 요소를 선택한 뒤 위치 메뉴에서 정렬 옵션을 확인하는 화면](./data/theory/canva/Week03/images/p159_01.png)

**고르게 띄우기**
여러 요소를 선택한 후 정렬 메뉴에서 [수직으로] 또는 [수평으로]를 클릭하면, 요소들 사이의 간격이 일정하게 맞춰집니다.

![여러 요소 사이 간격을 고르게 맞추는 정렬 메뉴 화면](./data/theory/canva/Week03/images/p159_05.png)

### 요소를 한 덩어리로 다루기: 그룹화

그룹화는 여러 개의 요소를 마치 하나의 개체처럼 묶어 주는 기능입니다. 그룹을 지정하면 여러 요소를 한 번에 이동하거나 크기를 조절할 수 있어 작업 효율이 높아집니다.

1. **그룹화하기**: 그룹으로 묶고 싶은 여러 요소들을 선택한 후, 에디터 툴 바의 [그룹화]를 클릭합니다. (단축키: `Ctrl` + `G` / Mac은 `Cmd` + `G`)
2. **그룹 요소를 페이지에서 정렬하기**: 그룹화된 요소 덩어리를 선택하고 플로팅 툴 바의 [...] (더보기) - [페이지 맞춤]에서 원하는 옵션(예: 가운데)을 선택하면 작업 페이지를 기준으로 요소 그룹의 위치를 정돈할 수 있습니다.

마지막으로, 이번 레슨에서 설명한 디자인 정돈 과정을 정리해 볼게요.

1. 페이지에 요소를 배치한 후, 에디터 툴 바 - [위치] - [레이어] 탭으로 레이어 구조를 한눈에 파악한다.
2. 디자인 작업 중에는 각 요소를 하나씩 편집할 때 에디터 툴 바 또는 단축키로 앞으로 가져오기/뒤로 보내기하여 바로바로 레이어 순서를 정리해 둔다.
3. 배경이나 메인 그래픽 요소 등은 잠금 기능을 활용해 레이아웃 구조를 고정한다.
4. 여러 요소를 선택해 정렬과 간격 띄우기 기능으로 위치를 정리한다.
5. 항상 함께 움직이는 요소들은 그룹화로 하나의 블록처럼 묶어 효율적으로 움직인다.
6. 판매용 템플릿이라면 잠금 해제 및 그룹화 해제하여 디자인을 마무리한다.

이 루틴에 익숙해지면, 보기 좋은 디자인을 넘어 정리된 설계가 느껴지는 디자인을 만들 수 있게 됩니다.

![그룹화된 요소를 페이지 맞춤 메뉴로 정렬하는 캔바 화면](./data/theory/canva/Week03/images/p160_01.png)

## 페이지 관리하기: 페이지 추가 및 삭제, 이동

여러 페이지를 만드는 작업에서는 보기 방식과 페이지 이동이 핵심입니다. 스크롤 · 섬네일 · 그리드 뷰를 활용해 흐름을 한눈에 파악하고 체계적으로 정리해 멀티 페이지 작업의 기본기를 익힙니다.

하나의 디자인이 여러 페이지로 확장되면, 페이지를 빠르게 추가 · 복제하고 정리하는 능력이 매우 중요해집니다. 인스타그램 카드뉴스, 프레젠테이션, PDF 가이드처럼 ‘시리즈로 만드는 작업’은 대부분 페이지 기반으로 이루어지기 때문이에요.

이번 레슨에서는 캔바의 3가지 페이지 뷰(스크롤 · 섬네일 · 그리드)를 활용해 페이지를 추가하고, 복제하고, 정렬하는 방법을 익혀 디자인을 더 체계적으로 관리해 보겠습니다.

### 페이지 뷰 이해하기: 스크롤 뷰 / 섬네일 뷰 / 그리드 뷰

디자인을 만들다 보면 한두 페이지로 끝나지 않을 때가 많습니다. 이럴 때는 페이지를 어떻게 바라보고, 어떤 뷰로 전환해서 확인하느냐에 따라 작업 효율이 달라져요. 캔바의 페이지 뷰는 크게 스크롤 뷰 · 섬네일 뷰 · 그리드 뷰 3가지입니다. 각 뷰의 특징을 이해해 두면, 이후 페이지 관리 기능을 훨씬 자연스럽게 사용할 수 있습니다.

1. **스크롤 뷰 - 페이지를 흐름으로 보는 방식**: 한 화면에서 페이지를 위아래로 이어서 보며 작업할 수 있어요. 자연스러운 흐름을 보며 이야기 구조를 잡을 때 적합합니다.

![스크롤 뷰에서 페이지를 세로 흐름으로 보는 캔바 작업 화면](./data/theory/canva/Week03/images/p161_11.png)

2. **섬네일 뷰 - 페이지를 목차처럼 보는 방식**: 작업 영역 하단에 페이지 섬네일이 작게 나열되며, 페이지 간 분위기 · 순서를 한눈에 비교하기 좋습니다. 여러 페이지를 번갈아 보며 수정할 때 많이 사용합니다.

![여러 페이지를 타일 형태로 펼쳐 보는 그리드 뷰 화면](./data/theory/canva/Week03/images/p162_01.png)

3. **그리드 뷰 - 페이지를 지도처럼 조망하는 방식**: 전체 페이지를 타일 형태로 펼쳐서 보여 줘서 전체 구조를 쉽게 파악할 수 있어요. 여러 페이지의 시리즈 디자인을 전반적으로 살펴보며 조율하거나 전체적인 톤을 비교할 때 가장 효율적인 방법입니다.

![여러 페이지를 타일 형태로 펼쳐 보는 그리드 뷰 화면](./data/theory/canva/Week03/images/p162_02.png)

### 페이지 관리 기능 개요

페이지를 효율적으로 관리하려면 기능의 개념부터 먼저 정리하는 것이 좋아요. 아래 네 가지 기능은 어떤 뷰에서든 동일하게 제공되는 기본 조작 원리입니다.

- **페이지 추가(Add)**: 새로운 빈 페이지 만들기
- **페이지 복제(Duplicate)**: 같은 레이아웃을 유지한 채 빠르게 복사하기
- **페이지 삭제(Delete)**: 필요 없는 페이지 정리하기
- **페이지 순서 변경(Reorder)**: 드래그로 원하는 위치로 이동하기

### 페이지 뷰에서 페이지 관리하기

**스크롤 뷰에서 페이지 관리하기**
대부분의 디자인 작업이 이루어지는 기본 화면입니다. 스크롤로 페이지를 세로로 넘기며 작업하는 방식입니다.

![스크롤 뷰에서 페이지 추가와 복제 등 관리 메뉴를 여는 화면](./data/theory/canva/Week03/images/p163_01.png)

1. **페이지 추가하기**: 페이지 상단의 [페이지 추가] 아이콘 또는 페이지 하단의 [페이지 추가] 버튼을 클릭하여 같은 형식으로 새 페이지를 추가할 수 있습니다. 하단 [페이지 추가] 버튼 옆의 [페이지 유형 추가] 버튼을 클릭해 다양한 형식 목록 중에 원하는 옵션을 골라 추가해 멀티 디자인으로 작업할 수 있습니다.

![스크롤 뷰에서 페이지 추가와 복제 등 관리 메뉴를 여는 화면](./data/theory/canva/Week03/images/p163_02.png)

2. **페이지 복제하기**: 페이지 상단의 [복제] 아이콘을 클릭하면 현재 페이지와 똑같은 페이지가 복제되어 추가됩니다.



3. **페이지 삭제 및 순서 바꾸기**: 페이지 삭제와 순서 바꾸기는 페이지 수가 2장 이상일 때부터 가능합니다. 페이지 상단의 위/아래로 [이동] 아이콘을 클릭해 현재 페이지의 순서를 이동하거나, [삭제] 아이콘을 클릭해 페이지를 삭제할 수 있습니다.

![페이지 상단 아이콘으로 페이지 삭제와 순서 이동을 하는 화면](./data/theory/canva/Week03/images/p164_01.png)

**섬네일 뷰에서 페이지 관리하기**
작은 섬네일 형태로 페이지를 모아 볼 수 있는 방식입니다. 페이지가 많을 때 섬네일을 가로로 스크롤해 전체적인 디자인 흐름을 파악하기 좋습니다.

1. **페이지 추가하기**: 하단의 페이지 섬네일에 마우스 포인터를 올리면 나타나는 [...] (더보기)를 클릭하면 페이지 추가, 복제, 삭제를 바로 실행할 수 있습니다. 또한 섬네일 바로 옆에 있는 [+] (페이지 추가) 버튼을 클릭해 새 페이지를 추가할 수 있습니다.
2. **페이지 복제/삭제하기**: 섬네일 - [...] (더보기)에서 페이지 복제 및 삭제가 가능하지만 단축키로 더 간단하고 빠르게 할 수 있습니다. 페이지 섬네일을 클릭해 선택한 후, 단축키 `Ctrl` + `D` (Mac은 `Cmd` + `D`) 키를 눌러 페이지를 복제하고 `Delete` / `Backspace` 키를 눌러 페이지를 삭제할 수 있습니다.

![섬네일 뷰에서 더보기 메뉴로 페이지 복제와 삭제를 실행하는 화면](./data/theory/canva/Week03/images/p164_03.png)

3. **여러 페이지일 때 페이지 추가하기**: 페이지가 2장 이상일 때에는, 페이지 섬네일 사이에 마우스 포인터를 올리면 나타나는 [+] (페이지 추가) 버튼을 클릭하면 새 페이지가 추가됩니다.

![그리드 뷰에서 페이지 썸네일의 메뉴로 추가·복제·삭제를 관리하는 화면](./data/theory/canva/Week03/images/p165_01.png)

4. **페이지 순서 바꾸기**: 페이지 삭제와 순서 바꾸기는 페이지 수가 2장 이상일 때부터 가능합니다. 섬네일을 클릭하고 드래그하여 원하는 위치로 옮기면 페이지 순서가 바뀝니다.

**그리드 뷰에서 페이지 관리하기**
모든 페이지를 한눈에 볼 수 있는 화면입니다. 페이지 수가 많은 디자인 작업을 할 때, 페이지의 전체적인 흐름을 파악하고 관리하는 데 가장 유용합니다.

1. **페이지 추가/복제/삭제**: 섬네일을 선택하고 마우스 우클릭 또는 섬네일의 [더보기] 클릭 또는 화면 상단 플로팅 툴 바의 [...] (더보기)를 클릭하거나 [+] (페이지 추가) 버튼을 클릭해 페이지 추가, 복제, 삭제가 가능합니다. 단축키 `Ctrl` + `D` (Mac: `Cmd` + `D`) 및 `Delete` 키를 활용할 수도 있습니다.

![그리드 뷰에서 페이지 썸네일의 메뉴로 추가·복제·삭제를 관리하는 화면](./data/theory/canva/Week03/images/p165_03.png)

2. **페이지 유형 추가**: [+] (페이지 추가) 버튼 바로 옆에 있는 [페이지 유형 추가] 버튼을 클릭해 원하는 형식의 페이지를 추가할 수 있습니다.

![여러 페이지 사이에 표시된 더하기 버튼으로 새 페이지를 추가하는 화면](./data/theory/canva/Week03/images/p166_01.png)

3. **여러 페이지일 때 페이지 추가하기**: 섬네일 사이에 마우스 포인터를 올리면 나타나는 [+] 버튼을 클릭하면 새 페이지가 추가됩니다.

![여러 페이지 사이에 표시된 더하기 버튼으로 새 페이지를 추가하는 화면](./data/theory/canva/Week03/images/p166_02.png)

4. **페이지 순서 바꾸기**: 원하는 페이지를 클릭하고 드래그하여 순서를 쉽게 바꿀 수 있습니다. 여러 페이지를 동시에 선택한 후 드래그해서 순서를 바꿀 수도 있습니다.

![사각형 드래그로 여러 페이지를 한 번에 선택하는 그리드 뷰 화면](./data/theory/canva/Week03/images/p166_03.png)

5. **여러 페이지 선택하기**: 섬네일 바깥 부분을 클릭한 뒤 화면에 사각형을 그리듯 드래그하거나, `Shift` 키를 누른 채로 마우스로 여러 페이지를 선택해 한번에 이동시키거나 복제할 수 있습니다.

![사각형 드래그로 여러 페이지를 한 번에 선택하는 그리드 뷰 화면](./data/theory/canva/Week03/images/p166_04.png)

**이번 레슨에서 배운 페이지 관리 루틴을 짧게 정리해 볼게요.**

1. 첫 페이지에서 레이아웃 · 색 · 폰트 · 레이어를 정리해 기본 디자인 포맷을 만든다.
2. 이 페이지를 복제해 2, 3, 4페이지를 만들고, 텍스트와 이미지만 교체한다.
3. 내용을 검토하며 필요 없는 페이지는 삭제, 빠진 내용은 새 페이지 추가로 보완한다.
4. 하단 섬네일 또는 그리드 뷰에서 페이지를 드래그해, 도입—전개—결론 흐름이 자연스럽게 이어지도록 순서를 정리한다.
5. 디자인을 완성한 뒤에는 그리드 뷰로 전체를 다시 확인하며, 각 페이지의 색 · 레이아웃 · 여백이 일관되게 보이는지를 확인한다.

페이지를 관리하는 일은 단순히 장수를 늘리고 줄이는 것이 아니라, 한 페이지 안에서 디자인을 완성하고, 여러 페이지를 이어서 배치하고, 필요하면 순서를 바꿔 전체 스토리를 재구성하는 과정입니다. 이 루틴을 통해, 한 장짜리 디자인에 머무르지 않고, 여러 장이 연결된 스토리형 콘텐츠를 안정적으로 만들 수 있게 됩니다.

## 디자인 저장과 공유하기: 다운로드 및 공유 옵션

완성된 디자인은 용도에 맞게 저장하고, 적절한 방식으로 공유해야 합니다. 파일 형식 선택부터 색상 모드 설정, 템플릿 링크 공유까지 실전 작업과 협업에서 필요한 기초 노하우를 익힙니다.

작업 페이지 안에서 디자인을 만드는 과정을 다뤘다면, 디자인 작업의 마지막 단계인 저장과 공유를 다룰 차례입니다. 캔바에서는 자동 저장 덕분에 작업 내용을 잃어버릴 걱정이 없습니다. 또한 완성한 디자인을 다운로드, 링크 공유, 템플릿화, SNS 직접 게시 등 다양한 방식으로 활용할 수 있습니다.

### 저장과 다운로드하기

**자동 저장 이해하기**
캔바는 클라우드 기반이라 작업이 실시간으로 자동 저장됩니다. 별도로 [저장] 버튼을 누를 필요가 없고, 인터넷이 불안정해도 접속이 다시 연결되면 변경 내역이 그대로 복구됩니다. 상단 메뉴에 체크 표시된 구름 아이콘이 보이면 자동 저장이 완료된 상태입니다.

![자동 저장 상태를 보여주는 구름 아이콘이 있는 캔바 편집 화면](./data/theory/canva/Week03/images/p168_13.png)

**디자인을 파일로 다운로드하기**
캔바는 디자인 용도에 맞춰 다양한 파일 형식으로 다운로드할 수 있습니다. 각 파일 형식의 특징을 이해하고 상황에 맞게 사용해 보세요.

1. **[다운로드] 창 열기**: 디자인 에디터 상단 메뉴 - [공유] - [다운로드] 버튼을 선택하면 [다운로드] 창이 열립니다.

![다운로드 창에서 JPG·PNG·PDF 등 파일 형식을 고르는 드롭다운 메뉴](./data/theory/canva/Week03/images/p169_01.png)

2. **다운로드 파일 형식 선택하기**: [다운로드] 창에서는 파일 형식, 품질, 페이지 선택 등의 다운로드 옵션을 선택할 수 있습니다. [파일 형식] 드롭다운 메뉴를 클릭하면 다양한 파일 형식 목록이 열립니다.

<!-- p.169 -->

![다운로드 창에서 JPG·PNG·PDF 등 파일 형식을 고르는 드롭다운 메뉴](./data/theory/canva/Week03/images/p169_02.png)

**전체 페이지 다운로드 vs 일부 페이지 다운로드**
캐러셀(카드뉴스) · 프레젠테이션처럼 여러 페이지의 디자인을 만들었을 때는 모든 페이지를 다운로드할지, 선택한 페이지만 다운로드할지 선택할 수 있습니다. 특히 여러 디자인 형식을 한 파일에서 작업한 멀티 디자인의 경우는, 필요한 페이지만 골라서 다운로드하는 게 효율적입니다.

<!-- p.170 -->



1. **파일 형식 선택하기**: 파일 형식 드롭다운 메뉴에서 다운로드할 파일 형식(예: PNG)을 선택하면 해당 파일 형식에서 선택할 수 있는 다운로드 세부 옵션이 표시됩니다.

![다운로드 창에서 파일 형식과 옵션을 설정하는 캔바 화면](./data/theory/canva/Week03/images/p170_01.png)

2. **페이지 선택하기**: [페이지 선택]의 드롭다운 메뉴를 엽니다. 모든 페이지는 만든 모든 페이지를 다운로드하는 옵션이고, [모든 페이지]의 체크박스를 해제한 후, [현재 페이지] 또는 원하는 페이지 번호만 체크하면 선택한 페이지만 다운로드하는 옵션입니다.

![다운로드 버튼을 눌러 파일 저장을 진행하는 캔바 화면](./data/theory/canva/Week03/images/p170_04.png)

3. **다운로드하기**: 모든 설정을 마치고 [다운로드] 버튼을 클릭하면 다운로드가 시작되고, 하단 메뉴에 다운로드 과정이 표시됩니다. 저장할 위치를 선택하고 [저장] 버튼을 클릭합니다.

![다운로드된 디자인 파일이 저장된 폴더를 보여주는 화면](./data/theory/canva/Week03/images/p171_01.png)
![선택한 요소만 골라 파일 형식과 옵션을 지정해 다운로드하는 화면](./data/theory/canva/Week03/images/p171_02.png)

> **선택 항목 다운로드**
> 디자인의 특정 요소만 선택해서 다운로드할 수 있어요. 이 방법으로 필요한 부분만 간편하게 저장할 수 있습니다.
>
> 1. 페이지에서 다운로드하고 싶은 요소들을 드래그하거나, `Shift` 키를 누른 채로 클릭해서 여러 개를 선택합니다. 선택한 항목 위에서 마우스 우클릭 - [선택 항목 다운로드]를 선택합니다.
> 2. [선택 항목 다운로드] 창에서 원하는 파일 형식을 고르고, 원하는 다운로드 옵션들을 선택합니다.

![선택한 요소만 골라 파일 형식과 옵션을 지정해 다운로드하는 화면](./data/theory/canva/Week03/images/p172_01.png)

디자인을 완성한 뒤에는 목적에 따라 적절한 파일 형식을 선택하는 것이 중요합니다.

- 블리드/재단 여백 옵션 확인하기
- 고해상도의 사진을 사용했는지 확인하기
- 브랜드 컬러는 HEX 값 기준으로 정확히 입력하기

### 공유 링크로 협업 및 수익화하기

캔바에서는 다양한 공유와 게시 기능을 지원하며 목적에 따라 선택하면 됩니다. 그중에서도 대표적인 공유 방법인 공개 보기 링크, 협업 링크, 템플릿 링크를 살펴보겠습니다.

**캔바의 공유 링크 3종 비교**
| 링크유형 | 주요목적 |
| :--- | :--- |
| **공개 보기 링크** | 상대가 디자인을 ‘보기’만 가능한 단순 열람 · 검토용 (포트폴리오, 시안 검토) |
| **협업 링크** | 상대에게 가능한 편집 권한을 지정해서 공유 가능 (공동작업, 피드백) |
| **템플릿 링크** | 상대가 디자인을 사본으로 열어 편집 가능 (템플릿 배포·판매) |

**캔바 공유 링크의 3가지 강점**

- **협업의 효율성**: 실시간으로 여러 명이 한 디자인을 함께 편집하며 피드백을 주고받을 수 있어 작업 시간을 획기적으로 단축합니다.
- **수익화의 도구**: 내가 만든 디자인을 다른 사람들이 쉽게 활용할 수 있도록 공유하여, 템플릿 판매 등 새로운 수익 파이프라인을 구축할 수 있습니다.
- **안전한 디자인 보호**: 원본은 안전하게 보호하면서 사본을 제공하는 방식으로, 내 창작물을 안전하게 지키며 공유할 수 있습니다.

**공개 보기 링크 만들기**
누구나 디자인을 볼 수 있는 링크로, 주로 완성된 결과물을 화면용으로 공유할 때 사용합니다. 링크를 받은 사람은 디자인을 볼 수만 있고, 수정 작업을 하거나 댓글을 남길 수 없습니다.

**협업 링크 만들기**
여러 명이 동시에 디자인을 편집하거나, 댓글을 남기며 협업할 수 있는 공동 작업 링크입니다. 링크에 접근하는 사용자의 권한(편집 가능/댓글 가능/보기 가능)을 설정해 팀원 또는 외부인과 실시간으로 작업하거나 피드백을 주고받을 수 있습니다.

1. 상단 메뉴에서 [공유] - [액세스 수준]을 클릭해 드롭다운 메뉴를 엽니다.
2. 드롭다운 메뉴에서 [링크가 있는 모든 사용자] 옵션을 선택합니다.
3. 드롭다운 메뉴에서 액세스 사용자의 편집 권한(편집 가능/댓글 가능/보기 가능) 옵션을 선택합니다.
4. 설정을 완료하고 [링크 복사] 버튼을 클릭한 후, 복사된 링크를 협업자에게 공유하면 됩니다.

![협업 링크의 액세스 권한을 편집 가능으로 설정하는 공유 화면](./data/theory/canva/Week03/images/p176_02.png)

> **협업 링크를 공유하기 전에 액세스 수준 설정을 꼭 체크하세요.**
>
> 1. 액세스 수준이 ‘본인만 액세스 가능’으로 되어 있진 않은가요? 비공개 상태로 만들어지므로 주의하세요.
> 2. 받은 사람에게 맞는 편집 권한으로 설정되어 있나요? 편집 가능, 댓글 가능, 보기 가능 권한을 한 번 더 확인합니다.

**템플릿 링크 만들기**
현재 디자인을 템플릿화하여 공유할 수 있는 링크입니다. 공유를 받은 사람이 링크를 클릭하면 자동으로 복사본으로 디자인이 열려 자유롭게 편집할 수 있습니다. 원본은 수정되지 않고 유지되는 방식이기에 팀원이나 외부인이 디자인을 참고하거나, 여러 명이 각자 복사해서 사용할 때 유용합니다. 디자인 템플릿을 판매할 때에도 이 방식을 활용하면 됩니다.

1. 상단 메뉴에서 [공유] - [...] (모두 보기)를 클릭합니다.
2. 목록에서 [템플릿 링크]를 클릭합니다.
3. 다음 단계에서 [템플릿 링크 만들기] 버튼을 클릭합니다.
4. 생성된 템플릿 링크를 복사해 공유하면 됩니다.

![공유 메뉴의 모두 보기에서 템플릿 링크를 선택하는 화면](./data/theory/canva/Week03/images/p178_01.png)

![공유 메뉴의 모두 보기에서 템플릿 링크를 선택하는 화면](./data/theory/canva/Week03/images/p178_02.png)

# CHAPTER 03 캔바 AI로 디자인 창작의 흐름 잡기

**AI로 아이디어를 시각화하는 가장 빠른 방법**
클릭 몇 번으로 내 아이디어를 멋지게 시각화해 주는 놀라운 AI 디자인 세계를 경험해 봅시다.

![챕터 03 캔바 AI로 디자인 창작의 흐름 잡기 표지 페이지](./data/theory/canva/Week03/images/p185_01.png)

캔바는 단순히 작업을 빠르게 해주는 편집 도구를 넘어, 아이디어를 떠올리고 시각으로 옮기는 과정을 돕는 AI 환경으로 진화하고 있어요. 이전 챕터에서 캔바의 기본 환경과 디자인 기초를 익혔다면, 이제는 캔바를 스마트한 창작 비서로 활용할 차례입니다.

캔바의 AI는 단순히 디자인을 대신 만들어 주는 도구가 아니라, 나의 디자인 작업에 함께하는 조력자에 가까워요. 복잡한 프롬프트를 몰라도, 짧은 문장과 몇 번의 클릭만으로 머릿속에 있던 생각을 디자인, 텍스트, 이미지, 영상으로 빠르게 구현할 수 있습니다. 이번 챕터에서는 캔바의 크리에이티브 OS 안에서 AI가 어디에, 어떤 흐름으로 배치되어 있는지를 살펴봅니다.

## AI가 녹아든 올인원 작업 환경, Visual Suite 이해하기

캔바 AI가 어떤 환경에서 작동하는지를 이해하면 아이디어를 더 자유롭게 실험할 수 있습니다. 이 레슨에서는 비주얼 스위트의 구조를 중심으로 창작의 출발점을 정리합니다.

### Visual Suite 한눈에 보기

비주얼 스위트는 하나의 프로젝트 안에서 문서, 프레젠테이션, 소셜 콘텐츠, 영상, 웹사이트 등 다양한 디자인 형식을 함께 다룰 수 있는 멀티 디자인 작업 환경이에요. 단순히 여러 디자인을 한 곳에 모아 둔 것뿐만 아니라, 하나의 이야기나 주제를 다양한 형식으로 자연스럽게 확장할 수 있도록 설계된 구조입니다.

![하나의 프로젝트 안에서 여러 디자인 형식을 함께 다루는 Visual Suite 편집 화면](./data/theory/canva/Week03/images/p188_11.png)

### 편집 가능한 시안을 생성해 주는 AI 디자인 엔진

캔바의 AI는 단순히 이미지를 생성하는 데서 멈추지 않고 AI 디자인 엔진(Canva Design Model)으로 진화했습니다. 사용자가 입력한 프롬프트에 맞춰 AI가 편집 가능한 디자인 시안(인스타그램 게시물, 프레젠테이션, 포스터 등)을 제안해 주면, 사용자는 그중에 원하는 디자인을 선택해 바로 에디터에서 편집 작업을 시작할 수 있습니다.

![프롬프트를 바탕으로 편집 가능한 디자인 시안을 추천하는 AI 화면](./data/theory/canva/Week03/images/p189_02.png)

여기서 꼭 기억해야 할 점은 AI는 디자인을 대신해 주는 것이 아니라 디자인을 시작할 수 있는 초안을 생성해 주고, 선택과 판단은 사람이 해야 한다는 것입니다.

### 흐름 속에서 바로 사용할 수 있는 AI 도구

AI 디자인 엔진의 가장 큰 특징은, 별도의 창으로 이동하지 않고 작업 중인 페이지에서 편집 패널이나 빠른 작업 등을 통해 바로 AI 기능을 사용할 수 있도록 설계되어 있다는 것입니다.

예를 들어, 작업 페이지에서 텍스트를 선택하면 [Magic Write], 이미지를 선택하면 [Magic Edit], [Magic Expand], [Magic Grab] 등 다양한 AI 도구를 바로 사용할 수 있어요. 작업 페이지에서 키보드의 슬래시(`/`) 키를 눌러 빠른 작업 창을 열어 더 빠르게 원하는 기능을 사용할 수 있습니다. 또한, 작업 중에 플로팅 툴 바의 [Canva AI에게 물어보기]를 통해 실시간으로 AI의 도움을 받을 수 있습니다.

## Visual Suite 둘러보기: 디자인 형식별 AI 활용 흐름

아이디어는 어떤 형식으로 옮기느냐에 따라 전혀 다르게 보입니다. 이번 레슨에서는 비주얼 스위트 안에서 디자인 형식별 AI 활용 흐름을 살펴봅니다.

### 문서·화이트보드·프레젠테이션

- **문서(Docs)**: 텍스트, 이미지, 표, 차트 등 다양한 요소를 자유롭게 배치할 수 있습니다. Magic Write를 사용해 주제나 아이디어를 입력하여 초안을 빠르게 만들 수 있습니다.
- **화이트보드**: 무한한 공간에서 아이디어를 자유롭게 펼치고 시각적으로 정리할 수 있습니다. AI의 요약 만들기 기능을 활용해 아이디어를 구조화하고 한눈에 파악할 수 있습니다.
- **프레젠테이션**: AI를 활용해 기본 구조를 빠르게 만들고 디자인 추천을 받아 시작점을 손쉽게 확보한 뒤, 필요한 부분만 수정하면 시선을 사로잡는 발표 자료를 쉽고 빠르게 만들 수 있습니다.

## 스마트한 AI 생성·편집 도구, Magic Studio 이해하기

Magic Studio는 캔바의 다양한 AI 기능을 한 번에 만날 수 있는 도구 모음입니다. 홈 화면의 검색 및 AI 바에서 Canva AI를 선택해 Magic Studio에 접근할 수 있으며, 에디터 화면에서는 각 편집 메뉴에 적절하게 배치되어 있습니다.

### Magic Studio의 주요 기능과 역할

- **Magic Write**: 글 요약, 문장 생성, 톤 변경, 브랜드 보이스 적용 등 AI가 텍스트 작업을 돕습니다.
- **Magic Design**: 아이디어나 이미지를 입력하면 AI가 디자인을 생성하거나 맞춤형 템플릿을 추천합니다.
- **Magic Media**: 텍스트 설명만으로 이미지, 그래픽, 짧은 영상을 생성해 줍니다.
- **다양한 AI 편집 도구**: 배경 제거, Magic Grab, Magic Expand, Magic Edit, Magic Morph 등 AI 기반 편집 기능이 포함되어 있습니다.
  <!-- p.195 -->
  ![Magic Studio를 상징적으로 보여주는 AI 생성·편집 도구 대표 이미지](./data/theory/canva/Week03/images/p195_12.png)

### Magic Studio의 장점

- **효율성 극대화**: 크기 조정 기능이나 Magic Switch(디자인 포맷 변환) 등을 활용해 작업 시간을 획기적으로 단축합니다.
- **창의성 확장**: 세상에 없던 독특한 이미지나 동영상을 텍스트 프롬프트로 생성해 줍니다.
- **간편한 편집**: 클릭 몇 번으로 배경을 지우거나 특정 부분을 교체할 수 있습니다.
- **전문성 강화**: 디자인 초보자도 전문가 수준의 결과물을 만들 수 있도록 도와줍니다.

### 프롬프트로 스마트하게 생성하기

캔바의 AI 기능은 사용자가 입력하는 짧은 설명인 프롬프트를 기반으로 작동합니다.

1. **효과적인 구조로 작성하기**: ‘주제 + 스타일 + 세부사항’ 조합으로 작성합니다. (예: 따뜻한 햇살 아래 웃고 있는 턱시도 고양이, 만화 스타일)
2. **구체적 표현 활용하기**: 추상적인 표현보다 구체적인 표현을 쓸 때 AI가 더 정확하게 생성합니다.
3. **스타일과 분위기 포함하기**: '미니멀한', '빈티지' 등 분위기를 추가하면 의도에 맞는 결과물을 얻을 수 있습니다.
4. **영어 프롬프트 활용하기**: 원하는 결과물이 나오지 않는다면 영어로 시도해 보는 것도 좋은 방법입니다.

> **AI 생성 콘텐츠의 저작권**
> AI 생성물의 소유권은 사용자에게 있으며 캔바 이용 약관 내에서 상업적 활용이 허용됩니다. 다만 타인의 권리를 침해하지 않도록 기존 요소에 창의성을 더해 디자인하고 특정 브랜드나 유명 인물을 묘사하는 프롬프트는 피하는 것이 안전합니다.

![AI 생성 결과물을 안전하게 활용하기 위한 가이드라인과 정책 안내 QR 코드](./data/theory/canva/Week03/images/p198_01.png)

### 홈 화면에서 바로 시작하는 Canva AI

홈 화면의 Canva AI는 자연어 프롬프트를 입력하면 맞춤 템플릿, 이미지, 문서, 코드, 영상을 생성해 주는 대화형 AI 허브입니다.

홈 화면에서 Canva AI를 사용하는 방법은 다음과 같습니다.

1. **Canva AI 열기**: 홈 화면의 검색 및 AI 바 상단 또는 탐색 패널에서 [Canva AI]를 선택합니다.
2. **프롬프트 입력하기**: 입력 창에 원하는 프롬프트를 입력합니다.
3. **작업 종류 선택하기**: 하단에서 [디자인] 생성, [이미지] 생성, [Docs(문서 초안)] 작성, [코드] 생성, [동영상 클립] 중 원하는 작업을 선택합니다.
4. **세부 옵션 정하기**: 디자인 형식에 맞는 세부 옵션을 선택합니다. 필요하다면 [+] (참조용 파일 삽입) 버튼을 눌러 파일이나 브랜드 키트를 추가할 수 있습니다.
5. **생성 결과 적용하기**: [제출하기]를 클릭해 결과물을 생성한 뒤, 마음에 드는 초안을 선택해 바로 디자인에 적용하거나 추가 편집합니다. 탐색 패널의 Canva AI 메뉴에서는 생성 내역도 확인할 수 있습니다.

![Canva AI에서 파일과 브랜드 키트를 함께 불러와 생성 준비를 하는 화면](./data/theory/canva/Week03/images/p200_02.png)

**디자인 생성**
검색 및 AI 바 입력 창에 프롬프트(예: 네온 그린과 연한 베이지, 모던한 여름 패션 프로모션)를 입력하고 하단에서 [디자인]을 선택하면 대표적인 디자인 형식 옵션이 나타납니다. 필요한 옵션(예: SNS-인스타그램)을 고른 뒤 [제출하기]를 누르면 디자인 초안이 생성됩니다.

![Canva AI에서 프롬프트를 입력하고 디자인 옵션을 선택하는 화면](./data/theory/canva/Week03/images/p200_04.png)

- **이미지 생성**: 텍스트로 원하는 이미지를 설명하고 스타일과 비율(예: 미니멀리스트, 16:9)을 선택하면 AI가 새로운 이미지를 만들어 줍니다.

### 에디터에서 Magic Studio 기능 사용하기

대부분의 Magic Studio 기능은 비슷한 순서로 사용합니다.

1. **도구 실행**: 에디터 사이드 패널에서 [앱]을 검색해 선택하거나, 편집할 요소를 선택한 후 에디터 툴 바의 [편집] 메뉴를 클릭합니다.
2. **내용 입력 또는 영역 선택**: 기능에 따라 프롬프트를 입력하거나 브러시, 클릭으로 편집할 영역을 지정합니다.
3. **결과 적용**: AI가 생성한 여러 결과물 중에서 마음에 드는 것을 골라 디자인에 적용합니다.

**아이디어를 멋진 텍스트로, Magic Write**
에디터 화면에서 사용할 수 있는 문장 도우미입니다. 카드뉴스 텍스트를 구성하거나 보고서 초안을 작성할 때 유용합니다. Magic Write 입력 창에 원하는 내용(예: 신규 오픈하는 베이커리 카페를 위한 인스타그램 게시물 아이디어 10개 작성해 줘)을 입력하고 [생성하기]를 누르면 초안이 만들어집니다. 생성된 텍스트는 디자인에 맞게 수정하고 폰트나 색상을 자유롭게 바꿔 편집할 수 있습니다.

![Magic Write로 베이커리 카페 홍보 문구 초안을 생성하는 화면](./data/theory/canva/Week03/images/p205_01.png)

**하나의 콘텐츠를 다양한 포맷으로 변신, Magic Switch**
완성된 콘텐츠를 다른 포맷(프레젠테이션 ➔ 블로그 글)이나 언어로 변환할 수 있는 기능입니다. 상단 메뉴의 [Magic Switch]를 클릭한 뒤 원하는 포맷(예: 창의적인 블로그 게시물)을 선택하거나 직접 입력하고 [Docs으로 변환]을 클릭하면 새 문서가 생성됩니다. 또한 [언어 변환]에서 번역할 언어를 선택하면 디자인 안의 텍스트를 자동으로 번역할 수 있어 다국어 콘텐츠 제작에도 도움이 됩니다.

![Magic Switch에서 문서를 다른 포맷의 Docs로 변환하는 화면](./data/theory/canva/Week03/images/p205_02.png)

**디자인을 다양한 사이즈로 확장하는, 크기 조정(Magic Resize)**
작업 중인 디자인의 형식과 사이즈를 즉시 변경하는 기능입니다. 상단 메뉴에서 [크기 조정]을 클릭한 뒤 디자인 카테고리 리스트에서 원하는 포맷을 선택합니다. 페이지가 여러 장일 때는 하단의 [모든 페이지]에서 크기 조정할 페이지를 골라 적용할 수 있습니다. 마지막으로 [복사 및 크기 조정] 또는 [이 디자인의 크기 조정] 중 하나를 선택해 실행합니다.

![크기 조정 메뉴에서 다양한 디자인 카테고리와 페이지 범위를 선택하는 화면](./data/theory/canva/Week03/images/p206_01.png)

**상상 속의 아이디어를 이미지와 영상으로, Magic Media**

2. **요소 메뉴에서 이미지 생성하기**: 에디터의 [요소] 메뉴에서 프롬프트를 입력하고 [이미지 생성] 버튼을 누르면 이미지를 생성할 수 있습니다.

## 내 작업에 맞는 AI 활용 전략 세우기

지금까지 배운 캔바 AI 도구들을 내 작업 유형에 맞게 묶어, 쉽게 따라 할 수 있는 활용 흐름으로 정리해 봅니다.

### AI를 활용한 디자인 작업의 공통 흐름 체크하기

1. **1단계: 아이디어 정리 및 초안 생성** - Docs나 Magic Write로 텍스트 초안을 빠르게 뽑아냅니다.
2. **2단계: 선택** - Canva AI 디자인 생성 기능으로 여러 시안을 만든 뒤, 마음에 드는 것을 고릅니다.
3. **3단계: 편집** - Magic Edit, 배경 제거 등으로 이미지와 레이아웃을 다듬습니다.
4. **4단계: 확장** - Magic Switch와 크기 조정으로 다양한 형식, 언어, 채널용으로 변환합니다.

### 소셜 콘텐츠 중심 작업 흐름으로 응용하기

- **1단계**: Magic Write로 '이번 달 인스타그램 게시물 아이디어 10개'를 뽑아냅니다.
- **2단계**: 홈 화면 디자인 생성에서 캠페인 컨셉을 입력해 피드 시안을 받습니다.
- **3단계**: Magic Edit, Magic Media로 상세 비주얼과 텍스트를 톤에 맞게 조정합니다.
- **4단계**: 크기 조정 기능으로 릴스, 스토리 등으로 확장합니다.

### 강의·설명 자료 중심 작업 흐름으로 응용하기

- **1단계**: Docs에서 Magic Write로 강의 개요와 목차를 만듭니다.
- **2단계**: 화이트보드에서 아이디어를 브레인스토밍하고 요약 기능을 사용합니다.
- **3단계**: Magic Switch를 사용해 문서를 프레젠테이션 개요 형식으로 자동 생성합니다.
- **4단계**: Magic Media와 Magic Animate, Chart를 활용해 시각 자료의 완성도를 높입니다.

### 1인 사업자 브랜딩 중심 작업 흐름으로 응용하기

- **1단계**: Docs로 브랜드 스토리와 캠페인 슬로건을 정리합니다.
- **2단계**: 디자인 생성으로 핵심 메인 비주얼을 여러 개 받아봅니다.
- **3단계**: Magic Switch를 활용해 랜딩 페이지나 블로그용 글로 변환합니다.
- **4단계**: 웹사이트 형식 페이지나 인쇄물(명함, 스티커) 형식으로 확장하고 목업 기능을 활용해 전체 느낌을 점검합니다.

### AI 활용 체크 포인트

- **큰 흐름 놓치지 않기**: 다양한 AI 기능 사용에만 치중해 전체 디자인 컨셉이 흐트러지지 않게 유의하세요.
- **AI는 초안 담당, 결정은 나**: AI가 만든 결과물은 ‘초안’이며 최종 판단과 수정은 사람이 해야 합니다.
- **브랜드 톤과 스타일은 사람이 맞추기**: 텍스트 어투와 생성 이미지 색감을 브랜드 키트에 맞게 보정하세요.
- **기능과 사용 한도 확인하기**: 일부 고급 기능은 유료 플랜 전용이거나 월별 한도가 존재합니다.
- **저작권·정책 가이드라인 준수하기**: AI 결과물에 나만의 콘텐츠를 섞어 독창적으로 재구성하는 편이 안전합니다.

# CHAPTER 04 캔바 디자인 실전

**감각과 원리를 연결하여 팔리는 디자인을 만드는 노하우**
단순히 예쁜 결과물을 넘어, 고객의 문제 해결을 돕는 디자인 기획력을 기릅니다. 6가지 업종별 페르소나 실습을 통해 템플릿 제작부터 외주 업무까지 가능한 프로의 한 끗 차이를 경험해 보세요.

![CHAPTER 04 캔바 디자인 실전 표지 페이지](./data/theory/canva/Week03/images/p225_01.png)

수익화를 꿈꾸는 예비 디자이너로서 이제는 기능을 활용하는 수준을 넘어, ‘팔리는 디자인’의 한 끗 차이를 경험할 차례입니다. 앞선 챕터에서 기초를 다졌다면, 이번 챕터에서는 초보의 티를 벗고 프로의 완성도를 만드는 지점에 집중합니다.

실제로 선택받는 디자인은 단순히 예쁘기만 해서는 안 됩니다. 누구에게 무엇을 말하고, 어떤 행동을 이끌어 낼지 처음부터 치밀하게 기획해야 하며, 자신의 디자인 의도를 논리적으로 설명할 수 있어야 합니다. 디자인 실력을 가장 빠르게 키우는 방법은 실제 클라이언트의 문제를 해결해 보는 것입니다.

그래서 이번 챕터에서는 템플릿 디자인을 필요로 하는 6가지 가상의 고객 페르소나를 설정했습니다. 베이커리 카페부터 기업까지, 업종별 비즈니스를 운영하는 데 필요한 ‘올인원 디자인 키트’를 함께 실습합니다. 이 과정은 템플릿 상품을 판매하거나, 외주 디자인 서비스로 연결할 수 있는 탄탄한 포트폴리오를 구축하는 데 실질적인 동력이 되어 줄 거예요.

**배울 내용**

- **LESSON 01 디자인 실전에서 놓치지 말아야 할 원칙들**: 기획부터 실행까지, 프로 디자이너의 사고방식과 작업 원칙을 배웁니다.
- **LESSON 02 베이커리 카페를 위한 디자인**: 이미지와 폰트의 조화를 통해 단순한 구조에 감성적인 무드를 담아내는 방법을 배웁니다.
- **LESSON 03 필라테스 스튜디오를 위한 디자인**: 복잡한 정보를 직관적으로 구조화하여 다양한 홍보 포맷으로 확장하는 방법을 배웁니다.
- **LESSON 04 동물병원을 위한 디자인**: 신뢰감이 생명인 정보를 부드러운 컬러와 요소로 친근하게 전달하는 방법을 배웁니다.
- **LESSON 05 강사를 위한 상세페이지 디자인**: 핵심 가치를 돋보이게 배치하여 구매 욕구를 자극하는 레이아웃 설계 방법을 배웁니다.
- **LESSON 06 기업을 위한 프레젠테이션 디자인**: 방대한 텍스트와 데이터를 시각화하여 설득력을 높이는 비즈니스 디자인을 익힙니다.
- **LESSON 07 디자인 자산 관리와 상품화 노하우**: 완성된 템플릿을 수익으로 연결하기 위한 패키징과 상품화 전략을 다룹니다.

### 왜 이런 구성인가요?

이번 챕터의 실습안은 시장의 수요를 반영하여 구성하였습니다. 현재 온라인 마켓 플레이스에서 가장 활발하게 판매되는 ‘인스타그램 템플릿 세트’를 메인으로 하되, 이를 시작으로 브랜드 통합 디자인 구축 과정을 경험하게 될 거예요.

학습 흐름은 ‘단단 기초 다지기 → 실전 프로젝트 수행 → 수익화 준비’의 3단계로 이어집니다. 레슨 01에서 디자인 원리와 결정의 기준을 세우고, 레슨 02~06에서는 가상의 프로젝트를 통해 실제 디자인 워크플로를 경험합니다. 마지막 레슨 07에서는 결과물을 상품화하는 과정을 다룹니다.

이렇게 인스타그램 게시물 하나를 만드는 법을 넘어, 한 업종의 브랜딩이 완성되는 과정을 한 묶음의 템플릿 설계부터 외주 디자인까지 아우르는 실전 역량을 갖추게 될 것입니다.
