# Python 출력 챌린지 1회차

### Q1. MCQ 1. 폭 지정 %2d

다음 프로그램의 출력으로 알맞은 것을 고르세요.

```c
print('|%2d|' % 3)
```

- **A**: |3|
- **B**: | 3|
- **C**: |  3|
- **D**: 오류가 발생한다.
