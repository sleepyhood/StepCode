# Python 출력 기초 3회차

### Q1. MCQ 1. 퍼센트(%) 문자 출력

다음 프로그램의 출력으로 알맞은 것을 고르세요.

```c
print('rate=%d%%' % 50)
```

- **A**: rate=50%
- **B**: rate=50%%
- **C**: rate=%d%
- **D**: 오류가 발생한다.

---

### Q2. MCQ 2. 서식문자 개수 불일치

다음 프로그램의 결과로 알맞은 것을 고르세요.

```c
print('%d %d %d' % (1, 2))
```

- **A**: 1 2 0이 출력된다.
- **B**: 1 2 3이 출력된다.
- **C**: 서식문자 개수와 값 개수가 맞지 않아 오류가 발생한다.
- **D**: 2가 자동으로 두 번 들어간다.

---

### Q3. MCQ 3. 타입 불일치(%d에 문자열)

다음 프로그램의 결과로 알맞은 것을 고르세요.

```c
print('%d' % '3')
```

- **A**: 3
- **B**: '3'
- **C**: 3이 그대로 출력된다.
- **D**: 오류가 발생한다.

---

### Q4. MCQ 4. 혼합 서식(%s, %d)

다음 프로그램의 출력으로 알맞은 것을 고르세요.

```c
print('name=%s age=%d' % ('Tom', 15))
```

- **A**: name=Tom age=15
- **B**: name=%s age=%d
- **C**: name='Tom' age='15'
- **D**: 오류가 발생한다.

---

### Q5. MCQ 5. '%%'의 의미

다음 프로그램의 출력으로 알맞은 것을 고르세요.

```c
print('%%' % ())
```

- **A**: %
- **B**: %%
- **C**: 오류가 발생한다.
- **D**: 아무 것도 출력되지 않는다.
