# 18.[COS PRO 3급 모의2 - 빈칸] 영어사전에서 앞에오는 문자열 출력

## 1. 문제 설명
두 문자열 중 영어사전 순으로앞에 오는 문자열을 구하려 합니다.

문자열 두 개를 전달 받아 영어사전 순으로앞에 있는 문자열을 출력하도록 코드를 작성하려 합니다.

빈칸을 채워 전체 코드를 완성해주세요.

---

## 2. 입출력 설명

* **입력:**
문자열 두 개가 주어집니다.

- 두 문자열 길이는 1 이상 100 이하입니다.

- 두 문자열은 알파벳 소문자로만 이루어져 있습니다.

* **출력:**
두 문자열 중 영어사전 순으로앞에 오는 문자열을 출력해 주세요.

---

## 3. 예시
### 예시 입력 1
```text
doing coding
```

### 예시 출력 1
```text
coding
```

---

## 4. 힌트
두 개의 입력된 문자열 중 사전순으로 앞에 오는 문자열을 비교할 때, 언어별 비교 방식에 유의해야 합니다.

1. **C 언어 (주의)**:
   - C언어에서 배열 이름(`data1 < data2`)을 직접 비교하면 문자열 내용이 아닌 **메모리 주소**를 비교하게 되어 잘못된 결과가 나옵니다.
   - 두 문자열의 알파벳 사전순 비교는 `<string.h>`의 `strcmp(str1, str2)` 함수를 사용합니다.
     - `strcmp(data1, data2) < 0` : `data1`이 사전순으로 앞섬
     - `strcmp(data1, data2) > 0` : `data2`가 사전순으로 앞섬
   - 삼항 연산자를 활용하여 `strcmp(data1, data2) < 0 ? data1 : data2` 형태로 작성합니다.

2. **Java**:
   - `data1.compareTo(data2) < 0 ? data1 : data2` 형태를 활용합니다.

3. **Python3**:
   - `data1 if data1 < data2 else data2` 또는 `min(data1, data2)`를 활용합니다.
