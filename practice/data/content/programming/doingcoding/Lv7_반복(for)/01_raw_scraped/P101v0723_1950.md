# 23. [반복-for 분기] 3 또는 5의 배수만 출력

## 1. 문제 설명
정수 n이 주어졌을 때, 1부터 n까지 중 3의 배수 또는 5의 배수만 출력하는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다. (1 ≤ n ≤ 100)

* **출력:**
3 또는 5의 배수만 한 줄에 하나씩 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
10
```

### 예시 출력 1
```text
3  
5  
6  
9  
10
```

---

## 4. 힌트
if문을 사용하여 i가 3의 배수이거나 5의 배수일 때만 출력해 주세요.
