# 09. [반복-for 기초1] 1부터 n까지 홀수 개수 세기

## 1. 문제 설명
정수 n이 주어졌을 때, 1부터 n까지 중 홀수의 개수를 출력하는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다. (1 ≤ n ≤ 1,000)

* **출력:**
1부터 n까지 중 홀수의 개수를 한 줄에 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
5
```

### 예시 출력 1
```text
3
```

---

## 4. 힌트
변수를 선언하여 짝수를 발견할 때마다 1씩 증가시켜 주세요.
