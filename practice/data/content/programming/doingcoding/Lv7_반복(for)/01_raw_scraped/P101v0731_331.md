# 31. [반복-for 응용] 소수 판별

## 1. 문제 설명
입력된 정수가 소수인지 판별해주세요

소수면 prime

소수가 아니면 composite를 출력해주세요.

소수란 약수의 개수가 1과 자기자신 즉 2개만이 존재하는 것을 말합니다.

---

## 2. 입출력 설명

* **입력:**
정수(1이상 ~ 1000이하)하나가 입력됩니다.

* **출력:**
입력받은 수가 소수면 prime

소수가 아니면 composite를 출력해주세요.

---

## 3. 예시
### 예시 입력 1
```text
7
```

### 예시 출력 1
```text
prime
```

### 예시 입력 2
```text
10
```

### 예시 출력 2
```text
composite
```

---

## 4. 힌트
나누어 떨어지는 수를 약수라고 합니다.

카운팅한 수의 약수가 2개 인지를 파악하여야 합니다.

약수가 2개면 소수, 아니면 합성수 입니다.
