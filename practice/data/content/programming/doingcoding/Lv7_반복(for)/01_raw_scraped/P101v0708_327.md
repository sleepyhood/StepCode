# 08. [반복-for 기초1] 1부터 입력받은 수까지의 짝수의 합 출력

## 1. 문제 설명
1부터 입력받은 수까지의 짝수만 모두 더한 합을 출력해주세요.

---

## 2. 입출력 설명

* **입력:**
정수 하나가 입력됩니다.

* **출력:**
1부터 입력받은 수까지 짝수만 모두 합한 값을 출력해주세요.

---

## 3. 예시
### 예시 입력 1
```text
100
```

### 예시 출력 1
```text
2550
```

### 예시 입력 2
```text
10
```

### 예시 출력 2
```text
30
```

---

반복문 for는 (초기값 ; 조건 ; 증감) 으로 작성을하고 조건이 맞을경우{} 명령어를 실행합니다.

ex)

int n=0;

int sum = 0;
