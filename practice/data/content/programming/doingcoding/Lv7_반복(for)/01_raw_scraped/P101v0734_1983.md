# 34. [반복-for 응용] 칠판 개표 결과 출력하기

## 1. 문제 설명
투표가 끝난 뒤에는 칠판에 선을 그어 개표를 표시합니다.

- 처음엔 아무것도 그려져 있지 않습니다.

- 한 표를 받을 때마다 `|`를 하나씩 뒤에 그립니다.

- 단, 표를 5표 받을 때마다 `||||`를 모아서 `++++`로 바꾸고, 그 뒤에 공백을 하나 추가합니다.

예를 들어, 12표를 받은 경우 `++++ ++++ ||`로 표시됩니다.

받은 표 수가 주어지면 칠판에 그려질 결과를 출력하세요.

---

## 2. 입출력 설명

* **입력:**
정수 n이 한 줄에 입력됩니다. (1 ≤ n ≤ 100)

* **출력:**
n표를 받은 경우 칠판에 그려지는 결과를 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
13
```

### 예시 출력 1
```text
++++ ++++ |||
```

### 예시 입력 2
```text
3
```

### 예시 출력 2
```text
|||
```

---

## 4. 힌트
5표를 받을 때마다 '++++ '를 출력하고, 나머지만큼 '|'를 이어서 출력하면 됩니다.
