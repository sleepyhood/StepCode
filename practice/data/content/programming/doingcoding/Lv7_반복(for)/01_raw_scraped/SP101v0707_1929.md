# 07. [반복-for 기초1] 1부터 n까지 홀수 합 구하기

## 1. 문제 설명
정수 n이 주어졌을 때, 1부터 n까지 중 홀수만 더한 합을 출력하는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다. (1 ≤ n ≤ 10,000)

* **출력:**
1부터 n까지 중 홀수만 누적하여 계산한 합을 한 줄에 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
7
```

### 예시 출력 1
```text
16
```

---

## 4. 힌트
for문 안에서 현재 수가 홀수일 때만 합에 더해 주세요.
