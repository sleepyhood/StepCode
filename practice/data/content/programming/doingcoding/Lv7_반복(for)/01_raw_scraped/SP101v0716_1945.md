# 16. [반복-for 분기] 1부터 n까지 7의 배수 만나면 멈추기

## 1. 문제 설명
정수 n이 주어졌을 때, 1부터 n까지 7의 배수를 처음 만나면 그 수를 출력하고 종료하는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다. (7 ≤ n ≤ 100)

* **출력:**
7의 배수를 처음 발견한 순간 그 수를 출력하고 종료합니다.

---

## 3. 예시
### 예시 입력 1
```text
20
```

### 예시 출력 1
```text
7
```

---

## 4. 힌트
i를 1부터 증가시키며 출력하고, i % 7 == 0 조건이 참이면 break로 멈추어 주세요.
