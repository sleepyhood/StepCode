# 13. [반복-for 기초2] n개의 숫자 입력받아 출력하기

## 1. 문제 설명
정수 n이 주어졌을 때, n개의 숫자를 차례대로 입력받아 입력된 순서대로 출력하는 프로그램을 작성해 주세요.

배열을 사용하지 않고, 입력 후 즉시 출력하는 방식으로 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다. (1 ≤ n ≤ 100)

그 다음 줄부터 n개의 줄에 걸쳐 정수 하나씩 입력됩니다.

* **출력:**
입력된 숫자를 한 줄에 하나씩 입력된 순서대로 출력합니다.

### **단, 출력은 바로바로 나와야 합니다. (입력 따로 출력 따로 받지 않습니다.)**

---

## 3. 예시
### 예시 입력 1
```text
3  
10  
20  
30
```

### 예시 출력 1
```text
10  
20  
30
```

---

## 4. 힌트
첫번째 줄에 입력된 숫자는 "앞으로 ~번 입력 받겠다" 라는 의미로 해석할 수 있습니다.

for문을 사용하여 입력을 한 번 받을 때마다 바로 출력해 주세요.
