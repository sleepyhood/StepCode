# 03. [반복-for 기초1] 1부터 n까지 출력하기

## 1. 문제 설명
정수 n이 주어지면, 1부터 n까지의 정수를 한 줄에 하나씩 출력하는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다. (1 ≤ n ≤ 100)

* **출력:**
1부터 n까지의 수를 순서대로 한 줄에 하나씩 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
3
```

### 예시 출력 1
```text
1
2
3
```

---

## 4. 힌트
for문을 이용하여 1부터 n까지 반복하며 출력해 주세요.
