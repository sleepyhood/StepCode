# 10. [반복-for 기초1] 1부터 n까지 홀수 평균 구하기

## 1. 문제 설명
정수 n이 주어졌을 때, 1부터 n까지 중 홀수의 평균을 정수로 출력하는 프로그램을 작성해 주세요.

단, 평균은 소수점 이하는 버리고 정수 부분만 출력해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다. (1 ≤ n ≤ 10,000)

* **출력:**
1부터 n까지 홀수들의 평균을 한 줄에 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
5
```

### 예시 출력 1
```text
3
```

---

## 4. 힌트
홀수일 때마다 합과 개수를 모두 누적한 뒤, 평균을 구해 주세요.
