# 15. [반복-for 기초2] 입력된 n개의 합계와 평균을 출력

## 1. 문제 설명
정수 하나(N)가 입력된 후

N 개 만큼 추가로 입력이 됩니다.

짝수의 합계와 홀수의 평균을 출력해주세요.

**Python으로 푸시는 분들은 넘어가셔도 괜찮습니다.**

---

## 2. 입출력 설명

* **입력:**
정수 하나(N)가 입력된 후

N 개 만큼 정수가 추가로 입력이 됩니다.

* **출력:**
두번째 이후부터 입력된 값의

짝수의 합과 홀수의 평균(소수 둘째자리)를 출력해주세요.

---

## 3. 예시
### 예시 입력 1
```text
10
68 50 25 17 86 93 33 57 4 25
```

### 예시 출력 1
```text
even sum : 208
odd avg : 41.67
```

### 예시 입력 2
```text
8
78 79 29 2 27 13 27 36
```

### 예시 출력 2
```text
even sum : 116
odd avg : 35.00
```

### 예시 입력 3
```text
7
71 49 31 31 81 64 71
```

### 예시 출력 3
```text
even sum : 64
odd avg : 55.67
```
