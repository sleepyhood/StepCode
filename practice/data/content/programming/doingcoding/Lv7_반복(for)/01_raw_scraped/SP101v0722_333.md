# 22. [반복-for 응용] 팩토리얼 구하기

## 1. 문제 설명
1부터 입력된 값까지 모두 곱한것을 팩토리얼이라고 합니다.

예를 들어, 4팩토리얼 = 1 x 2 x 3 x 4 = 24 입니다.

입력된 값의 팩토리얼 값을 출력해주세요.

---

## 2. 입출력 설명

* **입력:**
정수 하나가 입력됩니다.

(1<= n <= 7)

* **출력:**
1부터 입력받은 수까지 모두 곱한 값을 출력해주세요.

---

## 3. 예시
### 예시 입력 1
```text
3
```

### 예시 출력 1
```text
6
```

### 예시 입력 2
```text
7
```

### 예시 출력 2
```text
5040
```

---

## 4. 힌트
2를 n번곱한것과 1부터 n까지 곱하는 방법에는 큰 차이가 없습니다
