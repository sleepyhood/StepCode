# 30. [반복-for 응용] 약수의 개수 출력

## 1. 문제 설명
정수 하나가 입력됩니다.

약수개수를 출력해주세요.

약수란 나누어 떨어지는 수를 약수라고 합니다.

ex) 10의 약수의 수

4개 (1, 2, 5, 10)

---

## 2. 입출력 설명

* **입력:**
정수(1이상 ~ 1000이하)하나가 입력됩니다.

* **출력:**
입력된 수의 약수 개수를 출력해주세요.

---

## 3. 예시
### 예시 입력 1
```text
10
```

### 예시 출력 1
```text
4
```

### 예시 입력 2
```text
370
```

### 예시 출력 2
```text
8
```

---

## 4. 힌트
나누어 떨어지는 수를 약수라고 합니다.

if (n%i==0)

약수의 개수를 카운팅 하세요
