# 15. [반복-for 기초2] n개의 숫자 중 양수 합 구하기

## 1. 문제 설명
정수 n이 주어졌을 때, n개의 정수를 입력받아 그 중 양수만 더한 합을 출력하는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다. (1 ≤ n ≤ 100)

그 다음 줄부터 n개의 줄에 걸쳐 정수 하나씩 입력됩니다.

* **출력:**
입력된 정수 중 양수만 더한 합을 한 줄에 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
5  
3  
-2  
7  
0  
-1

```

### 예시 출력 1
```text
10

```

---

## 4. 힌트
입력받은 수가 0보다 크면 누적하여 더해 주세요.

당연히 출력은 한번! 입니다.

반복안에 출력이 있으면 안되요
