# 33. [반복-for 응용] 같이 만나는 날은?

## 1. 문제 설명
3명의 알바생이 있습니다.

각 알바생은 n일 마다 한번씩 아르바이트에 나오고 있습니다.

다같이 만나서 일하는 날은 언제일까요?

---

## 2. 입출력 설명

* **입력:**
정수 3개가 입력됩니다.

( 1 <= n <= 30 )

* **출력:**
처음 같이 만나는 날을 출력해주세요

---

## 3. 예시
### 예시 입력 1
```text
15
6
23
```

### 예시 출력 1
```text
690
```

### 예시 입력 2
```text
6
10
12
```

### 예시 출력 2
```text
60
```

### 예시 입력 3
```text
3
67
671
```

### 예시 출력 3
```text
134871
```

---

## 4. 힌트
날짜를 하루하루 늘려가면서 3명이 동시에 나누어 떨어지는지를 확인합니다.

for ( 초기값 ; 조건 ; 증가or감소)

조건자리에 아무것도 안쓰게되면 무한반복이 됩니다.
