# 02. [덱 - 2] 셔플

## 1. 문제 설명
음악 플레이어 시뮬레이션을 만드려고 합니다.  
이 플레이어는 항상 'A', 'B', 'C', 'D', 'E' 5개의 노래를 메모리에 저장합니다. 또한 플레이어는 플레이리스트를 관리하는데, 이는 이 5곡의 순서를 의미합니다. 플레이어에는 플레이리스트를 재배열하고 노래를 재생하기 위한 4개의 버튼이 있습니다.  
초기 플레이리스트는 'A', 'B', 'C', 'D', 'E' 입니다. 4개의 버튼은 다음과 같은 기능을 합니다.

* 버튼 1: 플레이리스트의 첫 번째 노래를 목록 맨 끝으로 이동시킵니다. 예) "A, B, C, D, E" → "B, C, D, E, A"
* 버튼 2: 플레이리스트의 마지막 노래를 목록 맨 앞으로 이동시킵니다. 예)"A, B, C, D, E"→ "E, A, B, C, D"
* 버튼 3: 플레이리스트의 처음 두 곡의 순서를 서로 바꿉니다.예)"A, B, C, D, E"→ "B, A, C, D, E"
* 버튼 4: 순서 변경을 멈추고 현재 플레이리스트를 출력합니다.

플레이어를 시뮬레이션하는 프로그램을 작성해 주세요.

이 프로그램은 두 개의 양의 정수 b, n을 반복해서 받습니다.

b는 사용자가 누르고자 하는 버튼(1<=b<=4), n은 b버튼을 누른 횟수를 나타냅니다. (1<=n<=10)

입력은 항상 b = 4, n = 1 쌍으로 끝납니다. 해당 버튼을 누르면 현재 플레이리스트의 노래 순서를 출력하고 프로그램을 종료합니다.

사용자가 4번 버튼을 여러 번 누르는 일은 없습니다.

---

## 2. 입출력 설명

* **입력:**
두 개의 양의 정수 b, n을 반복해서 받습니다.

b는 사용자가 누르고자 하는 버튼(1<=b<=4), n은 b버튼을 누른 횟수를 나타냅니다. (1<=n<=10)

입력은 항상 b = 4, n = 1 쌍으로 끝납니다.

사용자가 4번 버튼을 여러 번 누르는 일은 없습니다.

* **출력:**
b =4, n = 1 버튼을 누르면 현재 플레이리스트의 노래 순서를 출력하고 프로그램을 종료합니다.

---

### 예시 입력 1
```text
2
1
3
1
2
3
4
1
```

### 예시 출력 1
```text
B C D A E
```

두 줄씩 계속 입력받습니다.

입력 받은 두 줄이 4, 1이면 프로그램을 종료하고 출력합니다.
