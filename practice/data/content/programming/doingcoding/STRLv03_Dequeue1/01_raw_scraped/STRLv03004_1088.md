# 4. [덱 - 4] 풍선 터뜨리기

## 1. 문제 설명
1번부터 N번까지 N개의 풍선이 원형으로 놓여 있습니다. i번 풍선의 오른쪽에는 i+1번 풍선, 왼쪽에는 i-1번 풍선이 있습니다. 단, 1번 풍선의 왼쪽에는 N번 풍선이, N번 풍선의 오른쪽에는 1번 풍선이 있습니다. 각 풍선 안에는 -N보다 크거나 같고 N보다 작거나 같은 정수가 하나 적힌 종이가 있습니다. 이 풍선들을 다음과 같은 규칙으로 터뜨립니다.

1. 1번 풍선을 터뜨리고, 풍선 안에 있는 종이를 꺼냅니다.
2. 종이에 써있는 횟수만큼 이동합니다.
3. 양수가 적힌 경우 오른쪽, 음수가 적힌 경우 왼쪽입니다.
4. 도착한 위치의 풍선을 터트립니다.
5. 풍선이 전부 터질 때 까지 2번부터 반복합니다.
6. 이동할 때 이미 터진 풍선은 빼고 이동합니다.

예를 들어, 다섯 개의 풍선 안에 차례로 3, 2, 1, -3, -1이 적혀잇다면 3이 적힌 1번 풍선, -3이 적힌 4번 풍선, -1이 적힌 5번 풍선, 1이 적힌 3번 풍선, 2가 적힌 2번 풍선 순서대로 터지게 됩니다.

---

## 2. 입출력 설명

* **입력:**
첫 줄에 풍선의 개수 N이 입력됩니다. (1 <= N <= 1000)

다음 줄에 각 풍선에 적힌 숫자가 1번부터 N번까지 입력됩니다. 0은 입력되지 않습니다.

* **출력:**
풍선이 터진 번호를 차례대로 출력해주세요.

---

## 3. 예시
### 예시 입력 1
```text
5
3 2 1 -3 -1
```

### 예시 출력 1
```text
1 4 5 3 2
```
