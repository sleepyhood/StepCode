# 05. [큐 - 5] 기념품

## 1. 문제 설명
수진이는 알고리즘 캠프 참가자 한 명에게 기념품을 주려고 합니다. 게임을 통해서 기념품을 받을 사람을 정하기로 결정했습니다.

게임을 시작하기 전, N명의 참가자들은 원을 이루어서 앉습니다. 그 다음 게임 구분을 쉽게 하기 위해 1번부터 N번까지 번호가 적힌 티셔츠를 하나씩 순서대로 입습니다.

게임은 각 단계로 이루어져 있습니다.

* 우선 수진이가 어떠 참가자 앞에 서서 '하나'라고 외칩니다. 그 다음, 시계 방향으로 이동하여 '둘'을 외칩니다. 이 과정은 t단계일 경우 t의 3제곱 까지 진행합니다. 예를 들어, 1단계일 경우 1까지, 2단계일 경우 8, 3단계일 경우 27까지 외칩니다.
* 각 단계가 끝나면 수진이가 앞에 서 있는 사람은 게임에서 제외됩니다. (t단계일 경우 t의 세제곱 수를 외칠 때 앞에 있던 사람) 사람이 제거된 후에 수진이는 시계방향으로 다음 사람에게 이동합니다.

1단계에서 수진이는 1번 티셔츠를 입은 사람 앞에 서 있습니다. 게임은 원에 한 명이 남을 때까지 진행하며, 마지막 사람이 기념품을 받게 됩니다.

참가자 수 N명이 주어지면 어떤 티셔츠를 입은 사람이 기념품을 받을지 계산하는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 줄에 알고리즘 캠프 참가자 수 N이 주어집니다. (1<=N<=5000)

* **출력:**
기념품을 받는 사람이 입은 티셔츠 번호를 출력해 주세요.
