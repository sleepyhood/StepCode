# 04. [큐 - 4] 사탕

## 1. 문제 설명
준수 선생님은 아이들이 사탕을 좋아한다는 것을 알고 있습니다. 그래서 선생님은 N명의 아이들 중 단 한 명에게 비싼 사탕을 주려고 합니다.

아이들은 총 1<=n<=7100000이고, 각 아이들은 1번부터 n번까지 번호가 붙어 있습니다.

준수 선생님은 아이들을 원형으로 세우고 1번 아이부터 시작합니다. 2번 아이에게 가서 원에서 나가라고 합니다. 4번 아이에게 가서 원에서 나가라고 합니다. 즉, 한 명씩 건너 뛰면서 아이에게 원에서 나가라고 합니다.

마지막에 남은 아이가 비싼 사탕을 받게 됩니다.

몇 번 아이가 사탕을 받는지 계산하는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
정수 n이 입력됩니다.

* **출력:**
사탕을 받는 아이의 번호를 출력해 주세요.

---

## 3. 예시
### 예시 입력 1
```text
7
```

### 예시 출력 1
```text
7
```
