# [ALLv05002번] 02. [재귀함수 - 2] 소 배치하기

## 1. 문제 설명
농부 다원이는 대칭을 좋아합니다.

다원이는 자신의 n \* m크기의 밭에 소를 격자로 나누려고 합니다.(각각 1,000,000이하)

대칭을 유지하기 위해 다원이는 다음과 같은 방법으로 소를 놓으려고 합니다.

* 소 한마리를 밭의 정중앙에 놓습니다.
* 정중앙이 없을 경우, 소를 배치하지 않고 멈춥니다.
* 소를 두었다면, 밭을 정확하게 4등분 합니다.
* 더이상 밭을 나눌 수 없을 때 까지 계속 반복합니다.

예를 들어, n = 7, m= 15일 경우 다원이의 밭은 다음과 같이 변합니다.

```
...............    ...............    .......|.......    .C.|.C.|.C.|.C.
...............    ...............    ...C...|...C...    ---C---|---C---
...............    ...............    .......|.......    .C.|.C.|.C.|.C.
............... -> .......C....... -> -------C------- -> -------C-------
...............    ...............    .......|.......    .C.|.C.|.C.|.C.
...............    ...............    ...C...|...C...    ---C---|---C---
...............    ...............    .......|.......    .C.|.C.|.C.|.C.
```

.은 빈칸을, c는 소를 나타냅니다.

이 밭에서는 소가 21마리가 필요합니다, 하지만 5\*5크기의 밭에서는 2\*2의 정중앙이 없기 때문에 소 한마리만 있으면 됩니다.

농부 다원이를 도와서 다원이의 밭에 소가 몇마리나 필요한지 계산하는 프로그램을 작성해주세요.

---

* **출력:**
