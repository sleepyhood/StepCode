# [ALLv10004번] 04. [재귀함수 - 8] 프랙탈 십자 그리기

## 1. 문제 설명

지금까지 재귀를 이용해 **1차원 문자열**을 만들었습니다.

이번에는 재귀를 **2차원 격자(Grid)**에 적용해 봅시다.

다음 규칙으로 만들어지는 격자 패턴을 생각해 봅시다.

**$k = 1$ 일 때** ($3 \times 3$ 격자):
```
.+.
+++
.+.
```

**$k = 2$ 일 때** ($7 \times 7$ 격자):
```
.+..+..
+++.+++
.+..+..
+++++++
.+..+..
+++.+++
.+..+..
```

**$k = 3$ 일 때** ($15 \times 15$ 격자):
```
.+..+...+..+...
+++.+++.+++.+++
.+..+...+..+...
+++++++.+++++++
.+..+...+..+...
+++.+++.+++.+++
.+..+...+..+...
+++++++++++++++
.+..+...+..+...
+++.+++.+++.+++
.+..+...+..+...
+++++++.+++++++
.+..+...+..+...
+++.+++.+++.+++
.+..+...+..+...
```

### 규칙

격자의 크기 $N = 2^k - 1$ 입니다.

`draw(row_start, col_start, size)` 함수는 다음과 같이 동작합니다:
1. **기저 조건**: 크기가 `1`이면 더 이상 나눌 수 없으므로 아무것도 하지 않고 종료합니다.
2. 현재 영역의 **중앙 행 전체**를 `+`로 채웁니다.
3. 현재 영역의 **중앙 열 전체**를 `+`로 채웁니다.
4. 4개의 절반 크기(`size / 2`) 서브 영역에 대해 재귀 호출합니다.

---

## 2. 입출력 설명

* **입력:**
단계를 나타내는 정수 $k$가 입력됩니다. ($1 \le k \le 4$)

* **출력:**
크기 $N = 2^k - 1$ 인 격자 패턴을 $N$개의 줄로 출력합니다.
`+` 는 선이 그어진 칸, `.` 는 빈 칸을 나타냅니다.

---

## 3. 예시

### 예시 입력 1
```text
1
```

### 예시 출력 1
```text
.+.
+++
.+.
```

### 예시 입력 2
```text
2
```

### 예시 출력 2
```text
.+..+..
+++.+++
.+..+..
+++++++
.+..+..
+++.+++
.+..+..
```

---

## 4. 힌트

* 격자를 `char grid[N][N]`으로 선언하고, 먼저 전부 `.`으로 초기화하세요.
* `draw` 함수는 현재 담당하는 영역의 **시작 행/열 좌표**와 **크기**를 인자로 받습니다.
* 중앙의 행/열 인덱스는 `row_start + size / 2`, `col_start + size / 2` 입니다.
* 서브 영역의 크기는 `size / 2` 이며, 4개의 서브 영역 시작 좌표를 잘 계산하세요.

## [정답 및 해설 (Ground Truth)]

### 핵심 아이디어
`draw` 함수는 **먼저 기저 조건을 확인**하고, 그 다음 `+` 선을 긋고, 마지막으로 4개의 서브 영역에 재귀 호출합니다.

핵심: $N = 2^k - 1$ 구조에서 서브 영역의 크기는 `size / 2` 이고, 이 값이 홀수여야 유효한 서브 영역이 됩니다.
- $k=1$: size=3, sub=1 → 서브는 1×1이므로 더 이상 선을 긋지 않음
- $k=2$: size=7, sub=3 → 서브는 3×3이므로 재귀 가능

따라서 기저 조건은 `size == 1` 입니다.

### 모범 코드 (C)
```c
#include <stdio.h>

#define MAX_N 16

char grid[MAX_N][MAX_N + 1]; // +1 for null terminator
int N;

// (rs, cs): 현재 영역의 시작 행/열, size: 현재 영역의 크기
void draw(int rs, int cs, int size) {
    // 기저 조건: 1×1 영역은 더 이상 선을 그을 수 없음
    if (size == 1) return;

    int mid_r = rs + size / 2;
    int mid_c = cs + size / 2;

    // 중앙 행 전체를 '+' 로 채우기
    for (int c = cs; c < cs + size; c++) {
        grid[mid_r][c] = '+';
    }
    // 중앙 열 전체를 '+' 로 채우기
    for (int r = rs; r < rs + size; r++) {
        grid[r][mid_c] = '+';
    }

    int sub = size / 2; // 서브 영역 크기 (N=3이면 sub=1, N=7이면 sub=3)

    // 4개 서브 영역에 재귀 호출
    draw(rs,           cs,           sub); // 좌상
    draw(rs,           mid_c + 1,   sub); // 우상
    draw(mid_r + 1,   cs,           sub); // 좌하
    draw(mid_r + 1,   mid_c + 1,   sub); // 우하
}

int main() {
    int k;
    scanf("%d", &k);

    // N = 2^k - 1
    N = (1 << k) - 1;

    // 격자 초기화 ('.' 로 채우기)
    for (int r = 0; r < N; r++) {
        for (int c = 0; c < N; c++) {
            grid[r][c] = '.';
        }
        grid[r][N] = '\0'; // 문자열 종료
    }

    draw(0, 0, N);

    // 출력
    for (int r = 0; r < N; r++) {
        printf("%s\n", grid[r]);
    }

    return 0;
}
```

### 실행 추적 (k=1, N=3)
```
draw(0, 0, 3)
  size=3 ≠ 1 → 계속
  mid_r=1, mid_c=1
  행 1 전체 → '+': grid[1][0~2] = '+'
  열 1 전체 → '+': grid[0~2][1] = '+'
  sub = 1
  draw(0, 0, 1) → size==1, 기저 반환 (코너를 건드리지 않음 ✓)
  draw(0, 2, 1) → 기저 반환
  draw(2, 0, 1) → 기저 반환
  draw(2, 2, 1) → 기저 반환

최종 grid:
.+.   ← 열 1에만 '+', 코너(0,0) 등은 '.' 유지 ✓
+++   ← 행 1 전체 '+'
.+.
```
