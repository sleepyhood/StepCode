# [SALLv10007번] 04. 타일 채우기 기초 (2 x N)

## 1. 문제 설명
가로의 길이가 $N$, 세로의 길이가 $2$인 직사각형 모양의 벽이 있습니다. 여러분은 이 벽을 가로 2, 세로 1 크기의 타일(가로 타일)과 가로 1, 세로 2 크기의 타일(세로 타일)로 빈틈없이 채우려고 합니다.

벽의 크기 $N$이 주어졌을 때, 벽을 채우는 **서로 다른 방법의 수**를 구하는 프로그램을 재귀 함수로 작성하세요.

예를 들어 $N=3$일 때 가능한 방법은 다음과 같이 3가지입니다.
1. 세로 타일 3개 (`| | |`)
2. 세로 타일 1개 + 가로 타일 2개 (`| =`)
3. 가로 타일 2개 + 세로 타일 1개 (`= |`)

---

## 2. 입출력 설명

* **입력:**
벽의 가로 길이 정수 $N$이 입력됩니다. ($1 \le N \le 30$)

* **출력:**
벽을 채우는 총 방법의 수를 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
3
```

### 예시 출력 1
```text
3
```

---

## 4. 힌트
벽의 맨 마지막 부분이 어떻게 채워지는지 생각해 보세요.
* 마지막에 세로 타일(`|`)을 붙였다면, 그 앞은 $N-1$ 크기의 벽을 채우는 방법과 같습니다.
* 마지막에 가로 타일 2개(`=`)를 붙였다면, 그 앞은 $N-2$ 크기의 벽을 채우는 방법과 같습니다.

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (C)
```c
#include <stdio.h>

// tiling(n): 가로 길이가 n인 벽을 채우는 방법의 수
long long tiling(int n) {
    if (n == 1) return 1;
    if (n == 2) return 2;
    return tiling(n - 1) + tiling(n - 2);
}

int main() {
    int n;
    scanf("%d", &n);
    // n=30일 경우 재귀 호출 횟수가 많아질 수 있으나, 1초 내에 연산 가능합니다.
    // (더 큰 N에 대해서는 메모이제이션 또는 DP가 필요합니다.)
    printf("%lld", tiling(n));
    return 0;
}
```
