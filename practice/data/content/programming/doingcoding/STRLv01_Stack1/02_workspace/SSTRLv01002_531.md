# 02. [스택 - 2] 0은 빼!

## 1. 문제 설명
당신의 상관은 숫자를 차례대로 말합니다.

0이 입력되면 바로 이전에 말한 숫자가 무시됩니다.

0이 연속으로 나오면 앞서 말한 숫자들이 차례대로 계속 삭제됩니다.

모든 숫자를 순서대로 처리한 뒤 남은 수들의 합을 출력하는 프로그램을 작성하세요.

만약 모든 숫자가 무시되면 합은 0입니다.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에는 0을 포함하는 정수 K를 입력받습니다.

그 다음 K줄 동안 1부터 9 까지의 정수 또는 0을 입력받습니다.

범위 :

1 <= K <= 100000

* **출력:**
정확한 합을 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
10
1
3
5
4
0
0
7
0
0
6
```

### 예시 출력 1
```text
7
```
