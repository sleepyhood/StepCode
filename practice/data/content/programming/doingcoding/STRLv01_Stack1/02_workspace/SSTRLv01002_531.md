# 02. [스택 - 2] 0은 빼!

## 1. 문제 설명
당신의 상관은 당신이 작년에 회사의 실적에 얼마나 도움이 되었는지 횟수를 세었습니다.

불행히도 당신의 상관은 때때로 횟수를 틀리게 읽습니다.

다행히도 당신의 상관은 잘못된 숫자를 읽은 것을 인식하면 0이라고 말합니다.

이는 ‘직전의 숫자는 무시한다’는 것을 의미합니다.

불행히도 당신의 상관은 실수를 반복할 수 있고, 매 실수 마다 0이라고 말합니다.

0이라고 말하면 0을 제외하고 마지막에 말한 숫자가 무시됩니다.

어느 순간이나 당신의 상관은 0이라고 말할 수 있으며, 만약 모든 숫자들이 무시되면 그 합은 0이 됩니다.

상관이 말하는 문구를 입력받아 정확한 합을 구하는 프로그램을 작성해주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에는 0을 포함하는 정수 K를 입력받습니다.

그 다음 K줄 동안 1부터 9 까지의 정수 또는 0을 입력받습니다.

범위 :

1 <= K <= 100000

* **출력:**
정확한 합을 출력한다.

---

## 3. 예시
### 예시 입력 1
```text
10
1
3
5
4
0
0
7
0
0
6
```

### 예시 출력 1
```text
7
```

---

## 4. 힌트
10 개의 정수가 입력이 됩니다.

1이 입력이 되었으니 저장합니다.

저장 : 1

3이 입력이 되었으니 저장합니다.

저장 : 1, 3

5이 입력이 되었으니 저장합니다.

저장 : 1, 3, 5

4이 입력이 되었으니 저장합니다.

저장 : 1, 3, 5, 4

0이 입력이 되었으니 마지막 데이터를 삭제합니다.

저장 : 1, 3, 5

0이 입력이 되었으니 마지막 데이터를 삭제합니다.

저장 : 1, 3

7이 입력이 되었으니 저장합니다.

저장 : 1, 3, 7

0이 입력이 되었으니 마지막 데이터를 삭제합니다.

저장 : 1, 3

0이 입력이 되었으니 마지막 데이터를 삭제합니다.

저장 : 1

6이 입력이 되었으니 저장합니다.

저장 : 1, 6

저장되어 있는 모든 데이터의 합은 7입니다.
