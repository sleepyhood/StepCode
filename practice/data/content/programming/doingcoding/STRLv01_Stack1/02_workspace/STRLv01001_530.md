# 01. [스택 - 1] 스택 튜토리얼

## 1. 문제 설명
스택(Stack)은 "쌓아 올린 더미"라는 뜻을 가집니다. 책이나 신문을 바닥부터 차곡차곡 쌓아 올린 모습을 생각해보면 쉽습니다.

책 더미에서 책을 꺼낼 때 가장 정상적이고 쉬운 방법은 **맨 위에 있는 책(가장 마지막에 올려놓은 책)** 부터 가져오는 것입니다. 반대로 가장 먼저 놓은 책은 맨 아래에 깔리게 되므로 다른 책들을 모두 꺼내기 전까지는 가져올 수 없습니다.

이처럼 **가장 나중에 들어간 자료가 가장 먼저 나오는(Last-In-First-Out, LIFO 또는 선입후출 FILO)** 형태의 자료구조를 **스택(Stack)** 이라고 합니다.

![스택 구조도](./images/STRLv01001_366ca538d3.png)

### 💡 주요 기능 및 언어별 사용법

스택은 주로 아래의 다섯 가지 연산을 지원합니다:
1. **Push**: 자료를 스택의 맨 위에 넣기
2. **Pop**: 스택의 맨 위 자료를 빼기
3. **Top (또는 Peek)**: 스택의 맨 위 자료를 확인하기 (삭제하지 않음)
4. **Size**: 스택에 저장된 자료의 개수 확인하기
5. **Empty**: 스택이 비어있는지 확인하기

---

#### 💻 C++ 스택 사용법
C++ 표준 템플릿 라이브러리(STL)의 `<stack>` 헤더를 사용합니다.
```cpp
#include <iostream>
#include <stack>
using namespace std;

int main() {
    stack<int> s;
    s.push(10);     // 10 삽입
    s.pop();        // 맨 위 원소 삭제 (반환값 없음)
    // s.top()      // 맨 위 원소 확인
    // s.size()     // 크기 확인
    // s.empty()    // 비어있으면 true, 아니면 false
}
```
*주의*: C++의 `s.pop()`은 원소를 **삭제하기만 할 뿐 반환하지 않습니다.** 값을 확인하고 싶다면 반드시 `s.top()`을 먼저 호출해야 합니다.

---

#### 💻 Python 스택 사용법
파이썬은 기본 리스트(`list`)를 사용하거나, `collections.deque`를 사용하여 스택을 쉽게 모방할 수 있습니다.
```python
# 1. 일반 리스트 사용
s = []
s.append(10)      # push: 10 삽입
s.pop()           # pop: 맨 위 원소 제거 및 반환
# s[-1]           # top: 맨 위 원소 확인
# len(s)          # size: 크기 확인
# not s           # empty: 비어있으면 True

# 2. collections.deque 사용 (더 빠름)
from collections import deque
s = deque()
s.append(10)
s.pop()
```

---

#### 💻 Java 스택 사용법
자바의 `java.util.Stack` 클래스를 사용합니다.
```java
import java.util.Stack;

public class Main {
    public static void main(String[] args) {
        Stack<Integer> s = new Stack<>();
        s.push(10);      // push: 10 삽입
        s.pop();         // pop: 맨 위 원소 제거 및 반환
        // s.peek()      // top: 맨 위 원소 확인
        // s.size()      // size: 크기 확인
        // s.isEmpty()   // empty: 비어있으면 true
    }
}
```


---

### 문제 요구사항
주어진 명령은 다음의 3가지입니다.

1. `i a`: $a$라는 자연수를 스택에 넣습니다. ($a \le 10,000$)
2. `o`: 스택에서 맨 위 데이터를 빼고, 그 데이터를 출력합니다. 만약 스택이 비어있으면 `empty`를 출력합니다.
3. `c`: 스택에 들어있는 데이터의 개수를 출력합니다.

---

## 2. 입출력 설명

* **입력:**
첫째 줄에 명령어의 수 $N$이 주어집니다. ($1 \le N \le 100$)
둘째 줄부터 $N+1$째 줄까지 $N$개의 명령어가 한 줄에 하나씩 주어집니다.

* **출력:**
각 명령어에 대한 출력값을 한 줄에 하나씩 출력합니다. (출력 내용이 하나도 없는 입력은 주어지지 않습니다.)

---

## 3. 예시
### 예시 입력 1
```text
7
i 7
i 5
c
o
o
o
c
```

### 예시 출력 1
```text
2
5
7
empty
0
```
