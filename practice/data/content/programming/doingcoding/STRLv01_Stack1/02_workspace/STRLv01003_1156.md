# 03. [스택 - 3] 댄스파티

## 1. 문제 설명
댄스파티가 열렸습니다. 댄스파티에서는 서로 다같이 춤을 추다가 서로에게 인사합니다. 인사하는 사람의 쌍은 ><로 표현 가능합니다. 서로 인사하는 사람들 사이에 껴서 인사할 수 도 있고, 그럴경우 >><<로 표현 가능합니다.

댄스파티장에서는 서로 인사하는 사람들이 뒤섞여 보일 수 있습니다. 아래의 그림이 그 예시입니다.

```
     > > > >< < >< < >< >< >< <
     | | | -- | -- | -- -- -- |
     | | ------    |          |
     | -------------          |
     --------------------------
```

댄스파티를 구경하던 수아는 이 인사가 제대로 되고있는지 아닌지 궁금해졌습니다. 댄스파티중 인사하는 사람의 모습을 보고 제대로 인사를 하고 있는지 아닌지를 계산하는 프로그램을 작성해주세요.

---

## 2. 입출력 설명

* **입력:**
첫 줄에 댄스파티중 인사한 횟수 N이 입력됩니다. (1 <=  N <= 1,000)

다음 N개 줄에 댄스파티중 서로 인사한 사람의 수와 사람의 모양이 입력됩니다. 사람의 모양은 >또는 <로만 입력됩니다. (사람의 수는 1 이상 200 이하)

* **출력:**
N개 줄에 서로 쌍이 맞게 인사를 했다면legal을 아니라면illegal을 출력해주세요.

---

## 3. 예시
### 예시 입력 1
```text
2
6 >><<><
4 ><<>
```

### 예시 출력 1
```text
legal
illegal
```

### 예시 입력 2
```text
7
5 <<<<<
5 >>>>>
2 ><
3 >><
9 >><<><><<
11 ><><>><<>><
4 >><<

```

### 예시 출력 2
```text
illegal
illegal
legal
illegal
illegal
illegal
legal

```
