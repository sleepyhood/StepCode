# 03. [스택 - 3] 독서

## 1. 문제 설명
독서를 좋아하는 소정이는 좁은 원룸에 삽니다. 집이 작아서 바닥에 책을 한권밖에 둘 수 없지만 대신 집이 엄청나게 높아서 책을 높이 쌓을 수 있습니다. 소정이는 도서관에서 책을 빌려 읽을려고 합니다.

소정이는 Q개의 행동을 할 계획인데 (1<=Q<=200,000) 각 행동들은 문자열 Si로 표현할 수 있습니다. (Si의 길이는 10자 이하) 각 행동들은 아래와 같습니다.

* Si가 소문자로만 이루어져있다면 그 제목의 책을 도서관에서 빌려와서 책더미 맨 위에 쌓아둔 것 입니다.
* Si가 "READ"라면 책더미 맨 위의 책을 읽고 도서관에 반납했습니다.

소정이의 행동 Q개가 입력되면 소정이가 읽은 책을 순서대로 나열하는 프로그램을 작성해주세요.

---

## 2. 입출력 설명

* **입력:**
입력은 아래와 같이 들어옵니다.

```
Q
S1
S2
:
SQ
```

* **출력:**
"READ"가 입력될 때 마다 소정이가 읽은 책을 한 줄에 하나씩 출력해주세요.

---

### 예시 입력 1
```text

READ
```

```text
ioi

joig
```

## 4. 힌트
예제1에서는 joi책을 빌려와서 책더미에 올렸습니다.

joig책을 빌려와 책더미에 올렸습니다.

ioi책을 빌려와 책더미에 올렸습니다.

책더미 맨 위에 있는 ioi를 읽고 반납했습니다.

egoi책을 빌려와 책더미에 올렸습니다.

책더미 맨 위에 있는 egoi책을 읽고 반납했습니다.

책더미 낸 위에 있는 joig책을 읽고 반납했습니다.
