# 17. [구조체 배열] 학생 이름 알파벳 순 정렬

## 1. 문제 설명
N명의 학생 이름과 학년 정보를 입력받고, 이름을 알파벳 순으로 정렬하여 출력하는 프로그램을 작성하세요.

---

## 2. 입출력 설명

* **입력:**
첫 줄에 학생 수 N이 주어집니다.

이후 N줄에 걸쳐 이름과 학년이 공백으로 입력됩니다.

* **출력:**
이름이 알파벳 순으로 빠른 순서대로 이름과 학년을 출력하세요.

---

## 3. 예시
### 예시 입력 1
```text
3  
Yuna 3  
Anna 2  
Dora 1
```

### 예시 출력 1
```text
Anna 2  
Dora 1  
Yuna 3
```

---

## 4. 힌트
`strcmp()`를 활용해 이름을 비교하고 정렬하세요.
