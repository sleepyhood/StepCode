# 12. [구조체-배열] 특정 이름 찾기

## 1. 문제 설명
사람의 이름과 나이를 구조체 배열에 저장하고, 특정 이름과 일치하는 사람의 정보를 찾아 출력하는 프로그램을 작성하세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 사람 수 N이 주어집니다.

이후 N줄에 걸쳐 이름과 나이가 입력됩니다.

마지막 줄에는 검색할 이름이 주어집니다.

* **출력:**
검색한 이름과 일치하는 사람의 이름과 나이를 한 줄에 하나씩 출력합니다.

일치하는 사람이 없다면 아무 것도 출력하지 않습니다.

---

## 3. 예시
### 예시 입력 1
```text
3  
Amy 18  
Ben 22  
Cara 20  
Ben
```

### 예시 출력 1
```text
이름: Ben, 나이: 22
```

---

## 4. 힌트
strcmp 함수를 사용해 문자열 비교를 수행하세요.
