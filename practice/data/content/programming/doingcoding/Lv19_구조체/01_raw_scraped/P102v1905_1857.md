# 05. [구조체-중첩] 주소 포함 학생 정보 (1명)

## 1. 문제 설명
중첩 구조체를 활용하여 한 명의 학생 정보(이름, 나이, 도시, 우편번호)를 입력받아 출력하세요.

배열 없이 구조체 하나만 사용합니다.

---

## 2. 입출력 설명

* **입력:**
이름, 나이, 도시, 우편번호를 한 줄로 입력합니다.

* **출력:**
입력된 전체 정보를 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
Frank 16 Seoul 04500
```

### 예시 출력 1
```text
이름: Frank, 나이: 16, 도시: Seoul, 우편번호: 04500
```
