# 03. [구조체-입력] 사용자 입력 후 출력

## 1. 문제 설명
구조체 하나를 선언하고, 이름과 나이를 입력받은 뒤 그대로 출력하는 프로그램을 작성하세요.

---

## 2. 입출력 설명

* **입력:**
한 줄에 이름과 나이를 입력합니다.

* **출력:**
입력된 정보를 그대로 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
Diana 13
```

### 예시 출력 1
```text
이름: Diana, 나이: 13
```

---

## 4. 힌트
입력 예: scanf("%s %d", student.name, &student.age);
