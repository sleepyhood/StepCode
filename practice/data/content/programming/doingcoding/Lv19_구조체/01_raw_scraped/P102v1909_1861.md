# 09. [구조체-계산] 평균 가격 구하기 (상품)

## 1. 문제 설명
두 개의 상품 정보를 입력받고, 평균 가격을 정수로 계산해 출력하세요.

---

## 2. 입출력 설명

* **입력:**
두 줄에 각각 상품명과 가격을 입력합니다.

* **출력:**
평균 가격을 한 줄에 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
ItemA 5000  
ItemB 3000
```

### 예시 출력 1
```text
4000
```

---

## 4. 힌트
두 가격을 더한 후 2로 나누어 평균을 출력하세요.
