# 04. [구조체-함수] 구조체 매개변수 출력

## 1. 문제 설명
구조체를 함수에 전달하여 이름과 나이를 출력하는 프로그램을 작성하세요.

구조체는 하나만 사용하며, 배열은 사용하지 않습니다.

---

## 2. 입출력 설명

* **입력:**
한 줄에 이름과 나이를 입력합니다.

* **출력:**
출력 함수에서 이름과 나이를 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
Ethan 14
```

### 예시 출력 1
```text
이름: Ethan, 나이: 14
```

---

## 4. 힌트
`void printStudent(struct Student s)`와 같은 함수 정의 후 호출합니다.  
(템플릿을 참고해주세요.)
