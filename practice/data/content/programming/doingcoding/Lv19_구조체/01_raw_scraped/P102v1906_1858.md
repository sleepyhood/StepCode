# 06. [구조체-조건 출력] 특정 나이 이상만 출력

## 1. 문제 설명
두 명의 학생 정보를 입력받고, 나이가 15세 이상인 학생만 출력하는 프로그램을 작성하세요.

---

## 2. 입출력 설명

* **입력:**
두 줄에 각각 이름과 나이를 입력합니다.

* **출력:**
조건에 맞는 학생의 이름과 나이를 출력합니다. 조건에 맞는 학생이 없을 경우 아무 것도 출력하지 않습니다.

---

## 3. 예시
### 예시 입력 1
```text
Amy 14
Ben 16
```

### 예시 출력 1
```text
이름: Ben, 나이: 16
```

---

## 4. 힌트
구조체 변수 2개를 사용하고, 각각 if 조건문을 이용해 출력하세요.
