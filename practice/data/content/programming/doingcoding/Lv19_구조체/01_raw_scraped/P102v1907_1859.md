# 07. [구조체-비교] 나이 비교 후 출력

## 1. 문제 설명
두 사람의 이름과 나이를 입력받고, 나이가 적은 사람을 먼저 출력하는 프로그램을 작성하세요.

나이가 같으면 입력 순서대로 출력합니다.

---

## 2. 입출력 설명

* **입력:**
두 줄에 각각 이름과 나이를 입력합니다.

* **출력:**
나이 오름차순으로 두 사람의 정보를 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
Alice 25
Bob 22
```

### 예시 출력 1
```text
이름: Bob, 나이: 22  
이름: Alice, 나이: 25
```

---

## 4. 힌트
두 구조체 변수의 나이를 비교한 후 조건에 따라 출력 순서를 바꾸세요.
