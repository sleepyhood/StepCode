# 04. [구조체-배열] 나이 조건 만족 학생 출력

## 1. 문제 설명
$N$명의 학생 정보(이름, 나이)를 구조체 배열에 저장하고, 추가로 **기준 나이 $Cut$** 을 입력받습니다.

구조체 배열을 순회하며 나이가 $Cut$ 이상인 학생의 정보를 입력 순서대로 출력하는 프로그램을 작성하세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 학생 수 $N$이 주어집니다. ($1 \le N \le 100$)
다음 $N$개 줄에 각 학생의 이름과 나이가 공백으로 주어집니다.
마지막 줄에 기준 나이 $Cut$이 정수로 주어집니다.

* **출력:**
나이가 $Cut$ 이상인 학생의 정보를 `이름: [이름], 나이: [나이]` 형식으로 한 줄에 하나씩 출력합니다.
조건을 만족하는 학생이 없으면 아무것도 출력하지 않습니다.

---

## 3. 예시
### 예시 입력 1
```text
3
Amy 15
Ben 19
Cara 17
17
```

### 예시 출력 1
```text
이름: Ben, 나이: 19
이름: Cara, 나이: 17
```

---

## 4. 힌트
- 구조체 배열을 순회하며 `if (arr[i].age >= cut)` 조건을 만족하는 요소를 선별하여 출력하세요.
