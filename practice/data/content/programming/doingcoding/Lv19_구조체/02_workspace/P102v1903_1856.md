# 03. [구조체-함수] 구조체 매개변수 전달

## 1. 문제 설명
학생 한 명의 이름과 나이를 입력받아 구조체에 저장한 후, 이 구조체 전체를 **출력 전용 함수/메서드의 매개변수(인자)** 로 전달하여 출력하는 프로그램을 작성하세요.

구조체는 개별 속성을 일일이 전달할 필요 없이 데이터 묶음 자체를 전달할 수 있어 함수와의 연동성이 매우 뛰어납니다.

![](svg_P102v1903_1856.svg)

---

## 2. 입출력 설명

* **입력:**
한 줄에 학생의 이름과 나이가 공백으로 구분되어 주어집니다.

* **출력:**
구조체를 매개변수로 전달받은 출력 함수 내부에서 `이름: [이름], 나이: [나이]` 형식으로 출력합니다.

### 🖥️ 예시 1 추적 (Ethan 14 입력 시)
```text
1. [메인 로직] 입력받은 "Ethan"과 14를 Student 구조체 변수 s에 저장합니다.
2. [함수 호출] printStudent(s)와 같이 구조체 변수를 인자로 하여 함수를 호출합니다.
3. [함수 내부 처리] 전달받은 매개변수의 멤버에 접근하여 "이름: Ethan, 나이: 14"를 출력합니다.
```

---

## 3. 예시
### 예시 입력 1
```text
Ethan 14
```

### 예시 출력 1
```text
이름: Ethan, 나이: 14
```

---

## 4. 힌트
- 구조체 타입 매개변수를 받는 함수를 정의합니다.
  - C / C++: `void printStudent(struct Student s)` 또는 `void printStudent(const Student& s)`
  - Java: `static void printStudent(Student s)`
  - Python: `def print_student(s):`
- 메인 로직에서 입력받은 구조체 변수를 생성 후 해당 함수의 인자로 전달하세요.
