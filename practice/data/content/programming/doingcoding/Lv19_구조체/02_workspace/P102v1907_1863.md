# 07. [구조체-배열] 특정 나이 이상 데이터 필터링

## 1. 문제 설명
$N$명의 사람 이름과 나이를 구조체 배열에 입력받아 저장합니다.
배열을 순회하며 나이가 **20세 이상**인 사람만 선별(필터링)하여 입력된 순서대로 출력하는 프로그램을 작성하세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 사람의 수 $N$이 주어집니다. ($1 \le N \le 100$)
이후 $N$개 줄에 걸쳐 각 사람의 이름과 나이가 공백으로 구분되어 주어집니다.

* **출력:**
나이가 20세 이상인 사람의 정보만 `이름: [이름], 나이: [나이]` 형식으로 출력합니다.
조건을 만족하는 사람이 없으면 아무것도 출력하지 않습니다.

---

## 3. 예시
### 예시 입력 1
```text
3
Amy 18
Ben 22
Cara 20
```

### 예시 출력 1
```text
이름: Ben, 나이: 22
이름: Cara, 나이: 20
```

---

## 4. 힌트
- 반복문 내부에서 `if (arr[i].age >= 20)` 조건식을 평가하여 조건에 부합할 때만 출력합니다.
