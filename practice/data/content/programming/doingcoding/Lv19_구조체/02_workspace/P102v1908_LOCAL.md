# 08. [구조체-수정] 구조체 배열 멤버 데이터 갱신

## 1. 문제 설명
구조체 배열에 저장된 특정 인덱스의 데이터 멤버 값을 런타임에 직접 수정(In-place Update)하는 연습을 합니다.

$N$명의 학생 이름과 점수를 구조체 배열에 입력받아 저장합니다.
이후 점수를 변경할 **학생 인덱스 $K$** (0-based)와 **가산점 $X$** 를 입력받아 `arr[K].score`에 $X$를 더해 갱신합니다.

마지막으로 최종 결과를 **확인할 학생 인덱스 $M$** 을 입력받아 해당 학생의 갱신된 정보를 출력하는 프로그램을 작성하세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 학생 수 $N$이 주어집니다. ($1 \le N \le 100$)
다음 $N$개 줄에 이름과 점수가 공백으로 주어집니다.
다음 줄에 점수를 수정할 인덱스 $K$와 가산점 $X$가 주어집니다. ($0 \le K < N$)
마지막 줄에 최종 조회할 인덱스 $M$이 주어집니다. ($0 \le M < N$)

* **출력:**
인덱스 $M$ 위치의 학생 정보를 `이름: [이름], 점수: [점수]` 형식으로 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
3
Amy 80
Ben 75
Cara 90
1 10
1
```

### 예시 출력 1
```text
이름: Ben, 점수: 85
```

---

## 4. 힌트
- 입력 완료 후 `arr[K].score += X;`를 실행하여 실제로 구조체 배열 멤버를 인플레이스로 수정합니다.
- 마지막에 `arr[M]`의 정보를 출력하세요.
- 단순히 출력할 때만 더하는 꼼수를 차단하고 실제 메모리 상의 구조체 객체 갱신을 수행해야 합니다.
