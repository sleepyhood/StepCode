# 09. [구조체-배열] 특정 이름 검색 및 연산

## 1. 문제 설명
$N$명의 사람 이름과 나이를 구조체 배열에 입력받은 후, 검색할 **대상 이름(Target Name)** 을 입력받습니다.

배열을 탐색하여 이름이 일치하는 사람의 정보를 찾아 출력하는 프로그램을 작성하세요. 일치하는 정보가 존재하면 해당 사람의 정보를 출력하고 검색을 종료합니다.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 사람의 수 $N$이 주어집니다. ($1 \le N \le 100$)
다음 $N$개 줄에 각 사람의 이름과 나이가 주어집니다.
마지막 줄에 검색할 대상 이름이 단어로 주어집니다.

* **출력:**
검색한 이름과 일치하는 사람의 정보를 `이름: [이름], 나이: [나이]` 형식으로 출력합니다.
일치하는 사람이 없으면 아무것도 출력하지 않습니다.

---

## 3. 예시
### 예시 입력 1
```text
3
Amy 18
Ben 22
Cara 20
Ben
```

### 예시 출력 1
```text
이름: Ben, 나이: 22
```

---

## 4. 힌트
- 문자열 비교 함수/메서드를 사용해 `arr[i].name`과 검색 대상 이름을 비교하세요.
  - C: `strcmp(arr[i].name, target) == 0`
  - C++: `arr[i].name == target`
  - Java: `arr[i].name.equals(target)`
  - Python: `arr[i].name == target`
