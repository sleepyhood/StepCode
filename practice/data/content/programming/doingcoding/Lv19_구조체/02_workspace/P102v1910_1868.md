# 10. [구조체-정렬] 도서 대출 횟수 기준 정렬

## 1. 문제 설명
도서 정보(제목, 대출 횟수)를 담는 구조체 배열을 $N$개 입력받아, **대출 횟수가 적은 순서(오름차순)** 로 구조체 객체 전체를 정렬하여 출력하는 프로그램을 작성하세요.

대출 횟수가 같다면 **먼저 입력된 순서(안정 정렬 / Stable Order)** 를 유지하세요.

두 구조체 객체를 교환할 때는 멤버 하나만 바편적으로 옮기지 않고 `temp = arr[i]; arr[i] = arr[j]; arr[j] = temp;`와 같이 **구조체 객체 전체를 통째로 교환(Struct In-place Swap)** 해야 도서 제목과 대출 횟수의 짝이 깨지지 않습니다.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 도서의 수 $N$이 주어집니다. ($1 \le N \le 100$)
이후 $N$개 줄에 걸쳐 도서 제목과 대출 횟수가 공백으로 주어집니다.

* **출력:**
대출 횟수가 적은 도서부터 제목과 대출 횟수를 공백으로 구분하여 한 줄에 하나씩 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
3
C언어기초 12
파이썬중급 5
알고리즘입문 8
```

### 예시 출력 1
```text
파이썬중급 5
알고리즘입문 8
C언어기초 12
```

---

## 4. 힌트
- 정렬 알고리즘(버블 정렬, 선택 정렬, 삽입 정렬 등)을 이용해 `arr[i].count > arr[j].count` 조건 만족 시 교환합니다.
- 교환할 때 구조체 타입의 임시 변수 `temp`를 사용하여 `temp = arr[i]; arr[i] = arr[j]; arr[j] = temp;`와 같이 통째로 교환해야 제목과 횟수 한 쌍이 함께 이동합니다.
