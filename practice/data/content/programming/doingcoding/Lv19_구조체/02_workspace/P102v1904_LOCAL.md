# 04. [구조체-함수] 구조체 반환 함수

## 1. 문제 설명
함수는 단일 기본 자료형뿐만 아니라 여러 정보가 담긴 **구조체 자체를 반환값(Return Value)** 으로 반환할 수 있습니다.

이름과 나이를 매개변수로 전달받아 내부에서 구조체 객체를 생성 및 초기화한 후, 이 구조체를 **반환(Return)** 하는 전용 생산업 함수(`createStudent`)를 구현하세요.

메인 로직에서는 이 함수의 반환값으로 구조체를 전달받아 화면에 출력합니다.

![](svg_P102v1904_LOCAL.svg)

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 학생의 이름과 나이가 공백으로 구분되어 주어집니다.

* **출력:**
`createStudent` 함수에서 반환받은 구조체 정보를 `이름: [이름], 나이: [나이]` 형식으로 출력합니다.

### 🖥️ 예시 1 추적
```text
1. [입력 받기] 이름 "Brian"과 나이 16을 입력받습니다.
2. [생성 함수 호출] s = createStudent("Brian", 16); 형태로 구조체 반환 함수를 호출합니다.
3. [함수 내부] 입력받은 데이터로 구조체를 초기화한 뒤 return 연산자로 구조체 객체를 반환합니다.
4. [결과 출력] 반환받은 변수 s의 멤버를 참조하여 "이름: Brian, 나이: 16"을 출력합니다.
```

---

## 3. 예시
### 예시 입력 1
```text
Brian 16
```

### 예시 출력 1
```text
이름: Brian, 나이: 16
```

---

## 4. 힌트
- 반환 타입이 구조체인 함수를 정의합니다.
  - C / C++: `struct Student createStudent(char* name, int age)` 또는 `Student createStudent(...)`
  - Java / C#: `static Student createStudent(String name, int age)`
  - Python: `def create_student(name, age): return Student(name, age)`
- 함수 내부에서 임시 구조체 변수를 선언하여 멤버를 채운 뒤 `return`하세요.
