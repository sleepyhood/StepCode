# 15. [구조체-배열] 수학 점수 최고자 찾기

## 1. 문제 설명
N명의 학생 이름과 수학 점수를 입력받아, 수학 점수가 가장 높은 학생의 정보를 출력하는 프로그램을 작성하세요.

점수가 같다면 먼저 입력된 학생을 출력하세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 학생 수 N이 주어집니다.

이후 N줄에 걸쳐 이름과 수학 점수를 입력받습니다.

* **출력:**
수학 점수가 가장 높은 학생의 이름과 점수를 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
3  
Amy 80  
Ben 95  
Cara 87
```

### 예시 출력 1
```text
이름: Ben, 점수: 95
```

---

## 4. 힌트
최고 점수와 해당 학생의 인덱스를 기억해두었다가 마지막에 출력하세요.
