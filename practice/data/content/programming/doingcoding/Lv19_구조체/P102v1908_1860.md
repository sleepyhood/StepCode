# 08. [구조체-비교] 더 두꺼운 책 제목 출력

## 1. 문제 설명
두 권의 책 제목과 페이지 수를 입력받고, 더 두꺼운 책의 제목을 출력하세요.

페이지 수가 같으면 먼저 입력된 책의 제목을 출력합니다.

---

## 2. 입출력 설명

* **입력:**
두 줄에 각각 책 제목과 페이지 수를 입력합니다.

* **출력:**
더 두꺼운 책의 제목을 한 줄에 출력합니다.

두 책의 페이지 수가 같다면 앞의 책을 출력해 주세요.

---

## 3. 예시
### 예시 입력 1
```text
BookA 320  
BookB 150
```

### 예시 출력 1
```text
BookA
```

---

## 4. 힌트
if 조건문으로 페이지 수를 비교한 뒤 제목만 출력하세요.
