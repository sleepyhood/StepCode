# 02. [배열] 소수형 배열변수 입력 후 출력

## 1. 문제 설명
10개의 소수를 저장할 수 있는 배열변수를 만들어서

10개의 데이터를 입력 및 저장하여

순서대로 출력합니다.

---

## 2. 입출력 설명

* **입력:**
10개의 소수가 입력됩니다.

* **출력:**
입력된 소수를 소수2자리까지 표시로 순서대로 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
47.76 56.82 48.16 40.14 4.95 11.26 20.56 46.53 96.99 8.6 
```

### 예시 출력 1
```text
47.76 56.82 48.16 40.14 4.95 11.26 20.56 46.53 96.99 8.60 
```
