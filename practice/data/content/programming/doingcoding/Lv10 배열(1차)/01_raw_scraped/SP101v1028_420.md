# 28. [배열+조건] 0이 입력되기 전까지의 입력된 정수의 개수 출력3

## 1. 문제 설명
최대 25개까지의 숫자가 입력됩니다.

첫번째 줄에는 0이 입력되기 전까지의 입력된 개수를 출력하고

두번째 줄에는 입력된 모든 수를 역순으로 출력합니다.

---

## 2. 입출력 설명

* **입력:**
하나의 정수 N이 입력되고(1이상 25이하)

N개수만큼 정수가 추가 입력됩니다.

* **출력:**
첫번째 줄에는 0이 입력되기 전까지의 입력된 개수를 출력하고

두번째 줄에는 입력된 모든 수를 역순으로 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
7
75 469 326 424 178 314 0 
```

### 예시 출력 1
```text
6
0 314 178 424 326 469 75 
```

### 예시 입력 2
```text
5
1 2 3 0 4
```

### 예시 출력 2
```text
3
4 0 3 2 1
```

### 예시 입력 3
```text
1
448
```

### 예시 출력 3
```text
1
448
```

### 예시 입력 4
```text
1
0
```

### 예시 출력 4
```text
0
0
```
