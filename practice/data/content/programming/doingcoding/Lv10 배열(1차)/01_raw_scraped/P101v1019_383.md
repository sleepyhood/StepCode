# 19. [배열-19] 정수형 배열변수 입력 후 두배로 저장하여 출력

## 1. 문제 설명
10개의 정수를 저장할 수 있는 배열변수를 만들어서

10개의 데이터를 입력받습니다.

입력받은 데이터를 2배로 다시 저장하여

순서대로 출력합니다.

---

## 2. 입출력 설명

* **입력:**
10개의 정수가 입력됩니다.

* **출력:**
입력된 정수를 2배로 다시 저장하여 순서대로 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
240 127 164 114 281 3 58 434 225 164 
```

### 예시 출력 1
```text
480 254 328 228 562 6 116 868 450 328 
```

---

## 4. 힌트
배열은 변수의 확장개념으로 많은 변수를 한번에 만들기 위함에 있습니다.

배열 변수를 정의하는 방법은

타입 변수이름[개수] = {초기값};

기본 변수에 숫자 또는 문자를 초기화 했다면

여러개의 변수를 묶어서 한번에 저장하기 때문에 중괄호 '{', '}'로 묶어서 초기화 합니다.

사용할때는 변수이름[index]

index는 0부터 카운트 됩니다. 배열은 자료가 많기 때문에 for 반복문을 사용하면 편합니다.

ex( printf("%d", arr[0]);
