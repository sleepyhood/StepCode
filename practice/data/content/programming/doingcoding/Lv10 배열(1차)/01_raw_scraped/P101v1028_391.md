# 28. [배열-28] 10개의 입력값중 특정 숫자의 위치를 출력

## 1. 문제 설명
10개의 정수를 입력받고

정수 n을 입력받아

첫번째 줄에는 정수n이 몇번째에 위치한지를 출력하고(순서는 1번부터 이며, 같은 숫자가 있다면 먼저 입력되는 번호 하나만 출력)

두번째 줄에는 입력한 모든 값을 출력합니다.

---

## 2. 입출력 설명

* **입력:**
10개의 정수가 입력되고

정수 N을 입력받습니다.

* **출력:**
첫번째 줄에는 정수n이 맨 처음 위치한 순번을 출력하고(순서는 1번부터이며, 같은 숫자가 있다면 먼저 입력되는 번호 하나만 출력)

두번째 줄에는 입력한 모든 값을 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
165 210 94 459 417 50 408 383 277 96 
417

```

### 예시 출력 1
```text
5
165 210 94 459 417 50 408 383 277 96 
```
