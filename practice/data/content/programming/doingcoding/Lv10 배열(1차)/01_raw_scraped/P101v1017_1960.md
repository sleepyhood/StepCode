# 17. [배열-17] 알파벳 5개 거꾸로 출력

## 1. 문제 설명
문자 5개를 입력받고, 입력된 알파벳을 거꾸로 출력하세요.

---

## 2. 입출력 설명

* **입력:**
문자 5개를 공백으로 입력합니다.

* **출력:**
입력된 문자를 거꾸로 한 줄에 하나씩 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
A B C D E
```

### 예시 출력 1
```text
E
D
C
B
A
```
