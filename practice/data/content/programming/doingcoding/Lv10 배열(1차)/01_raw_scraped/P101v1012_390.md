# 12. [배열-12] 10개의 입력값중 n번째의 값을 출력

## 1. 문제 설명
10개의 정수를 입력받고

정수 n을 입력받아

첫번째 줄에는 n번째 입력한 값을 출력하고(순서는 0번부터)

두번째 줄에는 입력한 모든 값을 출력합니다.

---

## 2. 입출력 설명

* **입력:**
10개의 정수가 입력되고

정수 N을 입력받습니다.(0이상 10미만)

* **출력:**
첫번째 줄에는 n번째 입력한 값을 출력하고,

두번째 줄에는 입력한 모든 값을 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
360 123 165 172 473 178 452 343 151 3 
7

```

### 예시 출력 1
```text
343
360 123 165 172 473 178 452 343 151 3 
```

### 예시 입력 2
```text
126 301 328 350 223 425 51 374 229 206 
0

```

### 예시 출력 2
```text
126
126 301 328 350 223 425 51 374 229 206 
```
