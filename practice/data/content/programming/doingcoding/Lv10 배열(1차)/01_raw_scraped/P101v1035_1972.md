# 35. [배열-35] 문자 'A'가 몇 개 있는지 세기

## 1. 문제 설명
문자 7개를 입력받고, 그 중 'A' 문자가 몇 번 등장했는지 출력하세요.

---

## 2. 입출력 설명

* **입력:**
문자 7개를 공백으로 입력합니다.

* **출력:**
'A' 문자의 개수를 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
A B C A D A E
```

### 예시 출력 1
```text
3
```

---

## 4. 힌트
'A'와 같은지 비교하여 개수를 세어보세요. 조건문과 누적 변수를 함께 사용하면 좋아요.
