# 10. [배열] 정수형 배열변수 입력 후 절반으로 나눈수를 저장하여 역순 출력

## 1. 문제 설명
10개의 정수를 저장할 수 있는 배열변수를 만들어서

10개의 데이터를 입력 및 저장하여

첫번째 줄에는 절반으로 나눈 수를 역순으로 출력하고

두번째 줄에는 원본데이터를 역순으로 출력합니다.

---

## 2. 입출력 설명

* **입력:**
10개의 정수가 입력됩니다.

* **출력:**
첫번째 줄에는 입력된 정수들의 절반을 역순으로 출력하고,

두번째 줄에는 원본데이터를 역순으로 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
23 430 349 333 165 135 421 208 52 346 
```

### 예시 출력 1
```text
173 26 104 210 67 82 166 174 215 11 
346 52 208 421 135 165 333 349 430 23 
```
