# 26. [배열-26] 인덱스와 값이 같은 숫자 출력

## 1. 문제 설명
정수 6개를 입력받고, 인덱스 번호와 같은 값을 출력하세요.

(예: arr[2] == 2)

---

## 2. 입출력 설명

* **입력:**
정수 6개를 공백으로 입력합니다.

* **출력:**
조건에 맞는 숫자를 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
0 1 2 4 7 5
```

### 예시 출력 1
```text
0
1
2
5
```

---

## 4. 힌트
반복문을 사용해 인덱스와 값이 같은 경우만 출력해보세요.
