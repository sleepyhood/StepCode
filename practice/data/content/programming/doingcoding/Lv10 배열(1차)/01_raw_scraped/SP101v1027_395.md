# 27. [배열] 0이 입력되기 전까지의 입력된 정수의 개수 출력2

## 1. 문제 설명
20개의 정수가 입력됩니다.

첫번째 줄에는 0이 입력되기 전까지의 입력된 개수를 출력하고

두번째 줄에는 입력된 모든 수를 순서대로 출력합니다.

! 0이 두번이상 입력됐을때는 처음 만나는 0을 기준으로 개수를 출력합니다.

---

## 2. 입출력 설명

* **입력:**
20개의 정수가 입력됩니다.(0이상 500이하)

* **출력:**
첫번째 줄에는 0이 입력되기 전까지의 개수를 출력하고,

두번째 줄에는 입력된 모든 값을 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
497 336 214 447 321 185 78 0 303 143 136 101 69 250 22 53 351 140 87 156 
```

### 예시 출력 1
```text
7

```

### 예시 입력 2
```text
405 40 22 225 339 495 358 369 205 169 0 356 475 27 0 101 185 363 138 459 
```

### 예시 출력 2
```text
10
```
