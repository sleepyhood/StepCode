# 32. [배열+인덱스카운트] 투표

## 1. 문제 설명
n명의 사람들이 투표를 합니다.

후보는 1, 2, 3 총 3개 입니다.

각 후보를 몇명이 뽑혔는지 계산해주세요.

---

## 2. 입출력 설명

* **입력:**
첫 줄에 n이 입력됩니다. (n은 1이상 10이하)

두 번째 줄에 n개 숫자가 입력됩니다. (각 숫자는 1, 2, 3 중 하나)

* **출력:**
출력 예시에 맞게 한 줄에 하나씩 1번부터 3번까지 각각의 후보가 몇번 뽑혔는지 출력해주세요.

---

## 3. 예시
### 예시 입력 1
```text
5
1 1 2 3 2
```

### 예시 출력 1
```text
1 : 2
2 : 2
3 : 1
```
