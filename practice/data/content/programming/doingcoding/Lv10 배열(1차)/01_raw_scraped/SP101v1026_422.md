# 26. [배열+탐색] n개의 입력값중 가장 작은 값의 위치를 출력

## 1. 문제 설명
처음 숫자 N을 입력받아(N은 1이상 25이하)

N개의 정수를 추가로 입력받은 후

첫번째 줄에는 가장 작은 값이 몇번째 입력됬는지 위치를 출력합니다.

두번째 줄에는 입력받은 모든 수를 역순으로 출력합니다.

---

## 2. 입출력 설명

* **입력:**
하나의 정수 N이 입력되고(1이상25이하)

N개수만큼 정수가 추가 입력됩니다.

* **출력:**
첫번째 줄에는 가장 작은 숫자의 위치값을 출력하고,

(첫번째 데이터를 0번째로 정합니다.)

두번째 줄에는 입력한 모든 값을 역순으로 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
16
178 136 295 110 136 71 2 301 183 411 109 267 367 139 64 307 
```

### 예시 출력 1
```text
6
307 64 139 367 267 109 411 183 301 2 71 136 110 295 136 178 
```
