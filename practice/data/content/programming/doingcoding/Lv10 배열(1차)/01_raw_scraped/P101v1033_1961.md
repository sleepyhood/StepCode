# 33. [배열-33] 숫자 0이 몇 번 나왔는지 세기

## 1. 문제 설명
정수 8개를 입력받고, 그 중 0이 몇 번 나왔는지 출력하세요.

---

## 2. 입출력 설명

* **입력:**
정수 8개를 공백으로 입력합니다.

* **출력:**
숫자 0의 개수를 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
0 1 0 3 4 0 6 0
```

### 예시 출력 1
```text
4
```

---

## 4. 힌트
입력받은 수들을 배열에 저장한 뒤, 반복문과 조건문을 이용해 0의 개수를 세어보세요.
