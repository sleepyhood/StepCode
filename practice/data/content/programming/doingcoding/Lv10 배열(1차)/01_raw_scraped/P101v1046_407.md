# 46. [배열-46] 학생들의 성적표에서 학점별 인원수는 몇명일까요?

## 1. 문제 설명
학점은 A, B, C, D, F 5개의 종류가 있습니다.

15명의 학생들의 학점을 입력받고,

학점별 학생수를 출력해주세요

---

## 2. 입출력 설명

* **입력:**
15개의 (알파벳 A, B, C, D, F 중 하나) 학점 데이터가 입력됩니다.

* **출력:**
각 줄마다 A, B, C, D, F의 학생수를 표시합니다.

---

## 3. 예시
### 예시 입력 1
```text
F D D F B C A C B D F C D F F 
```

### 예시 출력 1
```text
A : 1
B : 2
C : 3
D : 4
F : 5

```

### 예시 입력 2
```text
C C A F B B A C F C C B B A D 
```

### 예시 출력 2
```text
A : 3
B : 4
C : 5
D : 1
F : 2
```

### 예시 입력 3
```text
B A D B F D D A B B B D B D B 
```

### 예시 출력 3
```text
A : 2
B : 7
C : 0
D : 5
F : 1
```
