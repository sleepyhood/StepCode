# 12. [배열+인덱스] 5개의 정수형 배열 입력값을 입력 후 입력되는 숫자가 저장된 인덱스 번호를 출력

## 1. 문제 설명
정수형 배열에 숫자 5개를 입력받습니다.

다음 줄에 숫자 x가 입력됩니다.

숫자 x가 저장된 위치를 전부 출력해주세요.

---

## 2. 입출력 설명

* **입력:**
첫 줄에 숫자 5개가 입력됩니다. (숫자는 -1000이상 1000이하의 정수)

다음 줄에 숫자 x가 입력됩니다. (x는 -1000이상 1000이하의 정수)

* **출력:**
숫자 x가 저장된 위치를 한 줄에 하나씩 전부 출력해 주세요.

숫자 x가 없을 수도 있습니다.

---

## 3. 예시
### 예시 입력 1
```text
9 8 7 6 5
5
```

### 예시 출력 1
```text
4
```

### 예시 입력 2
```text
1 1 1 1 1
1
```

### 예시 출력 2
```text
0
1
2
3
4
```
