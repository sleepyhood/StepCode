# 08. [배열] n개의 입력값중 마지막 3개 역순으로 출력2

## 1. 문제 설명
처음 숫자 N을 입력받아(N은 1이상 25이하)

N개의 정수를 추가로 입력받은 후(0이상 10250이하)

첫번째 줄에는 0이 입력되기 전까지의 마지막의 3개를 역순으로 출력합니다.

만약 입력된 수가 2개 이하일경우는 모두 출력합니다.

두번째 줄에는 입력받은 모든 수를 역순으로 출력합니다.

---

## 2. 입출력 설명

* **입력:**
하나의 정수 N이 입력되고(1이상 25이하)

N개수만큼 정수가 추가 입력됩니다.

* **출력:**
N개의 정수들 중에서 첫번째 줄에는 0이 입력되기 전까지의 마지막 3개만 역순으로 출력합니다.

단 2개 이하일 경우 모두 역순으로 출력하고,

두번째 줄에는 입력받은 모든 수를 역순으로 출력합니다.

첫째줄 마지막에는 띄어쓰기가 포함되어야 합니다.
