# 27. [배열-27] 문자형 배열변수 입력 후 모두 소문자로 출력1

## 1. 문제 설명
10개의 문자를 저장할 수 있는 배열변수를 만들어서

10개의 문자데이터를 입력받아 저장한 후

소문자로 변경하여 출력합니다.

---

## 2. 입출력 설명

* **입력:**
대문자 10개가 입력됩니다.

* **출력:**
소문자로 변경하여 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
 Q Z S F R X P J M S 
```

### 예시 출력 1
```text
q z s f r x p j m s 
```
