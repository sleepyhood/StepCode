# 24. [배열-24] n개의 입력값중 홀수번째 입력값의 합 출력

## 1. 문제 설명
처음 숫자 N을 입력받아(N은 1이상 25이하)

N개의 정수를 추가로 입력받은 후

첫번째 줄에는 홀수번째 입력값의 합을 출력합니다.

처음 입력하는 숫자를 첫번째(1번째)라고 정합니다.

두번째 줄에는 입력받은 모든 수를 출력합니다.

---

## 2. 입출력 설명

* **입력:**
하나의 정수 N이 입력되고(1이상 25이하)

N개수만큼 정수가 추가 입력됩니다.

* **출력:**
N개의 정수들 중에서 첫번째 줄에는 홀수번째(첫번째 데이터를 1번째로정합니다.) 입력값의 합을 출력하고,

두번째 줄에는 입력받은 모든 수를 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
20
210 143 280 63 54 419 58 407 140 315 83 92 143 367 224 280 204 393 53 364 
```

### 예시 출력 1
```text
1449
210 143 280 63 54 419 58 407 140 315 83 92 143 367 224 280 204 393 53 364 
```

### 예시 입력 2
```text
3
381 188 442 
```

### 예시 출력 2
```text
823
381 188 442 
```
