# 18. [배열-18] 소수형 배열변수 입력 후 역순 출력

## 1. 문제 설명
10개의 소수를 저장할 수 있는 배열변수를 만들어서

10개의 데이터를 입력 및 저장하여

역순으로 출력합니다.

---

## 2. 입출력 설명

* **입력:**
10개의 소수가 입력됩니다.

* **출력:**
입력된 소수10개를 소수 2자리까지 역순으로 출력해주세요.

---

## 3. 예시
### 예시 입력 1
```text
32.33 38.75 29.80 62.94 9.34 11.9 7.43 99.61 0.10 16.41 
```

### 예시 출력 1
```text
16.41 0.10 99.61 7.43 11.90 9.34 62.94 29.80 38.75 32.33 
```

---

## 4. 힌트
배열은 변수의 확장개념으로 많은 변수를 한번에 만들기 위함에 있습니다.

배열 변수를 정의하는 방법은

타입 변수이름[개수] = {초기값};

기본 변수에 숫자 또는 문자를 초기화 했다면

여러개의 변수를 묶어서 한번에 저장하기 때문에 중괄호 '{', '}'로 묶어서 초기화 합니다.

사용할때는 변수이름[index]

index는 0부터 카운트 됩니다. 배열은 자료가 많기 때문에 for 반복문을 사용하면 편합니다.

ex( printf("%d", arr[0]);
