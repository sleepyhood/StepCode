# 22. [배열+인덱스+평균] n개의 입력값중 짝수들의 입력값의 합계와 짝수번째 입력값의 평균 출력

## 1. 문제 설명
처음 숫자 N을 입력받아(N은 1이상 25이하)

N개의 정수를 추가로 입력받은 후

첫번째 줄에는 짝수들의 입력값의 합계와

두번째 줄에는 짝수번째 입력값의 평균을 출력하고,

새번째 줄에는 입력받은 모든 수를 역순으로 출력합니다.

---

## 2. 입출력 설명

* **입력:**
하나의 정수 N이 입력되고(1이상 25이하)

N개수만큼 정수가 추가 입력됩니다.

* **출력:**
첫번째 줄에는 짝수들의 입력값의 합계와

두번째 줄에는 짝수번째 입력값의 평균을 출력하고,

새번째 줄에는 입력받은 모든 수를 역순으로 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
5
295 62 423 93 498 
```

### 예시 출력 1
```text
560
77
498 93 423 62 295 
```

### 예시 입력 2
```text
1
220 
```

### 예시 출력 2
```text
220
0
220 
```
