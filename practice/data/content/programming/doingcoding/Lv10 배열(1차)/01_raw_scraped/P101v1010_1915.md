# 10. [배열-10] 문자 3개 입력 후 출력하기

## 1. 문제 설명
문자 3개를 입력받아 배열에 저장하고, 입력된 순서대로 출력하세요.

반복문 없이 작성하세요.

---

## 2. 입출력 설명

* **입력:**
문자 3개를 공백으로 입력합니다.

* **출력:**
입력된 순서대로 한 줄에 하나씩 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
X Y Z

```

### 예시 출력 1
```text
X
Y
Z
```
