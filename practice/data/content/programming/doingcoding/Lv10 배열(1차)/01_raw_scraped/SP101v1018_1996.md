# 18. [배열+인덱스] 10개의 문자형 배열이 입력되면 짝수번째 입력값만 출력

## 1. 문제 설명
첫 줄에 문자 10개가 입력됩니다.

입력된 문자 중 짝수번째 입력된 문자들을 출력해주세요.

---

## 2. 입출력 설명

* **입력:**
한 줄에 문자 10개가 입력됩니다. (각 문자는 대소문자 알파벳)

* **출력:**
한 줄에 홀수번째 입력된 문자들만 공백으로 구분하여 출력해주세요.

---

## 3. 예시
### 예시 입력 1
```text
A a B b C c D d E e
```

### 예시 출력 1
```text
a b c d e
```
