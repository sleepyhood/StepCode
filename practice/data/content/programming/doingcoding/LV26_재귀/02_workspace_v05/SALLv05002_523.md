# 02. [재귀1 - 2] 팩토리얼 계산

## 1. 문제 설명
팩토리얼(!)은 다음과 같이 정의됩니다.

n! = n \* (n-1) \* (n-2) \* ...2 \* 1

즉, 5! =  5 \* 4 \* 3 \* 2 \* 1 = 120입니다.

n이 입력되면 n!의 값을 출력합니다.

---

## 2. 입출력 설명

* **입력:**
자연수 n이 입력됩니다. ($n \le 12$)

* **출력:**
n!의 값을 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
5
```

### 예시 출력 1
```text
120
```
