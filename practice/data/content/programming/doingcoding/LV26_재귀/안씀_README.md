	# lv26. 재귀 (Recursion) 과정 가이드

이 단원은 **재귀(Recursion)**를 기초부터 심화까지 단계별로 학습할 수 있도록 구성되어 있습니다.
단순히 함수가 자신을 호출하는 것을 넘어, 실행 흐름의 중첩(Stack)과 상태 공간의 탐색(Branching)을 익히는 것이 목표입니다.

> **파일 명명 규칙**: `dc_ALLvXXXXX` (수업) / `dc_SALLvXXXXX` (숙제)  
> **`legacy_id`**: 이전 버전 파일명 또는 외부 출처 (`bj_*`: 백준, `dc_P301*`: 기존 시스템)

## 3. 학습 경로 요약

```
[v05] 선형 재귀 (Set 01~10)    → 반복문의 재귀 변환, 호출 전/후 시점 이해
[v05] 데이터 변환 (Set 11~13)  → 진법 변환, 문자열 역순 (실용적 적용)
[v05] 탐색 도입 (Set 14~15)    → 상태 공간 생성 첫 경험, 복잡도 인식
       ↓
[v10] 다중 분기 (Set 01~02)    → N갈래 재귀 호출 구조 이해
[v10] 프랙탈 구조 (Set 03~04)  → 1D 대칭 → 2D 쿼드트리 공간 분할
[v10] 상태 탐색 (Set 05~08)    → 제약 조건과 조합론 기초
[v10] 격자 탐색 (Set 09~10)    → 백트래킹 단원의 직접적 선수 학습
       ↓
[lv29] 백트래킹 단원으로 연계
```

> [!TIP]
> `v10 Set 09~10`을 마치면 **lv29. 백트래킹** 단원의 유망성 검사(Pruning)와 방문 배열(`visited`)을 활용한 상태 관리 기법을 배울 준비가 완료됩니다.
