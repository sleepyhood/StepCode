# 12. [재귀1 - 12] 재귀적 문자열 포장

## 1. 문제 설명
문자열 $S$가 주어지면, 재귀 함수를 이용해 문자열의 중심을 향해 파고들며 괄호로 감싸는 '포장지' 구조를 출력해 봅시다.

이 문제는 재귀 함수가 호출되기 **전**에 실행되는 코드와, 호출된 **후**에 실행되는 코드가 어떻게 대칭을 이루는지 이해하는 것이 핵심입니다.

**규칙:**
1. 문자열의 첫 번째 문자부터 시작하여 안쪽으로 들어갈 때마다 해당 문자를 출력하고 바로 `(`를 추가합니다.
2. 문자열의 **마지막 문자**에 도달하면 괄호 없이 그 문자만 출력하고 재귀를 종료(반환)합니다.
3. 재귀가 종료되어 돌아 나올 때마다 `)`를 출력하고 해당 문자를 다시 한번 출력합니다.

---

## 2. 입출력 설명

* **입력:**
공백이 없는 영어 소문자 문자열이 입력됩니다. (문자열의 길이는 1 이상 100 이하입니다.)

* **출력:**
규칙에 따라 포장된 문자열을 한 줄에 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
apple
```

### 예시 출력 1
```text
a(p(p(l(e)l)p)p)a
```

### 예시 입력 2
```text
code
```

### 예시 출력 2
```text
c(o(d(e)d)o)c
```

### 예시 입력 3
```text
a
```

### 예시 출력 3
```text
a
```
