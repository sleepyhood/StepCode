# 05. [재귀1 - 5] 2진수 변환

## 1. 문제 설명
어떤 10진수 n이 주어지면 2진수로 변환해서 출력하세요.

예시:
```
10 ----> 1010  
0 ----> 0  
1 ----> 1  
2 ----> 10  
1024 ----> 10000000000
```

---

## 2. 입출력 설명

* **입력:**
10진수 정수 n이 입력됩니다. ($0 \le n \le 2,000,000,000$)

* **출력:**
2진수로 변환해서 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
7
```

### 예시 출력 1
```text
111
```
