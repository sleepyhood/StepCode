# 04. [재귀1 - 4] 팩토리얼 계산

## 문제 설명
팩토리얼(!)은 다음과 같이 정의된다.

n! = n \* (n-1) \* (n-2) \* ...2 \* 1

즉, 5! =  5 \* 4 \* 3 \* 2 \* 1 = 120이다.

n이 입력되면 n!의 값을 출력하시오.

## 입력
자연수 n이 입력된다. (n <=12)

## 출력
n!의 값을 출력한다.

## 예제 입출력
### 예제 1
- **입력**: 
```text
5
```
- **출력**: 
```text
120
```
