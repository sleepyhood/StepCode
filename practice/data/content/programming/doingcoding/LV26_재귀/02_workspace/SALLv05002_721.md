# 02. [재귀1 - 2] 두 수 사이의 짝수 출력하기

## 1. 문제 설명
시작수(a)와 마지막 수(b)가 입력되면

시작수와 마지막수 까지의 모든 짝수를 출력하세요.

---

## 2. 입출력 설명

* **입력:**
두 정수 a, b가 입력됩니다. ($0 \le a \le b \le 100$)

* **출력:**
a~b사이의 모든 짝수를 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
2 7
```

### 예시 출력 1
```text
2 4 6 
```
