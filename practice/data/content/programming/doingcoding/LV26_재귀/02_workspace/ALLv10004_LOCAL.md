# 04. [재귀2 - 4] 프랙탈 십자 그리기

## 1. 문제 설명

지금까지 재귀를 이용해 **1차원 문자열**을 만들었습니다.

이번에는 재귀를 **2차원 격자(Grid)**에 적용해 봅시다.

다음 규칙으로 만들어지는 격자 패턴을 생각해 봅시다.

**$k = 1$ 일 때** ($3 \times 3$ 격자):
```
.+.
+++
.+.
```

**$k = 2$ 일 때** ($7 \times 7$ 격자):
```
.+..+..
+++.+++
.+..+..
+++++++
.+..+..
+++.+++
.+..+..
```

**$k = 3$ 일 때** ($15 \times 15$ 격자):
```
.+..+...+..+...
+++.+++.+++.+++
.+..+...+..+...
+++++++.+++++++
.+..+...+..+...
+++.+++.+++.+++
.+..+...+..+...
+++++++++++++++
.+..+...+..+...
+++.+++.+++.+++
.+..+...+..+...
+++++++.+++++++
.+..+...+..+...
+++.+++.+++.+++
.+..+...+..+...
```

### 규칙

격자의 크기 $N = 2^k - 1$ 입니다.

`draw(row_start, col_start, size)` 함수는 다음과 같이 동작합니다:
1. **기저 조건**: 크기가 `1`이면 더 이상 나눌 수 없으므로 아무것도 하지 않고 종료합니다.
2. 현재 영역의 **중앙 행 전체**를 `+`로 채웁니다.
3. 현재 영역의 **중앙 열 전체**를 `+`로 채웁니다.
4. 4개의 절반 크기(`size / 2`) 서브 영역에 대해 재귀 호출합니다.

---

## 2. 입출력 설명

* **입력:**
단계를 나타내는 정수 $k$가 입력됩니다. ($1 \le k \le 4$)

* **출력:**
크기 $N = 2^k - 1$ 인 격자 패턴을 $N$개의 줄로 출력합니다.
`+` 는 선이 그어진 칸, `.` 는 빈 칸을 나타냅니다.

---

## 3. 예시

### 예시 입력 1
```text
1
```

### 예시 출력 1
```text
.+.
+++
.+.
```

### 예시 입력 2
```text
2
```

### 예시 출력 2
```text
.+..+..
+++.+++
.+..+..
+++++++
.+..+..
+++.+++
.+..+..
```

---

## 4. 힌트

* 격자를 `char grid[N][N]`으로 선언하고, 먼저 전부 `.`으로 초기화하세요.
* `draw` 함수는 현재 담당하는 영역의 **시작 행/열 좌표**와 **크기**를 인자로 받습니다.
* 중앙의 행/열 인덱스는 `row_start + size / 2`, `col_start + size / 2` 입니다.
* 서브 영역의 크기는 `size / 2` 이며, 4개의 서브 영역 시작 좌표를 잘 계산하세요.
