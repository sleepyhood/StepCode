# 04. [재귀1 - 4] 1부터 n까지 합 구하기

## 문제 설명
정수 n이 입력으로 들어오면 1부터 n까지의 합을 구하시오.

## 입력
입력으로 자연수 n이 입력됩니다.(n은 1이상 10,000이하)

## 출력
1부터 n까지의 합을 출력한다.

## 예제 입출력
### 예제 1
- **입력**: 
```text
100
```
- **출력**: 
```text
5050
```
