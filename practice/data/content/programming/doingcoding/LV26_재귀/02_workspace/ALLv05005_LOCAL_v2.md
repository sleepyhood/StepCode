# 06. [재귀1 - 6] 10진수를 N진수로 변환하기

---

## 1. 핵심 아이디어 — 나머지를 거꾸로 읽는다

> 진법 변환 = 나누기를 반복 → **나머지를 아래에서 위로** 읽기

`10`을 2진수로 바꾸는 과정을 직접 써보면 다음과 같다.

```
  2 )  10
     -----
  2 )   5  ··· 0   ↑
     -----         │
  2 )   2  ··· 1   │  거꾸로 올라가며 읽음
     -----         │
  2 )   1  ··· 0   │
     -----         │
        0  ··· 1   │  ← 여기서 멈춤 (몫 = 0)
```

나머지가 생기는 순서(위→아래)와 읽어야 하는 순서(아래→위)가 **정반대**다.  
이게 이 문제의 핵심 난관이다.

- **반복문으로 구현하면?** → 나머지를 배열에 담았다가 뒤집어서 출력해야 한다.  
- **재귀로 구현하면?** → 함수 호출 스택이 알아서 순서를 뒤집어준다. 코드가 훨씬 짧아진다.

---

## 2. 왜 순서가 뒤집히나? — 전위 vs 후위

재귀 함수는 호출될 때마다 현재 상태를 **스택에 저장**하고 안으로 들어간다.  
`printf`를 어디에 두느냐에 따라 실행 시점이 달라진다.

### ⚠️ 전위 출력 — 먼저 출력, 나중에 호출 (잘못된 구조)

```c
void toBase(int n, int k) {
    if (n == 0) return;
    printf("%d", n % k);  // 출력이 먼저!
    toBase(n / k, k);
}
```

![전위 호출 시 출력 결과](image-19.png)

`10 → 5 → 2 → 1` 순서로 들어가며 나머지를 바로 찍기 때문에,  
**위에서 아래** 순서로 출력 → `0101` (뒤집힘)

---

### ✅ 후위 출력 — 먼저 호출, 돌아오면서 출력 (올바른 구조)

```c
void toBase(int n, int k) {
    if (n == 0) return;
    toBase(n / k, k);     // 호출이 먼저!
    printf("%d", n % k);  // 돌아오면서 출력
}
```

![후위 호출 시 흐름도](image-18.png)

`1 → 2 → 5 → 10` 순서로 **돌아 나오면서** 나머지를 출력하기 때문에,  
자동으로 역순이 되어 → `1010` (정상)

> 재귀 함수가 끝났다고 사라지는 게 아니다. **자신을 호출한 함수로 돌아가는 것**이다. 이 '돌아가는 경로'에서 `printf`가 실행된다.

---

## 3. 코드 — 완성본

```c
void toBase(int n, int k) {
    if (n == 0) return;          // [종료 조건] 몫이 0이 되면 더 이상 나눌 게 없음
    toBase(n / k, k);            // [내려가기] 몫을 가지고 재귀 호출 → 스택에 쌓임
    printf("%d", n % k);         // [돌아오기] 스택에서 꺼내며 나머지 출력
}
```

![코드와 호출 스택 매핑](image-20.png)

코드 두 줄의 순서가 이 문제의 전부다.

| 줄 | 역할 | 대응 동작 |
|----|------|-----------|
| `toBase(n / k, k)` | 더 깊이 들어가기 | 나눗셈표에서 한 칸 아래로 |
| `printf("%d", n % k)` | 돌아오면서 출력 | 나눗셈표를 아래에서 위로 읽기 |

> **`printf` 한 줄의 위치**가 결과를 완전히 바꾼다. 호출 전이냐, 후냐.

---

## 4. 입출력

- **입력:** 정수 $n$, $k$ (공백 구분) — $0 \le n \le 10{,}000$, $2 \le k \le 9$
- **출력:** $n$을 $k$진수로 변환한 값

| 입력 | 출력 |
|------|------|
| `10 2` | `1010` |
| `25 8` | `31` |

---

## 5. 주의사항

### `n = 0` 입력 처리
`toBase(0, k)`는 조건 `n == 0`에서 즉시 `return` → **화면에 아무것도 출력되지 않는다.**  
이 문제에서는 `0 ≤ n`이지만, 실제로 `0`이 들어오면 빈 출력이 된다.  
필요하다면 `main`에서 먼저 처리해야 한다.

```c
if (n == 0) printf("0");  // main에서 예외 처리 예시
else toBase(n, k);
```

### `printf` 위치 실수
가장 흔한 실수. 코드를 짜다 보면 습관적으로 `printf`를 먼저 쓰게 된다.  
출력이 뒤집혀 나온다면 → **2번 섹션**으로 돌아가서 전위/후위 비교를 다시 확인.
