# 03. [재귀2 - 3] 알파벳 트리

## 1. 문제 설명

지금까지 배운 재귀는 한 방향으로만 파고들었습니다.
예를 들어 `f(n)` 이 `f(n-1)` 을 호출하는 방식으로 말이죠.

이번에는 하나의 재귀 함수 안에서 **자신을 두 번** 호출하는 구조를 배워봅시다.

다음 규칙으로 만들어지는 문자열을 생각해 봅시다.

```
깊이 1:      A
깊이 2:    A B A
깊이 3:  A B A C A B A
깊이 4: A B A C A B A D A B A C A B A
```

규칙을 살펴보면, 깊이 $N$의 문자열은 다음과 같이 만들어집니다:

> **깊이 N의 문자열 = 깊이 (N-1)의 문자열 + N번째 알파벳 + 깊이 (N-1)의 문자열**

이 구조를 코드로 표현하면 다음과 같습니다:

```
print_tree(N-1);    // 왼쪽 절반
print 'A' + (N-1); // 중심 알파벳
print_tree(N-1);    // 오른쪽 절반 (왼쪽과 동일)
```

N이 주어지면 깊이 N의 알파벳 트리 문자열을 출력하는 프로그램을 작성하세요.

---

## 2. 입출력 설명

* **입력:**
깊이를 나타내는 정수 $N$이 입력됩니다. ($1 \le N \le 16$)

* **출력:**
깊이 $N$의 알파벳 트리 문자열을 한 줄에 출력합니다.
알파벳 사이에는 공백을 출력하지 않습니다.

---

## 3. 예시

### 예시 입력 1
```text
1
```

### 예시 출력 1
```text
A
```

### 예시 입력 2
```text
2
```

### 예시 출력 2
```text
ABA
```

### 예시 입력 3
```text
3
```

### 예시 출력 3
```text
ABACABA
```

---

## 4. 힌트

* 기저 조건(Base Case)은 `N == 0` 일 때 아무것도 출력하지 않고 바로 반환하는 것입니다.
* `N`번째 알파벳은 `'A' + N - 1` 로 구할 수 있습니다. (`N=1` → `'A'`, `N=2` → `'B'`, ...)
* 재귀 호출이 두 번 일어날 때, 깊이 $N$의 문자열 길이는 $2^N - 1$ 이 됩니다. ($N=4$ → 15자)
