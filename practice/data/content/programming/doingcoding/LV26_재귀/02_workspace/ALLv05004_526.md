# 04. [재귀1 - 4] 우박수 (3n+1)

## 1. 문제 설명

이전에 while을 사용하여 콜라츠의 추측을 배운 적이 있습니다.

콜라츠의 추측, 3n +1 문제, 우박수 문제라고 불리는 문제는 다음과 같습니다.

1. 어떤 자연수 n이 입력되면,(n이 1이면 출력하고 끝남)

2. n이 홀수이면 3n+1을 하고,

3. n이 짝수이면 n/2를 한다.

4. 4.이 n이 1이 될때까지 2 3 과정을 반복한다.

예를 들어 5는 `5 -> 16 -> 8 -> 4 -> 2 -> 1`이 됩니다.

이처럼 어떤 자연수 n이 입력되면 위 알고리즘에 의해 1이 되는 과정을 모두 출력하세요.

---

## 2. 입출력 설명

* **입력:**
자연수 n이 입력된다.($1 \le n \le 10$)

단 `3n+1`이 되는 과정에서 `int` 범위를 넘는 수는 입력으로 주어지지 않는다.

* **출력:**
`3n+1`의 과정을 출력한다.
