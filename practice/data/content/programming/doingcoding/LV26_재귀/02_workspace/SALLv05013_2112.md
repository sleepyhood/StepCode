# 13. [재귀1 - 13] 9진수

## 1. 문제 설명
10진수를 9진수로 바꾸자

---

## 2. 입출력 설명

* **입력:**
첫째 줄에 10진수 T가 주어진다. (1<=T<=10,000)

* **출력:**
T를 9진수로 변환한 수를 출력한다.

---

## 3. 예시
### 예시 입력 1
```text
100
```

### 예시 출력 1
```text
121
```
