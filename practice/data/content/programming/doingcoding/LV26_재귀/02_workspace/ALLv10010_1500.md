# 10. [재귀2 - 10] 이상한 주사위

## 1. 문제 설명
이상한 주사위가 있습니다.

이상한 주사위는 정육면체지만 각 면의 숫자가 일반적인 정육면체 주사위와는 조금 다른 주사위 입니다.

주사위의 각 면에 쓰여진 숫자 6개와 주사위를 던진 횟수 n이 주어지면

주사위를 n번 던졌을 때 나온 합 중, 제일 자주 나오는 숫자를 출력해주세요.

나오는 횟수가 똑같더라면 큰 숫자를 출력해주세요.

주사위는 정육면체인 만큼 각 숫자가 나오는 횟수는 모두 같습니다.

---

## 2. 입출력 설명

* **입력:**
첫 줄에 주사위 6면에 쓰여있는 숫자 6개가 입력됩니다.(각 숫자는 1 이상 10 이하)

두 번째 줄에 주사위를 던진 횟수 n이 입력됩니다. (n은 1이상 10이하)

* **출력:**
주사위를 n회 던져서 나온 합 중 가장 자주 나오는 합을 출력해주세요.

빈도가 같다면 그중 가장 큰 수를 출력해주세요.

---

## 3. 예시
### 예시 입력 1
```text
6 1 6 8 5 3 
2
```

### 예시 출력 1
```text
11
```

### 예시 입력 2
```text
8 7 7 2 5 3 
1
```

### 예시 출력 2
```text
7
```

## 4. 힌트
예시 1번의 해석으로

6면체의 주사위를 2번씩 던지면 나올 수 있는 경우의 수는 36번 입니다.

그중 합의 가장 많이 나온 숫자는 5번 나온 11입니다.

(6 + 6) = 12, (6 + 1) =  7, (6 + 6) = 12, (6 + 8) = 14, (6 + 5) = 11, (6 + 3) =  9, // 11이 1번

(1 + 6) =  7, (1 + 1) =  2, (1 + 6) =  7, (1 + 8) =  9, (1 + 5) =  6, (1 + 3) =  4, // 11이 0번

(6 + 6) = 12, (6 + 1) =  7, (6 + 6) = 12, (6 + 8) = 14, (6 + 5) = 11, (6 + 3) =  9, // 11이 1번

(8 + 6) = 14, (8 + 1) =  9, (8 + 6) = 14, (8 + 8) = 16, (8 + 5) = 13, (8 + 3) = 11, // 11이 1번

(5 + 6) = 11, (5 + 1) =  6, (5 + 6) = 11, (5 + 8) = 13, (5 + 5) = 10, (5 + 3) =  8, // 11이 1번

(3 + 6) =  9, (3 + 1) =  4, (3 + 6) =  9, (3 + 8) = 11, (3 + 5) =  8, (3 + 3) =  6, // 11이 1번
