# 03. [재귀1 - 3] 재귀 챗봇

## 1. 문제 설명
인공지능 챗봇에게 "재귀함수가 뭔가요?"라고 물었습니다.

챗봇은 답하기 위해 깊이 생각할수록 **같은 질문을 스스로에게 다시 던집니다.** 이 과정이 $N$번 반복되면 챗봇은 드디어 결론을 내리고, 다시 밖으로 나오며 차례로 답변을 마무리합니다.

재귀가 한 단계 깊어질 때마다 문장 앞에 `____` (언더바 4개)를 추가로 붙여 출력합니다.

출력 규칙은 다음과 같습니다:
- 각 단계(깊이 $d$) 시작: `____` × $d$ + `"잘 들어보게. 옛날옛날 한 산 꼭대기에 선인이 있었어."`
- 마지막 단계(깊이 $N$): `____` × $N$ + `"재귀함수는 자기 자신을 호출하는 함수라네."`
- 각 단계 종료 시(되돌아올 때): `____` × $d$ + `"라고 답변하였지."`

---

## 2. 입출력 설명

* **입력:**
재귀 깊이 $N$이 입력됩니다. ($1 \le N \le 50$)

* **출력:**
아래 예시를 참고하여 챗봇의 응답을 출력합니다.
첫 줄은 들여쓰기 없이 항상 다음 문장으로 시작합니다:
```
어느 한 학생이 챗봇에게 물었다.
"재귀함수가 뭔가요?"
```

2

그 선인에게 한 제자가 찾아와서 물었어."

____마을 사람들은 모두 그 선인에게 수많은 질문을 했고, 모두 지혜롭게 대답해 주었지.

## 4. 힌트
`depth` (현재 깊이)를 재귀 함수의 매개변수로 전달하세요.
문장을 출력하기 전, `depth`만큼 `____`를 반복 출력하는 방법을 먼저 떠올려 보세요.

```text
함수 바_출력(현재_깊이):
    반복문 i를 0부터 현재_깊이까지:
        "____"를 출력한다 (줄바꿈 없이)
```

재귀 호출 **전**에 "잘 들어보게..." 문장을 출력하고,  
재귀 호출 **후**에 "라고 답변하였지."를 출력하는 것이 핵심입니다.
