# 04. [재귀1 - 4] 우박수 (3n+1)(reverse)

## 1. 문제 설명
콜라츠의 추측, 3n +1 문제, 우박수 문제라고 불리는 문제는 다음과 같습니다.

```
1. 어떤 자연수 n이 입력되면,  

2. n이 홀수이면 3n+1을 하고,  

3. n이 짝수이면 n/2를 합니다.  

4. 이 n이 1이 될때까지 2 3 과정을 반복합니다.
```

예를 들어 5는 5 -> 16 -> 8 -> 4-> 2 -> 1이 됩니다.

그런데 이번에는 이 순서의 역순을 출력하고자 합니다.

즉, 1 2 4 8 16 5가 출력되어야 합니다.

이 처럼 어떤 자연수 n이 입력되면 위 알고리즘에 의해 1이 되는 과정을 모두 출력합니다.

---

## 2. 입출력 설명

* **입력:**
자연수 n이 입력됩니다. ($1 \le n \le 100$)

* **출력:**
3n+1의 과정을 역순으로 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
5
```

### 예시 출력 1
```text
1
2
4
8
16
5
```
