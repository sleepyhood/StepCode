#### 6. [ALLv05003_522.md (1부터 n까지 합 구하기)](02_workspace/ALLv05003_522.md)
* **티어 판정**: 🟢 **Tier 1 (입문형)** — `return` 누적 개념 도입
* **메타데이터**: `has_hint: "false"` ← **⚠️ 불일치**
* **문제점**:
  * **메타데이터 불일치**: YAML에서 `has_hint: "false"`로 선언
  * 그런데 실제 "4. 힌트" 섹션에:
    ```
    * 합을 저장할 변수는 **전역 변수**로 설정해주세요.
    ```
    - 이것은 명확한 팁 제공
    - Tier 1이므로 `return` 방식이 핵심인데, 전역 변수 방식을 암시하는 것은 혼란 야기
* **즉시 수정 항목**:
  1. **옵션 A**: `has_hint: "true"`로 변경하고, 힌트를 명확한 형태로 재구성
     - 권장: `return sum(n-1) + n;` 형태로 스택 누적을 설명
  2. **옵션 B**: 전역 변수 힌트를 제거하고 `has_hint: "false"` 유지
     - 이 경우 학생이 `return` 방식을 독립적으로 발견하도록 함
