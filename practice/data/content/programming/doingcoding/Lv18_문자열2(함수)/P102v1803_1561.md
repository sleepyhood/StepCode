# 03. [문자열2(함수)] 두 문자열 길이 비교 작은 길이 값과 문자열 출력

## 1. 문제 설명
두개의 문자열이 입력됩니다.

두 문자열 중 길이가 짧은 문자열의 길이와 문자열을 출력해주세요.

---

## 2. 입출력 설명

* **입력:**
문자열 두개가 입력됩니다.

- 문자열은 1글자 이상 20글자 이하 입니다.

* **출력:**
문자열의 길이가 짧은 문자열의 길이와 문자열을 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
korea english
```

### 예시 출력 1
```text
5 korea
```

---

## 4. 힌트
지금까지 배운 문자열 변수

#include <string.h>

strlen(문자열 또는 문자열변수) // 문자열 길이 return
