# 15. [문자열2(함수)] 문자 찾기 출력

## 1. 문제 설명
하나의 문자열과 하나의 문자가 입력됩니다.

문자열안에 찾고자 한는 문자가존재한다면 "In"

그렇지 않으면 "Out"을 출력해주세요.

**< 찾고자 하는 문자는 대소문자를 구분하지 않습니다! >**

---

## 2. 입출력 설명

* **입력:**
문자열 하나와 문자 하나가 입력됩니다.

- 문자열은 1글자 이상 20글자 미만 입니다.

* **출력:**
**대소문자 구분을 하지 않고,**

찾는 문자가 포함되어 있다면 "In"

없다면 "Out"을 출력해주세요.

---

## 3. 예시
### 예시 입력 1
```text
doingcoding c
```

### 예시 출력 1
```text
In
```

### 예시 입력 2
```text
welcometomyhome C
```

### 예시 출력 2
```text
In
```

### 예시 입력 3
```text
doingcoding K
```

### 예시 출력 3
```text
Out
```
