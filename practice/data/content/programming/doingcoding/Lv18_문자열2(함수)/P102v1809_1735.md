# 09. [문자열2(함수)] 두 문자열을 서로 n 개만 이어붙여서 출력

## 1. 문제 설명
문자열 2개와 정수하나가 입력됩니다.

문자열의 길이가 짧은 문자열 뒤에 길이가 긴 문자열의 앞부분 n개를 붙여서

변경된 문자열을 출력해주세요.

---

## 2. 입출력 설명

* **입력:**
문자열 두개와 정수하나가 입력됩니다.

- 문자열의 길이는 서로 다릅니다.

- 문자열은 1글자 이상 20글자 미만 입니다.

- 정수는 긴 문자열 길이보다 작은 숫자 입니다.

* **출력:**
두 문자열 중**길이가 짧은 문자열 뒤에 긴문자열의 앞부분 n개**를 이어 붙인 후 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
doing coding 3
```

### 예시 출력 1
```text
doingcod
```

### 예시 입력 2
```text
welcome tomyhome 5
```

### 예시 출력 2
```text
welcometomyh
```
