# 13. [문자열2(함수)] 문자열 찾기 출력

## 1. 문제 설명
문자열 2개가 입력됩니다.

두개의 단어를 비교했을때 서로 포함된 단어가 존재한다면 "In"

그렇지 않으면 "Out"을 출력해주세요.

---

## 2. 입출력 설명

* **입력:**
문자열 두개 입력됩니다.

- 문자열은 1글자 이상 20글자 미만 입니다.

* **출력:**
서로 포함하는 단어가 하나라도 있다면 "In"

없다면 "Out"을 출력해주세요.

---

## 3. 예시
### 예시 입력 1
```text
doingcoding cod
```

### 예시 출력 1
```text
In
```

### 예시 입력 2
```text
cod doingcoding
```

### 예시 출력 2
```text
In
```

### 예시 입력 3
```text
doingcoding korea
```

### 예시 출력 3
```text
Out
```
