# 04. [문자열2(함수)] 단어장 3단어 색인 체인 생성기

## 1. 문제 설명
사전 편찬 프로그램에서 무작위 순서로 입력된 3개의 단어 A, B, C를 사전순으로 정렬한 뒤, 하나의 색인 체인 표기 형식으로 묶어 등록하고자 합니다.

프로그램의 동작 규칙은 다음과 같습니다.

1. **3단어 사전순 정렬**:
   - 세 단어 A, B, C를 사전순으로 비교하여 오름차순($A \le B \le C$)이 되도록 메모리 상에서 맞바꿉니다(스왑).
   - 먼저 A와 B를 비교하여 A가 B보다 사전순으로 뒤에 있다면 두 단어를 맞바꿉니다.
   - 이어서 B와 C를 비교하여 B가 C보다 사전순으로 뒤에 있다면 두 단어를 맞바꿉니다.
   - 마지막으로 다시 A와 B를 비교하여 A가 B보다 사전순으로 뒤에 있다면 두 단어를 맞바꿉니다.
2. **색인 체인 결합**:
   - 정렬된 세 단어를 하이픈(`"-"`)으로 연결하여 하나의 색인 문자열 버퍼 `result`에 결합합니다. (형식: `A-B-C`)
3. **동일 단어 예외 처리**:
   - 만약 입력된 세 단어가 **모두 같은 단어**라면, 색인 문자열 뒤에 `"(ALL_SAME)"` 태그를 추가로 이어 붙입니다.

모든 가공이 끝난 후, 첫째 줄에 **최종 결합된 색인 문자열 `result`**, 둘째 줄에 **색인 문자열의 전체 글자 수**를 출력하는 프로그램을 작성하세요.

---

## 2. 입출력 설명

* **입력:**
첫째 줄에 영문 소문자로 구성된 세 단어 A, B, C가 공백으로 구분되어 입력됩니다. (각 단어는 공백 없는 1자 이상 30자 이하의 영문 소문자)

* **출력:**
첫째 줄에 가공된 색인 문자열 `result`를 출력합니다.
둘째 줄에 색인 문자열의 전체 길이를 정수로 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
cherry banana apple
```

### 예시 출력 1
```text
apple-banana-cherry
19
```

### 예시 입력 2
```text
apple dog cat
```

### 예시 출력 2
```text
apple-cat-dog
13
```

### 예시 입력 3
```text
code code code
```

### 예시 출력 3
```text
code-code-code(ALL_SAME)
24
```

## 4. 힌트
- **핵심 아이디어**: 세 숫자의 크기를 비교하여 정렬할 때 임시 변수를 사용하듯이, 세 문자열도 임시 문자열 변수(`temp`)와 사전순 비교 함수(`strcmp`), 문자열 복사 함수(`strcpy`)를 사용하여 정렬할 수 있습니다.
- **생각해볼 점**:
  1. `strcmp(A, B) > 0` 일 때, 임시 배열 `temp`를 경유하여 `A`와 `B`의 내용을 교체(`strcpy`)해 보세요.
  2. A와 B 비교/교체 $\rightarrow$ B와 C 비교/교체 $\rightarrow$ 다시 A와 B 비교/교체를 차례대로 수행하면 세 단어가 사전순으로 완벽하게 정렬됩니다.
  3. 정렬된 단어들을 결합할 때는 `strcpy`로 첫 단어를 넣고, `strcat`으로 `"-"` 기호와 다음 단어들을 이어 붙일 수 있습니다.
  4. 세 단어가 모두 같은지(`strcmp(A, B) == 0 && strcmp(B, C) == 0`) 확인하여 `strcat`으로 `"(ALL_SAME)"` 태그를 붙여 보세요.
