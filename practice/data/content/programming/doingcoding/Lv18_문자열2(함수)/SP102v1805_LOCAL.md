# 05. [문자열2(함수)] 런렝스 압축 문자열 복원기

## 1. 문제 설명
데이터 압축 기술 중 하나인 런렝스 부호화(Run-Length Encoding)는 동일한 문자가 연속될 때 `[문자][반복횟수]` 쌍으로 나타내는 기법입니다.

예를 들어 `aaabbcccc` 라는 문자열은 `a3b2c4` 로 압축됩니다.

`[문자][반복횟수]` 쌍으로 연속하여 구성된 압축 문자열 S가 입력될 때, 이를 파싱하고 복원하여 원래의 원본 문자열 버퍼 `restored`를 복원해 내는 프로그램을 작성하고자 합니다. (단, 반복 횟수는 1 이상 9 이하의 한 자리 정수입니다.)

첫째 줄에 **복원된 원본 문자열 `restored`**, 둘째 줄에 **복원된 문자열의 전체 길이**를 출력하는 프로그램을 작성하세요.

---

## 2. 입출력 설명

* **입력:**
첫째 줄에 `[문자][반복횟수]` 쌍으로 구성된 압축 문자열 S가 주어집니다. (문자는 영문 소문자, 반복 횟수는 1 이상 9 이하의 한 자리 정수, 압축 문자열의 길이는 2자 이상 30자 이하)

* **출력:**
첫째 줄에 복원된 원본 문자열 `restored`를 출력합니다.
둘째 줄에 복원된 문자열의 전체 길이를 정수로 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
a3b2c4
```

### 예시 출력 1
```text
aaabbcccc
9
```

### 예시 입력 2
```text
x1y4z2
```

### 예시 출력 2
```text
xyyyyzz
7
```

---

## 4. 힌트
- **핵심 아이디어**: `[문자][숫자]` 2글자씩 짝지어진 패턴을 반복 순회하면서, 숫자만큼 문자를 복원 버퍼에 반복해서 덧붙이는 문제입니다.
- **생각해볼 점**: 
  1. 문자 형태의 숫자인 `'3'`을 실제 정수 `3`으로 변환(아스키 연산 등)하려면 어떻게 해야 할까요?
  2. 반복 횟수만큼 해당 문자를 결합 버퍼에 추가하여 최종 원본 문자열을 완성해 보세요.
