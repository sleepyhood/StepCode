# 03. [문자열2(함수)] 단어 블록 누적 조립기

## 1. 문제 설명
문자열 조립 버퍼 S에 여러 단어를 순서대로 이어 붙이는 시뮬레이터를 제작하고자 합니다.

첫째 줄에 초기 단어 S와 이후 추가될 단어의 개수 N이 공백으로 구분되어 입력됩니다.

둘째 줄부터 N개의 줄에 걸쳐 추가할 단어 `word`가 한 줄에 하나씩 입력됩니다. 단어가 하나씩 들어올 때마다 다음 조립 규칙을 순서대로 적용합니다.

1. **길이 측정 및 비교**:
   - 현재 조립된 버퍼 S의 길이 `lenS`와 새로 들어온 단어의 길이 `lenW`를 측정합니다.
2. **조건부 결합**:
   - 현재 버퍼 S가 새 단어보다 **길거나 같다면 (`lenS >= lenW`)**: 새 단어 `word` **전체**를 버퍼 S의 뒤에 이어 붙입니다.
   - 현재 버퍼 S가 새 단어보다 **짧다면 (`lenS < lenW`)**: 새 단어 `word`의 **앞 3글자**만 버퍼 S의 뒤에 이어 붙입니다.
3. **버퍼 길이 상한 제어 (Truncation)**:
   - 결합 후 버퍼 S의 전체 길이가 **20자를 초과**하게 되면, 보안 규정에 따라 **앞 20글자까지만 남기고 뒷부분을 잘라냅니다**.

N개의 단어를 모두 처리한 후, 첫째 줄에 **최종 완성된 버퍼 S**, 둘째 줄에 **버퍼 S의 전체 글자 수**를 출력하는 프로그램을 작성하세요.

---

## 2. 입출력 설명

* **입력:**
첫째 줄에 초기 단어 S와 추가 단어 개수 N이 공백으로 구분되어 주어집니다. (S는 1자 이상 20자 이하의 영문 소문자, N은 0 이상 10 이하의 정수)
둘째 줄부터 N개의 줄에 걸쳐 추가할 단어 `word`가 한 줄에 하나씩 주어집니다. (각 단어는 1자 이상 20자 이하의 영문 소문자)

* **출력:**
첫째 줄에 최종 완성된 버퍼 S를 출력합니다.
둘째 줄에 버퍼 S의 전체 길이를 정수로 출력합니다.

## 4. 힌트
- **핵심 아이디어**: 반복문 안에서 단어의 길이를 측정(`strlen`)하고, 대소 비교 결과에 따라 전체를 붙이거나(`strcat`) 지정한 개수만큼만 붙이는(`strncat`) 문제입니다.
- **생각해볼 점**:
  1. 버퍼 S의 길이와 새 단어 `word`의 길이를 측정한 뒤 조건문으로 비교해 보세요.
  2. 단어 전체를 붙일 때는 `strcat(S, word)`를, 앞 3글자만 붙일 때는 `strncat(S, word, 3)`을 활용할 수 있습니다.
  3. 결합 후 `strlen(S) > 20` 인 경우, C언어에서는 20번째 인덱스 위치에 널 문자(`S[20] = '\0'`)를 대입하면 문자열을 20글자로 자를 수 있습니다.
