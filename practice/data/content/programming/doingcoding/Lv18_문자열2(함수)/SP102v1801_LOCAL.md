# 01. [문자열2(함수)] 끝말잇기 단어 체인

## 1. 문제 설명
친구들과 재미있는 끝말잇기 게임을 진행하고 있습니다. 

첫째 줄에 시작 단어 S와 이후 입력될 단어의 개수 N이 공백으로 구분되어 입력됩니다.

이후 N개의 줄에 걸쳐 단어가 한 줄에 하나씩 입력됩니다. 입력되는 단어마다 다음 규칙을 적용합니다.

- 현재 연결된 단어 S의 **마지막 글자**와 새로 들어온 단어 `word`의 **첫 번째 글자**가 일치하는지 확인합니다.
- 글자가 서로 일치한다면, 단어 S의 뒤에 새로 들어온 단어 `word`를 결합(`strcat`)하여 연결 체인을 이어 나갑니다.
- 만약 글자가 일치하지 않는다면 끝말잇기가 실패한 것이므로, **이후의 단어 검사를 즉시 중단(종료)**하고 현재까지 연결된 체인을 유지합니다.

모든 단어 검사가 끝난 후(또는 실패로 중단된 후), 첫째 줄에 **최종 연결된 단어 체인 S**, 둘째 줄에 **최종 단어 체인 S의 전체 글자 수**를 출력하는 프로그램을 작성하세요.

---

## 2. 입출력 설명

* **입력:**
첫째 줄에 시작 단어 S와 단어 개수 N이 공백으로 구분되어 입력됩니다. (S는 영문 소문자 1자 이상 20자 이하, N은 1 이상 10 이하의 정수)
둘째 줄부터 N개의 줄에 걸쳐 검사할 단어가 한 줄에 하나씩 주어집니다. (단어는 영문 소문자 1자 이상 20자 이하)

* **출력:**
첫째 줄에 최종 연결된 단어 체인 S를 출력합니다.
둘째 줄에 최종 단어 체인 S의 글자 수를 정수로 출력합니다.

## 4. 힌트
### 💡 힌트 (개념 조합)
- 이 문제는 **문자열의 길이를 측정하여 마지막 글자 인덱스를 구하는 함수(`strlen`)**와 **두 문자열을 연결하는 함수(`strcat`)**를 조합하여 순차 조작하는 문제입니다.
- C언어 구동 방식:
  - 현재 연결 문자열 S의 길이 `len = strlen(S)`를 구하면, 마지막 글자는 `S[len - 1]` 입니다.
  - 새로 들어온 단어의 첫 글자 `word[0]`과 비교하여 `S[len - 1] == word[0]` 인 경우 `strcat(S, word)`를 실행합니다.
  - 다를 경우 `break` 문으로 루프를 종료합니다.
- Python에서는 `S[-1] == word[0]` 으로 비교 후 `S += word`로 연결하고, Java에서는 `S.charAt(S.length()-1) == word.charAt(0)`으로 비교합니다.
