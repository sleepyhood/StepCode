# 19. [문자열2(함수)] 부분문자열 찾기

## 1. 문제 설명
어떤 문자열 A가 다른 문자열 B안에 속하면 A를 B의 부분 문자열이라고 합니다.

예를 들어 문자열 "abc"는 문자열 "aabcc"의 부분 문자열입니다.

문자열`str1`과`str2`가 주어질 때,`str1`이`str2`의 부분 문자열이라면 "found"를 부분 문자열이 아니라면 "not found"를출력 해 주세요.

---

## 2. 입출력 설명

* **입력:**
문자열 두개가 입력됩니다.

- 문자열은 1글자 이상 20글자 미만 입니다.

* **출력:**
문자열`str1`과`str2`가 주어질 때,`str1`이`str2`의 부분 문자열이라면 "found"를 부분 문자열이 아니라면 "not found"를출력 해 주세요.

---

## 3. 예시
### 예시 입력 1
```text
abc aabcc
```

### 예시 출력 1
```text
found
```

### 예시 입력 2
```text
tbt tbbttb
```

### 예시 출력 2
```text
not found
```
