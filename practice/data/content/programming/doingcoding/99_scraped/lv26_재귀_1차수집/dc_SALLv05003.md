# [SALLv05003번] 03. [재귀함수 - 3] 마트료시카 (러시아 인형)

## 1. 문제 설명
마트료시카(Matryoshka)는 큰 인형 안에 조금 더 작은 인형이 들어있고, 그 안에 또 더 작은 인형이 들어있는 러시아 전통 인형입니다.

인형의 깊이 $N$이 주어졌을 때, 다음 규칙에 따라 인형을 여는 과정과 닫는 과정을 출력하는 프로그램을 재귀 함수로 작성하세요.

**출력 규칙:**
- 재귀가 한 단계 깊어질 때마다 문장 앞에 `____` (언더바 4개)를 추가로 붙입니다.
- 인형을 열 때 (재귀 호출 전): `____` × $d$ + `"인형을 열었다."`
- 마지막 인형 (깊이 $N$): `____` × $N$ + `"사탕을 발견했다!"`
- 인형을 닫을 때 (재귀 호출 후): `____` × $d$ + `"인형을 닫았다."`

---

## 2. 입출력 설명

* **입력:**
인형의 깊이 $N$이 입력됩니다. ($1 \le N \le 50$)

* **출력:**
규칙에 따라 인형을 열고 닫는 과정을 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
1
```

### 예시 출력 1
```text
인형을 열었다.
____사탕을 발견했다!
인형을 닫았다.
```

### 예시 입력 2
```text
3
```

### 예시 출력 2
```text
인형을 열었다.
____인형을 열었다.
________인형을 열었다.
____________사탕을 발견했다!
________인형을 닫았다.
____인형을 닫았다.
인형을 닫았다.
```

## 4. 힌트
수업에서 배운 챗봇 문제와 구조가 동일합니다.
- **재귀 호출 전**: `"인형을 열었다."` 출력
- **기저 조건**: `"사탕을 발견했다!"` 출력
- **재귀 호출 후**: `"인형을 닫았다."` 출력

`print_bar(depth)` 함수를 먼저 만들어서 들여쓰기 출력에 활용하세요.

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (C)
```c
#include <stdio.h>

void print_bar(int depth) {
    for (int i = 0; i < depth; i++) printf("____");
}

void open_doll(int depth, int n) {
    // 재귀 호출 전: 인형을 열기
    print_bar(depth);
    printf("인형을 열었다.\n");

    if (depth == n - 1) {
        // 기저 조건: 마지막 인형 안의 사탕 발견
        print_bar(depth + 1);
        printf("사탕을 발견했다!\n");
    } else {
        // 재귀 호출 (한 단계 더 깊이)
        open_doll(depth + 1, n);
    }

    // 재귀 호출 후: 인형을 닫기
    print_bar(depth);
    printf("인형을 닫았다.\n");
}

int main() {
    int n;
    scanf("%d", &n);
    open_doll(0, n);
    return 0;
}
```
