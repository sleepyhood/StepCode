# 04. [포인터] 포인터로 배열 출력

## 1. 문제 설명
정수 5개를 입력받아 배열에 저장하고, 포인터를 이용해 배열의 값을 출력하세요.

---

## 2. 입출력 설명

* **입력:**
정수 5개가 공백 구분되어 주어집니다.

* **출력:**
각 값을 한 줄에 하나씩 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
1 2 3 4 5
```

### 예시 출력 1
```text
1  
2  
3  
4  
5
```
