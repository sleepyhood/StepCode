기초문법 코스(P102v/SP102v)의 성격과 파이프라인의 **5:3 문항 압축 원칙**에 따라, 단일 변수 주소 기초부터 포인터 순회 및 원본 갱신까지 총 8문항(수업 5, 숙제 3)으로 스캐폴딩을 완성하였습니다.

    │  "변수가 메모리에 저장된 '주소(&)'를 포인터(*)에 담고 값을 간접 참조한다"
    ▼

  - `수업 1`에서 주소와 역참조의 기본 기호를 익힌 후, `수업 2`에서 원본 값 수정(Mutation)의 필요성을 체감합니다.
  - `수업 3`에서 오개념을 유발하던 용어(`배열 포인터`)를 정정하고 배열 이름과 포인터의 등가성을 확인합니다.
  - `수업 4`에서 포인터 연산(`p++`, `p + i`)을 통한 순회를 배우고, `수업 5`에서 문자열 리터럴의 포인터 특성으로 개념을 확장합니다.
  - 숙제 `H1`, `H2`, `H3`은 수업에서 도약이 요구되는 핵심 3개 지점(Swap, 역순 순회, 최댓값 주소 기억)을 일대일로 복습/심화합니다.

## 🚫 2. 입출력 꼼수 방지(Bypass Prevention) 정교화 분석

지문에 단순 텍스트 제약만 두었을 때 발생하던 포인터 미사용 우회(Hardcoded print 등)를 원천 차단하기 위해, **런타임 입출력 구조 자체를 인메모리 연산을 강제하도록 전면 개편**하였습니다.

| 문항 ID | 기존 취약점 (꼼수 방식) | 적용된 꼼수 차단 입출력 설계 |
|:---|:---|:---|
| **`P102v2001_1870`** | 10 입력에 단순 10 출력 $\rightarrow$ 일반 변수로 통과 | $A$와 $K$를 입력받아 포인터 `p = &num;`을 통해 `*p += K;` 간접 연산 결과 검증 |
| **`P102v2002_1871`** | 10 입력에 무조건 20 출력 $\rightarrow$ `printf("20\n")` 우회 | 두 변수 $A, B$ 중 수정 대상(1 또는 2)과 새 값 $V$를 받아 포인터 동적 바인딩 검증 |
| **`P102v2003_1872`** | 입력 없이 10, 20, 30 출력 $\rightarrow$ 단순 하드코딩 우회 | 정수 3개를 동적으로 받아 시작 포인터 `p`를 통해 `*(p + i)` 순차 출력 |
| **`P102v2004_1873`** | 5개 입력 후 단순 순회 $\rightarrow$ 일반 `arr[i]`로 우회 | 5개 정수와 배수 $K$ 입력 후, 포인터 순회 중 짝수 원소만 $K$배 인플레이스 갱신 |
| **`P102v2005_1874`** | 입력 없이 "hello" 출력 $\rightarrow$ `printf("hello\n")` 우회 | 건너뛸 글자 수 $N$을 받아 포인터 오프셋 연산(`str + N`)으로 부분 문자열 출력 |

| **`SP102v2002_LOCAL`** | 단순 역순 루프 $\rightarrow$ `arr[n-1-i]` 우회 | 끝 주소(`arr + N - 1`)로부터 포인터 감소 연산(`p--`)을 통한 역순 출력 강제 |
| **`SP102v2003_LOCAL`** | 단순 max 값 출력 $\rightarrow$ 인플레이스 미수행 | 최댓값 주소를 기억한 포인터로 `*max_ptr += X;` 수행 후 임의 인덱스 `arr[K]` 조회 |

## 🐍 4. Python 1초 내 해결 가능성 및 다중 언어 대응 전략

1. **언어적 특수성**:
   - 포인터는 C/C++ 고유의 물리 메모리 주소(`&`) 및 직접 역참조(`*`)를 다루는 문법입니다.
   - Python과 Java에는 직접 메모리 주소를 가리키는 원시 포인터 타입이 없습니다.
2. **StepCode 코스 격리 전략**:
   - 본 단원은 C/C++ 기초문법 코스(`P102v` / `SP102v`)로 명확히 트랙이 격리되어 있으므로, 마크다운 front-matter의 `supported_languages`를 `["C", "C++"]`로 명시하였습니다.
3. **Python 개념 매핑 학습 방안**:
   - Python 학습자의 경우, 물리 포인터 대신 객체 참조 ID(`id(x)`) 및 가변 객체(Mutable List)의 참조 전달(Pass-by-assignment) 메커니즘으로 개념을 유추할 수 있도록 힌트 가이드라인을 제공합니다.
   - 연산 복잡도는 $N \le 20$의 단순 상수 또는 $O(N)$ 순회이므로 모든 언어에서 1초(1s) 제한시간 내에 여유 있게 통과 가능합니다.
