# 02. [포인터] 포인터로 변수 값 바꾸기

## 1. 문제 설명
정수 x를 입력받고, 포인터를 이용해 그 값을 20으로 바꾸세요.

변경 후 x의 값을 출력하세요.

---

## 2. 입출력 설명

* **입력:**
x의 초기 값이 주어집니다.

* **출력:**
변경된 x의 값을 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
10
```

### 예시 출력 1
```text
20
```
