# 02. [포인터1(기본)] 포인터 역방향 이동을 통한 배열 거꾸로 순회

## 1. 문제 설명
포인터에 덧셈을 하면 다음 원소의 주소로 이동하듯, 포인터에 뺄셈을 하거나 감소 연산자(`p--`)를 적용하면 이전 원소의 주소로 이동합니다.

원소의 개수 $N$과 $N$개의 정수를 입력받아 배열에 저장하세요.  
포인터 변수 `p`를 **배열의 마지막 원소를 가리키는 주소(`arr + N - 1`)**로 초기화한 뒤, 포인터를 역방향으로 1씩 이동시키며(`p--`) 첫 번째 원소(`arr`)까지 거꾸로 순회하여 출력하세요.

---

## 2. 입출력 설명

* **입력:**
  - 첫 번째 줄에 원소의 개수 $N$ ($1 \le N \le 20$)이 입력됩니다.
  - 두 번째 줄에 $N$개의 정수가 공백으로 구분되어 입력됩니다.
  - ($-1000 \le \text{각 정수} \le 1000$)

* **출력:**
  - 배열의 마지막 원소부터 첫 번째 원소까지 역순으로 공백으로 구분하여 한 줄에 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
5
10 20 30 40 50
```

### 예시 출력 1
```text
50 40 30 20 10
```

### 예시 입력 2
```text
3
7 14 21
```

### 예시 출력 2
```text
21 14 7
```

---

## 4. 힌트

- **핵심 아이디어**:
  - 배열의 시작 주소는 `arr`이고, 마지막 원소의 주소는 `arr + N - 1`입니다.
- **생각해볼 점**:
  - 포인터 변수 `p`를 `arr + N - 1`부터 시작하여 `p >= arr`인 동안 반복하고, 매 반복마다 `p--`로 주소를 하나씩 앞으로 이동시켜 보세요.
