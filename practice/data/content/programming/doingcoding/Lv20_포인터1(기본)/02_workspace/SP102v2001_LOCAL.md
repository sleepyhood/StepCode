# 01. [포인터1(기본)] 포인터를 활용한 두 변수의 값 맞교환

## 1. 문제 설명
두 변수의 주소를 포인터로 연결하면, 포인터 역참조(`*`)를 통해 변수들의 원래 값을 서로 맞바꿀 수 있습니다.

정수형 변수 $A, B$를 선언하고 초기값을 입력받습니다.  
두 포인터 변수 `pa, pb`를 선언하여 각각 변수 $A$와 $B$의 주소를 가리키도록 설정하세요. (`pa = &A; pb = &B;`)

임시 변수 `temp`와 포인터 역참조를 사용하여 변수 $A$와 $B$에 저장된 값을 서로 교환(Swap)하세요.  
교환이 끝난 후, 조회 대상 번호 $Op$를 입력받아 $Op$가 `1`이면 변수 $A$의 최종 값을, $Op$가 `2`이면 변수 $B$의 최종 값을 출력하세요.

---

## 2. 입출력 설명

* **입력:**
  - 첫 번째 줄에 두 정수 $A, B$가 공백으로 구분되어 입력됩니다.
  - 두 번째 줄에 조회 대상 번호 $Op$ ($1$ 또는 $2$)가 입력됩니다.
  - ($-1000 \le A, B \le 1000$)

* **출력:**
  - $Op$가 1인 경우 변수 $A$의 값을, $Op$가 2인 경우 변수 $B$의 값을 한 줄에 정수로 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
10 20
1
```

### 예시 출력 1
```text
20
```

### 예시 입력 2
```text
100 500
2
```

### 예시 출력 2
```text
100
```

---

## 4. 힌트

- **핵심 아이디어**:
  - 임시 변수 `temp`를 준비하고, 포인터 `pa`와 `pb`가 가리키는 실제 메모리의 값을 단계별로 이동시킵니다.
- **생각해볼 점**:
  1. `temp = *pa;`로 $A$의 원본 값을 백업합니다.
  2. `*pa = *pb;`로 $B$의 값을 $A$가 위치한 메모리에 덮어씁니다.
  3. `*pb = temp;`로 백업해 둔 값을 $B$가 위치한 메모리에 저장하면 맞교환이 완성됩니다.
