# 02. [포인터1(기본)] 포인터를 이용한 변수 값 변경

## 1. 문제 설명
포인터는 가리키는 대상 메모리 주소를 상황에 따라 유연하게 바꿀 수 있습니다.

두 정수형 변수 $A, B$를 선언하고 초기값을 입력받습니다.  
그 다음 수정할 대상 번호 $Target$과 새로운 값 $V$를 입력받아, 포인터 변수 `p`가 대상 변수를 가리키도록 설정하세요.

- $Target$이 `1`인 경우: 포인터 `p`가 변수 $A$의 주소를 가리킵니다. (`p = &A;`)
- $Target$이 `2`인 경우: 포인터 `p`가 변수 $B$의 주소를 가리킵니다. (`p = &B;`)

포인터 `p`를 역참조하여 그 값을 $V$로 변경한 후, 최종 변수 $A$와 $B$의 값을 순서대로 출력하세요.

---

## 2. 입출력 설명

* **입력:**
  - 첫 번째 줄에 초기 정수 $A, B$가 공백으로 구분되어 주어집니다.
  - 두 번째 줄에 수정할 대상 번호 $Target$ ($1$ 또는 $2$)과 새로운 정수 $V$가 공백으로 구분되어 주어집니다.
  - ($-1000 \le A, B, V \le 1000$)

* **출력:**
  - 최종 변수 $A$와 $B$의 값을 한 줄에 공백으로 구분하여 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
10 20
1 99
```

### 예시 출력 1
```text
99 20
```

### 예시 입력 2
```text
5 8
2 50
```

### 예시 출력 2
```text
5 50
```

---

## 4. 힌트

📘 **포인터가 가리키는 대상을 동적으로 결정할 수 있습니다.**

![image.png](./images/P102v2002_98eb27bdb2.png)

- **핵심 작성 가이드 (C/C++)**:
  ```c
  int *p = NULL;
  if (Target == 1) {
      p = &A;
  } else {
      p = &B;
  }
  *p = V; // 포인터가 가리키는 변수의 원본 값이 V로 변경됩니다.
  ```
