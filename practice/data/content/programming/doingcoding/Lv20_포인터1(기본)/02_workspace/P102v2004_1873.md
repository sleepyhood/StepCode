# 04. [포인터1(기본)] 포인터 이동 연산과 배열 순회

## 1. 문제 설명
포인터 변수에 정수를 더하거나(`p + 1`), 증감 연산자(`p++`)를 사용하면 다음 원소가 저장된 메모리 위치로 주소가 이동합니다.

정수 5개를 입력받아 크기 5인 배열에 저장하고, 추가로 곱할 배수 $K$를 입력받습니다.  
포인터를 이용해 배열의 처음부터 끝까지 순회하면서, **현재 포인터가 가리키는 원소의 값이 짝수(Even)인 경우에만 그 원소의 값에 $K$를 곱하여 배열의 값을 직접 갱신**하세요.

모든 순회와 갱신이 완료된 후, 배열의 5개 원소를 한 줄에 하나씩 순서대로 출력하세요.

---

## 2. 입출력 설명

* **입력:**
  - 첫 번째 줄에 5개의 정수가 공백으로 구분되어 주어집니다.
  - 두 번째 줄에 곱할 정수 $K$가 주어집니다.
  - ($-1000 \le \text{각 정수}, K \le 1000$)

* **출력:**
  - 가공이 완료된 배열의 5개 원소를 첫 번째 원소부터 차례대로 한 줄에 하나씩 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
1 2 3 4 5
10
```

### 예시 출력 1
```text
1
20
3
40
5
```

### 예시 입력 2
```text
6 8 10 12 14
2
```

### 예시 출력 2
```text
12
16
20
24
28
```

## 4. 힌트

📘 **포인터를 이동시키는 반복문을 구성해 원본 배열을 순회할 수 있습니다.**

![image.png](./images/P102v2004_37e5e01d86.png)

- **핵심 작성 가이드 (C/C++)**:
  ```c
  int arr[5];
  // 입력 처리 후
  for (int *p = arr; p < arr + 5; p++) {
      if (*p % 2 == 0) {
          *p *= K; // 포인터가 가리키는 짝수 원소에 K를 곱함
      }
  }
  for (int i = 0; i < 5; i++) {
      printf("%d\n", arr[i]);
  }
  ```
