# 03. [포인터1(기본)] 배열과 포인터 주소 참조 튜토리얼

## 1. 문제 설명
C/C++에서 **배열의 이름은 배열의 첫 번째 원소가 저장된 메모리의 시작 주소**와 같습니다.

- 정수형 배열 `int arr[3];`이 있을 때, `arr`는 곧 `&arr[0]`과 동일한 주소입니다.
- 포인터 변수 `p`에 배열의 시작 주소를 담으면(`int *p = arr;`), 포인터 연산을 통해 배열의 각 원소에 접근할 수 있습니다.
- `*(p + 0)`은 `arr[0]`, `*(p + 1)`은 `arr[1]`, `*(p + 2)`는 `arr[2]`를 가리킵니다.

정수 3개를 입력받아 크기 3인 배열에 저장하고, 배열의 시작 주소를 가리키는 포인터를 선언하여 포인터 역참조 연산으로 각 원소를 출력하세요.

---

## 2. 입출력 설명

* **입력:**
  - 첫 번째 줄에 3개의 정수가 공백으로 구분되어 입력됩니다.
  - ($-1000 \le \text{각 정수} \le 1000$)

* **출력:**
  - 각 줄마다 `arr[i] = [값]` 형식으로 0번 인덱스부터 2번 인덱스까지 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
10 20 30
```

### 예시 출력 1
```text
arr[0] = 10
arr[1] = 20
arr[2] = 30
```

### 예시 입력 2
```text
7 14 21
```

### 예시 출력 2
```text
arr[0] = 7
arr[1] = 14
arr[2] = 21
```

---

## 4. 힌트

📘 **배열의 이름은 첫 번째 원소의 주소를 가리키는 포인터 상수처럼 동작합니다.**

![image.png](./images/P102v2003_654ec26b72.png)

- **핵심 작성 가이드 (C/C++)**:
  ```c
  int arr[3];
  // 입력 처리 후
  int *p = arr; // arr는 &arr[0]과 같습니다.
  for (int i = 0; i < 3; i++) {
      printf("arr[%d] = %d\n", i, *(p + i));
  }
  ```
