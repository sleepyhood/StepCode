# 03. [자료구조 종합 - 03] 취업

## 1. 문제 설명
두잉 아카데미는 대한민국에 기반을 둔 국제 리더십 훈련 아카데미입니다. 매년 이 회사는 전 세계 기업에 공급될 수천 명의 인재를 훈련합니다. 모든 훈련생에게 공정하게 배정하기 위해, 회사는 번호 시스템을 사용하여 선발 과정을 진행합니다. 훈련생들은 1부터 N까지의 숫자 중 하나를 선택하며, 한 숫자가 여러 훈련생에게 선택될 수도 있습니다. 여기서 N은 아카데미에 훈련생을 요청한 회사의 총 수입니다.

선발은 1번부터 시작합니다. 무작위로 숫자 M을 정하면 1번부터 시작하여 M번째 번호를 선택합니다. N에 도달하면 다시 1번부터 시작하고, 이미 선택된 번호는 건너뒵니다.

예를 들어 N = 15, M = 6 이라면 번호는 다음과 같은 순서로 선택됩니다.

6, 12, 3, 10, 2, 11, 5, 15, 13, 9, 14, 4, 1, 8, 7.

마지막 7번을 제외한 번호를 선택한 훈련생들은 해외의 회사에 취업합니다.

민준이는 대한민국에서 일하고 싶어합니다. 민준이는 대한민국이 제일 좋고 대한민국이라면 어디든지 상관 없습니다. 민준이를 도와서 민준이가 선택할 번호를 고르는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
입력은 여러 줄로 주어집니다. 각 줄은 기업 수 N과 건너뛰기 값 M이 주어집니다. (1<=N<=1500, 1<=M<=50)

N과 M 모두 0이 입력되면 입력을 종료합니다.

* **출력:**
각 테스트케이스마다 민준이가 골라야할 숫자를 한 줄에 하나씩 출력해 주세요.

---

## 3. 예시
### 예시 입력 1
```text
15 6
550 23
0 0
```

### 예시 출력 1
```text
7
470
```
