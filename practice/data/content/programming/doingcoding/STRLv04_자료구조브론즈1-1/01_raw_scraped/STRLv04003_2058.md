# 03. [자료구조 종합 - 03] 테세우스와 미노타우르스

## 1. 문제 설명
테세우스는 아테네의 건국 영웅 중 한명으로, 강인함과 지능, 용기로 유명한 영웅입니다. 헤라클레스만큼 고단한 인생은 아니었지만 여러 드라마로 가득했습니다. 의붓어머니는 테세우스를 독살하려고 했고, 아버지는 테세우스가 미노타우르스를 쓰러뜨리고 돌아올 때 돛의 색을 바꾸는 걸 깜빡하는 바람에 스스로 목숨을 끊었습니다. (살아돌아오면 흰 돛, 그 반대는 검은 돛을 달기로 했는데 검은 돛을 단 채로 귀환했습니다.) 테세우스는 특히 크레타의 미궁에 살며 제물로 바쳐진 아테네 청년들을 잡아먹던 반인반수 미노타우르스를 쓰러뜨린 걸로 유명합니다. 전설에 따르면 크레타의 아리아드네는 테세우스를 사랑하게 되어 미궁에서 길을 잃지 않도록 실타래를 건네주었습니다. 그는 입구에 실을 묶어두고 이동하는 동안 실이 풀렸다가 다시 감기도록 했습니다.

여러분은 주어진 이동 경로가 이러한 "실을 이용한 미궁 탐색" 방식과 일치하는지를 판단해야 합니다. 즉, 이동을 모두 마쳤을 때 실타래가 완전히 다시 감겼는지를 확인해야 합니다. 입력으론 직사각형 격자에서 테세우스가 걸어간 네 방향 (l, r, u, d)를 나타내는 소문자 문자열이 주어집니다. 예를 들어 urdl을 걸었다면 다시 시작 지점으로 돌아오지만, 기둥을 한 바퀴 도는 등 실이 완전히 되감기지 않았다면 실이 완전히 감기지 않습니다.

---

## 2. 입출력 설명

* **입력:**
첫 줄엔 테스트케이스의 수 K가 주어집니다.

다음 K줄엔 소문자lrud로 이루어진 최대 100글자인 문자열이 한 줄에 하나씩 주어집니다.

l은 왼쪽, r은 오른쪽, u는 위쪽, d는 아래쪽을 나타냅니다.

* **출력:**
각 테스트케이스 마다 Data Set x: 형식으로 테스트케이스 번호 x와 함께 출력합니다.

그 다음 줄에는 이동이 끝났을 때 실이 완전히 감겼다면 Yes, 아니면 No를 출력해주세요.

그리고 나서 한 줄 비워줍니다.

---

## 3. 예시
### 예시 입력 1
```text
3
uldrurdl
uuldurudrruuddrllldd
uuuuurrrllllrdddddd
```

### 예시 출력 1
```text
Data Set 1:
No

Data Set 2:
Yes

Data Set 3:
No
```
