# 02. [자료구조 종합 - 02] 회의

## 1. 문제 설명
26명이서 회의를 하고 있습니다. 회의의 진행 방법은 다음과 같습니다.

* 회의 시작 시, 안건으로 올라온 것은 없습니다.
* 새로운 회의 안건은 언제든지 누구든지 제출할 수 있습니다. (이미 안건에 대해 회의중이어도.)
* 새 안건이 제출되면, 이전 안건에 대한 논의는 모두 중단되고 새로운 안건에 대한 논의가 시작됩니다. 새 안건에 대한 표결이 끝난 후에, 중단했던 이 전 안건에 대한 논의가 시작됩니다.
* 어떤 안건에 대한 논의든 반드시 그 안건에 대한 표결로 끝나야 합니다.
* 회의가 끝날 때, 표결이 완료되지 않은 법안이 남아서는 안 됩니다.

회의 기록이 주어지면 이 기록이 위 규정에 맞는 올바른 회의 진행 순서인지 아닌지 판단하는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
입력 첫 줄에는 회의 기록의 길이 K가 주어집니다. (1<=K<=1000)

다음 K줄에는 회의 기록이 나타납니다. 회의 기록은 두 가지 사건 중 하나를 나타냅니다.

* Add x : x가 새 안건을 제출했습니다.
* Vote x : x가 낸 안건에 대해 표결이 끝났습니다.

x는 소문자 a부터 z까지 주어집니다.

* **출력:**
만약 주어진 회의 기록이 올바른 회의 진행 순서면 Yes, 아니면 No를 출력해 주세요.

---

## 3. 예시
### 예시 입력 1
```text
4
Add a
Add b
Vote a
Vote b
```

### 예시 출력 1
```text
No
```

### 예시 입력 2
```text
8
Add z
Vote z
Add x
Add y
Add x
Vote x
Vote y
Vote x
```

### 예시 출력 2
```text
Yes
```

### 예시 입력 3
```text
1
Vote z
```

### 예시 출력 3
```text
No
```
