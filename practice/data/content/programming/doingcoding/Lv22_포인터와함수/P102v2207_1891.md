# 07. [포인터+함수] 특정 문자 찾기

## 1. 문제 설명
문자열과 문자 하나를 입력받아, 문자열에서 해당 문자가 처음 등장하는 위치를 포인터로 찾아 출력해 주세요.

해당 문자가 존재하지 않으면 "문자가 없습니다"를 출력합니다.

---

## 2. 입출력 설명

* **입력:**
첫 번째 입력은 문자열, 두 번째 입력은 한 개의 문자로, 공백을 구분하여 한 줄에 주어집니다.

* **출력:**
문자가 포함되어 있다면 그 문자를 출력하고, 없다면 "문자가 없습니다"를 출력해 주세요.

---

## 3. 예시
### 예시 입력 1
```text
apple p
```

### 예시 출력 1
```text
p
```
