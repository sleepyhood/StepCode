# 02. [포인터+함수] 두 변수의 값을 바꾸기

## 1. 문제 설명
정수 두 개를 입력받고, 포인터를 이용해 값을 서로 바꾸는 함수를 작성하세요.

---

## 2. 입출력 설명

* **입력:**
두 정수가 공백을 구분하여 입력됩니다.

* **출력:**
두 변수에 저장된 값을 바꾼 후 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
10 20
```

### 예시 출력 1
```text
20 10
```
