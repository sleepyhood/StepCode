# 10. [포인터+배열] 여러 문자열 출력하기

## 1. 문제 설명
n개의 문자열을 입력받은 뒤, 포인터 배열을 이용하여 순서대로 출력하는 프로그램을 작성해 주세요.

각 문자열은 포인터 배열에 저장되어야 하며, 출력 시 반복문을 활용해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에는 정수 n이 주어집니다.

이후 n줄에는 각각 한 개씩의 문자열이 주어집니다.

* **출력:**
입력된 문자열들을 입력된 순서대로 한 줄에 하나씩 출력해 주세요.

---

## 3. 예시
### 예시 입력 1
```text
3  
apple  
banana  
cherry
```

### 예시 출력 1
```text
apple  
banana  
cherry
```

---

## 4. 힌트
입력된 문자열은 배열 buffer에 저장되고, 해당 주소를 포인터 배열에 연결해서 관리하면 됩니다.
