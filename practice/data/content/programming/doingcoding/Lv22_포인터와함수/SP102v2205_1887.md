# 임시. 05. [포인터+함수] 배열 평균 구하기

## 1. 문제 설명
배열의 평균을 구하는 함수를 작성하고, 소수점 둘째 자리까지 출력하세요.

---

## 2. 입출력 설명

* **입력:**
첫번째 줄에 배열의 길이 n이 입력됩니다.

두번째 줄에는 n개의 정수가 공백을 구분하여 입력됩니다.

* **출력:**
평균을 소수 둘째 자리까지 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
3  
1 2 3
```

### 예시 출력 1
```text
2.00
```
