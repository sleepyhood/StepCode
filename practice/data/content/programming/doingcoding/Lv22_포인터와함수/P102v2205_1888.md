# 05. [포인터+함수] 문자열 길이 튜토리얼

## 1. 문제 설명
문자열을 입력받은 뒤, 포인터를 이용해 해당 문자열의 길이를 구하는 함수를 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
문자열 1개가 한 줄에 주어집니다.

* **출력:**
해당 문자열의 길이를 정수로 출력해 주세요.

---

## 3. 예시
### 예시 입력 1
```text
apple
```

### 예시 출력 1
```text
5
```

---

문자열의 주소를 이용하여, 함수에 전달할 수 있습니다.
