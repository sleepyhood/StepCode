# 15. [포인터 반환] 특정 문자 찾기

## 1. 문제 설명
문자열과 문자 하나를 입력받고, 문자열에서 해당 문자가 처음 등장하는 위치를 찾아 출력해 주세요.

존재하지 않으면 "없음"을 출력해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 문자열, 두 번째 줄에 문자 하나가 주어집니다.

* **출력:**
문자가 존재하면 해당 문자를 출력하고, 존재하지 않으면 "없음"을 출력해 주세요.

---

## 3. 예시
### 예시 입력 1
```text
banana  
n
```

### 예시 출력 1
```text
n

```

---

## 4. 힌트
`\*s == c`가 참인 위치를 찾고, 그 포인터를 반환해 주세요.

`while (\*s!='\0)`를 활용해 문자열 끝까지 확인하세요.
