# 11. [포인터+배열] 문자열 배열 복사하기

## 1. 문제 설명
n개의 문자열을 입력받아 포인터 배열을 이용하여 다른 배열로 복사하고, 복사된 배열의 내용을 출력하는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에는 정수 n이 주어집니다.

이후 n줄에는 각각 문자열이 주어집니다.

* **출력:**
복사된 문자열들을 한 줄에 하나씩 출력해 주세요.

---

## 3. 예시
### 예시 입력 1
```text
2  
hello  
world

```

### 예시 출력 1
```text
hello  
world
```

---

## 4. 힌트
문자열 복사는 strcpy를 활용하면 편리합니다.

포인터 배열의 각 항목이 메모리를 가리키고 있어야 복사가 가능합니다.
