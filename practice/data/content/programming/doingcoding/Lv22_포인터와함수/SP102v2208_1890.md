# 임시. 08. [포인터+함수] 문자열 비교하기

## 1. 문제 설명
두 개의 문자열을 입력받고, 포인터를 활용한 함수를 사용하여 문자열이 같은지 비교해 주세요.

strcmp와 유사한 동작을 직접 구현해 봅시다.

---

## 2. 입출력 설명

* **입력:**
두 개의 문자열이 공백을 사이에 두고 한 줄에 주어집니다.

* **출력:**
두 문자열이 같으면 "같습니다", 다르면 "다릅니다"를 출력해 주세요.

---

## 3. 예시
### 예시 입력 1
```text
apple apple
```

### 예시 출력 1
```text
같습니다
```
