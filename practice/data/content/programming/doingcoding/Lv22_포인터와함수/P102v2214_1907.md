# 14. [포인터 반환] 첫 번째 짝수 찾기

## 1. 문제 설명
정수 배열에서 처음 등장하는 짝수의 주소를 반환하여, 해당 값을 출력하는 프로그램을 작성해 주세요.

만약 짝수가 없다면 "짝수 없음"을 출력해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다.

두 번째 줄에 n개의 정수가 주어집니다.

* **출력:**
처음으로 발견된 짝수 값을 출력하거나, 없을 경우 "짝수 없음"을 출력해 주세요.

---

## 3. 예시
### 예시 입력 1
```text
6  
1 3 5 7 8 9

```

### 예시 출력 1
```text
8

```

---

## 4. 힌트
짝수를 만나면 `return &arr[i];`로 해당 위치 주소를 반환하고, 반복을 종료해 주세요.
