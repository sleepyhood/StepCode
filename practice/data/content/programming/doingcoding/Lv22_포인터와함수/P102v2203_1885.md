# 03. [포인터+함수] 배열 출력 튜토리얼

## 1. 문제 설명
정수 배열을 함수에 전달하여, 모든 원소를 공백으로 구분하여 출력하세요.

---

## 2. 입출력 설명

* **입력:**
첫 줄에 n (배열 크기)이 입력됩니다.

둘째 줄에 n개의 정수가 한 줄에 공백을 구분하고 입력됩니다.

* **출력:**
배열을 공백으로 구분하여 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
3  
1 2 3
```

### 예시 출력 1
```text
1 2 3
```

---

## 4. 힌트
배열의 주소를 이용하여, 함수에 전달할 수 있습니다.  
코드 템플릿을 참고하여 제출해봅시다.
