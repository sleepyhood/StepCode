# 06. [포인터+함수] 문자열 복사하기

## 1. 문제 설명
입력된 문자열을 다른 배열에 복사한 뒤 출력하는 프로그램을 작성해 주세요.

복사는 포인터를 이용한 함수를 통해 수행해야 합니다.

---

## 2. 입출력 설명

* **입력:**
문자열 1개가 한 줄에 주어집니다.

* **출력:**
복사된 문자열을 한 줄에 출력해 주세요.

---

## 3. 예시
### 예시 입력 1
```text
banana
```

### 예시 출력 1
```text
banana
```

---

## 4. 힌트
포인터를 사용하면, 문자열의 복사를 직접 구현할 수 있습니다.

`src`가 가리키는 문자의 값을 하나씩`dest`로 복사하고, 마지막에 널문자`'\0'`를 꼭 붙여주세요.

포인터 연산자`*`와`++`를 함께 사용하는 것이 포인트입니다.
