# 04. [포인터+함수] 배열 값 제곱하기

## 1. 문제 설명
정수 배열을 함수에 전달하고, 모든 원소를 제곱하여 변경하세요.

---

## 2. 입출력 설명

* **입력:**
첫번째 줄에 n (배열 크기)이 입력됩니다.

두번째 줄에 n개의 정수가 한줄에 공백을 구분하여 입력됩니다.

* **출력:**
제곱된 배열을 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
3  
2 4 6
```

### 예시 출력 1
```text
4 16 36
```
