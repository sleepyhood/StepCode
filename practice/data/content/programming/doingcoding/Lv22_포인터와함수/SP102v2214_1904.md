# 임시. 14. [포인터+배열] 문자열 길이 출력하기

## 1. 문제 설명
여러 개의 문자열을 포인터 배열에 저장한 뒤, 각 문자열의 길이를 출력하는 프로그램을 작성해 주세요.

길이 계산은 반복문과 포인터를 사용하여 직접 구현해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에는 정수 n이 주어집니다.

이후 n줄에는 각각 문자열이 한 개씩 주어집니다.

* **출력:**
각 문자열의 길이를 한 줄에 하나씩 순서대로 출력해 주세요.

---

## 3. 예시
### 예시 입력 1
```text
3  
hi  
hello  
bye
```

### 예시 출력 1
```text
2  
5  
3
```

---

## 4. 힌트
포인터를 활용해서 문자열을 한 글자씩 순회하며 길이를 직접 세어 보세요.
