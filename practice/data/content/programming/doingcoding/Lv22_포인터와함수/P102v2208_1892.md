# 08. [포인터+함수] 문자열 뒤집기

## 1. 문제 설명
입력된 문자열을 포인터를 이용해 뒤집은 뒤, 결과를 출력하는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
문자열 1개가 한 줄에 주어집니다.

* **출력:**
문자열을 뒤집은 결과를 한 줄에 출력해 주세요.

---

## 3. 예시
### 예시 입력 1
```text
apple
```

### 예시 출력 1
```text
elppa
```
