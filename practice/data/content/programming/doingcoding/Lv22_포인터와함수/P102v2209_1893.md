# 09. [포인터+함수] 특정 문자의 개수 세기

## 1. 문제 설명
문자열과 특정 문자를 입력받은 뒤, 해당 문자가 문자열 안에 몇 번 등장하는지를 세는 프로그램을 작성해 주세요.

반복문과 포인터를 활용하여 구현해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째로 문자열이 주어지고, 두 번째로 한 개의 문자가 공백으로 구분되어 한 줄에 주어집니다.

* **출력:**
입력된 문자열에 포함된 해당 문자의 개수를 정수로 출력해 주세요.

---

## 3. 예시
### 예시 입력 1
```text
apple p
```

### 예시 출력 1
```text
2
```
