# 임시. 12. [포인터+함수] 숫자의 개수 세기

## 1. 문제 설명
문자열 안에 포함된 숫자(0~9)의 개수를 세는 프로그램을 작성해 주세요.

포인터를 활용하여 각 문자를 하나씩 확인해 주세요.

---

## 2. 입출력 설명

* **입력:**
문자열 1개가 한 줄에 주어집니다.

* **출력:**
문자열 안에 있는 숫자의 개수를 정수로 출력해 주세요.

---

## 3. 예시
### 예시 입력 1
```text
abc123
```

### 예시 출력 1
```text
3
```
