# 12. [포인터+배열] 가장 긴 문자열 찾기

## 1. 문제 설명
n개의 문자열을 입력받고, 그 중 가장 긴 문자열을 출력하는 프로그램을 작성해 주세요.

포인터 배열을 이용하며, 길이가 같은 경우 먼저 입력된 문자열을 출력하세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에는 정수 n이 주어집니다.

이후 n줄에는 문자열이 하나씩 주어집니다.

* **출력:**
가장 긴 문자열을 한 줄에 출력해 주세요.

---

## 3. 예시
### 예시 입력 1
```text
3  
hi  
hello  
bye
```

### 예시 출력 1
```text
hello

```

---

## 4. 힌트
strlen을 사용하여 각 문자열의 길이를 비교하고, 가장 긴 문자열의 포인터를 저장해 주세요.
