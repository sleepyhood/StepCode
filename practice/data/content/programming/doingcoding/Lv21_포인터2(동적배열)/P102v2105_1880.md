# 05. [동적 문자열] 입력된 문자열 출력

## 1. 문제 설명
문자열을 입력받아 동적 메모리에 저장하고 출력하세요.

---

## 2. 입출력 설명

* **입력:**
첫번째 줄에 문자열이 입력됩니다.

* **출력:**
입력한 문자열을 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
HelloWorld
```

### 예시 출력 1
```text
HelloWorld
```

---

### **[C언어]**
