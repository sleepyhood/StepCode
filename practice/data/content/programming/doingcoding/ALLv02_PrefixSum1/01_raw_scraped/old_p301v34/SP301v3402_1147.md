# 02. [누적합 - 2] 사탕 먹기

## 1. 문제 설명
유치원에서 간단한 게임을 합니다. 10개의 사탕이 일렬로 있습니다. 각 사탕에는 점수가 매겨져 있습니다.

게임의 룰은 간단합니다. 맨 처음 사탕부터 먹어서 점수가 100점에 제일 가까운 사람이 이깁니다. 사탕은 맨 앞에서부터 하나씩 순서대로 먹어야 하며 중간에 사탕 먹는걸 멈춘다면 더이상 사탕을 먹을 수 없습니다. 만약 100점에 가까운 점수가 98점 102점 두개가 나왔다면 더 높은 점수인 102점을 획득한 사람이 승리합니다.

게임에 참가한 주연이는 게임에서 꼭 이기고 싶어합니다. 주연이를 도와서 주연이가 받아야하는 점수를 계산하는 프로그램을 작성해주세요.

---

## 2. 입출력 설명

* **입력:**
사탕의 점수가 첫 번째부터 열 번째까지 순서대로 주어집니다.

* **출력:**
주연이가 받아야하는 최고점수를 출력해주세요.
