# 02. [누적합 - 2] 전구 장식

## 1. 문제 설명
준혁이는 학교 축제에서 전구를 장식하는 일을 맡았습니다.

전구는 N개의 전구를 한 줄로 배치하여 장식할 생각으로 각 전구는 서쪽에서부터 순서대로 1번부터 N번까지의 번호가 붙어있습니다. 각 전구엔 켜짐과 꺼짐 두 가지의 상태가 있으며, 처음에 전구는 모두 꺼짐 상태입니다.

준혁이가 원하는 전구의 상태는 A1, A2, ... An 으로 나타낼 수 있으며 Ai = 1이라면 i번째 전구가 켜진 상태, Ai = 0 이라면 i번째 전구가 꺼진 상태입니다. 준혁이는 가능한 한 짧은 시간 안에 이 모양대로 전구의 상태를 바꾸려고 합니다.

준혁이는 처음에 다음 작업을 1번만 수행할 수 있으며, 하지 않아도 됩니다.

* 서쪽 끝에 연결된 구간의 전구를 켜짐 상태로 바꿉니다. 이때, 1 이상 N 이하의 정수 r을 하나 선택하여, 전구 1, 2, ... , r을 켜짐 상태로 합니다.

이 작업에 걸리는 시간은 0초 입니다.

그 이후 다음과 같은 작업을 몇번이든 수행할 수 있습니다.

* 전구를 하나 선택하여, 상태를 반전시킵니다. (켜진 전구는 끄고, 꺼진 전구는 켜고.)

이 작업은 1회당 1분이 걸립니다.

전구의 개수 N과 목표로 하는 전구의 상태가 주어질 때, 준혁이가 목표 상태를 만드는데까지 걸리는 최소 시간을 계산하는 프로그램을 작성해주세요.

---

## 2. 입출력 설명

* **입력:**
입력은 다음과 같은 형식으로 표준 입력에서 주어집니다.

N

A1, A2, ... An

제한

1 <= N <= 200,000

Ai는 모두 0 또는1

입력값은 모두 정수

* **출력:**
목표한 전구 상태를 만들기까지 걸리는 최소 시간 (분 단위)을 한 줄로 출력해 주세요.

---

## 3. 예시
### 예시 입력 1
```text
6
0 1 1 0 0 1
```

### 예시 출력 1
```text
2
```

### 예시 입력 2
```text
4
0 0 0 1
```

### 예시 출력 2
```text
1
```

### 예시 입력 3
```text
4
1 1 1 1
```

### 예시 출력 3
```text
0
```

### 예시 입력 4
```text
15
1 0 0 0 0 1 1 1 0 1 0 0 1 0 1
```

### 예시 출력 4
```text
6
```

---

## 4. 힌트
예제 1은 다음과 같습니다.

* 처음에 r = 3을 선택하여 1, 2, 3을 킵니다. 그 후 1번 전구를 끄고, 6번 전구를 킵니다. 총합 2분동안 작업을 했습니다. 2분보다 더 짧은 시간내에 할 수는 없으니 답은 2입니다.

예제 2는 다음과 같습니다.

* 맨 처음 작업을 하지 않습니다. 그리고 4번 전구만 킵니다. 총합 1분이며, 1분보다 짧게 할 수는 없습니다.

예제 3은 다음과 같습니다.

* r = 4를 선택하여 1, 2, 3, 4를 모두 키면 끝납니다. 0분 걸리니 0을 출력합니다.
