# 17. [클래스와 상속 - 17] 상수와 디폴트 메서드

## 1. 문제 설명

인터페이스에는 추상 메서드 외에도 **상수**와 **디폴트 메서드(Default Method)**를 선언할 수 있습니다.

- **인터페이스 상수**: 선언된 모든 변수는 자동으로 `public static final`이 되어 수정 불가능한 상수가 됩니다.
- **디폴트 메서드 (`default`)**: Java 8부터 도입된 기능으로, 인터페이스 내에서 **기본 실행 코드(본문 `{...}`)를 직접 가질 수 있는 메서드**입니다. 이를 통해 모든 구현 클래스에 공통 로직을 기본 제공할 수 있으며, 구현 클래스에서 필요할 때만 선택적으로 재정의할 수 있습니다.
- (C++과 Python에서는 추상 클래스 내의 `static const` 상수와 기본 구현을 가진 일반 멤버 함수로 동일하게 표현합니다.)

문제

미완성된 코드가 주어지면 빈칸에 올바른 코드를 적어 완성시켜주세요.

---

## 2. 입출력 설명

* **입력:**
음향 장비 볼륨 규격 Adjustable 인터페이스를 정의합니다.
- 상수: `MIN_VOLUME = 0`, `MAX_VOLUME = 100`
- 추상 메서드: `setVolume(int level)`
- 디폴트 메서드: `checkSafety(int level)`
  - level이 MIN_VOLUME 이상 MAX_VOLUME 이하이면 "SAFE", 아니면 "OUT_OF_RANGE" 반환

Speaker 클래스는 Adjustable을 구현하며, checkSafety는 인터페이스의 디폴트 메서드를 그대로 상속받아 사용합니다.
설정할 볼륨 수치 정수 V를 입력받습니다.

* **출력:**
- 1줄: `checkSafety(V)` 메서드 실행 결과(SAFE 또는 OUT_OF_RANGE) 출력
- 2줄:
  - SAFE인 경우: `Volume set to [V]` 출력
  - OUT_OF_RANGE인 경우: `Volume setting failed` 출력

## 4. 힌트
Java에서는 인터페이스 메서드 선언부 앞에 `default` 키워드를 붙여 본문({ ... })을 작성합니다.

## C++ Template

```c++
#include <iostream>
#include <string>

using namespace std;

class Adjustable
{
public:
	static const int MIN_VOLUME = 0;
	static const int MAX_VOLUME = 100;

	virtual void setVolume(int level) = 0;

	// C++에서는 인터페이스에 기본 구현 함수를 둘 수 있습니다.
	virtual string checkSafety(int level)
	{
		if (level >= MIN_VOLUME && level <= MAX_VOLUME) {
			return "SAFE";
		}
		return "OUT_OF_RANGE";
	}

	virtual ~Adjustable() {}
};

class Speaker : public Adjustable
{
private:
	int volume;
public:
	Speaker() : volume(0) {}

	void setVolume(int level) override
	{
		volume = level;
		cout << "Volume set to " << volume << endl;
	}
};

int main()
{
	int v;
	if (!(cin >> v)) return 0;

	Speaker speaker;
	string safety = speaker.checkSafety(v);
	cout << safety << endl;

	if (safety == "SAFE") {
		speaker.setVolume(v);
	} else {
		cout << "Volume setting failed" << endl;
	}

	return 0;
}
```

## Java Template

```java
import java.util.Scanner;

interface Adjustable {
    int MIN_VOLUME = 0;
    int MAX_VOLUME = 100;

    void setVolume(int level);

    // 디폴트 메서드는 default 키워드를 붙입니다.
    빈칸 String checkSafety(int level) {
        if (level >= MIN_VOLUME && level <= MAX_VOLUME) {
            return "SAFE";
        }
        return "OUT_OF_RANGE";
    }
}

class Speaker implements Adjustable {
    private int volume = 0;

    @Override
    public void setVolume(int level) {
        this.volume = level;
        System.out.println("Volume set to " + volume);
    }
}

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        if (!sc.hasNextInt()) return;
        int v = sc.nextInt();

        Speaker speaker = new Speaker();
        String safety = speaker.checkSafety(v);
        System.out.println(safety);

        if (safety.equals("SAFE")) {
            speaker.setVolume(v);
        } else {
            System.out.println("Volume setting failed");
        }
    }
}
```

## Python3 Template

```python
from abc import ABC, abstractmethod

class Adjustable(ABC):
    MIN_VOLUME = 0
    MAX_VOLUME = 100

    @abstractmethod
    def setVolume(self, level: int):
        pass

    # 파이썬에서는 일반 메서드로 기본 구현을 제공합니다.
    def checkSafety(self, level: int) -> str:
        if self.MIN_VOLUME <= level <= self.MAX_VOLUME:
            return "SAFE"
        return "OUT_OF_RANGE"

class Speaker(Adjustable):
    def __init__(self):
        self.volume = 0

    def setVolume(self, level: int):
        self.volume = level
        print(f"Volume set to {self.volume}")

line = input().strip()
if line:
    v = int(line)
    speaker = Speaker()
    safety = speaker.checkSafety(v)
    print(safety)

    if safety == "SAFE":
        speaker.setVolume(v)
    else:
        print("Volume setting failed")
```
