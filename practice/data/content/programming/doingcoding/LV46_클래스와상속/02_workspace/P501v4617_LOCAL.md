# 17. [클래스와 상속 - 17] 상수와 디폴트 메서드

## 1. 문제 설명

인터페이스에는 추상 메서드 외에도 **상수**와 **디폴트 메서드(Default Method)**를 선언할 수 있습니다.

- **인터페이스 상수**: 선언된 모든 변수는 자동으로 `public static final`이 되어 수정 불가능한 상수가 됩니다.
- **디폴트 메서드 (`default`)**: Java 8부터 도입된 기능으로, 인터페이스 내에서 **기본 실행 코드(본문 `{...}`)를 직접 가질 수 있는 메서드**입니다. 이를 통해 모든 구현 클래스에 공통 로직을 기본 제공할 수 있으며, 구현 클래스에서 필요할 때만 선택적으로 재정의할 수 있습니다.
- (C++과 Python에서는 추상 클래스 내의 `static const` 상수와 기본 구현을 가진 일반 멤버 함수로 동일하게 표현합니다.)

음향 장비 볼륨 규격 `Adjustable` 인터페이스를 정의하세요.
- 규격 상수:
  - `MIN_VOLUME = 0`
  - `MAX_VOLUME = 100`
- 추상 메서드:
  - `setVolume(int level)`: 볼륨을 설정하고 성공 시 설정된 볼륨 반환
- 디폴트 메서드:
  - `checkSafety(int level)`: `level`이 `MIN_VOLUME` 이상 `MAX_VOLUME` 이하이면 `"SAFE"`, 아니면 `"OUT_OF_RANGE"` 문자열 반환
- 구현 클래스 `Speaker`:
  - `checkSafety`는 인터페이스의 디폴트 메서드를 그대로 사용하고, `setVolume`만 구현합니다.

## 2. 입출력 설명

- **입력:**
  - 첫 번째 줄에 설정하려는 볼륨 수치 정수 `V`가 주어집니다. (-50 ≤ V ≤ 150)

- **출력:**
  - 1줄: `checkSafety(V)` 메서드의 실행 결과(`SAFE` 또는 `OUT_OF_RANGE`)를 출력합니다.
  - 2줄:
    - 결과가 `SAFE`인 경우: `Volume set to [V]`를 출력합니다.
    - 결과가 `OUT_OF_RANGE`인 경우: `Volume setting failed`를 출력합니다.

## 3. 예시

### 예시 입력 1
```text
75
```

### 예시 출력 1
```text
SAFE
Volume set to 75
```

### 예시 입력 2
```text
120
```

### 예시 출력 2
```text
OUT_OF_RANGE
Volume setting failed
```

### 예시 입력 3
```text
-5
```

### 예시 출력 3
```text
OUT_OF_RANGE
Volume setting failed
```

## 4. 힌트

- **핵심 아이디어**: 자바에서 디폴트 메서드를 작성할 때는 시그니처 앞에 `default` 키워드를 붙이고 중괄호 `{ ... }` 안에 공통 실행 코드를 작성합니다. 구현 클래스에서는 이를 따로 오버라이딩하지 않아도 바로 호출할 수 있습니다.
- **생각해볼 점**:
  1. `MIN_VOLUME`과 `MAX_VOLUME` 상수를 조건식에 직접 참조하여 경계값을 검사하고 있는가?
  2. 디폴트 메서드의 판정에 따라 `setVolume` 호출 여부를 결정하는 흐름이 안전하게 작성되었는가?
