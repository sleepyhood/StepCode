# 13. [클래스와 상속 - 13] 인터페이스와 다형성

## 1. 문제 설명

인터페이스의 진정한 힘은 **다형성(Polymorphism)**에서 나옵니다.
인터페이스 타입의 참조 변수 하나로, 그 규격을 구현한 어떠한 구체 클래스의 객체라도 자유롭게 가리킬(업캐스팅) 수 있습니다.

- **다형적 참조 예시**:
  - `Shape s = new Rectangle(w, h);`
  - `Shape s = new Circle(r);`
  - 호출 코드는 `s.getArea()` 하나뿐이지만, 실제로 어떤 객체가 들어있느냐에 따라 서로 다른 계산식이 동작합니다.

도형 규격 `Shape` 인터페이스를 정의하고, 이를 구현하는 `Rectangle`(사각형)과 `Circle`(원) 클래스를 작성하세요.
- `Shape` 규격 메서드:
  - `getName()`: 도형의 영문 이름 문자열 반환
  - `getArea()`: 도형의 넓이(`double`) 반환 (원주율 $\pi = 3.14$)

## 2. 입출력 설명

- **입력:**
  - 첫 번째 줄에 도형의 종류를 나타내는 타입 코드 `T`가 주어집니다.
    - `1` → 사각형 (`Rectangle`)
    - `2` → 원 (`Circle`)
  - 두 번째 줄에 도형의 크기 정보가 주어집니다.
    - `T == 1`인 경우: 가로 길이 `W`와 세로 길이 `H`가 공백으로 주어집니다. (1 ≤ W, H ≤ 1000)
    - `T == 2`인 경우: 반지름 `R`이 주어집니다. (1 ≤ R ≤ 1000)

- **출력:**
  - 첫 번째 줄에 도형의 이름(`Rectangle` 또는 `Circle`)을 출력합니다.
  - 두 번째 줄에 계산된 넓이를 소수점 둘째 자리까지 서식(`%.2f`)에 맞춰 출력합니다.

## 3. 예시

### 예시 입력 1
```text
1
5 8
```

### 예시 출력 1
```text
Rectangle
40.00
```

### 예시 입력 2
```text
2
10
```

### 예시 출력 2
```text
Circle
314.00
```

## 4. 힌트

- **핵심 아이디어**: 다형성을 활용하면 조건문 분기 안에서는 객체 생성만 하고, 이름 출력과 넓이 계산은 `Shape` 인터페이스 변수를 통해 한 번만 호출하도록 코드를 깔끔하게 구조화할 수 있습니다.
- **생각해볼 점**:
  1. 원의 넓이 공식은 $3.14 \times R \times R$ 입니다.
  2. 부동소수점 오차를 방지하기 위해 반환 타입은 `double`을 사용하고 있는가?
