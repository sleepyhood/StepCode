# 12. [클래스와 상속 - 12] public 오버라이딩 규칙

## 1. 문제 설명

인터페이스에 선언된 메서드는 누구나 접근할 수 있는 공개 표준 규격이므로, 기본적으로 `public` 성격을 갖습니다.
객체지향에서는 부모나 인터페이스로부터 물려받은 메서드를 오버라이딩할 때 **부모의 접근 범위보다 더 좁게 가시성을 축소할 수 없습니다.**

따라서 자바에서는 인터페이스 메서드를 구현할 때 메서드 앞에 반드시 **`public` 키워드**를 명시해야 컴파일 에러를 피할 수 있으며, C++에서도 상속과 멤버 함수 모두 `public` 영역에 두어야 외부에서 규격대로 사용할 수 있습니다.

문제

미완성된 코드가 주어지면 빈칸에 올바른 코드를 적어 완성시켜주세요.

---

## 2. 입출력 설명

* **입력:**
숫자를 세고 누적하는 Countable 인터페이스를 정의합니다.
Countable 규격을 구현한 SafeCounter 클래스를 만듭니다.
- `increment()`: 카운트 1 증가
- `add(int val)`: 카운트에 val 누적
- `getCount()`: 현재 카운트 반환

시작 숫자 S, 1씩 증가시킬 횟수 K, 더할 값 V를 입력받습니다.
SafeCounter 객체를 생성하고 increment()를 K번, add(V)를 1번 호출합니다.

* **출력:**
최종 카운트 값을 출력합니다.

## C++ Template

```c++
#include <iostream>

using namespace std;

class Countable
{
public:
	virtual void increment() = 0;
	virtual void add(int val) = 0;
	virtual int getCount() = 0;
	virtual ~Countable() {}
};

class SafeCounter : 빈칸 Countable
{
private:
	int count;
public:
	SafeCounter(int initial) : count(initial) {}

	void increment() override
	{
		count++;
	}

	void add(int val) override
	{
		count += val;
	}

	int getCount() override
	{
		return count;
	}
};

int main()
{
	int s, k, v;
	if (!(cin >> s >> k >> v)) return 0;

	SafeCounter counter(s);
	for (int i = 0; i < k; i++) {
		counter.increment();
	}
	counter.add(v);

	cout << counter.getCount() << endl;

	return 0;
}
```

## Python3 Template

class Countable(ABC):
    @abstractmethod
    def increment(self):
        pass

    @abstractmethod
    def add(self, val: int):
        pass

    @abstractmethod
    def getCount(self) -> int:
        pass

class SafeCounter(Countable):
    def __init__(self, initial: int):
        self.count = initial

    def increment(self):
        self.count += 1

    def add(self, val: int):
        self.count += val

        빈칸 self.count
