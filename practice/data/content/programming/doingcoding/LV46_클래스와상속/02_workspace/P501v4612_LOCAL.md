# 12. [클래스와 상속 - 12] public 오버라이딩 규칙

## 1. 문제 설명

인터페이스에 선언된 메서드는 누구나 접근할 수 있는 공개 표준 규격이므로, 기본적으로 `public` 성격을 갖습니다.
객체지향에서는 부모나 인터페이스로부터 물려받은 메서드를 오버라이딩할 때 **부모의 접근 범위보다 더 좁게 가시성을 축소할 수 없습니다.**

따라서 자바에서는 인터페이스 메서드를 구현할 때 메서드 앞에 반드시 **`public` 키워드**를 명시해야 컴파일 에러를 피할 수 있으며, C++에서도 상속과 멤버 함수 모두 `public` 영역에 두어야 외부에서 규격대로 사용할 수 있습니다.

숫자를 세고 누적하는 `Countable` 인터페이스를 구현한 `SafeCounter` 클래스를 작성하세요.
- 규격 메서드:
  - `increment()`: 카운트 1 증가
  - `add(int val)`: 카운트에 `val` 누적
  - `getCount()`: 현재 카운트 반환

## 2. 입출력 설명

- **입력:**
  - 첫 번째 줄에 시작 숫자 `S`, 1씩 증가시킬 횟수 `K`, 한 번에 더할 값 `V`가 공백으로 구분되어 주어집니다. (0 ≤ S, K, V ≤ 1000)

- **출력:**
  - `SafeCounter` 객체를 시작 숫자 `S`로 생성한 후, `increment()`를 `K`번 호출하고 `add(V)`를 1번 호출했을 때의 최종 카운트 값을 출력합니다.

## 3. 예시

### 예시 입력 1
```text
10 3 5
```

### 예시 출력 1
```text
18
```

### 예시 입력 2
```text
0 10 25
```

### 예시 출력 2
```text
35
```

## 4. 힌트

### 💡 팁
- 자바에서 클래스의 메서드 앞에 `public`을 빠뜨리면 기본 패키지(default) 접근 권한이 되어 "Cannot reduce the visibility of the inherited method" 컴파일 오류가 발생합니다. 반드시 `public`을 명시하세요.
