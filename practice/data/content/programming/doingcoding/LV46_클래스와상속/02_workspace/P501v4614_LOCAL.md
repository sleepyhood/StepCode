# 14. [클래스와 상속 - 14] 인터페이스 배열 일괄 제어

## 1. 문제 설명

인터페이스의 강력한 장점 중 하나는 **서로 다른 클래스의 객체들을 하나의 인터페이스 배열(또는 리스트)에 묶어 동일한 방식으로 일괄 제어**할 수 있다는 점입니다.

- 예: `Device[] devices = new Device[3];` 배열에 `TV`, `AirConditioner`, `Computer` 객체를 각각 담은 후, 반복문 하나로 모든 기기의 동작 메서드를 순차 실행할 수 있습니다.

전자기기 공통 규격인 `Device` 인터페이스를 정의하고, 기기별 전력 소비량을 계산하는 스마트 전력 관리 프로그램을 작성하세요.
- `Device` 규격 메서드:
  - `getName()`: 기기명 문자열 반환
  - `calculatePower(int hour)`: 가동 시간(`hour`) 동안 소비한 총 전력량(W) 반환
- 기기별 시간당 전력 소비 기준:
  - `TV` → 시간당 100W
  - `AirConditioner` → 시간당 800W
  - `Computer` → 시간당 250W

## 2. 입출력 설명

- **입력:**
  - 첫 번째 줄에 등록할 기기의 수 `N`이 주어집니다. (1 ≤ N ≤ 10)
  - 두 번째 줄부터 `N`개의 줄에 걸쳐 기기 종류 문자열 `Type`과 가동 시간 정수 `H`가 공백으로 주어집니다. (1 ≤ H ≤ 24)

- **출력:**
  - 입력 순서대로 각 기기의 이름과 소비 전력량을 "[기기명]: [소비전력]W" 형식으로 출력합니다.
  - 마지막 줄에 모든 기기의 총 소비 전력량을 "Total: [총소비전력]W" 형식으로 출력합니다.

## 3. 예시

### 예시 입력 1
```text
3
TV 3
AirConditioner 2
Computer 4
```

### 예시 출력 1
```text
TV: 300W
AirConditioner: 1600W
Computer: 1000W
Total: 2900W
```

### 예시 입력 2
```text
2
Computer 8
TV 5
```

### 예시 출력 2
```text
Computer: 2000W
TV: 500W
Total: 2500W
```
