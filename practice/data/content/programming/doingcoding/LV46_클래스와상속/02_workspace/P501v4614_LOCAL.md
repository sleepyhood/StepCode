# 14. [클래스와 상속 - 14] 인터페이스 배열 일괄 제어

## 1. 문제 설명

인터페이스의 강력한 장점 중 하나는 **서로 다른 클래스의 객체들을 하나의 인터페이스 배열(또는 리스트)에 묶어 동일한 방식으로 일괄 제어**할 수 있다는 점입니다.

- 예: `Device[] devices = new Device[3];` 배열에 `TV`, `AirConditioner`, `Computer` 객체를 각각 담은 후, 반복문 하나로 모든 기기의 동작 메서드를 순차 실행할 수 있습니다.

문제

미완성된 코드가 주어지면 빈칸에 올바른 코드를 적어 완성시켜주세요.

---

## 2. 입출력 설명

* **입력:**
전자기기 공통 규격 Device 인터페이스를 정의합니다.
- `getName()`: 기기명 문자열 반환
- `calculatePower(int hour)`: 가동 시간 동안 소비한 전력량(W) 반환
  - `TV` → 시간당 100W
  - `AirConditioner` → 시간당 800W
  - `Computer` → 시간당 250W

기기 개수 N을 입력받고, N개의 기기 종류와 가동 시간 H를 입력받아 Device 인터페이스 배열에 저장합니다.

* **출력:**
배열을 순회하며 각 기기의 이름과 소비 전력량을 "[기기명]: [소비전력]W" 형식으로 출력합니다.
마지막 줄에 모든 기기의 총 소비 전력량을 "Total: [총소비전력]W" 형식으로 출력합니다.

## C++ Template

```c++
#include <iostream>
#include <string>
#include <vector>

using namespace std;

class Device
{
public:
	virtual string getName() = 0;
	virtual int calculatePower(int hour) = 0;
	virtual ~Device() {}
};

class TV : public Device
{
public:
	string getName() override { return "TV"; }
	int calculatePower(int hour) override { return hour * 100; }
};

class AirConditioner : public Device
{
public:
	string getName() override { return "AirConditioner"; }
	int calculatePower(int hour) override { return hour * 800; }
};

class Computer : public Device
{
public:
	string getName() override { return "Computer"; }
	int calculatePower(int hour) override { return hour * 250; }
};

int main()
{
	int n;
	if (!(cin >> n)) return 0;

	// Device 인터페이스 포인터를 담는 벡터
	vector<빈칸*> devices;
	vector<int> hours(n);

	for (int i = 0; i < n; i++) {
		string type;
		int h;
		cin >> type >> h;
		hours[i] = h;

		if (type == "TV") devices.push_back(new TV());
		else if (type == "AirConditioner") devices.push_back(new AirConditioner());
		else if (type == "Computer") devices.push_back(new Computer());
	}

	int total = 0;
	for (int i = 0; i < n; i++) {
		int power = devices[i]->calculatePower(hours[i]);
		cout << devices[i]->getName() << ": " << power << "W" << endl;
		total += power;
		delete devices[i];
	}
	cout << "Total: " << total << "W" << endl;

	return 0;
}
```

## Java Template

```java
import java.util.Scanner;

interface Device {
    String getName();
    int calculatePower(int hour);
}

class TV implements Device {
    @Override
    public String getName() { return "TV"; }
    @Override
    public int calculatePower(int hour) { return hour * 100; }
}

class AirConditioner implements Device {
    @Override
    public String getName() { return "AirConditioner"; }
    @Override
    public int calculatePower(int hour) { return hour * 800; }
}

class Computer implements Device {
    @Override
    public String getName() { return "Computer"; }
    @Override
    public int calculatePower(int hour) { return hour * 250; }
}

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        if (!sc.hasNextInt()) return;
        int n = sc.nextInt();

        // 인터페이스 배열 선언
        빈칸[] devices = new 빈칸[n];
        int[] hours = new int[n];

        for (int i = 0; i < n; i++) {
            String type = sc.next();
            hours[i] = sc.nextInt();

            if (type.equals("TV")) devices[i] = new TV();
            else if (type.equals("AirConditioner")) devices[i] = new AirConditioner();
            else if (type.equals("Computer")) devices[i] = new Computer();
        }

        int total = 0;
        for (int i = 0; i < n; i++) {
            int power = devices[i].calculatePower(hours[i]);
            System.out.println(devices[i].getName() + ": " + power + "W");
            total += power;
        }
        System.out.println("Total: " + total + "W");
    }
}
```

```python
        pass

        pass

class TV(Device):

        return "TV"

        return hour * 800
```
