# 15. [클래스와 상속 - 15] 다중 구현

## 1. 문제 설명

자바는 클래스의 다중 상속(여러 부모 클래스를 동시에 상속)을 지원하지 않습니다. 부모들이 동일한 이름의 멤버를 가질 때 발생하는 모호성(다이아몬드 문제) 때문입니다.
하지만 인터페이스는 실제 구현 코드가 없는 순수 규격이므로 충돌 위험이 없어 **한 클래스가 여러 인터페이스를 동시에 구현(다중 구현)**할 수 있습니다.

- **문법**: `class Duck implements Swimmable, Flyable`
- C++과 Python에서는 다중 상속 문법(`class Duck : public Swimmable, public Flyable`, `class Duck(Swimmable, Flyable):`)으로 완전히 동일하게 구현됩니다.

두 개의 독립된 규격 인터페이스를 정의하세요.
- `Swimmable`: `swim(int meter)` → 수영 메시지 반환
- `Flyable`: `fly(int meter)` → 비행 메시지 반환

각 동물별 구현 능력:
- `Duck` → `Swimmable`, `Flyable` 둘 다 구현
- `Penguin` → `Swimmable`만 구현 (비행 불가)
- `Sparrow` → `Flyable`만 구현 (수영 불가)

## 2. 입출력 설명

- **입력:**
  - 첫 번째 줄에 동물 이름 `Animal`이 주어집니다. (`Duck`, `Penguin`, `Sparrow` 중 하나)
  - 두 번째 줄에 명령할 동작 `Action`과 이동 거리 `D`가 공백으로 주어집니다.
    - `Action`은 `swim` 또는 `fly` 중 하나입니다. (1 ≤ D ≤ 1000)

- **출력:**
  - 동물이 해당 인터페이스 능력을 가지고 있으면 다음 형식으로 출력합니다.
    - 수영 성공 시: `[Animal] swims [D]m`
    - 비행 성공 시: `[Animal] flies [D]m`
  - 동물이 해당 인터페이스 능력을 지원하지 않으면 다음 형식으로 출력합니다.
    - `[Animal] cannot [Action]!`

## 3. 예시

### 예시 입력 1
```text
Duck
swim 50
```

### 예시 출력 1
```text
Duck swims 50m
```

### 예시 입력 2
```text
Penguin
fly 20
```

### 예시 출력 2
```text
Penguin cannot fly!
```

### 예시 입력 3
```text
Duck
fly 100
```

### 예시 출력 3
```text
Duck flies 100m
```

## 4. 힌트

- **핵심 아이디어**: 객체가 특정 인터페이스를 구현하고 있는지 확인할 때는 `instanceof` 연산자(C++은 `dynamic_cast`, Python은 `isinstance`)를 유용하게 활용할 수 있습니다.
- **생각해볼 점**:
  1. `Duck` 클래스는 `implements Swimmable, Flyable`처럼 쉼표(`,`)로 구분하여 두 규격을 모두 오버라이딩했는가?
  2. `Penguin` 객체에 `fly`를 시도했을 때 예외가 터지지 않고 안전하게 검사되어 불가 메시지가 출력되는가?
