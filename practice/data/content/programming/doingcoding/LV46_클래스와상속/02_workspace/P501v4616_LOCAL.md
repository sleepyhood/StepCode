# 16. [클래스와 상속 - 16] 인터페이스 상속

## 1. 문제 설명

클래스가 인터페이스를 물려받을 때는 `implements`(구현)를 쓰지만, **인터페이스가 다른 인터페이스를 물려받아 규격을 확장할 때는 `extends`(상속)**를 사용합니다.
특히 클래스와 달리, **인터페이스끼리는 여러 인터페이스를 한꺼번에 다중 상속(`extends A, B`)하는 것이 완벽하게 허용**됩니다.

- 하위 인터페이스를 구현하는 클래스는 상위 인터페이스들의 모든 추상 메서드까지 남김없이 구현해야 합니다.

문제

미완성된 코드가 주어지면 빈칸에 올바른 코드를 적어 완성시켜주세요.

---

## 2. 입출력 설명

* **입력:**
기본 규격 Printable(출력)과 Scannable(스캔) 인터페이스를 정의합니다.
두 인터페이스를 상속받고 faxDoc 기능을 추가한 SmartOffice 인터페이스를 만듭니다.
SmartOffice 규격을 구현하는 MultiFunctionPrinter 클래스를 작성합니다.

문서 제목 Doc과 팩스 대상 전화번호 Phone을 입력받습니다.
MultiFunctionPrinter 객체를 생성하여 printDoc, scanDoc, faxDoc 메서드를 순차 실행합니다.

* **출력:**
- 1줄: `Printing: [Doc]`
- 2줄: `Scanning: [Doc]`
- 3줄: `Faxing: [Doc] to [Phone]`

## C++ Template

```c++
#include <iostream>
#include <string>

using namespace std;

class Printable
{
public:
	virtual void printDoc(string doc) = 0;
	virtual ~Printable() {}
};

class Scannable
{
public:
	virtual void scanDoc(string doc) = 0;
	virtual ~Scannable() {}
};

// Printable과 Scannable을 다중 상속받아 규격을 확장한 SmartOffice
class SmartOffice : public Printable, 빈칸
{
public:
	virtual void faxDoc(string doc, string phone) = 0;
};

class MultiFunctionPrinter : public SmartOffice
{
public:
	void printDoc(string doc) override
	{
		cout << "Printing: " << doc << endl;
	}

	void scanDoc(string doc) override
	{
		cout << "Scanning: " << doc << endl;
	}

	void faxDoc(string doc, string phone) override
	{
		cout << "Faxing: " << doc << " to " << phone << endl;
	}
};

int main()
{
	string doc, phone;
	if (!(cin >> doc >> phone)) return 0;

	MultiFunctionPrinter mfp;
	mfp.printDoc(doc);
	mfp.scanDoc(doc);
	mfp.faxDoc(doc, phone);

	return 0;
}
```

## Java Template

```java
import java.util.Scanner;

interface Printable {
    void printDoc(String doc);
}

interface Scannable {
    void scanDoc(String doc);
}

// 인터페이스가 다른 인터페이스들을 상속받을 때는 extends를 사용합니다.
interface SmartOffice 빈칸 Printable, Scannable {
    void faxDoc(String doc, String phone);
}

class MultiFunctionPrinter implements SmartOffice {
    @Override
    public void printDoc(String doc) {
        System.out.println("Printing: " + doc);
    }

    @Override
    public void scanDoc(String doc) {
        System.out.println("Scanning: " + doc);
    }

    @Override
    public void faxDoc(String doc, String phone) {
        System.out.println("Faxing: " + doc + " to " + phone);
    }
}

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        if (!sc.hasNext()) return;
        String doc = sc.next();
        String phone = sc.next();

        MultiFunctionPrinter mfp = new MultiFunctionPrinter();
        mfp.printDoc(doc);
        mfp.scanDoc(doc);
        mfp.faxDoc(doc, phone);
    }
}
```
