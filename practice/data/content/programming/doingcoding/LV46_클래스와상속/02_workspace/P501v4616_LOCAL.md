# 16. [클래스와 상속 - 16] 인터페이스 상속

## 1. 문제 설명

클래스가 인터페이스를 물려받을 때는 `implements`(구현)를 쓰지만, **인터페이스가 다른 인터페이스를 물려받아 규격을 확장할 때는 `extends`(상속)**를 사용합니다.
특히 클래스와 달리, **인터페이스끼리는 여러 인터페이스를 한꺼번에 다중 상속(`extends A, B`)하는 것이 완벽하게 허용**됩니다.

- 하위 인터페이스를 구현하는 클래스는 상위 인터페이스들의 모든 추상 메서드까지 남김없이 구현해야 합니다.

사무기기 규격을 확장하는 복합기 시스템을 구현하세요.
- 기본 규격:
  - `Printable`: `printDoc(String doc)` → `Printing: [doc]`
  - `Scannable`: `scanDoc(String doc)` → `Scanning: [doc]`
- 확장 규격:
  - `SmartOffice extends Printable, Scannable`
  - 추가 메서드: `faxDoc(String doc, String phone)` → `Faxing: [doc] to [phone]`
- 구현 클래스:
  - `MultiFunctionPrinter implements SmartOffice`

## 2. 입출력 설명

- **입력:**
  - 첫 번째 줄에 처리할 문서의 제목 문자열 `Doc`이 주어집니다.
  - 두 번째 줄에 팩스를 보낼 대상 전화번호 문자열 `Phone`이 주어집니다.

- **출력:**
  - `MultiFunctionPrinter` 객체를 생성하여 다음 순서대로 세 메서드를 실행하고 각각 한 줄씩 출력합니다.
    - 1줄: `Printing: [Doc]`
    - 2줄: `Scanning: [Doc]`
    - 3줄: `Faxing: [Doc] to [Phone]`

## 3. 예시

### 예시 입력 1
```text
Report.pdf
010-1234-5678
```

### 예시 출력 1
```text
Printing: Report.pdf
Scanning: Report.pdf
Faxing: Report.pdf to 010-1234-5678
```

### 예시 입력 2
```text
Invoice.docx
02-987-6543
```

### 예시 출력 2
```text
Printing: Invoice.docx
Scanning: Invoice.docx
Faxing: Invoice.docx to 02-987-6543
```
