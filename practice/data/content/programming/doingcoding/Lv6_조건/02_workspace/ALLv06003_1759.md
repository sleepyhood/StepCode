# 15. [조건-switch case default] switch case default 문제

## 1. 문제 설명
사용자로부터 숫자를 입력받고, 해당 숫자에 따라 알맞은 메시지를 출력하세요.

단, 1~3 이외의 값은 모두 "지원하지 않는 번호입니다"를 출력해야 합니다.

---

## 2. 입출력 설명

* **입력:**
정수(1~9) 하나가 입력됩니다.

* **출력:**
해당 번호에 맞는 메시지를 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
2
```

### 예시 출력 1
```text
선택: 2
```

### 예시 입력 2
```text
5
```

### 예시 출력 2
```text
지원하지 않는 번호입니다
```

---

## 4. 힌트
- case 1~3까지만 정의하고 나머지는 default로 처리하세요.
