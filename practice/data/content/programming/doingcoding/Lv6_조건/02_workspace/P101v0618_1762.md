# 18. [조건-switch case default] 계산기 만들기

## 1. 문제 설명
간단한 계산기 프로그램을 만들어보세요.

두 정수와 연산자(+,-,\*,/)가 입력되었을 때, 그 결과를 출력합니다.

---

## 2. 입출력 설명

* **입력:**
정수1 연산자 정수2 (공백으로 구분됨) 가 한 줄에 입력됩니다.

* **출력:**
올바른 연산이라면 계산 결과를 정수로 출력합니다.

만약 연산이 불가할 경우,"잘못된 연산입니다" 라고 출력합니다.

만약 잘못된 연산자리면, "잘못된 연산자입니다" 라고 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
5 + 3
```

### 예시 출력 1
```text
8
```

### 예시 입력 2
```text
7 & 2
```

### 예시 출력 2
```text
잘못된 연산자입니다
```

### 예시 입력 3
```text
9 / 0
```

### 예시 출력 3
```text
잘못된 연산입니다
```

---

## 4. 힌트
- 연산자는 switch-case로 처리하고, 나머지는 기본 연산을 활용할 수 있습니다.

- case 내부에는 조건문(if)를 사용할 수 있습니다.
