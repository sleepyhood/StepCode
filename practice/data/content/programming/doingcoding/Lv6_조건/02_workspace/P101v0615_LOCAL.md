# 15. [조건-switch break] 평일/주말 구분기

## 1. 문제 설명
요일 번호를 입력받아 평일인지 주말인지 출력하는 프로그램을 작성하세요.

- **1 ~ 5** (월요일 ~ 금요일) → `평일`
- **6 ~ 7** (토요일 ~ 일요일) → `주말`

1~7 이외의 정수가 입력되면 `잘못된 입력`을 출력합니다.

---

## 2. 입출력 설명

* **입력:**
정수 하나가 입력됩니다.

* **출력:**
`평일`, `주말`, `잘못된 입력` 중 하나를 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
3
```

### 예시 출력 1
```text
평일
```

### 예시 입력 2
```text
7
```

### 예시 출력 2
```text
주말
```

### 예시 입력 3
```text
9
```

### 예시 출력 3
```text
잘못된 입력
```

---

## 4. 힌트
- 1~5는 모두 같은 결과(`평일`)를 출력합니다. `case 1: case 2: ... case 5:` 처럼 연속으로 나열한 뒤 출력하세요.

- 6과 7도 마찬가지로 `case 6: case 7:` 으로 묶어 `주말`을 출력하세요.
