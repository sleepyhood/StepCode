# 17. [조건-switch case] 달력 문제

## 1. 문제 설명
사용자로부터 월(1~12)을 입력받아 해당 월의 날짜 수를 출력하는 프로그램을 작성하세요.

2월은 28일로 간주하며, 입력이 1~12가 아니면 "잘못된 입력"을 출력합니다.

---

## 2. 입출력 설명

* **입력:**
월을 의미하는 정수 하나 (1~12)가 입력됩니다.

* **출력:**
입력된 월의 날짜 수 또는 오류 메시지를 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
3
```

### 예시 출력 1
```text
31일
```

### 예시 입력 2
```text
2
```

### 예시 출력 2
```text
28일
```

### 예시 입력 3
```text
13
```

### 예시 출력 3
```text
잘못된 입력
```

---

## 4. 힌트
- 월에 따라 날짜가 다르므로 여러 개의 case가 같은 결과를 출력할 수 있습니다.

- default 문으로 범위를 벗어난 입력을 처리하세요.
