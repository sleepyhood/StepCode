# [숙제 4] 도형 넓이 계산기

## 1. 문제 설명
도형의 종류를 나타내는 문자와 가로, 세로 길이를 입력받아 넓이를 출력하는 프로그램을 작성하세요.

대문자와 소문자를 모두 받아들입니다.

| 도형 문자 | 도형 | 넓이 공식 |
|:---:|:---:|:---:|
| `T` 또는 `t` | 삼각형 | `(가로 × 세로) / 2` |
| `R` 또는 `r` | 사각형 | `가로 × 세로` |

다음의 경우에는 결과 대신 오류 메시지를 출력합니다.
- 가로 또는 세로가 **0 이하**인 경우 → `잘못된 길이입니다`
- 위 표에 없는 문자가 입력된 경우 → `잘못된 도형`

> **주의**: 넓이는 **정수로 출력**합니다. 소수점 이하는 버립니다.

---

## 2. 입출력 설명

* **입력:**
도형 문자, 가로, 세로가 한 줄에 공백으로 구분되어 입력됩니다.

* **출력:**
넓이(정수), `잘못된 길이입니다`, `잘못된 도형` 중 하나를 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
T 4 5
```

### 예시 출력 1
```text
10
```

### 예시 입력 2
```text
r 3 6
```

### 예시 출력 2
```text
18
```

### 예시 입력 3
```text
T 0 5
```

### 예시 출력 3
```text
잘못된 길이입니다
```

### 예시 입력 4
```text
Q 4 5
```

### 예시 출력 4
```text
잘못된 도형
```

## 4. 힌트
### 💡 힌트 1 (방향) — 무엇을 먼저 처리해야 하나?
도형 문자(`T`, `R`)를 먼저 판별한 다음, 그 안에서 길이의 유효성을 검사하세요.
길이가 잘못된 경우보다 **도형이 잘못된 경우를 먼저 필터링**하는 것이 자연스러운 흐름입니다.

### 💡 힌트 2 (전략) — 두 개의 제어 구조를 어떻게 조합할까?
`switch`문으로 도형을 분기하고, 각 `case` 내부에서 `if`문으로 길이를 검사하세요.
수업 시간에 배운 **18번 계산기 문제**에서 나누기 0을 `case '/'` 안의 `if`로 처리한 방법과 동일한 패턴입니다.

### 💡 힌트 3 (구현 방향) — 의사 코드
```
입력: shape, w, h

switch(shape):
    case 'T', 't':
        if (w 또는 h가 0 이하):
            출력: "잘못된 길이입니다"
        else:
            출력: (w * h) / 2
        break
    case 'R', 'r':
        if (w 또는 h가 0 이하):
            출력: "잘못된 길이입니다"
        else:
            출력: w * h
        break
    default:
        출력: "잘못된 도형"
```
