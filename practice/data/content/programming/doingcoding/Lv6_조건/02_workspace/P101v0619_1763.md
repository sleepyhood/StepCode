# 19. [조건-switch case default] 성적표

## 1. 문제 설명
점수를 입력받아 등급을 출력하는 프로그램을 작성하세요.

90점 이상은 A, 80~89는 B, 70~79는 C, 그 외는 F로 출력합니다.

---

## 2. 입출력 설명

* **입력:**
0~100 사이 정수 하나가 입력됩니다.

* **출력:**
A, B, C, F 중 하나가 출력됩니다.

---

## 3. 예시
### 예시 입력 1
```text
85
```

### 예시 출력 1
```text
B
```

### 예시 입력 2
```text
63
```

### 예시 출력 2
```text
F
```

---

## 4. 힌트
- 점수를 10으로 나눈 몫을 기준으로 switch문을 구성하세요.
- **주의:** 입력 범위가 100점까지이므로, 100점일 때는 10으로 나눈 몫이 `10`이 됩니다. 몫이 `9`일 때와 `10`일 때 모두 `A` 등급을 출력하도록 case를 묶어주어야 합니다. (C/C++ 등에서는 `score / 10`, Python3에서는 `score // 10`을 활용하세요.)
