# 13. [조건-switch case default] switch case break 배우기

## 1. 문제 설명
switch문에서 break의 유무에 따라 결과가 달라지는 것을 확인하는 예제를 작성하세요.

입력된 숫자가 1일 때, break가 없다면 어떤 출력이 나오는지 확인합니다.

---

## 2. 입출력 설명

* **입력:**
1~3 사이 정수 하나가 입력됩니다.

* **출력:**
실행된 출력 메시지가 입력에 따라 변합니다.

---

## 3. 예시
### 예시 입력 1
```text
1
```

### 예시 출력 1
```text
1입니다
2입니다
3입니다
```

### 예시 입력 2
```text
2
```

### 예시 출력 2
```text
2입니다
3입니다
```

---

## 4. 힌트
- break가 없다면 그 아래 case들도 실행됩니다.
