# 12. [조건-switch case] switch case 배우기

## 1. 문제 설명
1부터 3 사이의 정수를 입력받아 각 숫자에 해당하는 한글 단어를 출력하세요.

- 1 → `하나`
- 2 → `둘`
- 3 → `셋`

입력은 항상 1, 2, 3 중 하나입니다.

---

## 2. 입출력 설명

* **입력:**
1, 2, 3 중 하나의 정수가 입력됩니다.

* **출력:**
입력에 해당하는 문자열을 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
2
```

### 예시 출력 1
```text
둘
```

---

## 4. 힌트
- switch문의 각 case에 숫자를 지정하고, 해당 한글 단어를 출력하세요.
