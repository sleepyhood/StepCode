# 16. [조건-switch char] 알파벳 신호등

## 1. 문제 설명
신호등 색상을 나타내는 알파벳 문자를 입력받아, 해당 신호의 의미를 출력하는 프로그램을 작성하세요.

대문자와 소문자를 모두 받아들입니다.

- `R` 또는 `r` → `정지`
- `G` 또는 `g` → `진행`
- `Y` 또는 `y` → `주의`
- 그 외의 문자 → `잘못된 신호`

---

## 2. 입출력 설명

* **입력:**
알파벳 문자 하나가 입력됩니다.

* **출력:**
해당 신호의 의미를 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
R
```

### 예시 출력 1
```text
정지
```

### 예시 입력 2
```text
g
```

### 예시 출력 2
```text
진행
```

### 예시 입력 3
```text
B
```

### 예시 출력 3
```text
잘못된 신호
```

---

## 4. 힌트
- switch문에서 `case 'R': case 'r':` 처럼 여러 case를 연속으로 나열하면, 두 문자에 동일한 동작을 적용할 수 있습니다.

- 이 기법을 **case 묶기(그룹핑)**라고 합니다.
