# 5. [조건-switch break] 요일 출력하기

## 1. 문제 설명
1~7 사이의 숫자를 입력받아 해당 요일 이름을 출력하는 프로그램을 작성하세요.

| 입력 | 출력 |
|:---:|:---:|
| 1 | 월요일 |
| 2 | 화요일 |
| 3 | 수요일 |
| 4 | 목요일 |
| 5 | 금요일 |
| 6 | 토요일 |
| 7 | 일요일 |

반드시 **해당 요일 하나만** 출력되어야 합니다.
1~7 이외의 숫자가 입력되면 `잘못된 입력입니다`를 출력합니다.

---

## 2. 입출력 설명

* **입력:**
정수 하나 (1~7)가 입력됩니다.

* **출력:**
해당 요일 이름을 출력합니다. 범위를 벗어난 입력은 `잘못된 입력입니다`를 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
3
```

### 예시 출력 1
```text
수요일
```

### 예시 입력 2
```text
6
```

### 예시 출력 2
```text
토요일
```

### 예시 입력 3
```text
9
```

### 예시 출력 3
```text
잘못된 입력입니다
```

---

## 4. 힌트
- 각 case마다 요일 이름을 출력한 뒤 반드시 `break`를 사용해야 원하는 요일 하나만 출력됩니다.

- `break`를 빠뜨리면 그 아래 case들도 함께 실행됩니다. 직접 실험해보세요!
