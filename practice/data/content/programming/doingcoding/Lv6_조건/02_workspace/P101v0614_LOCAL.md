# 14. [조건-switch default] 식당 키오스크

## 1. 문제 설명
식당 키오스크에서 메뉴 번호를 입력받아 해당 메뉴 이름을 출력하는 프로그램을 작성하세요.

메뉴 구성은 다음과 같습니다.
- 1번: 비빔밥
- 2번: 불고기
- 3번: 냉면

메뉴에 없는 번호가 입력되면 `준비중인 메뉴입니다`를 출력합니다.

---

## 2. 입출력 설명

* **입력:**
정수 하나가 입력됩니다.

* **출력:**
해당 번호의 메뉴 이름 또는 `준비중인 메뉴입니다`를 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
2
```

### 예시 출력 1
```text
불고기
```

### 예시 입력 2
```text
5
```

### 예시 출력 2
```text
준비중인 메뉴입니다
```

---

## 4. 힌트
- case 1, 2, 3 각각에 해당 메뉴 이름을 출력하세요.

- 메뉴에 없는 번호는 `default`로 처리하세요.
