# 12. [조건-switch case] switch case 배우기

## 1. 문제 설명
숫자 1부터 3 사이의 정수를 입력받아 각 숫자에 해당하는 한글 단어를 출력하세요.

1은 "하나", 2는 "둘", 3은 "셋"을 출력하고, 그 외 숫자는 "알 수 없음"을 출력합니다.

**Python으로 푸시는 분들은 넘어가셔도 괜찮습니다. (12번~19번까지)**

---

## 2. 입출력 설명

* **입력:**
1~3 사이의 정수 하나가 입력됩니다.

* **출력:**
입력에 해당하는 문자열을 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
2
```

### 예시 출력 1
```text
둘
```

### 예시 입력 2
```text
4
```

### 예시 출력 2
```text
알 수 없음
```

---

## 4. 힌트
- switch문을 활용하여 숫자별 출력을 만드세요.

- default 문을 활용해 예외를 처리하세요.
