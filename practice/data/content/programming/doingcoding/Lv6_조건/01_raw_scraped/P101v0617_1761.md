# 17. [조건-switch case default] switch case break 문제

## 1. 문제 설명
입력된 숫자에 따라 출력이 이어지는지를 확인해보는 문제입니다.

switch 문에 break 문이 없을 경우 출력 흐름을 예측해보세요.

---

## 2. 입출력 설명

* **입력:**
정수 하나 (1~4)가 입력됩니다.

* **출력:**
case에 따라 메세지가 순차 출력됩니다.

---

## 3. 예시
### 예시 입력 1
```text
2
```

### 예시 출력 1
```text
2입니다
3입니다
4입니다
```

---

## 4. 힌트
- break가 없다면, 다음 case들도 함께 실행됩니다.
