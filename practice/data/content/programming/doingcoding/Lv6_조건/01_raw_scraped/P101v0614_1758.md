# 14. [조건-switch case default] switch case default 배우기

## 1. 문제 설명
switch-case 문에서 default의 역할을 확인해보는 예제를 작성하세요.

입력된 값이 case에 없을 경우 어떻게 처리되는지 연습합니다.

---

## 2. 입출력 설명

* **입력:**
정수(1~5)가 하나 입력됩니다.

* **출력:**
입력에 따른 메시지 (존재하거나, default)를 출력합니다.

---

## 3. 예시
### 예시 입력 1
```text
1
```

### 예시 출력 1
```text
1입니다
```

### 예시 입력 2
```text
7
```

### 예시 출력 2
```text
기본값입니다
```

---

## 4. 힌트
- switch-case에서 default는 case가 일치하지 않을 때 실행됩니다.
