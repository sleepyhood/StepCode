# Python Pygame Round01 응용 실습 활동지

## 진행 방법

이번 활동지는 `읽고 바로 답하기`가 아니라 `실행 -> 관찰 -> 수정 -> 재실행`으로 진행합니다.
각 문제는 반드시 해당 파일을 직접 실행한 뒤 작성하세요.

답을 쓸 때는 아래 4가지를 최대한 구분해서 적으세요.

1. 실행 전 예상
2. 실제로 본 결과
3. 내가 바꾼 코드 또는 숫자
4. 다시 실행한 뒤 달라진 점

## 준비 체크

- `pygame`이 설치되어 있나요? `예 / 아니오`
