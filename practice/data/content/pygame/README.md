# Pygame 콘텐츠 구조

`pygame` 콘텐츠는 `2주 1세트` 기준의 `roundXX/` 폴더로 관리합니다.

## 폴더 규칙

- `round01/`
- `round02/`
- `round03/`

각 세트 폴더는 아래 구조를 기본으로 사용합니다.

```text
roundXX/
  source/
  lesson/
  interactive/
  worksheets/
```

## 역할

- `source/`: 원본 수업 자료, 추출 md/json, 이미지
- `lesson/`: 회차 공통 설명 및 운영 메모
- `interactive/`: 인터랙티브 문제 세트
- `worksheets/`: 출력용 활동지와 정답

## 운영 기준

- `round01` = `1~2주차`
- `round02` = `3~4주차`
- `round03` = `5~6주차`

즉 `roundXX`는 보통 `개념 1주 + 응용 1주`를 묶은 하나의 제작 단위입니다.

각 세트는 아래 산출물을 기본으로 둡니다.

- `source/`: 개념 본문 1개
- `lesson/`: 교사용 운영 메모 1개
- `interactive/`: 공통 포맷 문제 세트 1개
- `worksheets/`: 출력용 활동지 1개, 정답/해설 1개

## 현재 구성

- `round01`: 세트 1 초안
  - 범위: 창 생성, 화면 갱신, 이벤트/종료, FPS/좌표의 일부
  - 현 상태: 1주차 개념 범위보다 넓게 작성되어 있어, 필수 범위와 심화 범위를 분리해 사용하는 것이 적절함

## 원본 `py_*.py` 게임 파일 취급 기준

- 원본 `py_*.py` 게임 파일은 `2주 1세트`에 맞춰 선별할 수 있는 후보 소스다.
- 다만 바로 수업에 투입하는 최종 자료가 아니라, 필요할 때만 `줄인 수업용 버전`으로 변환해 사용한다.
- `roundXX`는 원본 게임 파일을 그대로 복제하기보다, 필요한 범위만 남긴 `줄인 수업용 버전`을 기준으로 구성한다.
