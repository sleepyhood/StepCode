# Pygame Week09 문제 검수 원본

이 문서는 삼각함수 기반 움직임 응용 문제를 웹 세트 JSON으로 만들기 위한 검수 원본이다.

## 1번. 원운동과 좌표 변화

코드 설명:

이 프로그램은 공 하나를 중심점 `(240, 160)`을 기준으로 원운동시키려는 코드이다.
현재는 각도 처리와 좌표 계산이 잘못되어
공이 의도한 원형 경로로 움직이지 않는다.

제시 코드:

```python
import math

center_x = 240
center_y = 160
radius = 80
angle = 0
xpos = center_x + radius * math.cos(angle)
ypos = center_y + radius * math.sin(angle)
```

### 1.1

난이도:

- 하

형식:

- 코드 입력형

출제 의도:

- 각도를 조금씩 증가시키는 한 줄을 쓰게 한다.

문제:

매 프레임 각도를 조금씩 증가시키기 위한 한 줄을 쓰시오.

정답:

```python
angle += 0.05
```

해설:

- 각도를 조금씩 바꿔야 위치가 계속 달라진다.

부분 정답 기준:

- `angle += ...` 형태면 부분 정답
- 작은 증가값까지 적절히 쓰면 정답

실제 실행 확인 결과:

- 각도를 증가시키면 공이 조금씩 다른 위치로 이동한다.

검수 체크:

- 한 줄 정답으로 고정되는지 확인

### 1.2

난이도:

- 하

형식:

- 빈칸형

출제 의도:

- x좌표가 `cos`를 사용한다는 점을 확인하게 한다.

문제:

아래 빈칸에 들어갈 함수 이름을 쓰시오.

```python
xpos = center_x + radius * math.____(angle)
```

정답:

- `cos`

해설:

- x좌표는 중심에서 가로 방향 길이를 더하는 구조로 계산한다.

부분 정답 기준:

- 없음. `cos`만 정답 처리

실제 실행 확인 결과:

- x좌표 계산에는 `cos`가 연결된다.

검수 체크:

- 함수 이름 확인 문제로 읽히는지 확인

### 1.3

난이도:

- 중

형식:

- 빈칸형

출제 의도:

- y좌표가 `sin`을 사용한다는 점을 확인하게 한다.

문제:

아래 빈칸에 들어갈 함수 이름을 쓰시오.

```python
ypos = center_y + radius * math.____(angle)
```

정답:

- `sin`

해설:

- y좌표는 중심에서 세로 방향 길이를 더하는 구조로 계산한다.

부분 정답 기준:

- 없음. `sin`만 정답 처리

실제 실행 확인 결과:

- y좌표 계산에는 `sin`이 연결된다.

검수 체크:

- x좌표와 y좌표 역할이 구분되는지 확인

### 1.4

난이도:

- 중

형식:

- 복수정답 객관식형

출제 의도:

- 각도 증가와 좌표 계산을 함께 수정했을 때의 결과를 판단하게 한다.

문제:

아래 코드로 바꾸었다고 가정한다.

```python
angle += 0.05
xpos = center_x + radius * math.cos(angle)
ypos = center_y + radius * math.sin(angle)
```

실행 후 옳은 것을 모두 고른 것은?

- ㄱ. 공 위치는 각도에 따라 계속 바뀐다.
- ㄴ. 공은 중심점 주변을 도는 것처럼 보일 수 있다.
- ㄷ. x좌표와 y좌표는 각도와 전혀 관계가 없다.
- ㄹ. 반지름 값은 움직임 크기에 영향을 준다.

정답:

- `ㄱ, ㄴ, ㄹ`

해설:

- 각도와 반지름이 함께 좌표를 결정하므로 원형 경로가 만들어진다.

부분 정답 기준:

- `ㄱ, ㄴ` 또는 `ㄴ, ㄹ`이면 부분 정답
- `ㄱ, ㄴ, ㄹ`이면 정답

실제 실행 확인 결과:

- 각도와 반지름을 반영하면 중심 주변을 도는 움직임이 만들어진다.

검수 체크:

- 움직임 해석 문제로 읽히는지 확인
