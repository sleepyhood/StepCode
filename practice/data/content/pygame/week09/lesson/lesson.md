# Python Pygame 모듈 09 · 삼각함수와 궤적 이동

이번 차시는 `sin`, `cos`가 들어간 움직임 코드를 다시 읽고,
궤적이 잘못된 부분을 직접 수정하는 데 초점을 둡니다.

## 이번 모듈에서 다룰 핵심

- `math.sin(...)`
- `math.cos(...)`
- 각도와 좌표
- 원운동
- 진동 움직임

## 학습 방식

이번 모듈은 각도, 반지름, 속도 값이 들어간 코드를 읽고,
왜 원형 또는 진동 경로가 이상하게 보이는지 확인하는 흐름으로 진행합니다.

핵심은 삼각함수 공식을 외우는 것이 아니라,
어떤 값이 좌표 변화를 만들고
그 결과가 화면에서 어떤 경로로 보이는지 설명하는 데 있습니다.

좌표 변화와 각도 개념을 가볍게 복습한 뒤 진행하는 것을 권장합니다.
이 모듈은 값 변화, 시간, 위치 해석이 누적된 뒤 다루는 심화 응용입니다.

## 학습 시작

- 주제: 삼각함수 응용
- 형태: 코드 수정형 + 빈칸형 + 복수정답 객관식형
