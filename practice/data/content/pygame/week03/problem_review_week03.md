## 1번. `MOUSEMOTION`과 입력 이벤트 읽기

제작 기준 코드:

- `problems/problem06.py`의 이벤트 읽기 파트 변형

확인 개념:

- `MOUSEMOTION`
- `event.type`
- 입력 이벤트 발생 시점
- 좌표 저장의 시작점

코드 설명:

이 프로그램은 마우스를 움직일 때마다
이벤트를 읽고 좌표를 저장하는 가장 단순한 그림판 코드이다.
아직 클릭 조건은 없고,
먼저 어떤 이벤트를 읽고 있는지와
그 이벤트가 왜 점 찍기와 연결되는지를 확인한다.

제시 코드:

```python
import sys
import pygame
from pygame.locals import QUIT, MOUSEMOTION

pygame.init()
SURFACE = pygame.display.set_mode((600, 420))
pygame.display.set_caption("week03 problem01")


def main():
    mouse_positions = []

    while True:
        for event in pygame.event.get():
            if event.type == QUIT:
                pygame.quit()
                sys.exit()

            # BLOCK_A_START
            # 문제 1.3: 이벤트 이름을 올바르게 완성하세요.
            elif event.type == MOUSEMOTION:
                mouse_positions.append(event.pos)
            # BLOCK_A_END

        SURFACE.fill((255, 255, 255))

        for pos in mouse_positions:
            pygame.draw.circle(SURFACE, (20, 20, 20), pos, 4)

        pygame.display.update()


if __name__ == "__main__":
    main()
```

코드 설명:

제시 코드:

```python

import pygame
from pygame.locals import QUIT, MOUSEMOTION

pygame.init()
SURFACE = pygame.display.set_mode((600, 420))
pygame.display.set_caption("week03 problem02")
FPSCLOCK = pygame.time.Clock()


def main():
    mouse_positions = []

    while True:
        for event in pygame.event.get():
            if event.type == QUIT:
                pygame.quit()
                sys.exit()

            # BLOCK_A_START
            # 문제 2.2, 2.3: 클릭 상태 조건을 추가하세요.
            elif event.type == MOUSEMOTION:
                mouse_positions.append(event.pos)

        for pos in mouse_positions:
            pygame.draw.circle(SURFACE, (20, 20, 20), pos, 5)

        pygame.display.update()
        FPSCLOCK.tick(60)


if __name__ == "__main__":
    main()
```
