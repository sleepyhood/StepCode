# Python Pygame 모듈 03 · 마우스 입력과 그림판 규칙

이번 차시는 마우스 입력과 그림판 규칙을
서로 다른 네 개의 독립 프로젝트 안에서 다시 읽고,
고장난 코드를 직접 수정하는 데 초점을 둡니다.

## 이번 모듈에서 다룰 핵심

- `MOUSEMOTION`
- 클릭 상태 조건
- `event.pos`
- 좌표 저장
- 반복 출력

## 학습 방식

이번 모듈은 `round01`의 6번 문제를 바탕으로 하되,
이를 `호버 트래커 보드`, `클릭 드로잉 패드`,
`드래그 상태 기록 캔버스`, `스탬프 패턴 보드`의
네 개 독립 프로젝트로 분리해 진행합니다.

핵심은 그림판을 새로 완성하는 것이 아니라,
호버 입력, 클릭 조건, 버튼 상태 기억, 좌표 저장, 반복 출력이
각 프로젝트에서 어떤 역할을 하는지 설명하고 수정하는 데 있습니다.

- 형태: 코드 수정형 + 빈칸형 + 복수정답 객관식형
