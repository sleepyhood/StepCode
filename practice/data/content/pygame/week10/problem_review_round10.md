# Pygame Week10 문제 검수 원본

이 문서는 클래스 구조화 응용 문제를 웹 세트 JSON으로 만들기 위한 검수 원본이다.

## 1번. 플레이어 상태를 클래스로 묶기

코드 설명:

이 프로그램은 플레이어의 좌표와 속도를 따로따로 관리하는 코드이다.
현재는 같은 역할의 값이 흩어져 있어
이동 규칙을 읽고 수정하기가 어렵다.

제시 코드:

```python
player_x = 100
player_y = 120
player_speed = 4

class Player:
    def __init__(self):
        self.x = 100
        self.y = 120
        self.speed = 4
```

### 1.1

난이도:

- 하

형식:

- 코드 입력형

출제 의도:

- 클래스 인스턴스를 만드는 한 줄을 쓰게 한다.

문제:

`Player` 객체 하나를 `player`라는 이름으로 만드는 한 줄을 쓰시오.

정답:

```python
player = Player()
```

해설:

- 클래스를 사용하려면 먼저 객체를 만들어야 한다.

부분 정답 기준:

- `Player()` 호출 형태가 있으면 부분 정답
- 변수명과 호출 형식까지 맞히면 정답

실제 실행 확인 결과:

- 객체를 만들면 `player.x`, `player.y`, `player.speed`처럼 접근할 수 있다.

검수 체크:

- 객체 생성 한 줄로 읽히는지 확인

### 1.2

난이도:

- 하

형식:

- 빈칸형

출제 의도:

- 속성 접근 문법을 확인하게 한다.

문제:

아래 빈칸에 들어갈 말을 쓰시오.

```python
player_x 대신 player.____ 를 사용한다.
```

정답:

- `x`

해설:

- 객체 안에 들어간 좌표는 속성 이름으로 접근한다.

부분 정답 기준:

- 없음. `x`만 정답 처리

실제 실행 확인 결과:

- `player_x`를 `player.x`로 바꾸면 같은 의미를 객체 안에 묶을 수 있다.

검수 체크:

- 속성 접근 문제로 읽히는지 확인

### 1.3

난이도:

- 중

형식:

- 빈칸형

출제 의도:

- 이동 메서드 안에서 속성 갱신을 연결하게 한다.

문제:

아래 메서드의 빈칸에 들어갈 코드를 쓰시오.

```python
def move_right(self):
    self.x += ____
```

정답:

- `self.speed`

해설:

- 이동량도 객체 안 속성으로 함께 묶으면 읽기 쉽다.

부분 정답 기준:

- `speed`를 가리키는 구조면 부분 정답
- `self.speed`면 정답

실제 실행 확인 결과:

- 속도를 속성으로 사용하면 이동 규칙이 한곳에 모인다.

검수 체크:

- 상태값과 메서드 연결 문제로 읽히는지 확인

### 1.4

난이도:

- 중

형식:

- 복수정답 객관식형

출제 의도:

- 클래스로 상태를 묶었을 때의 장점을 판단하게 한다.

문제:

플레이어 좌표와 속도를 `Player` 클래스 안으로 묶고
`player = Player()`로 사용한다고 가정한다.

옳은 것을 모두 고른 것은?

- ㄱ. 같은 역할의 값과 동작을 한곳에 모으기 쉬워진다.
- ㄴ. `player.x`, `player.y`처럼 읽을 수 있다.
- ㄷ. 클래스는 좌표를 전혀 저장할 수 없다.
- ㄹ. 이동 메서드 안에서 `self.speed`를 사용할 수 있다.

정답:

- `ㄱ, ㄴ, ㄹ`

해설:

- 클래스는 같은 역할의 상태와 동작을 함께 묶는 데 유리하다.

부분 정답 기준:

- `ㄱ, ㄴ` 또는 `ㄱ, ㄹ`이면 부분 정답
- `ㄱ, ㄴ, ㄹ`이면 정답

실제 실행 확인 결과:

- 흩어진 변수보다 객체 안에 묶은 구조가 읽기 쉽고 수정하기 편하다.

검수 체크:

- 구조화 장점 판단 문제로 읽히는지 확인
