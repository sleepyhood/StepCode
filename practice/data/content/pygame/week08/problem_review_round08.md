## 1번. 제한시간과 등장 간격

코드 설명:

이 프로그램은 2초마다 목표물을 한 번씩 등장시키고
10초가 지나면 게임을 끝내려는 코드이다.
현재는 등장 간격과 제한시간 조건이 잘못되어 의도와 다른 동작이 나온다.

제시 코드:

```python
import time

spawn_interval = 2.0
time_limit = 10.0
last_spawn = 0.0
start_time = time.time()
```

### 1.1

난이도:

- 하

형식:

- 코드 입력형

출제 의도:

- 등장 간격 비교식을 올바르게 완성하게 한다.

문제:

현재 시간 `now`가 있을 때,
마지막 등장 시각 `last_spawn` 이후 `2초`가 지났는지 확인하는 한 줄을 쓰시오.

정답:

```python
if now - last_spawn >= spawn_interval:
```

해설:

- 현재 시각에서 마지막 등장 시각을 빼서 지난 시간을 구한다.
- 지난 시간이 등장 간격 이상이면 새 목표물을 등장시킬 수 있다.

부분 정답 기준:

- `now - last_spawn` 구조를 유지하면 부분 정답
- 비교 방향과 기준값까지 맞히면 정답

실제 실행 확인 결과:

- 시간 차이를 비교해야 간격 규칙이 제대로 동작한다.

검수 체크:

- 한 줄 정답으로 고정되는지 확인

### 1.2

난이도:

- 하

형식:

- 빈칸형

출제 의도:

- 제한시간 변수 의미를 정확히 확인하게 한다.

문제:

아래 빈칸에 들어갈 숫자를 쓰시오.

```python
time_limit = ____
```

정답:

- `10.0`

해설:

- 이 값은 전체 제한시간을 뜻한다.

부분 정답 기준:

- 없음. `10.0`만 정답 처리

실제 실행 확인 결과:

- 제한시간은 10초 기준으로 설계되어 있다.

검수 체크:

- 변수 의미 확인 문제로 읽히는지 확인

### 1.3

난이도:

- 중

형식:

- 빈칸형

출제 의도:

- 게임 시작 시각과 현재 시각의 차이를 제한시간 판정에 연결하게 한다.

문제:

현재 시각 `now`를 사용해 제한시간이 끝났는지 확인하려고 한다.
아래 빈칸에 들어갈 식을 쓰시오.

```python
elapsed = ____
```

정답:

- `now - start_time`

해설:

- 현재 시각에서 시작 시각을 빼야 지난 시간을 알 수 있다.

부분 정답 기준:

- 시작 시각과 현재 시각을 빼는 구조면 부분 정답
- `now - start_time`이면 정답

실제 실행 확인 결과:

- 지난 시간을 올바르게 계산해야 제한시간 판정이 맞게 동작한다.

검수 체크:

- 시간 차이 개념과 직접 연결되는지 확인

### 1.4

난이도:

- 중

형식:

- 복수정답 객관식형

출제 의도:

- 등장 간격과 제한시간 조건을 함께 수정했을 때의 결과를 판단하게 한다.

문제:

아래 코드로 바꾸었다고 가정한다.

```python
if now - last_spawn >= spawn_interval:
    last_spawn = now

elapsed = now - start_time
game_over = elapsed >= time_limit
```

실행 후 옳은 것을 모두 고른 것은?

- ㄱ. 목표물은 최소 2초 간격으로 등장한다.
- ㄴ. 10초 이상 지나면 게임 종료 조건이 참이 된다.
- ㄷ. 목표물은 매 프레임마다 무조건 등장한다.
- ㄹ. 지난 시간은 `start_time - now`로 계산된다.

정답:

- `ㄱ, ㄴ`

해설:

- 시간 차이를 비교해 등장 간격과 제한시간을 함께 판정한다.

부분 정답 기준:

- `ㄱ`만 또는 `ㄴ`만 고르면 부분 정답
- `ㄱ, ㄴ`이면 정답

실제 실행 확인 결과:

- 등장 간격과 게임 종료 규칙이 시간 차이 기준으로 안정적으로 동작한다.

검수 체크:

- 등장과 종료 규칙을 함께 읽는 문제로 보이는지 확인
