# Python Pygame 모듈 08 · 시간 규칙과 간격 제어

이번 차시는 시간 규칙이 들어간 코드를 다시 읽고,
너무 빠르거나 느린 동작을 직접 수정하는 데 초점을 둡니다.

## 이번 모듈에서 다룰 핵심

- 시간 간격
- 제한시간
- 카운트다운
- 주기적 등장
- 시간 차이 비교

## 학습 방식

이번 모듈은 시간 조건이 빠지거나 잘못 들어간 코드를 읽고,
왜 너무 자주 또는 너무 늦게 동작하는지 확인하는 흐름으로 진행합니다.

핵심은 시간 모듈을 외우는 것이 아니라,
등장 간격과 제한시간 규칙을 고쳤을 때
게임 흐름이 어떻게 안정적으로 바뀌는지 설명하는 데 있습니다.

- 주제: 시간 모듈 응용
