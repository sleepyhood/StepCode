# Python Pygame 모듈 04 · 이동, FPS, 값 변화

이번 차시는 이동, 좌표, FPS, 값 변화를 함께 읽고,
고장난 코드를 직접 수정하는 데 초점을 둡니다.

## 이번 모듈에서 다룰 핵심

- 좌표 누적
- 이동량 변경
- `clock.tick(FPS)`
- FPS와 체감 속도
- 값 변화가 화면 결과로 이어지는 방식

## 학습 방식

이번 모듈은 움직임과 색 변화처럼
여러 값이 동시에 바뀌는 코드를 읽고,
숫자 하나를 바꾸었을 때 화면 결과가 어떻게 달라지는지 비교하는 흐름으로 진행합니다.

핵심은 직접 긴 코드를 작성하는 것이 아니라,
이미 주어진 코드에서 속도, 위치, 값 변화의 의미를 해석하고
필요한 줄을 수정해 원하는 결과로 바꾸는 데 있습니다.

## 학습 시작

- 주제: 이동과 값 변화 응용
- 형태: 코드 수정형 + 빈칸형 + 복수정답 객관식형
- 핵심 포인트: 이동량, 좌표 누적, FPS 비교
