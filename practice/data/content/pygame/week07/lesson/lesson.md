# Python Pygame 모듈 07 · 랜덤 규칙과 등장 제어

이번 차시는 `random` 모듈이 들어간 코드를 다시 읽고,
고장난 규칙을 직접 수정하는 데 초점을 둡니다.

## 이번 주차에서 다룰 핵심

- `random.randint(...)`
- `random.choice(...)`
- 랜덤 위치
- 랜덤 색상
- 랜덤 등장 규칙

## 학습 방식

이번 주차는 매번 다른 값이 나오는 코드를 읽고,
랜덤 범위나 등장 규칙이 잘못되었을 때
어떤 화면 결과가 나오는지 비교하는 흐름으로 진행합니다.

핵심은 랜덤을 외우는 것이 아니라,
숫자 범위와 선택 규칙을 고쳤을 때
결과가 어떻게 안정적으로 바뀌는지 설명하는 데 있습니다.

- 주제: 랜덤 모듈 응용
