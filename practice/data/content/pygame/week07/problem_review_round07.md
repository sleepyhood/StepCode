# Pygame Week07 문제 검수 원본

이 문서는 `random` 모듈 응용 문제를 웹 세트 JSON으로 만들기 위한 검수 원본이다.

## 1번. 랜덤 위치와 등장 규칙

코드 설명:

이 프로그램은 별 하나를 화면 위쪽 어딘가에 떨어뜨리도록 만들려는 코드이다.
현재는 랜덤 범위와 색상 선택 규칙이 잘못되어
별이 화면 밖에 나오거나 의도와 다른 색으로 보일 수 있다.

제시 코드:

```python
import random
import pygame

pygame.init()
SURFACE = pygame.display.set_mode((480, 320))

star_x = random.randint(0, 800)
star_color = random.choice([(255, 255, 0), (255, 120, 120)])
```

### 1.1

난이도:

- 하

형식:

- 코드 입력형

출제 의도:

- 랜덤 x좌표 범위를 화면 너비에 맞게 수정하게 한다.

문제:

가로 폭이 `480`인 화면 안에서만 별이 나오도록
`star_x`를 만드는 한 줄을 다시 쓰시오.

정답:

```python
star_x = random.randint(0, 479)
```

해설:

- 화면 가로 범위는 `0`부터 `479`까지다.
- `800`까지 뽑으면 화면 밖 좌표가 나올 수 있다.

부분 정답 기준:

- `random.randint(...)` 형태를 유지하면 부분 정답
- 시작과 끝 범위를 모두 맞히면 정답

실제 실행 확인 결과:

- 기존 코드에서는 별이 화면 오른쪽 밖에서 시작할 수 있다.

검수 체크:

- 범위 수정 의도가 한 줄 정답으로 고정되는지 확인

### 1.2

난이도:

- 하

형식:

- 빈칸형

출제 의도:

- 랜덤 함수 이름과 선택 규칙을 구분하게 한다.

문제:

아래 빈칸에 들어갈 함수 이름을 쓰시오.

```python
star_color = random.________([(255, 255, 0), (255, 120, 120)])
```

정답:

- `choice`

해설:

- 여러 후보 중 하나를 고를 때는 `choice()`를 사용한다.

부분 정답 기준:

- 없음. `choice`만 정답 처리

실제 실행 확인 결과:

- 색상 후보 목록 중 하나를 골라 별 색을 정할 수 있다.

검수 체크:

- 함수 이름 확인 문제로 읽히는지 확인

### 1.3

난이도:

- 중

형식:

- 빈칸형

출제 의도:

- y좌표 시작 위치를 화면 위쪽 바깥으로 설정하는 이유를 이해하게 한다.

문제:

별이 화면 위쪽에서 떨어져 내려오게 하려면
아래 빈칸에 들어갈 숫자를 쓰시오.

```python
star_y = ____
```

정답:

- `-20`

해설:

- 작은 음수로 시작하면 화면 위 바깥에서 내려오는 것처럼 보인다.

부분 정답 기준:

- 없음. `-20`만 정답 처리

실제 실행 확인 결과:

- `-20`에서 시작하면 별이 위쪽 밖에서 나타난다.

검수 체크:

- 화면 밖 시작 위치의 의미가 문제와 연결되는지 확인

### 1.4

난이도:

- 중

형식:

- 복수정답 객관식형

출제 의도:

- 랜덤 범위와 색상 선택을 함께 수정했을 때의 결과를 판단하게 한다.

문제:

아래 코드로 바꾸었다고 가정한다.

```python
star_x = random.randint(0, 479)
star_color = random.choice([(255, 255, 0), (255, 120, 120)])
star_y = -20
```

실행 후 옳은 것을 모두 고른 것은?

- ㄱ. 별은 화면 가로 범위 안에서 시작한다.
- ㄴ. 별 색은 두 후보 중 하나로 정해진다.
- ㄷ. 별은 항상 화면 아래쪽에서 시작한다.
- ㄹ. 별 x좌표는 매번 같게 고정된다.

정답:

- `ㄱ, ㄴ`

해설:

- x좌표는 화면 안 범위에서 랜덤으로 뽑힌다.
- 색상도 후보 두 개 중 하나로 선택된다.

부분 정답 기준:

- `ㄱ`만 또는 `ㄴ`만 고르면 부분 정답
- `ㄱ, ㄴ`이면 정답

실제 실행 확인 결과:

- 별은 화면 안쪽 가로 범위에서 시작하고 색은 두 후보 중 하나가 된다.

검수 체크:

- 결과 예측이 랜덤 규칙과 직접 연결되는지 확인
