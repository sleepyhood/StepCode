# Python Pygame 6주차

이번 주차는 `세트 3. FPS, 좌표, 값 변화`의 응용 차시입니다.

- 좌표 수정으로 위치와 속도를 조절하는 방법을 설명할 수 있다.
- 값 변화가 화면 결과로 이어지는 흐름을 오픈북 문제로 연결할 수 있다.
