# Python Pygame 모듈 06 · 미니게임 종합 응용

이번 차시는 앞에서 다룬 요소를 함께 읽고,
고장난 미니게임 코드를 직접 수정하는 데 초점을 둡니다.

## 이번 주차에서 다룰 핵심

- 화면 갱신
- 입력 처리
- 좌표 이동
- 조건 판정
- 간단한 점수 또는 목표 규칙

## 학습 방식

이번 주차는 앞 주차에서 다룬 수정 포인트를 한 문제 안에 다시 조합해,
부분 기능이 고장난 미니게임 코드를 단계적으로 복구하는 흐름으로 진행합니다.

핵심은 완성된 게임을 처음부터 만드는 것이 아니라,
이미 있는 코드에서 어떤 부분이 잘못 연결되었는지 읽고
입력, 이동, 판정, 결과 표시를 순서대로 바로잡는 데 있습니다.

## 학습 시작

- 주제: 미니게임 조립형 종합 응용
- 형태: 코드 수정형 + 빈칸형 + 복수정답 객관식형
- 핵심 포인트: 입력, 이동, 판정, 결과 연결
