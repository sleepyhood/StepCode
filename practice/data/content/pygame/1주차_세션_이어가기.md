# Pygame 1주차 세션 이어가기

이 문서는 새 세션에서 바로 이어서 작업할 수 있도록,
현재까지의 배경, 구조, 작성 산출물, 로더 이슈, 다음 우선순위를 한 번에 정리한 문서입니다.

## 1. 현재 프로젝트 목표

`pygame` 1주차 원본 수업을 바탕으로,
단순 문제풀이가 아니라 학생이 직접 실행하고 수정해야만 풀 수 있는 `응용수업` 체계를 만드는 작업을 진행했다.

핵심 방향은 아래와 같다.

1. 읽기
2. 실행 전 예상
3. 실행 후 관찰
4. 버그 수정 또는 규칙 변경
5. 재실행 검증
6. 회고

즉, "코드를 따라 적었다"가 아니라
"왜 그렇게 동작하는지 보고, 망가진 부분을 고치고, 규칙 하나를 직접 바꿨다"까지 가는 수업이 목표다.

## 2. 핵심 배경 판단

기존 문제점은 다음과 같이 정리되었다.

- 학생이 pygame 게임을 만들기는 했지만, 왜 그렇게 만들었는지 이해가 분리되어 있었다.
- 짝수 회차를 빈칸 채우기만으로 운영하면 복붙형 수업의 연장선이 되기 쉽다.
- 디버깅만 단독으로 주면 약한 학생은 어디서부터 봐야 할지 막막해진다.

그래서 응용 회차의 최적 구조를 다음으로 잡았다.

- `읽기 -> 버그 수정 -> 규칙 변경`

이 구조는 원본 게임을 다시 "재현"하는 것이 아니라,
"해석 + 수정 + 확장"하는 구조다.

모든 실습/활동지/미션 설계는 가능하면 아래 4단계를 포함하도록 잡았다.

- 실행 전 예상
- 실행 후 관찰
- 직접 수정 또는 실험
- 재실행 후 변화 기록

## 9. 중요한 설계 판단

새 세션에서 이어서 작업할 때 아래 판단을 유지해야 한다.

- 학생용 활동지보다 예제 파일 설계와 실제 파일을 먼저 만드는 것이 맞다.
- 활동지는 항상 실제 미션 파일 동작을 기준으로 써야 한다.
- 질문은 `정답 맞히기`보다 `실행 결과 기록` 중심이어야 한다.
- 버그는 한 파일에 여러 개 넣지 않는다.
- 원본 1회차에서 다룬 범위를 크게 벗어나지 않는다.
- 90분 수업은 문제 수를 늘리는 방식이 아니라, 한 문제 안에서 오래 실험하게 만드는 방식으로 운영한다.
- 웹 반영까지 고려한다면, 현재는 `round01`을 독립 콘텐츠 루트로 승격하는 방향이 더 자연스럽다.

## 10. 새 세션에서 바로 이어서 하면 좋은 다음 작업

우선순위:

1. `round01`을 독립 콘텐츠 루트로 승격할지 결정
2. 결정 후 웹 로더 규칙에 맞도록 구조 정리
3. `학생용 활동지`에 대응하는 `교사용 정답/관찰 포인트 md` 작성
4. 각 미션 파일의 난이도와 실제 수업 소요 시간 미세 조정
5. 필요하면 `round02`용 동일 구조 복제
6. 필요하면 `missions`를 배포용/교사용 버전으로 분리

가장 자연스러운 다음 산출물은 아래 둘 중 하나다.

- `교사용 활동지 해설서`
- `round01 웹 반영용 구조 재정의안`
