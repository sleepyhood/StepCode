#### 모듈의 문제점

모듈은 코드를 보기 편하게 만들어 줍니다. 하나의 파일 안에 코드를 다 집어넣는게 아니라

여러 파일에 나누어 넣다보니 훨씬 보기 편합니다.

그래서 보통 개발을 하게 되면 모듈 파일 여러 개와 모듈을 import해서 코드를 실제로 실행할 메인 파일 하나로 이루어지게 됩니다. 그런데 처음에는 모듈로만 쓰려고 했던 파일을 메인으로 사용하 고 싶어질 수도 있습니다. 이 때 어떤 문제가 생길까요?

#### 참고) FPS란?

Frame Per Second의 약자입니다.

Frame = 사진 한 장. 즉 FPS는 1초에 사진 몇 장을 보여주는지를 말합니다.

30FPS는 1초에 30개의 사진, 60FPS는 1초에 60개의 사진입니다. 앞에서 게임 화면은 동영상 화면과도 같다고 했습니다. 움직이는 것처럼 보이는게 사실은 여러 개의

사진을 연속으로 보여주는겁니다.

FPS가 높을수록 화면이 더 부드럽게 보이겠지만 그 만큼 컴퓨터에게 높은 사양이 요구됩니다.

그리고 theta가 360 이상이 되면 theta % 360은 다시 0부터 시작해 2까지 증가합니다

그래서 이 코드는 글자가 최대 크기가 된 뒤 다시 크기 0부터 시작하게 됩니다

글자의 크기가 최대가 된 뒤 바로 크기 0이 되는게 아니라 조금씩 크기를 줄이려면 어떻게 해야할까요?

조금 뒤에서 배울 삼각함수를 이용해서 할 수 있습니다.

## 그림 그리기

import sys import pygame from pygame.locals import QUIT, MOUSEMOTION

pygame.init() SURFACE = pygame.display.set_mode((400,300)) pygame.display.set_caption("game") def main():

mousepos = [] while True:

SURFACE.fill((255,255,255))

for event in pygame.event.get():

if event.type == QUIT: pygame.quit() sys.exit()

elif event.type == MOUSEMOTION: mousepos.append(event.pos)

for pos in mousepos:

pygame.draw.circle(SURFACE, (0,0,0), pos, 5)

pygame.display.update()

if __name__ == '__main__':

main()
