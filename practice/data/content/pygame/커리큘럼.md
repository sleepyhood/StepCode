# pygame 커리큘럼 재정비안

기준:

- 대상: 파이썬 기초 문법을 학습한 학생
- 수업 시간: 회당 90분
- 기본 운영 단위: `2주 1세트`
- 우선 기준: 교육 흐름보다 `제작 최소화`를 먼저 고려

핵심 목표:

- 학생이 90분 수업 안에서 무리 없이 따라올 수 있게 한다.
- 강사가 매 주차마다 완전히 새로운 자료를 다시 만들지 않게 한다.

## 전체 구조

이 커리큘럼은 `필수 12주`와 `선택 8주`로 나눈다.

- `필수 12주`
  - 모든 반에서 공통 운영하는 기본 과정
  - 총 `6세트`
- `선택 8주`
  - 반 수준, 남은 일정, 강사 준비도에 따라 고르는 프로젝트/심화 과정
  - 총 `4세트 내외`

즉, 실제 제작 단위는 `20개의 독립 주차`가 아니라 `필수 6세트 + 선택 세트 몇 개`로 본다.

## 운영 원칙

- 모든 필수 세트는 `1주차 개념 + 2주차 응용` 구조를 유지한다.
- 1주차는 `설명 + 예제 확인 + 즉시 수정 실습 + 핵심 코드 1개 완성`을 목표로 한다.
- 2주차는 `오픈북 복습 + 오류 수정 + 일부 기능 추가 + 응용 문제 풀이`를 목표로 한다.
- 새 문법 설명과 새 문제 해결을 같은 차시에 과도하게 배치하지 않는다.
- 초반 필수 구간에서는 자산 의존도가 높은 기능을 후순위로 둔다.
- 후반 프로젝트는 모든 기수에서 전부 운영하는 것을 전제로 하지 않는다.

## 세트 표준 템플릿

모든 필수 세트는 아래 항목으로 설계한다.

1. 학습 목표
2. 1주차 개념 범위
3. 2주차 응용 범위
4. 필수 산출물
5. 심화 제외 항목

문제 구성 난도도 통일한다.

- 필수 문제
  - 오류 수정 1~2개
  - 값 수정 1~2개
  - 조건 추가 1개
  - 결과 예측 1개
- 선택 심화
  - 기능 변형 1~2개

## 필수 공통 과정 12주

### 세트 1. 창 생성과 화면 갱신 기초

- 운영 주차: `1~2주차`
- 학습 목표:
  - pygame 창을 만들고 화면을 원하는 색으로 갱신할 수 있다.
  - 화면이 바뀌기 위해 필요한 최소 구조를 이해한다.
- 1주차 개념 범위:
  - pygame 설치와 실행 확인
  - `pygame.init()`
  - `display.set_mode()`
  - `display.set_caption()`
  - `fill()`
  - `pygame.display.update()`
- 2주차 응용 범위:
  - 창 크기 변경
  - 배경색 변경
  - `update()` 누락 시 차이 확인
  - 오픈북 문제풀이
- 필수 산출물:
  - 창 생성 예제 1개
  - 배경색 수정 문제 세트 1개
- 심화 제외 항목:
  - 이미지 출력
  - 회전
  - 그림판

### 세트 2. 이벤트 큐와 정상 종료

- 운영 주차: `3~4주차`
- 학습 목표:
  - 이벤트 큐를 읽고 종료 버튼 입력에 정상 반응할 수 있다.
  - 무한 반복문 안에서 이벤트 처리가 왜 필요한지 이해한다.
- 1주차 개념 범위:
  - `pygame.event.get()`
  - `QUIT`
  - `pygame.quit()`
  - `sys.exit()`
  - 무한 반복문 구조
- 2주차 응용 범위:
  - 종료 처리 누락 코드 고치기
  - 이벤트에 따라 동작 바꾸기
  - 오픈북 문제풀이
- 필수 산출물:
  - 정상 종료 예제 1개
  - 이벤트 복구 문제 세트 1개
- 심화 제외 항목:
  - 마우스/키보드 이벤트 세부 분기
  - 복잡한 상태 관리

### 세트 3. FPS, 좌표, 값 변화

- 운영 주차: `5~6주차`
- 학습 목표:
  - `tick()`과 화면 갱신의 차이를 이해한다.
  - 좌표와 값 변화를 이용해 간단한 움직임을 만들 수 있다.
- 1주차 개념 범위:
  - `pygame.time.Clock()`
  - `tick()`
  - FPS 의미
  - 좌표계 이해
  - 값 증가/감소에 따른 화면 변화
- 2주차 응용 범위:
  - FPS 값 비교
  - 좌표 수정으로 위치 조절
  - 속도 변화 관찰
  - 오픈북 문제풀이
- 필수 산출물:
  - 이동 예제 1개
  - FPS/좌표 문제 세트 1개
- 심화 제외 항목:
  - 삼각함수 이동
  - 가속도/관성

### 세트 4. 도형 그리기와 화면 구성

- 운영 주차: `7~8주차`
- 학습 목표:
  - 기본 도형을 그릴 수 있다.
  - 그리기 순서에 따라 화면 결과가 달라짐을 이해한다.
- 1주차 개념 범위:
  - `draw.rect`
  - `draw.circle`
  - `draw.line`
  - 색상과 두께
  - 그리기 순서
- 2주차 응용 범위:
  - 좌표 수정으로 도형 재배치
  - 도형 겹침 순서 바꾸기
  - 화면 구성형 오픈북 문제풀이
- 필수 산출물:
  - 도형 예제 1개
  - 좌표/도형 문제 세트 1개
- 심화 제외 항목:
  - `polygon`
  - `lines`
  - 이미지 자산 사용

### 세트 5. 키보드 입력과 이동

- 운영 주차: `9~10주차`
- 학습 목표:
  - 키 입력에 따라 오브젝트를 움직일 수 있다.
  - 속도와 경계 제한을 적용할 수 있다.
- 1주차 개념 범위:
  - 키 입력 확인
  - 좌표 이동
  - 속도 개념
  - 화면 밖 제한
- 2주차 응용 범위:
  - 방향 바꾸기
  - 속도 조절
  - 벽 충돌처럼 보이게 제한하기
  - 오픈북 문제풀이
- 필수 산출물:
  - 키보드 이동 예제 1개
  - 이동/경계 처리 문제 세트 1개
- 심화 제외 항목:
  - 대각선 보정
  - 복수 키 우선순위 설계

### 세트 6. 시간, 랜덤, 마우스 입력, 에임 트래킹

- 운영 주차: `11~12주차`
- 학습 목표:
  - 시간과 랜덤 값을 이용해 게임 요소를 만들 수 있다.
  - 마우스 입력을 이용한 간단한 미니게임을 완성할 수 있다.
- 1주차 개념 범위:
  - `random`
  - 시간 기반 등장/제한시간

  - 필요한 만큼의 객체 묶음 개념
- 2주차 응용 범위:
  - 목표물 배치
  - 클릭 판정
  - 점수
  - 제한시간
  - 에임 트래킹 미니게임
- 필수 산출물:
  - 마우스 입력 예제 1개
  - 에임 트래킹 미니게임 1개

- 심화 제외 항목:
  - 독립적인 객체지향 이론 설명
  - 복잡한 적 AI

각 세트마다 강사가 준비해야 할 기본 산출물은 아래와 같이 고정한다.

- `source/`
  - 개념 본문 1개
- `lesson/`
  - 교사용 운영 메모 1개
- `interactive/`
  - 공통 포맷 문제 세트 1개
- `worksheets/`
  - 출력용 활동지 1개
  - 정답/해설 1개

즉, `12주 = 12종류의 완전히 다른 자료`가 아니라
`6개의 반복 가능한 제작 세트`로 본다.

## 검토 체크리스트

- 각 필수 주차가 90분 안에 `설명 + 실습 + 정리`로 끝나는가
- 필수 12주 안에서 새 개념이 한 주에 과도하게 몰리지 않는가
- 선택 프로젝트가 전부 필수처럼 읽히지 않는가
- 각 세트가 같은 제작 단위로 환산되는가
- 현재 `round01` 자료가 세트 1 범위와 대조 가능한가

## 기존 초안 대비 조정 사항

- `20주 전부 고정 주차표`처럼 보이던 구조를 `필수 12주 + 선택 8주`로 재구성
- `2주 1세트` 운영 기준을 문서의 기본 구조로 승격
- 후반 프로젝트를 전부 제작해야 하는 필수 항목처럼 보이지 않게 조정
- `클래스`를 독립 대주제에서 빼고, 필요한 범위만 세트 6에서 사용하도록 축소
- 후반 프로젝트는 필수 제작 범위가 아니라 선택 운영 항목으로 고정
- 자료 제작 단위를 `주차`가 아니라 `세트` 기준으로 명시
