# C언어 경시대회 커리큘럼 (2023-1, 2024-2, 2024-3 기반)

## 장별 목차
1. C 언어 개요와 표준 라이브러리/헤더
2. 자료형/상수 표현/범위(오버플로 포함)
3. 기본 입출력과 포맷(printf/scanf)
4. 연산자/우선순위/조건식(함정 포함)
5. 제어문(반복/분기) 실행 결과 추적
6. 함수 기본과 재귀
7. 배열(1차원)과 인덱싱/반복 패턴
8. 문자열/문자 처리 + `string.h`
9. 전처리기 매크로
10. 동적 메모리/포인터 활용
11. 2차원 배열/행렬/격자
12. 그래프/DFS
13. 탐색/최적화 패턴

## 장 귀속 규칙 (중복 방지)
- 연산 우선순위 중심 문항은 4장으로 귀속한다.
- 반복 구조 추적 중심 문항은 5장으로 귀속한다.
- 배열 접근이 핵심이면 7장, 문자열 API가 핵심이면 8장으로 귀속한다.
- DFS/격자라도 핵심이 탐색 규칙이면 12장, 행렬 계산이면 11장으로 귀속한다.
