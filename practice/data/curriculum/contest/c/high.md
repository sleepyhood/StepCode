# C 경시대회 고등 트랙

## 목표
- C 함정 + 재귀/탐색/최적화까지 실전 완주
- 대회형 문제를 단계 추적으로 재현 가능하게 훈련

## 필수 장
- 1~13장 전 범위
- 특히 9~13장(매크로, 동적 메모리, 2D, DFS, 최적화)은 코어

## 운영 규칙
- 재귀/DFS 문제는 반드시 호출표 또는 탐색 로그를 작성한다.
- 정답만 채점하지 않고 중간 추적값을 함께 채점한다.
- 11~13장은 단원별 미니 모의로 분리 운영한다.

## 주차 매핑 (권장 10주)
1. 1~2주: 1~4장 리빌드
2. 3~4주: 5~8장 고난도 추적
3. 5주: 9장 매크로
4. 6주: 10장 동적 메모리
5. 7주: 11장 2차원/행렬
6. 8주: 12장 DFS
7. 9주: 13장 최적화
8. 10주: 실전 모의 2회
