# C 경시대회 초등 트랙

## 목표
- 코드 흐름 추적 능력 확보
- 입력/출력, 조건, 반복, 1차원 배열/문자열 기초 정착

## 필수 장
1. 3장 기본 입출력
2. 4장 연산자/조건식 기초
3. 5장 제어문 추적
4. 7장 배열 기초
5. 8장 문자열 기초

## 선택/보류
- 선택: 1장 개요, 2장 진법 맛보기, 6장 함수 호출/반환
- 보류: 9~13장

## 주차 매핑 (권장 6주)
1. 1주: 3장
2. 2주: 4장(기초)
3. 3주: 5장
4. 4주: 7장
5. 5주: 8장(기초)
6. 6주: 종합 복습 + 모의
