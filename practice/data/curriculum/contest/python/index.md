# Python 경시대회 커리큘럼 (2023-1, 2024-2, 2024-3 기반)

## Part 목차
1. 기본 문법(연산/대입/출력 형식)
2. 조건문/반복문 제어(Truthiness, break/continue, 중첩 루프)
3. 표준 라이브러리/모듈 감각(내장 컨테이너, 날짜/정규식)
4. 자료형/리스트 메서드/인덱싱(1차원/2차원)
5. 함수/스코프/람다(global 포함)
6. 재귀(점화식/분할 호출/출력 순서)
7. 비트 연산/진법/표현(shift, XOR, 8진/7진)
8. 문자열 처리(포맷/치환/eval/패턴 스캔)
9. 알고리즘형 문제(수학/행렬/탐색/정렬)

## Part 귀속 규칙 (중복 방지)
- 흐름 추적이 핵심이면 Part 2로 귀속한다.
- 리스트/인덱스 조작이 핵심이면 Part 4로 귀속한다.
- 함수 호출 규칙은 Part 5, 재귀 호출 구조는 Part 6으로 분리한다.
- 비트/진법 표현 해석은 Part 7로 귀속한다.
- 정규식은 난이도와 무관하게 Part 3으로 귀속한다.
