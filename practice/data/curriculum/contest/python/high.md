# Python 경시대회 고등 트랙

## 목표
- 재귀/비트/탐색까지 포함한 후반 난도 대응
- 정답뿐 아니라 추적 근거(호출표/탐색로그)까지 재현

## 필수 Part (심화 코어)
1. Part 6 재귀(전체)
- 단순 재귀 곱
- 점화식 재귀
- 분할 호출 + 출력 순서
- 다변수 재귀(격자/조합)

2. Part 7 비트/진법/표현(전체)
- shift, XOR, 비트 마스크
- 8진수 출력/해석
- 7진 분해 재귀
- 빠른 거듭제곱(모듈러)

3. Part 3 모듈/정규식(전체)
- `re.fullmatch` 결과/패턴 해석

4. Part 8 문자열 처리(전체)
- 치환 + `eval` 조합 해석

5. Part 9 알고리즘형(전체)
- 격자 탐색(DFS/BFS)
- 클래스 + 정렬(key=lambda)
- 격자/문자 아트 비교 카운팅

## 운영 규칙
- 재귀 문제는 `depth | call | return` 호출표를 필수로 작성한다.
- 탐색 문제는 방문 순서 또는 상태 로그를 필수로 남긴다.
- `eval`/정규식 문항은 결과 해석과 안전성 포인트를 함께 다룬다.

6. 8~9주: Part 9 탐색/정렬 심화
