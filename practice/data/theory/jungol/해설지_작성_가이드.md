# 주차별 해설지 작성 가이드 및 템플릿

이 문서는 AI에게 주차별 교사용 PDF를 전달하여 **"선생님 수업용(판서용) 해설 스크립트"**를 일관성 있게 생성하기 위한 프롬프트 가이드와 템플릿입니다.

새로운 주차의 해설을 작성할 때 LLM(AI)에게 **[제공할 프롬프트]**와 **[출력 양식]**을 복사해서 전달하면, 모든 주차의 해설 라인업을 동일한 퀄리티와 포맷으로 유지할 수 있습니다.

---

## 1. AI(LLM)에게 전달할 명령어 (프롬프트 복사용)

> 첨부된 O주차 중등부 교사용 PDF 교재를 분석해서, 내가 실제 수업에서 쓸 수 있도록 상세한 **'수업용 해설 텍스트 스크립트'**를 아래의 [마크다운 출력 템플릿] 양식에 맞춰 완벽하게 작성해 줘.
>
> **[작업 조건]**
>
> 1. **대상 범위:** 교재의 본문(실전 문제)만 다루고, 단순 '연습문제'는 제외할 것.
> 2. **해설 표현 우선순위 (시각/복잡도 기준):** 해설 작성 시 가급적 아래 우선순위를 따를 것.
>    - **1순위 (텍스트, 필수):** 수식($$...$$)과 텍스트만으로도 충분히 이해할 수 있도록 상세히 서술할 것.
>    - **2순위 (테이블, 필요시):** 텍스트만으로 상태 변화나 논리가 복잡해질 경우(예: 규칙성, DP 등) 마크다운 표(Table)를 활용하여 시각화할 것.
>    - **3순위 (SVG 다이어그램 등):** 텍스트나 표만으로는 해설이 너무 길어지거나, 반드시 시각적 자료(기하 도형, 트리, 그래프 등)를 토대로 설명이 필요한 경우에 제한적으로 `mermaid`나 `svg` 코드를 추가할 것. (단, SVG 제작 시 **상단 헤더는 생략**하고, **배경색은 기본 하얀색이나 배경 없음**으로 처리할 것.)
> 3. **어조 및 설명 방식:** 전문적이되, 중학생이 직관적으로 이해할 수 있도록 일상적인 비유(예: 2진법 설명 시 10진수 999+1=1000을 예로 드는 방식 등)를 적극 활용하여, 친절한 선생님이 과외하듯 풀어서 설명할 것.
> 4. **양식 엄수 (매우 중요):** 반드시 아래에 제공된 마크다운 구조를 100% 동일하게 복사하여 사용할 것. 특히 `📝`, `✅`, `💡` 등의 **이모지**와, 선택지의 **원문자(`①`, `②`, `③`...)**를 실수로 누락하는 경우가 잦으니 출력 시 절대 빠지지 않도록 각별히 주의할 것. 정답 항목에도 `✅ 정답: ③ 9` 처럼 원문자와 정답을 함께 기재할 것.

## 3. 작성 예시 (참고용)

**<진수>**

### 📝 1. 진법의 변환 (2019 X 2021)

**문제:** 2019 X 2021 을 2 진수로 표현할 때 가장 오른쪽에 나타나는 연속된 1 의 개수는 몇 개일까? (중등 2019 년도 1 번)

**선택지:** ① 2 ② 3 ③ 4 ④ 5 ⑤ 6

**✅ 정답: ③ 4**

**💡 선생님을 위한 풀이 가이드:**

- **출제 의도:** 단순히 진수 변환을 묻는 것이 아니라, 수식의 변형을 통해 $2^n$의 인수 개수를 찾아낼 수 있는지 묻는 논리력 문제입니다. $N+1$의 형태를 관찰하는 아이디어를 제시해 주세요.
- **상세 풀이:**
  1. $2019 \times 2021$을 그대로 계산하면 너무 숫자가 커지겠죠? 중3 과정에서 배운 **합차 공식**을 이용해 식을 간단히 변형해 봅시다.
     $$2019 \times 2021 = (2020 - 1) \times (2020 + 1) = 2020^2 - 1$$
  2. 이제 수의 끝자리를 생각해 봅시다. 우리가 쓰는 10진수에서 $999$처럼 끝이 9로 연속되는 수에 $1$을 더하면 $1000$이 되면서 0이 3개로 변하죠?
  3. 2진수에서도 똑같습니다! 어떤 2진수의 맨 오른쪽이 `...1111` ($1$이 4개)로 끝날 때 $1$을 더하면, 연쇄적으로 자릿수가 올라가면서 `...10000` ($0$이 4개)으로 바뀝니다.
  4. 2진수에서 맨 끝에 0이 $t$개 있다는 것은, 10진수로 바꿨을 때 **$2$를 $t$번 거듭제곱한 수($2^t$)로 나누어 떨어진다**는 뜻입니다.
  5. 즉, 처음 수식인 $2020^2 - 1$ 에 $1$을 더한 **$2020^2$** 을 살펴봤을 때, $2$가 총 몇 번 곱해져 있는지를 찾으면 그것이 바로 연속된 1의 개수($t$)가 됩니다.
  6. $2020$을 중1 때 배운 방법으로 소인수분해 해보면 $2020 = 2^2 \times 505$ 입니다. (505는 홀수이므로 2가 없어요.)
  7. 그러면 $2020^2 = (2^2 \times 505)^2 = 2^4 \times 505^2$ 가 됩니다.
  8. $2^4$ 이므로 2가 총 4번 곱해져 있네요! 따라서 가장 오른쪽에 나타나는 연속된 $1$의 개수는 $4$개(③)입니다.
  - _(Tip! 10진수 $999+1=1000$ 예시를 판서에 같이 적어주시면 학생들이 진법의 올림 원리를 아주 직관적으로 이해합니다!)_
