# Unity 주차 정답지 W02

## 메타
- 대상 문제지: `problem_unity_w02.md`
- 유닛: U02 Log/Operator

## 정답표
| 문항 ID | 정답 | 한 줄 근거 |
|---|---|---|
| P01 | B | Unity 표준 콘솔 출력 API는 `Debug.Log` |
| P02 | `=`-할당, `==`-같음, `!=`-같지 않음, `++`-1 증가, `+`-문자열 연결 | 연산자 기능 구분 |
| P03 | B | OR 조건은 `||` |
| P04 | `i % 2 == 0` | 짝수 판별 표준식 |
| P05 | (1) 참, (2) 거짓 | API/이벤트 함수는 대소문자 정확히 일치해야 함 |
| P06 | B | `CompareTag`, `enabled`, `public`만 정확 표기 |
| X01 | 예: `bool isOdd = (n % 2) != 0;` / `Debug.Log("isOdd=" + isOdd);` | 계산+비교+로그 흐름 완성 |
| X02 | C | `OnTriggerEnter` 철자가 틀리면 이벤트가 호출되지 않음 |

## 해설
### P01
- 개념 정의: Unity 로그 출력은 `Debug.Log(...)`를 사용합니다.
- 오답 포인트: C# 콘솔 API와 Unity API를 혼동합니다.
- 판별 기준: `Debug` 클래스와 `Log` 메서드 조합인지 확인합니다.

### P02
- 개념 정의: 대입/비교/증가/연결 연산자는 역할이 다릅니다.
- 오답 포인트: `=`와 `==`를 혼동합니다.
- 판별 기준: 조건식에 들어가면 비교 연산자(`==`, `!=`)인지 확인합니다.

### P03
- 개념 정의: OR는 둘 중 하나라도 참이면 참입니다.
- 오답 포인트: `&&`를 습관적으로 쓰는 경우가 많습니다.
- 판별 기준: "또는" 문장 조건이면 `||`를 우선 점검합니다.

### P04
- 개념 정의: 나머지가 0이면 짝수입니다.
- 오답 포인트: `i % 2 = 0`처럼 대입 연산자를 쓰는 오류가 있습니다.
- 판별 기준: `%` 계산 뒤 `== 0` 비교까지 포함되어야 합니다.

### P05
- 개념 정의: Unity 메시지 함수와 API 식별자는 대소문자 민감합니다.
- 오답 포인트: 함수명 첫 글자를 소문자로 써도 동작할 것으로 오해합니다.
- 판별 기준: 공식 표기(`MonoBehaviour`, `OnTriggerEnter`)와 완전 일치 여부를 봅니다.

### P06
- 개념 정의: C# 키워드와 Unity API는 각각 고정 철자/대소문자를 가집니다.
- 오답 포인트: `Enabled`/`Public`처럼 대문자를 섞어도 될 것으로 착각합니다.
- 판별 기준: 키워드는 소문자, Unity API는 공식 표기를 유지합니다.

### X01
- 개념 정의: 홀수 판별은 `%` 결과가 0이 아닌지 비교합니다.
- 오답 포인트: 문자열 연결 시 변수 값 대신 식별자 이름만 적는 오류가 있습니다.
- 판별 기준: `bool` 계산식과 `Debug.Log` 출력식이 모두 있어야 합니다.

### X02
- 개념 정의: Unity 이벤트 함수는 이름이 정확히 일치해야 호출됩니다.
- 오답 포인트: `onTriggerEnter`처럼 소문자 시작 함수를 허용한다고 오해합니다.
- 판별 기준: `OnTriggerEnter`의 O/T/E 대문자 패턴을 확인합니다.
