## 해설
### P01
- 개념 정의: Unity 환경에서 콘솔(Console) 창에 디버깅 메시지를 띄울 때는 `Debug.Log(...)` 구문을 사용합니다.
- 오답 포인트: 순수 C# 콘솔 프로그램에서 쓰는 `Console.WriteLine`이나 기타 `print`문 등과 헷갈리기 쉽습니다.
- 판별 기준: `Debug` 클래스와 `Log` 메서드가 각각 대문자로 올바르게 시작된 조합인지 점검합니다.

### P02
- 개념 정의: 대입, 비교, 증감, 문자열 병합 등 각 연산자는 고유의 역할과 수학적/논리적 의미가 분리되어 있습니다.
- 오답 포인트: 수학에서 '같다'는 의미인 `=` 기호를 C#의 비교 연산 구문(`==`) 대신 조건문에 잘못 집어넣어 에러를 유발합니다.
- 판별 기준: 단일 `=`는 값 할당용이고, 이중 `==`나 `!=` 등은 논리 비교 판별용으로 작동함을 명확히 인지하는지 확인합니다.

### P03
- 개념 정의: 논리 연산자에서 '둘 중 하나라도 참이면 참'이라는 느슨한 조건을 걸어주는 OR 개념은 `||` 기호로 표기합니다.
- 오답 포인트: 습관적으로 '그리고(AND)'의 의미인 `&&`를 쓰거나 대입 연산 기호를 조건문 괄호 안에 끼워 넣습니다.
- 판별 기준: 지문의 '...하거나(또는)' 이라는 의도를 파악하여, 두 좌우항 사이의 결합 연산자로 최적의 수식 `||`를 골라야 합니다.

### P04
- 개념 정의: 특정한 수를 2로 나누어 모듈로(나머지, `%`) 연산의 결과가 0이라면 그 수는 직관적으로 짝수(Even)입니다.
- 오답 포인트: `i % 2 = 0`처럼 비교가 아닌 변수 대입 연산을 선택하거나 연산자를 혼동합니다.
- 판별 기준: 비교 연산자 `==`를 사용해 나머지가 0인지를 비교하는 `i % 2 == 0` (B)가 정답입니다.

### P05
- 개념 정의: C#은 식별자의 대소문자에 매우 엄격(Case-Sensitive)하며, Unity의 자체 메시지 함수(`Update`, `OnCollisionEnter` 등) 역시 단 하나의 알파벳도 대소문자가 다르면 작동하지 않습니다.
- 오답 포인트: 소문자로 임의로 기입된 메서드도 유니티 엔진이 알아서 콜백으로 연결해 줄 것이라는 안일한 기대를 합니다.
- 판별 기준: 지정 클래스명(`MonoBehaviour`)과 이벤트 함수명 시그니처(`OnTriggerEnter`)의 대문자 및 낙타 표기법 등 강제된 룰을 검증합니다.

### P06
- 개념 정의: C# 언어 기본 키워드(`public`, `if` 등)는 소문자이며, 유니티의 클래스 및 주요 함수들은 대문자(PascalCase), 외부로 노출된 컴포넌트 변수나 프로퍼티(`enabled` 등)는 소문자(camelCase)로 표기됩니다.
- 오답 포인트: C# 예약어를 `Public`처럼 대문자로 시작하거나 프로퍼티를 멋대로 선언해 컴파일 오류를 냅니다.
- 판별 기준: 예약어 소문자 규칙과 API PascalCase/camelCase가 동시에 정확하게 적용된 B가 정답입니다.

### X01
- 개념 정의: 홀수를 안전하게 판별하려면 `% 2 != 0`을 사용해야 합니다. C#에서는 음수 홀수(예: -3)에 대해 `% 2`를 계산하면 결과가 `1`이 아니라 `-1`이 되기 때문입니다. 따라서 `n % 2 == 1` 대신 `n % 2 != 0`을 사용하는 것이 모범 답안입니다.
- 오답 포인트: 음수 홀수 연산 예외를 고려하지 않거나, C# 출력 함수인 `Console.WriteLine`을 고르거나, 대소문자 변수명(`isodd` 오타) 오류를 선택하기 쉽습니다.
- 판별 기준: `n % 2 != 0` 식과 대소문자가 정확한 `isOdd` 변수명이 결합된 B가 가장 알맞은 코드 세트입니다.

### X02
- 개념 정의: 유니티의 물리 이벤트 함수(`OnTriggerEnter` 등)는 그 이름이 한 치도 어긋남 없이 완벽해야만 물리 엔진이 내부적으로 해당 함수를 찾아내어 콜백해 냅니다.
- 오답 포인트: `onTriggerEnter`처럼 알파벳 O를 소문자로 적게 되면, 문법(컴파일) 자체는 에러가 없으나 물리 충돌 시에 아무 일도 일어나지 않는 무서운 '조용한 실패(Silent Failure)' 함정에 빠집니다.
- 판별 기준: 제공된 보기 중에서 `OnTriggerEnter`의 O/T/E 대문자 시작 카멜 규칙을 깨버린 지뢰 항목인 C가 정답입니다.
