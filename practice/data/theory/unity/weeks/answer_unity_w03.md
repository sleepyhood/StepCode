# Unity 주차 정답지 W03

## 메타
- 대상 문제지: `problem_unity_w03.md`
- 유닛: U03 Function/static

## 정답표
| 문항 ID | 정답 | 한 줄 근거 |
|---|---|---|
| P01 | (1) 거짓, (2) 참, (3) 참, (4) 참 | `void`는 무반환, 반환형 함수는 `return` 필요 |
| P02 | A | static 메서드에서 접근하려면 필드도 static이어야 함 |
| X01 | `private static int Multiply(int a, int b)` | 시그니처 순서: 접근제어자 + static + 반환형 + 이름 + 매개변수 |
| X02 | C | static 메서드에서 인스턴스 필드 직접 접근 불가 |

## 해설
### P01
- 개념 정의: `void`는 값을 반환하지 않는 반환형입니다.
- 오답 포인트: `void == null 반환`으로 오해하는 경우가 많습니다.
- 판별 기준: 반환형이 `void`인지, 비-void인지에 따라 `return` 의무를 나눕니다.

### P02
- 개념 정의: static 메서드는 클래스 컨텍스트에서 실행됩니다.
- 오답 포인트: 인스턴스 필드/클래스 필드 구분 없이 접근하려고 합니다.
- 판별 기준: static 메서드 내부에서 사용하는 필드는 static이어야 합니다.

### X01
- 개념 정의: 메서드 선언은 시그니처 규칙을 지켜 작성해야 합니다.
- 오답 포인트: `static` 위치 누락, 반환형과 메서드명 순서 오류가 잦습니다.
- 판별 기준: `private static int Multiply(int a, int b)` 형태를 정확히 맞춥니다.

### X02
- 개념 정의: static은 인스턴스와 분리된 클래스 단위 멤버입니다.
- 오답 포인트: static 메서드가 인스턴스 필드를 직접 읽고 쓸 수 있다고 착각합니다.
- 판별 기준: 인스턴스 접근이 필요하면 객체 참조를 통해 접근해야 합니다.
