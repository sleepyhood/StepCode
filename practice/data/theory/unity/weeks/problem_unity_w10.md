- 핵심 개념: `Color` 변수 출력 문법, `Material.SetColor(string, Color)` 시그니처와 셰이더 프로퍼티명 규칙

## 원문 대응 문항
### [P01] Color 변수 값 출력식 완성
- 출처: 원문 20번
- 유형: 단답
- 문제:
  - 클래스 내부에 `public Color color;`로 선언된 색상 필드 변수가 있습니다. 이 변수에 저장된 RGBA 색상 정보를 유니티 콘솔 창에 출력하여 디버깅하고자 합니다.
  - 아래 코드의 `[드롭다운]` 빈칸에 들어갈 **가장 올바른 표현**을 쓰세요.
  - `Debug.Log("Color:" + [드롭다운]);`
  - 주의: C#에서 `Debug.Log`의 문자열 결합(`+`) 안에는 **실제 데이터가 담긴 변수명**이 와야 하며, 타입 이름(클래스명) 자체를 넣으면 의도한 값이 출력되지 않습니다.

### [P02] Material.SetColor 두 인자 완성
- 출처: 원문 40번
- 유형: 단답
- 문제:
  - 3D 오브젝트의 머티리얼(Material) 색상을 C# 스크립트 런타임에서 빨간색으로 동적 변경하려고 합니다.
  - `Material.SetColor(string propertyName, Color color)` API의 시그니처에 맞게 아래 두 빈칸을 순서대로 채우세요.
  - `material.SetColor( [①] , [②] );`
  - 조건:
    - ① 유니티 기본 Standard Shader에서 메인 알베도(Albedo) 색상 프로퍼티에 접근하기 위한 **관례적 문자열 프로퍼티명** (쌍따옴표 포함, 언더스코어 시작)
    - ② 빨간색을 나타내는 유니티 내장 **`Color` 구조체의 정적 상수** 표현

## 확장 문항 (변형/함정/응용)
### [X01] 변형 - 파란색으로 머티리얼 메인 색상 변경 코드 작성
- 출처 개념: U10 Material/Color
- 유형: 코드
- 문제:
  - 스크립트에 `Material mat;` 변수가 선언되어 있습니다. 이 머티리얼의 **메인 알베도 색상**을 파란색으로 즉시 변경하는 완전한 C# 코드 1줄을 작성하세요.
  - 작성 조건:
    - 첫 번째 인자: Standard Shader의 메인 색상에 접근하는 정확한 **문자열 프로퍼티명** (언더스코어 시작, 쌍따옴표 포함)
    - 두 번째 인자: 파란색을 나타내는 `Color` 구조체의 **정적 상수**
- 의도: P02에서 익힌 `"_Color"` + `Color.red` 조합 패턴을 다른 색상 상수(`Color.blue`)로 전이하여, 셰이더 프로퍼티명 규칙과 Color API의 범용적 활용 능력을 검증합니다.

### [X02] 함정 - SetColor 첫 번째 인자의 올바른 형식 판별
- 출처 개념: U10 Material/Color
- 유형: 객관식
- 문제:
  - `Material.SetColor`의 첫 번째 인자에는 셰이더 프로퍼티 이름을 전달해야 합니다. 다음 보기 중 **C# 컴파일 오류 없이 올바르게 셰이더 프로퍼티에 접근**할 수 있는 형식을 고르세요.
- 보기:
  - A. `_Color` — 따옴표 없이 식별자(변수명)처럼 기입
  - B. `"_Color"` — 쌍따옴표로 감싼 문자열 리터럴로 기입
  - C. `Color` — 타입 이름을 그대로 기입
  - D. `"Color"` — 언더스코어 없이 문자열로 기입
- 의도: 셰이더 프로퍼티명은 C# 코드 상에서 반드시 **쌍따옴표로 감싼 문자열 리터럴**이어야 하며, 관례적으로 언더스코어(`_`)로 시작한다는 두 가지 규칙을 동시에 검증합니다. 따옴표를 빼면 C#이 변수로 인식하여 컴파일 에러가 나고, 언더스코어를 빼면 셰이더에서 프로퍼티를 찾지 못합니다.
