# Unity 주차 정답지 W10

## 메타
- 대상 문제지: `problem_unity_w10.md`
- 유닛: U10 Material/Color

## 정답표
| 문항 ID | 정답 | 한 줄 근거 |
|---|---|---|
| P01 | `color` | 출력 대상은 타입명이 아니라 필드 변수 값 |
| P02 | `"_Color"`, `Color.red` | `SetColor(string, Color)` 시그니처와 기본 셰이더 관례 |
| X01 | `mat.SetColor("_Color", Color.blue);` | 문자열 프로퍼티명 + `Color` 정적 값 |
| X02 | B | 첫 인자는 문자열 리터럴 `"_Color"` |

## 해설
### P01
- 개념 정의: `Debug.Log`에는 실제 값(변수)을 전달해야 하며 `Color` 타입 변수도 문자열 결합으로 출력할 수 있습니다.
- 오답 포인트: `Color`(타입명)를 넣거나 새 객체 생성식으로 문제 요구를 벗어납니다.
- 판별 기준: `public Color color;`의 변수명 `color`를 선택하면 정답입니다.

### P02
- 개념 정의: `Material.SetColor`는 첫 인자에 문자열 프로퍼티명, 두 번째 인자에 `Color` 값을 받습니다.
- 오답 포인트: `_Color`를 따옴표 없이 쓰거나 `"Color"`로 잘못 쓰는 경우가 많습니다.
- 판별 기준: `material.SetColor("_Color", Color.red);` 형태면 정답입니다.

### X01
- 개념 정의: 메인 컬러 변경은 `_Color` 문자열과 원하는 `Color` 상수 조합으로 처리합니다.
- 오답 포인트: 첫 인자를 식별자로 쓰거나 두 번째 인자 타입을 문자열로 쓰는 실수가 잦습니다.
- 판별 기준: `SetColor("_Color", Color.blue)` 핵심 패턴이 포함되어야 합니다.

### X02
- 개념 정의: 셰이더 프로퍼티 이름은 C# 문자열로 전달해야 합니다.
- 오답 포인트: `_Color`를 변수처럼 쓰면 컴파일 오류가 납니다.
- 판별 기준: 정답은 `"_Color"` 단일 선택입니다.
