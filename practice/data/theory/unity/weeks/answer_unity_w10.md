# Unity 주차 정답지 W10

## 메타
- 대상 문제지: `problem_unity_w10.md`
- 유닛: U10 Material/Color

## 정답표
| 문항 ID | 정답 | 한 줄 근거 |
|---|---|---|
| P01 | `color` | `Debug.Log` 문자열 결합에는 타입명(`Color`)이 아니라 실제 RGBA 데이터가 담긴 인스턴스 필드 변수명(`color`, 소문자)을 전달해야 값이 출력됨 |
| P02 | "_Color", Color.red | SetColor 첫 인자는 Standard Shader 메인 알베도 프로퍼티의 관례적 문자열명(언더스코어+쌍따옴표), 두 번째 인자는 Color 구조체의 정적 상수 |
| X01 | B | Standard Shader의 메인 알베도 색상 지칭 방식("_Color")과 Color.blue 상수를 조합한 한 줄 코드 선택 |
| X02 | B | 셰이더 프로퍼티명은 반드시 쌍따옴표로 감싼 문자열 리터럴이어야 하며, 관례적으로 언더스코어(`_`)로 시작 |

## 해설
### P01
- 개념 정의: `Debug.Log` 안의 문자열 결합(`+`) 연산자 우측에는 **실제 값을 보관하고 있는 변수의 이름**을 넣어야 하며, C#은 해당 변수의 `.ToString()` 메서드를 자동 호출하여 RGBA 색상 정보를 문자열로 변환해 콘솔에 표시합니다.
- 오답 포인트: `Color`(대문자 C, 클래스/구조체 타입명)를 변수명으로 착각하여 넣으면 타입 자체의 `System.Type` 정보가 출력되거나, 정적 컨텍스트에서 동작하지 않습니다. 또한 `new Color(...)`처럼 새 객체를 생성하는 식을 넣는 것은 문제의 요구(기존 필드 값 출력)에서 벗어납니다.
- 판별 기준: `public Color color;`에서 선언된 **소문자 변수명** `color`를 정확히 기입했는지 확인합니다.

### P02
- 개념 정의: `Material.SetColor(string propertyName, Color color)` API는 첫 인자에 셰이더 내부에 정의된 프로퍼티의 이름을 **C# 문자열 리터럴로** 받고, 두 번째 인자에 적용할 색상값을 `Color` 구조체로 받습니다. 유니티 Standard Shader의 메인 알베도 색상은 관례적으로 `"_Color"`라는 이름을 사용합니다.
- 오답 포인트: ① 프로퍼티명에서 쌍따옴표를 빼고 `_Color`를 식별자(변수명)처럼 쓰면 C# 컴파일러가 선언되지 않은 변수로 인식하여 컴파일 에러가 발생합니다. ② 언더스코어를 빼고 `"Color"`로 쓰면 셰이더에서 해당 프로퍼티를 찾지 못해 색상 변경이 적용되지 않습니다.
- 판별 기준: 첫 인자가 `"_Color"` (쌍따옴표 + 언더스코어 시작) 이고, 두 번째 인자가 `Color.red` (정적 상수)인지 정확히 확인합니다.

### X01
- 개념 정의: P02에서 학습한 `"_Color"` + `Color.red` 패턴은 색상 상수 부분만 교체하면 어떤 색상으로든 즉시 전환할 수 있는 범용적 머티리얼 색 변경 코드입니다.
- 오답 포인트: 따옴표 없이 프로퍼티명을 쓰거나(A), 언더스코어를 빼먹거나(C), `Color.blue` 대신 정의되지 않은 파란색 변수명 `blue`를 사용하는(D) C# 문법 에러 및 오작동이 있습니다.
- 판별 기준: 첫 인자는 Standard Shader 전용 메인 알베도인 `"_Color"`, 두 번째 인자는 `Color.blue` 상수로 안전하게 형 일치를 이룬 B를 선택합니다.

### X02
- 개념 정의: 유니티 셰이더 프로퍼티명을 C# 코드에서 참조할 때는 반드시 **쌍따옴표로 감싼 문자열 리터럴** 형태여야 합니다. 이는 프로퍼티명이 런타임에 문자열 검색으로 셰이더 내부를 매칭하기 때문이며, 관례적으로 유니티 Standard Shader의 프로퍼티들은 언더스코어(`_`)로 시작합니다.
- 오답 포인트: 보기 A처럼 따옴표 없이 `_Color`를 쓰면 C#이 이를 변수명으로 인식하여 "선언되지 않은 이름" 컴파일 에러가 발생합니다. 보기 D처럼 `"Color"`는 문법적으로 컴파일은 되지만, 셰이더 내부에 `Color`라는 프로퍼티가 등록되어 있지 않아 `SetColor` 호출이 아무 효과도 발휘하지 못하는 묵인 실패(Silent Failure)가 됩니다.
- 판별 기준: **쌍따옴표 존재** + **언더스코어 시작** 두 조건을 동시에 만족하는 `"_Color"`(보기 B)만이 유일한 정답입니다.
