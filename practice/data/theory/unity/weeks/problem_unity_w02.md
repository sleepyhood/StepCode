### [X01] 변형 - 로그 + 판별 결과 출력
- 출처 개념: U02 / `%`, `==`, `Debug.Log`
- 유형: 객관식
- 문제:
  - 임의의 정수 변수 `n`이 홀수인지 판별한 불리언(boolean) 논리 결과를 `isOdd`라는 변수에 저장한 뒤, 유니티 콘솔 창에 `"isOdd="` 라는 문자열과 그 결괏값(`true` 또는 `false`)을 이어붙여 완성된 출력문으로 로깅하는 가장 올바른 코드를 고르세요.
- 보기:
  - A. `bool isOdd = n % 2 == 0; Debug.Log("isOdd=" + isOdd);`
  - B. `bool isOdd = n % 2 != 0; Debug.Log("isOdd=" + isOdd);`
  - C. `bool isOdd = n % 2 != 0; Console.WriteLine("isOdd=" + isOdd);`
  - D. `bool isOdd = n % 2 == 1; Debug.Log("isOdd=" + isodd);`
