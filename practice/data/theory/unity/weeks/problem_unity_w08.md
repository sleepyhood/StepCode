- 핵심 개념: UI Text 갱신, 메서드 선언(반환형/이름/매개변수), OnMouseUp, Button.onClick 등록 시점

## 원문 대응 문항
### [P01] 점수 UI 코드 3요소 쓰기
- 출처: 원문 6번
- 유형: 단답
- 문제:

  - ① UI 네임스페이스 using
  - ② Text 변수 선언
  - ③ 점수 갱신 후 Text 반영 코드

### [P02] SetMessageToDisplay 선언 완성
- 출처: 원문 7번
- 유형: 단답
- 문제:
  - 아래 호출을 만족하는 메서드 선언 3요소를 쓰세요.
  - 호출: `SetMessageToDisplay("...")`
  - ① 반환형 ② 메서드명 ③ 매개변수

### [P03] OnMouseUp 함수 선언 완성
- 출처: 원문 16번
- 유형: 단답
- 문제:
  - 패널 토글용 Unity 메시지 함수 선언의 빈칸 3개를 쓰세요.
  - ① 접근 제한자 ② 반환형 ③ 메서드명

### [P04] 버튼 이벤트 등록 위치 T/F
- 출처: 원문 30번
- 유형: 단답
- 문제:
  - 아래 문장의 참/거짓을 순서대로 쓰세요.
  - 1. `Start`에서 `button1.onClick.AddListener(...)`를 등록하면 `button1` 클릭으로 동작한다.
  - 2. `OnTriggerEnter2D`는 버튼 클릭 감지 전용 함수이므로 `button3`만 동작한다.
  - 3. `Update`에서 `button2.onClick.AddListener(...)`를 등록해도 클릭 시 동작은 한다.
  - 답안 형식 예: `1 참, 2 거짓, 3 참`

## 확장 문항 (변형/함정/응용)

- 유형: 코드

### [X02] 함정 - AddListener 등록 위치 선택
