## 원문 대응 문항
### [P01] 함수 설명 참/거짓
- 출처: 원문 25번
- 유형: 참거짓
- 문제:
  - 다음은 C# 프로그래밍에서 함수의 시그니처와 반환형, 그리고 매개변수 사용에 대한 설명입니다.
  - 각 문장의 참/거짓을 판별하세요. (문장별 부분 점수 가능)
  - (1) `void` 키워드는 함수가 아무런 결괏값을 반환하지 않는다는 것을 의미하므로, `null` 객체를 반환한다는 뜻과 문법적으로 동일하다.
  - (2) 하나의 함수(메서드) 선언부 안에서 `int` 타입과 `string` 타입 등, 서로 다른 자료형의 매개변수를 여러 개 함께 전달받도록 구성할 수 있다.
  - (3) 작성된 일반 함수(메서드) 코드는 프로그램 실행 중에 다른 코드 블록에 의해 명시적으로 호출(Call)되지 않으면 내부 로직이 절대 스스로 실행되지 않는다.
  - (4) 반환형이 `void`가 아닌 구체적인 자료형(예: `int`, `float`)으로 선언된 함수는, 본문 종료 전에 반드시 해당 타입에 맞는 결괏값을 `return` 키워드로 반환해야만 컴파일 오류가 나지 않는다.
  - 답안 형식 예: `(1) 거짓, (2) 참, (3) 참, (4) 참`

### [P02] 문맥 오류 수정 (static 접근)
- 출처: 원문 28번
- 유형: 객관식
- 문제:
  - 다음 유니티 C# 스크립트에서 컴파일 에러가 발생하고 있습니다. `ThisStat()` 메서드가 `static`으로 선언되어 있기 때문에 발생하는 문맥(Context) 충돌 문제입니다.
  - 메서드 내부에서 `statFloat` 변수를 정상적으로 수정할 수 있도록, ①번 빈칸에 들어갈 가장 알맞은 키워드를 고르세요.
  - ```csharp
    public class Example : MonoBehaviour
    {
        [ ① ] float statFloat = 0;
        private static void ThisStat()
        {
            statFloat = 1;
        }
    }
    ```
- 보기:
  - A. `static`
  - B. `const`
  - C. `readonly`
  - D. `private`

## 확장 문항 (변형/함정/응용)
### [X01] 변형 - 함수 시그니처 완성
- 출처 개념: U03 Function/static
- 유형: 코드
- 문제:
  - 다음의 구체적 요구사항 5가지를 모두 만족하는 C# 메서드의 선언부(시그니처) 첫 줄 코드를 완성하여 작성하세요.
  - 요구 범위:
    - 1. 클래스 외부에서 접근할 수 없도록 접근제어자를 제한(`private`)할 것.
    - 2. 객체 인스턴스 생성 없이도 메모리에 고정되어 클래스 이름으로 바로 호출 가능한 정적(`static`) 메서드일 것.
    - 3. 정수형 결괏값을 반환(`int`)할 것.
    - 4. 메서드 이름은 `Multiply`로 지정할 것.
    - 5. 외부로부터 두 개의 정수형 매개변수인 `a`와 `b`를 전달받을 것.
  - (메서드 내부의 중괄호 `{ }` 본문 구현이나 `return` 문은 굳이 작성하지 않아도 무방합니다.)
- 의도: C# 클래스 메서드를 정의할 때 접근제어자, 지정자, 반환형, 이름, 매개변수 목록을 올바른 문법 순서대로 조립할 수 있는지 점검합니다.

### [X02] 함정 - 함수/static 오개념 종합 판별
- 출처 개념: U03 Function/static
- 유형: 객관식
- 문제:
  - C# 및 유니티 프로그래밍에서 지켜야 할 함수의 반환형(Return Type) 및 정적(Static) 문맥의 규칙에 대해 **잘못 설명하고 있는 것(틀린 원리)**을 고르세요.
- 보기:
  - A. 반환형이 `void`로 지정된 함수는 작업이 끝난 후 호출자에게 어떠한 값도 돌려주지(반환하지) 않는다.
  - B. `int`, `float`, `GameObject` 등 특정 자료형을 반환형으로 선언한 함수는, 코드 블록이 끝나기 전에 동일한 타입의 적절한 값을 `return` 문으로 응답해야 한다.
  - C. `static` 키워드로 선언된 정적 메서드 내부에서는, 같은 클래스 안에 있더라도 `static`이 붙지 않은 일반 인스턴스 멤버 변수(필드)에 대해 별도의 객체 생성 없이 곧바로 직접 접근하여 값을 수정할 수 있다.
  - D. 하나의 함수(메서드) 괄호 안에는 서로 다른 자료형(`int`, `string`, `bool` 등)의 매개변수를 쉼표로 구분하여 여러 개 선언하고 전달받을 수 있다.
- 의도: static 인스턴스 접근 불가 원리 등 헷갈리기 쉬운 C# 함수의 기본 개념들을 종합 점검하고 함정을 가려냅니다.
