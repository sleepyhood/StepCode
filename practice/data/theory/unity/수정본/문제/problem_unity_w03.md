## 원문 대응 문항
### [P01] 함수 설명 참/거짓
- 출처: 원문 25번
- 유형: 참거짓
- 문제:
  - 다음 문장의 참/거짓을 판별하세요.
  - (1) `void` 키워드는 함수가 `null` 값을 반환한다는 뜻이다.
  - (2) 서로 다른 타입의 매개변수를 한 함수에 함께 전달할 수 있다.
  - (3) 일반 함수는 호출되지 않으면 실행되지 않는다.
  - (4) `void`가 아닌 반환형 함수는 `return`이 필요하다.
  - 답안 형식 예: `1 거짓, 2 참, 3 참, 4 참`

### [P02] 문맥 오류 수정
- 출처: 원문 28번
- 유형: 객관식
- 문제:
  - 아래 코드에서 ①번 빈칸에 들어갈 키워드를 고르세요.
  - ```csharp
    public class Example : MonoBehaviour
    {
        [ ① ] float statFloat = 0;
        private static void ThisStat()
        {
            statFloat = 1;
        }
    }
    ```
- 보기:
  - A. `static`
  - B. `const`
  - C. `readonly`
  - D. `private`

## 확장 문항 (변형/함정/응용)
### [X01] 변형 - 함수 시그니처 완성
- 출처 개념: U03 Function/static
- 유형: 코드
- 문제:
  - 아래 요구를 만족하는 메서드 한 줄 선언을 작성하세요.
  - 요구:
    - 접근제어자 `private`
    - `static` 메서드
    - 반환형 `int`
    - 메서드명 `Multiply`
    - 매개변수 `int a, int b`
  - (메서드 본문은 생략 가능)
- 의도: 시그니처 구성요소를 순서대로 조립하는 능력 점검

### [X02] 함정 - `void`/`return` 오개념 판별
- 출처 개념: U03 Function/static
- 유형: 객관식
- 문제:
  - 다음 중 틀린 설명을 고르세요.
- 보기:
  - A. `void` 메서드는 값을 반환하지 않는다.
  - B. `int` 반환형 메서드는 적절한 값을 `return`해야 한다.
  - C. static 메서드는 인스턴스 필드를 직접 접근할 수 있다.
  - D. 매개변수는 서로 다른 타입을 함께 사용할 수 있다.
- 의도: 가장 자주 발생하는 오개념(static-인스턴스 접근)을 분리
