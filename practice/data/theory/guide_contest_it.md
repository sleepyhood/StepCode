# 청소년 IT경시대회 기반 학습자료 제작 가이드

## 목적
1. 대회 문항을 그대로 소비하지 않고, 학생 수준에 맞는 학습 단위로 재구성한다.
2. 언어 문법 학습과 이론 문항을 분리하지 않고 하나의 세트에서 함께 훈련한다.
3. 재귀/탐색 문항은 "정답 암기"가 아니라 "시각적 추적 능력"까지 평가한다.

## 적용 범위
1. 대상 문항: 청소년 IT경시대회 C/Python 공개 문항
2. 문서 위치: `practice/data/theory/*`
3. 세트 제작 시 이 가이드를 공통 기준으로 사용

## 핵심 설계 원칙
1. 학생 노출 단위는 "문항 번호"가 아니라 "개념 묶음"으로 구성한다.
2. 각 문항은 아래 3요소를 모두 포함해 재작성한다.
   - 개념: 무엇을 물어보는가
   - 오답 포인트: 어디서 자주 틀리는가
   - 판별 기준: 무엇을 확인하면 맞는가
3. 정답만 맞히는 문제는 최소화하고, 추적형 문항(표/트리)을 반드시 포함한다.

## 난이도 태그 운영 규칙 (초/중/고)
1. 태그 해석 규칙
   - `초`: 초등 대상
   - `중`: 중등 대상
   - `고`: 고등 대상
   - `초,중`: 초/중 공통
   - `중,고`: 중/고 공통
   - `초,중,고`: 전 학년 공통
2. 세트 편성 규칙
   - 초등 세트: `초`, `초,중`, `초,중,고`만 사용
   - 중등 세트: `중`, `초,중`, `중,고`, `초,중,고` 사용
   - 고등 세트: `고`, `중,고`, `초,중,고` 사용
3. 재귀/탐색 같은 고부하 문항은 기본적으로 중/고 트랙에 배치한다.
4. 같은 문항이라도 초/중/고 버전의 해설 깊이는 다르게 만든다.

## 문항 타입 분류 규칙
1. `CODE_TRACE`: 코드 실행 결과 추적
2. `THEORY_CONCEPT`: 개념/라이브러리/문법 정의
3. `CODE_FILL`: 빈칸 채우기
4. `INPUT_OUTPUT`: 입력 기반 출력 예측
5. `RECURSION_TRACE`: 재귀 호출 구조 추적
6. `GRID_DFS_BFS`: 2D 탐색/연결요소 문제

## 권장 세트 구성 (한 세트 5문항)
1. Trace 2문항: 반복/조건/연산 우선순위
2. Theory 1문항: 라이브러리/문법 정확성
3. Input-Output 1문항: 문자열/배열/2차원 입력
4. Challenge 1문항: 재귀 또는 탐색(중/고), 대체 Trace(초)

## 이론+코드 통합 규칙
1. 이론 문항은 반드시 바로 다음 코드 문항과 연결한다.
   - 예: `strncmp` 원형 -> 문자열 비교 코드 추적
   - 예: `collections` 개념 -> 실제 컨테이너 사용 결과
2. 이론 섹션도 "오답 이유"를 작성한다.
3. 용어 정의만 있는 문항은 단독으로 끝내지 않는다.

## 재귀 문항 제작 규칙 (가장 중요)
1. 재귀 문항은 항상 아래 3단계로 제시한다.
   - 1단계: 종료 조건 확인
   - 2단계: 호출 트리 또는 호출 순서 표 작성
   - 3단계: 반환값 역추적
2. 학생 입력 UI가 가능하면 아래 형식을 우선 사용한다.
   - 호출 추적표: `depth | call | return`
   - 트리 요약표: `node(call) -> children`
3. 채점은 최종 정답 1개만 보지 말고 중간 추적값도 검증한다.
4. 초등 트랙에서는 재귀를 "반복 확장" 비유와 작은 n 값으로 제한한다.

## 시각화 권장 포맷
1. 반복문: 반복 횟수/누적값 표
2. 조건문: 조건식별 T/F 표
3. 재귀: 콜스택 표 또는 트리
4. DFS/BFS: 방문 순서 격자 또는 좌표 로그

## 품질 체크리스트
1. 난이도 태그 필터가 정확히 적용됐는가
2. 코드 문항과 이론 문항이 최소 1회 이상 연결됐는가
3. 재귀 문항에 추적표/트리 단계가 포함됐는가
4. 최종 정답 외 중간 추적값 검증 항목이 있는가
5. 초/중/고별 해설 깊이가 분리되어 있는가
6. 학생 화면에 제작 메모/문항 번호가 노출되지 않는가

## 운영 제안 (실무)
1. 같은 문항을 3단계 해설로 관리
   - L1(초): 결과 중심 + 쉬운 근거
   - L2(중): 과정 중심 + 조건/반복 분해
   - L3(고): 일반화 + 경계값/복잡도
2. 세트 생성 시 우선순위
   - 공통 태그(`초,중,고`) 문항으로 기본축 구성
   - 대상 학년에만 해당하는 문항으로 변별력 추가
3. 재귀/탐색은 별도 주간으로 묶어 반복 노출
