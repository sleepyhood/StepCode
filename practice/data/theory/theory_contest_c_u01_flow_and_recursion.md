# C 경시대회 실전 1 - 흐름 추적과 재귀

## 학습 목표
- 반복문/조건문 코드의 실행 결과를 표로 추적할 수 있다.
- 연산자 우선순위(`&&`, `||`)에 따라 조건식 결과를 정확히 판별할 수 있다.
- C 표준 함수 원형 관련 이론 문제를 실전 코드와 연결해 이해할 수 있다.
- 재귀 함수를 호출표로 분석해 반환값을 역추적할 수 있다.

## 대상 난이도
- 공통: `초,중,고`
- 중등 이상: `중`, `중,고`
- 고등 심화: `고`

## 범위
- 개념: 반복 누적, 조건식 우선순위, 함수 원형, 재귀 호출 구조
- 코드 패턴: `for`, `while`, 배열 순회, `if` 결합 조건, 재귀 함수

## 핵심 패턴
```c
int a = 0;
for (int i = 2; i < 15; i++) {
    if (i % 2 == 0 || i % 3 == 0 && i % 5 == 0) {
        a++;
    }
}
printf("%d\n", a);
```

## 문항 핵심 포인트
### 1) 반복 + 누적
- 개념: 반복 횟수와 누적 변수 변화량을 분리해서 본다.
- 오답 포인트: 머릿속 계산만 하다가 `초기값`과 `종료 조건`을 놓친다.
- 정답 판별: `i`의 실제 순회값 목록과 `a` 증가 시점을 모두 적었는지 확인한다.

### 2) 조건식 우선순위
- 개념: `&&`가 `||`보다 먼저 계산된다.
- 오답 포인트: `(A || B) && C`로 잘못 묶어 해석한다.
- 정답 판별: `A || (B && C)` 형태로 해석했는지 확인한다.

### 3) 이론 + 코드 연결
- 개념: 함수 원형을 알면 반환형/인자형 오류를 빠르게 걸러낼 수 있다.
- 오답 포인트: `strncmp`의 반환형을 `char*`로 착각한다.
- 정답 판별: 반환형 `int`, 인자 `(const char*, const char*, size_t)`를 정확히 말할 수 있는지 본다.

### 4) 재귀 호출 추적
- 개념: 종료 조건 확인 후, 호출 단계와 반환 단계를 분리해서 추적한다.
- 오답 포인트: 호출만 따라가고 반환식 결합을 누락한다.
- 정답 판별: `depth | call | return` 3열 표가 완성되어 있는지 본다.

## 시각 추적 연습
### A. 반복 추적표
```text
열: i | 조건식 결과 | a(누적값)
```

### B. 재귀 호출표
```text
열: depth | f(인자) 호출 | 하위 호출 결과 | 현재 반환값
```

## 자주 하는 실수
- `while (a > 0)`에서 갱신문(`a -= 6`)을 놓쳐 무한 루프로 오해한다.
- 배열 문제에서 인덱스 조건(`i % 2 == 1`, `i % 3 == 2`)을 값 조건으로 착각한다.
- 매크로 문제에서 괄호 없는 매크로 확장 부작용을 계산하지 않는다.

## 미니 체크
### Q1
다음 중 조건식 해석이 올바른 것은?
```c
A || B && C
```
- 정답: `A || (B && C)`

### Q2
재귀 분석의 첫 단계는 무엇인가?
- 정답: 종료 조건이 언제 참이 되는지 먼저 찾는다.

### Q3
`strncmp`의 반환형은?
- 정답: `int`

## 연결 세트
- 기초: 반복 누적 + 단일 조건 추적
- 심화: 재귀 반환 추적 + 2차원 탐색(DFS)
