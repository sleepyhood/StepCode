# Python 경시대회 실전 1 - 흐름 추적과 재귀

## 학습 목표
- 중첩 반복문의 총 실행 횟수를 정확히 계산할 수 있다.
- 조건 누적 코드에서 더하기/빼기 분기를 분리 추적할 수 있다.
- 이론 문제(`collections`, `re.fullmatch`)를 코드 결과와 연결해 설명할 수 있다.
- 재귀 호출을 표와 트리로 시각화해 최종 결과를 도출할 수 있다.

## 대상 난이도
- 공통: `초,중,고`
- 중등 이상: `중`, `중,고`
- 고등 심화: `고`

## 범위
- 개념: 반복 횟수 계산, 조건 분기 누적, 컨테이너 이론, 정규식 매칭, 재귀
- 코드 패턴: `range`, 리스트 순회, `if` 중첩, 함수 재귀, 2D 경로 탐색

## 핵심 패턴
```python
a = 0
for i in range(1, 30, 2):
    for j in range(2, 20, 3):
        a += 1
print(a)
```

## 문항 핵심 포인트
### 1) 반복 횟수 곱셈
- 개념: 바깥 반복 횟수 x 안쪽 반복 횟수로 총 실행 횟수를 구한다.
- 오답 포인트: `range` 끝값 미포함을 잊고 개수를 1개씩 더 센다.
- 정답 판별: 각 `range` 실제 원소 개수를 먼저 썼는지 확인한다.

### 2) 조건 누적 분리
- 개념: 한 반복에서 `+=`와 `-=`가 동시에 발생할 수 있다.
- 오답 포인트: `if`와 `elif`를 혼동해 한 분기만 실행된다고 착각한다.
- 정답 판별: 각 원소에서 더해진 값과 빠진 값을 따로 기록했는지 본다.

### 3) 이론 + 코드 연결
- 개념: `collections`는 내장 컨테이너 대안 모음이며 `str` 대체 컬렉션은 아니다.
- 오답 포인트: 모든 내장 타입이 collections로 대체된다고 이해한다.
- 정답 판별: `list/dict/set/tuple`과 `str`의 역할 차이를 설명할 수 있는지 본다.

### 4) 재귀/탐색 시각화
- 개념: 재귀는 호출 순서와 반환 순서를 나눠 추적한다.
- 오답 포인트: 종료 조건 이전에 호출 트리를 끝까지 쓰지 않는다.
- 정답 판별: `depth | call | return` 표 또는 간단 트리를 완성했는지 본다.

## 시각 추적 연습
### A. 반복-누적 추적표
```text
열: i | j | a 변화 | 현재 a
```

### B. 재귀 호출표
```text
열: depth | f(인자) | 종료 여부 | 반환값
```

### C. 탐색 기록표 (2x2 또는 3x3)
```text
열: 시작좌표 | 이동경로 | 생성된 값 | set 크기
```

## 자주 하는 실수
- `range(1, 30, 2)`에서 30이 포함된다고 오해한다.
- `fullmatch`를 `search`처럼 일부 일치로 해석한다.
- 재귀 함수에서 `global` 갱신 시점을 놓쳐 누적값을 틀린다.
