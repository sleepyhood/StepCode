# 청소년 IT 경시대회(C언어) 커리큘럼 초안

## 1) 설계 방향
- 출제 경향상 핵심은 `문법 암기`보다 `코드 실행 흐름 추적`이다.
- 운영은 `공통 코어 70% + 학년 분기 30%`를 기본으로 한다.
- 같은 출처 문항도 초/중/고에서 해설 깊이를 다르게 설계한다.

## 2) 공통 코어 트랙 (전체 필수)
아래 개념은 학년과 무관하게 공통으로 다룬다.

### 코어 A. 자료형/진법/기본 입출력
- 정수형 범위(`short`, `int`)와 오버플로우
- 정수 리터럴 진법(`0`, `0x`) 해석
- `printf/scanf` 서식 지정자와 폭/정밀도

### 코어 B. 연산자/조건식/비트
- 산술/논리 연산 우선순위와 괄호 전략
- 삼항 연산자 조건 분기
- `&`, `^` 기반 비트 연산 해석

### 코어 C. 반복문/흐름 제어
- `for`, `while` 반복 횟수 계산
- `break`, `continue`가 흐름에 미치는 영향
- 누적/카운팅 문제의 상태표 작성

### 코어 D. 배열/문자열
- 1차원 배열 집계(합, 최댓값/최솟값)
- 문자 배열 순회와 비교 카운팅
- `string.h` 함수 원형/의미 구분

### 코어 E. 함수/재귀/분할정복
- 종료 조건과 재귀 호출 순서 추적
- 점화식 기반 결과 계산
- 구간 분할 출력(분할정복)의 방문 순서

### 코어 F. 메모리/탐색/최적화
- 전처리기 매크로 함정(괄호/치환)
- `malloc/calloc/realloc` 개념과 포인터 활용
- 격자 DFS, 이분 탐색(파라메트릭 서치) 기초

## 3) 초등 추가 트랙 (입문 심화)
공통 코어 위에 다음을 추가한다.

### 목표
- 짧은 C 코드의 실행 결과를 빠르게 예측한다.
- 반복/조건/배열에서 인덱스 실수를 줄인다.

### 추가 내용
- 서식 지정자와 기본 산술/조건 추적
- 단일/이중 반복 카운팅 문제
- 문자열 길이/문자 비교 기초

### 평가 포인트
- 10~20줄 내 코드의 출력 예측 정확도
- 반복 횟수와 조건 분기 누락 방지

## 4) 중등 추가 트랙 (중간 난도)
공통 코어 위에 다음을 추가한다.

### 목표
- 재귀와 반복의 차이를 설명할 수 있다.
- 배열/문자열/매크로 문항에서 함정을 식별한다.

### 추가 내용
- 재귀 호출 표(`depth | call | return`) 작성
- 3중 반복과 조건 결합 추적
- 매크로 치환 결과 해석 훈련

### 평가 포인트
- 상태 추적표를 근거로 답을 설명
- 오답 원인을 연산 우선순위/치환 규칙으로 분류

## 5) 고등 추가 트랙 (상위 난도)
공통 코어 위에 다음을 추가한다.

### 목표
- 포인터/동적 메모리/탐색을 결합한 문제를 해결한다.
- 복합 문제에서 시간 복잡도 감각을 기른다.

### 추가 내용
- 인접 리스트/재귀 DFS 구조 해석
- 2D 격자 연결요소 계산
- 이분 탐색 기반 최적화 판별 문제

### 평가 포인트
- 재귀/탐색의 중간 상태를 정확히 검증
- 경계값 입력에서 동작 차이를 설명

## 7) 레벨 트랙 전용 심화 과제 (주차별)
분기 30분 외에 숙제로 운영한다.

### 초등
- 1~4주: 연산/반복 결과 예측 6문항/주
- 5~8주: 배열/문자열/재귀 기초 6문항/주
- 9~12주: 분할정복/종합 추적 8문항/주

### 중등
- 1~4주: 우선순위/반복 상태표 8문항/주
- 5~8주: 매크로/재귀 점화 8문항/주
- 9~12주: 포인터/격자 탐색 10문항/주

### 고등
- 1~4주: 연산+조건 복합 추적 10문항/주
- 5~8주: 재귀 심화/중간값 검증 10문항/주
- 9~12주: 동적 메모리/DFS/최적화 12문항/주

## 8) 수업 1회 운영 템플릿 (90분)
- 20분: 핵심 개념 정리
- 25분: 실행 결과 예측 문제 풀이
- 30분: 구현/변형 문제 적용
- 15분: 오답 정리 및 실수 패턴 기록

## 9) 평가 체계
- 주간 퀴즈: 실행 결과 예측 70% + 개념 단답 30%
- 월간 모의: 공통 70% + 레벨 트랙 30%
- 오답 분류: `포맷`, `우선순위`, `종료조건`, `인덱스`, `방문처리`, `치환오류`

## 10) 변동 출제 대비(확장 버퍼)
기출 고정 범위 외 변동에 대비해 월 1회 확장 세션을 둔다.

- 확장 후보: `qsort`, 함수 포인터 기초, 비트마스킹 입문, 파일 입출력 기초
- 원칙: 한 주제 과심화보다 3~4개 주제의 기초 대응력 확보를 우선한다.
