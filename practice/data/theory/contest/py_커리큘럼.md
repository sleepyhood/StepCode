# 청소년 IT 경시대회(Python) 커리큘럼 초안

## 1) 설계 방향
- 출제 경향상 핵심은 `코드 작성`보다 `실행 결과 예측`이다.
- 따라서 모든 반은 `공통 코어`를 먼저 학습하고, 이후 `초등/중등/고등 추가 트랙`으로 분기한다.
- 운영 비율은 `공통 70% + 레벨 트랙 30%`를 기본으로 한다.

## 2) 공통 코어 트랙 (전체 필수)
아래 개념은 학년과 무관하게 공통으로 다룬다.

### 코어 A. 반복문과 흐름 추적
- `for`, `while`, `range`, 누적합/카운팅
- 중첩 반복(`2중`, `3중`)의 실행 순서
- 출력 결과 예측(반복 횟수, 조건 충족 횟수 계산)

### 코어 B. 배열/문자열 처리
- 리스트 인덱싱, `append/insert/pop/remove`
- 2차원 배열 순회와 조건 탐색
- 문자열 슬라이싱, 비교, 기본 메서드
- 반복문 + 문자열 결합 문제

### 코어 C. 함수/스코프/람다
- 함수 호출 흐름, 반환값 추적
- 전역변수/지역변수, 가변 객체 주의점
- `lambda` 기본과 정렬 `key`
- 삼항 연산자와 조건식 해석

### 코어 D. 재귀 기본
- 종료 조건, 초기값, 재귀 깊이
- 꼬리 재귀의 동작 이해
- 재귀 호출 결과 예측 문제

### 코어 E. 모듈/내장 함수 핵심
- `datetime` 포맷(`strftime`)
- `re`의 `compile`, `fullmatch` 기초
- `collections` 핵심 자료구조 개념
- 자주 나오는 내장 함수/메서드 해석

### 코어 F. 비트/진수 기초
- 비트연산(`&`, `|`, `^`, `~`, `<<`, `>>`)
- 8진수 출력(`%o`)과 형식 변환

## 3) 초등 추가 트랙 (입문 심화)
공통 코어 위에 다음을 추가한다.

### 목표
- 긴 코드보다 짧은 코드의 정확한 추적 능력 확보
- 반복/배열/기초 재귀에 대한 실수 감소

### 추가 내용
- `while` 기반 유클리드 호제법(최대공약수) 흐름 이해
- 2중 반복 + 문자열/배열 비교 카운트
- 조건 탐색 문제(최대/최소/개수) 템플릿
- 그림/표 기반 꼬리 재귀 설명
- 모듈은 `os`, `math`, 출력 포맷 수준으로 제한

### 평가 포인트
- 10~20줄 코드 결과를 시간 내 정확히 예측
- 인덱스 실수, 종료 조건 누락 방지

## 4) 중등 추가 트랙 (중간 난도)
공통 코어 위에 다음을 추가한다.

### 목표
- 재귀와 반복을 연결해서 사고
- 3중 반복, 상태 추적, 모듈 활용 안정화

### 추가 내용
- 꼬리 재귀 심화(초기값 변경 시 결과 변화)
- `3중 for` + 배열/문자열 혼합 문제
- 비트연산 문제 비중 확대
- `datetime`, `re`, `collections` 실전형 문항
- DFS 기본(재귀 기반 방문 처리, 결과 예측)

### 평가 포인트
- 중첩 반복 추적표를 스스로 작성
- DFS 호출 순서/방문 결과 설명 가능

## 5) 고등 추가 트랙 (상위 난도)
공통 코어 위에 다음을 추가한다.

### 목표
- 고난도 혼합 문제(반복+재귀+탐색) 해결
- 알고리즘 문제에서 결과 예측과 구현을 모두 수행

### 추가 내용
- 2차원 `DFS/BFS`(방문 배열, 큐/스택)
- 경로 수/연결 요소 수 계산 문제
- `4중 for` 및 형 변환 혼합 문제
- `set` 기반 방문 관리, 중복 제거
- 비트연산 심화 + 조건문 함정(`0`, `''`, `False`)

### 평가 포인트
- 2차원 탐색 구현 + 결과 검증
- 경로/개수 유형에서 시간 복잡도 감각 확보

## 7) 레벨 트랙 전용 심화 과제 (주차별)
분기 30분 외에 숙제로 운영한다.

### 초등
- 1~4주: 짧은 코드 추적(10~15줄) 6문항/주
- 5~8주: 2중 반복/배열/재귀 기초 6문항/주
- 9~12주: 모듈 기초 + 종합 예측 8문항/주

### 중등
- 1~4주: 반복/배열 추적표 작성 8문항/주
- 5~8주: 꼬리 재귀/3중 반복 8문항/주
- 9~12주: 모듈+비트+DFS 기초 10문항/주

### 고등
- 1~4주: 반복/조건/형변환 혼합 10문항/주
- 5~8주: 재귀 심화/상태 추적 10문항/주
- 9~12주: 2차원 DFS/BFS, 경로/개수 문제 12문항/주

## 8) 수업 1회 운영 템플릿 (90분)
- 20분: 핵심 개념 정리
- 25분: 실행 결과 예측 문제 풀이
- 30분: 구현 문제(동일 개념)
- 15분: 오답 정리 및 실수 패턴 기록

## 9) 평가 체계
- 주간 퀴즈: 실행 결과 예측 60% + 구현 40%
- 월간 모의: 공통 70% + 레벨 트랙 30%
- 오답 분류: `인덱스`, `종료조건`, `방문처리`, `형변환`, `연산자 우선순위`

## 10) 변동 출제 대비(모듈 버퍼)

- 확장 후보: `itertools`, `random`, 파일 입출력 기초, 예외 처리 기초
- 원칙: 깊게 1개보다 얕게 3~4개를 빠르게 익혀 대응력 확보

- 각 주차의 `공통 코어`는 11-1에서 최소 2개 문항을 선택해 `예측형`으로 사용한다.
- 각 주차의 `트랙 분기 30분`은 11-2/11-3/11-4에서 난도별로 1개 이상 연결한다.
- 월간 모의(12주차)는 `공통 70%`를 1~11주 문항에서, `트랙 30%`를 서술형/탐색형 문항에서 구성한다.
