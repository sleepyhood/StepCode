## 공통 이론 (COMMON)
<!-- audience:common -->
### 1) 모듈 이름-역할 매칭
- `datetime`: 날짜/시간 처리
- `math`: 수학 함수(`sqrt`, `ceil`, `floor` 등)
- `os`: 운영체제 인터페이스(환경변수, 경로, 디렉터리 이동)
- `pickle`: 파이썬 객체 직렬화/역직렬화
- `traceback`: 예외 추적 정보 출력

문제 풀이 기준:
- 설명이 "파일 이름 목록 조회"라고 나오면 보통 `os` 계열이다.
- `pickle`은 파일 목록 조회 모듈이 아니라 "객체 저장/복원"에 가깝다.
- 보기 중 `os` 함수는 실제 함수명인지 철자를 먼저 확인한다.

이론 정리:
- `모듈`은 파이썬 기능 묶음이다. 함수 하나를 외우기보다 "모듈의 책임 범위"를 먼저 잡는다.
- `os`: 운영체제 자원 접근(파일 시스템, 경로, 환경변수)
- `pickle`: 파이썬 객체를 바이트 스트림으로 저장/복원
- `traceback`: 예외가 난 위치와 호출 흐름 출력

판별 프레임:
1. 문제 설명이 "무엇을 다루는가"를 먼저 읽는다. (`시간`, `파일`, `객체`, `오류`)
2. 책임 범위가 가장 직접 맞는 모듈을 고른다.
3. 함수명 철자와 의미가 실제 API처럼 보이는지 확인한다.

### 2) 연산/대입/나머지
```python
s = -20
s += 1
s %= 5
print(s)
```
추적 순서:
- `s = -20`
- `s += 1` -> `-19`
- `-19 % 5`는 파이썬에서 `1` (나머지 결과는 제수 `5`와 같은 부호 범위)

체크 포인트:
- `%`를 C식 직관으로 계산해 음수로 두면 오답 가능.

이론 정리:
- 파이썬에서 `a % b`는 `a = b*q + r`를 만족하는 `r`이며, `r`은 `b`와 같은 부호 범위를 갖는다.
- `b > 0`이면 `r`은 `0 <= r < b`.
- 그래서 음수 피제수라도 결과가 양수로 나올 수 있다.

### 3) 출력 포맷 `.format()`
```python
print("A{:-7d}30{:6s}A".format(2023, "KITPA"))
```
핵심 문법:
- `{: -7d}` 패턴에서 폭(width) `7`은 정수 자리 폭.
- `{:6s}`는 문자열 폭 `6`, 문자열 길이가 5면 공백 1칸이 채워짐.
- 폭은 "최소 칸수"라 값이 더 길면 잘리지 않는다.

이론 정리:
- `format`의 핵심은 "형(type) + 폭(width) + 정렬(align) + 채움(fill)" 조합이다.
- 이 문제에서는 폭 해석이 핵심이며, 공백이 실제 출력 문자열 일부가 된다.
- 시험에서는 공백을 `_`로 바꿔서 제시하는 경우가 많다.

### 4) 함수 키워드/전역 키워드
- 함수 정의: `def`
- 함수 내부에서 전역 변수 사용 선언: `global`

이론 정리:
- 함수 안에서 변수에 대입하면 기본은 지역 변수로 취급된다.
- 전역 변수 값을 함수 안에서 "대입/변경"하려면 `global` 선언이 필요하다.
- 단순 조회만 할 때는 `global` 없이 읽을 수 있다.

### 5) 반올림 `round`
- `round(a, 1)`: 소수 첫째 자리까지 반올림
- 예: `a = 87.362` -> `87.4`

주의:
- `round(a)`는 정수 반올림
- `round(a, 2)`는 `87.36`
- `round(a, -1)`는 1의 자리 앞에서 반올림(예: 90.0)

이론 정리:
- `round(x, n)`에서 `n`은 소수점 기준 자리수다.
- `n > 0`: 소수점 아래 자리
- `n = 0` 또는 생략: 정수 자리
- `n < 0`: 10의 자리, 100의 자리 같은 정수부 반올림

## 고등 트랙 (HIGH)
<!-- audience:high -->
### 고등 포인트
- 보기형 문항의 "거짓 설명 1개"를 빠르게 제외하는 전략이 필요하다.
- 모듈 설명의 정확한 역할 경계를 구분한다.

### 고등 이론 보강
- 개념형 문항은 "경계선"을 물어본다.
- `os`와 `pickle` 경계:
- `os`: 시스템/경로/환경
- `pickle`: 객체 직렬화

고등 판별 루틴:
1. 보기 문장을 동사 기준으로 자른다. (`제어`, `저장`, `추적`)
2. 동사와 모듈 책임을 매핑한다.
3. 코드 문항은 `연산 -> 대입 -> 출력` 순서로 실행 스냅샷을 만든다.
4. 포맷 문항은 폭/정렬/자료형을 분리해서 확인한다.

### 고등 연계 연습

- 작업 디렉터리 변경
- 객체를 바이너리 직렬화해 저장
- 파일/경로 관련 제어
2. 실행 결과를 쓰시오.
```python
s = -14
s += 9
s %= 4
print(s)
```
3. `a = 98.765`일 때 `98.8`을 출력하는 코드를 작성하시오.

### 고등 오답 패턴
- `pickle` 기능을 `os` 기능으로 착각
- `%` 연산의 언어별 차이를 무시
