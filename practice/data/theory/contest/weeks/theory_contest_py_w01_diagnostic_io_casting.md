### 개념 1) 연산/대입/나머지
- 한 줄 요약: 변수 값이 대입 연산을 거치며 어떻게 변하는지를 추적하는 유형입니다.
- 암기 규칙: `+=`, `-=`, `*=` 같은 누적 대입을 먼저 계산하고, `%`는 파이썬 나머지 규칙으로 판단한다.
- 풀이 3단계: 초기값 확인 -> 대입 연산 순차 적용 -> 나머지 연산 적용 -> 출력값 후보 비교한다.
- 함정 포인트: 다른 언어 직관으로 음수 나머지를 처리하면 오답이 발생하기 쉽습니다.

음수 나눗셈 전개:
- 파이썬은 아래 관계를 항상 만족하도록 `//`, `%`를 정한다.
- `a = b * (a // b) + (a % b)`
- `b > 0`일 때 나머지 범위는 `0 <= (a % b) < b`다.

예시 전개:
- `-13 // 5 = -3`
- `-13 % 5 = 2`
- 검산: `5 * (-3) + 2 = -13`

원형 트랙 비유로 이해하기:
- 트랙 한 바퀴를 `b`칸으로 보고, 칸 번호는 `0`부터 `b-1`까지만 존재한다고 본다.
- `a mod b`는 "0번에서 `a`칸 이동했을 때 도착한 칸 번호"로 해석한다.
- 그래서 나머지는 항상 `0` 이상 `b-1` 이하로 표현한다.

왜 음수 나머지가 양수로 보이나:
- 예를 들어 `b=5`에서 0번 칸에서 왼쪽으로 1칸(`-1`) 가면 4번 칸으로 간다.
- 즉 `-1 mod 5 = 4`다. 음수 이동을 "유효한 칸 번호(0~4)"로 다시 적은 결과다.
- 같은 방식으로 `-2 mod 5 = 3`, `-3 mod 5 = 2`, `-4 mod 5 = 1`이 된다.

`-7 mod 5`를 트랙으로 계산:
- 왼쪽 7칸 이동 = 왼쪽 5칸(한 바퀴) + 왼쪽 2칸이다.
- 한 바퀴는 제자리 효과이므로 결국 왼쪽 2칸만 남는다.
- 0번에서 왼쪽 2칸은 3번 칸이므로 `-7 mod 5 = 3`이다.

몫과 나머지까지 연결:
- `a = bq + r`에서 `q`는 "완전한 바퀴 수", `r`은 "마지막 남은 칸 수"다.
- 트랙 칸 번호는 음수가 될 수 없으므로 `r`은 `0 <= r < b`를 만족해야 한다.
- `a=-7, b=5`이면 `-7 = 5q + r`.
- `q=-1`이면 `r=-2`라서 불가, `q=-2`이면 `r=3`이라서 가능하다.
- 따라서 `-7 = 5*(-2) + 3`, 즉 `-7 // 5 = -2`, `-7 % 5 = 3`이다.

한 줄 정리:
- 음수 나눗셈에서 나머지가 양수로 나오는 이유는, 원형 트랙의 도착 칸 번호를 `0~b-1`로 표현하기 때문이다.

### 개념 2) 출력 포맷 `.format()`
- 한 줄 요약: 값 자체가 아니라 "폭(width), 정렬, 자료형" 규칙으로 문자열 결과를 해석하는 유형입니다.
- 암기 규칙: 폭 숫자는 값이 아니라 칸 수이며, 문자열/정수 포맷은 각각의 규칙으로 채워진다.
- 풀이 3단계: 포맷 문자열을 조각별로 분리 -> 각 조각의 폭/형식 적용 -> 공백 포함 최종 문자열 비교한다.
- 함정 포인트: 폭 숫자를 출력값으로 오해하거나 공백을 무시하면 선택지가 뒤집히기 쉽습니다.

![format 폭(width) 시각화](./data/theory/images/contest_w01_format_width.svg)

| 표기 | 의미 | 기본 정렬 | 폭(Width) 해석 | 예시 코드 | 결과 조각 (`·`=공백) |
| --- | --- | --- | --- | --- | --- |
| `{:d}` | 정수 출력 | 오른쪽 | 최소 칸 수(부족하면 공백 채움) | `f"{314:6d}"` | `"···314"` |
| `{:s}` | 문자열 출력 | 왼쪽 | 최소 칸 수(부족하면 공백 채움) | `f"{'AB':5s}"` | `"AB···"` |
| `{:>6d}` | 정수 출력(오른쪽 강제) | 오른쪽 | 6칸 확보 | `f"{314:>6d}"` | `"···314"` |
| `{:<5s}` | 문자열 출력(왼쪽 강제) | 왼쪽 | 5칸 확보 | `f"{'AB':<5s}"` | `"AB···"` |
| `{:^6s}` | 문자열 가운데 정렬 | 가운데 | 6칸 확보 | `f"{'AB':^6s}"` | `"··AB··"` |
| `{:2d}` + 큰 값 | 폭보다 값이 길면 그대로 출력 | 해당 없음 | 잘리지 않음 | `f"{123:2d}"` | `"123"` |

**대표 예시**
```python
print("B{:6d}X{:5s}B".format(314, "AB"))
```
```io
input:
(없음)
output:
B   314XAB   B
```

**변형 예시**
```python

```
```io
input:
(없음)
output:
|CAT |  7|
```

**함정 예시**
```python

```


### 개념 3) 함수 키워드/스코프
- 한 줄 요약: 함수 선언 키워드와 전역 변수 대입 시 필요한 키워드를 구분하는 유형입니다.
- 암기 규칙: 함수 선언은 `def`, 함수 내부 전역 대입은 `global`을 사용한다.
- 풀이 3단계: 함수 밖/안 변수 위치 확인 -> 함수 내부에서 "읽기"인지 "대입"인지 구분 -> 키워드 필요 여부 판단한다.
- 함정 포인트: 전역 변수 조회와 전역 변수 대입을 같은 규칙으로 보면 오류가 발생합니다.

| 키워드 | 언제 필요 | 필요 없는 경우 | 변수 영향 범위 | 메모 |
| --- | --- | --- | --- | --- |
| `def` | 함수 정의를 시작할 때 | 일반 코드 블록/조건문 내부 | 함수 이름을 전역/현재 스코프에 바인딩 | 선언 키워드 |
| `global x` | 함수 내부에서 전역 변수 `x`에 대입/증감할 때 | 전역 변수 읽기만 할 때 | 함수 밖 `x` 값이 변경됨 | 쓰기(대입) 시 핵심 |
| `global` 없음 | 함수 내부 지역 변수만 다룰 때 | 전역 값을 바꿔야 할 때 | 함수 내부 지역 변수만 변경 | 같은 이름이면 가림(shadowing) |

**대표 예시**
```python
total = 1

def add_one():
    global total
    total += 1

add_one()
print(total)
```
```io
input:
(없음)
output:
2
```

**변형 예시**
```python
count = 5

def show():
    print(count)

show()
```
```io
input:
(없음)
output:
5
```

**함정 예시**
```python
score = 10

def change():
    score = score + 1

change()
```
```io
input:
(없음)
output:
UnboundLocalError
```

### 개념 4) 반올림 `round`
- 한 줄 요약: 자리수 인자 `n`의 의미를 해석해 반올림 결과를 판단하는 유형입니다.
- 암기 규칙: `n>0`은 소수부, `n=0`은 정수, `n<0`은 정수부 앞자리 반올림이다.
- 풀이 3단계: 목표 자리 확인 -> 해당 자리 다음 숫자 확인 -> 반올림 적용 후 형식 비교한다.
- 함정 포인트: `round(x)`와 `round(x, 1)`, `round(x, -1)`을 섞어 판단하면 실수가 잦습니다.

| 표현 | 의미 | 기준 자리 | 예시 (`x=54.378`) | 결과 |
| --- | --- | --- | --- | --- |
| `round(x, 2)` | 소수 둘째 자리까지 | 소수점 아래 2번째 | `round(54.378, 2)` | `54.38` |
| `round(x, 1)` | 소수 첫째 자리까지 | 소수점 아래 1번째 | `round(54.378, 1)` | `54.4` |
| `round(x)` / `round(x, 0)` | 정수 자리 반올림 | 일의 자리 | `round(54.378)` | `54` |
| `round(x, -1)` | 십의 자리 반올림 | 십의 자리 | `round(54.378, -1)` | `50.0` |
| `round(x, -2)` | 백의 자리 반올림 | 백의 자리 | `round(54.378, -2)` | `100.0` |

**대표 예시**
```python
x = 54.378
print(round(x, 1))
```

```io
54.4
```

### 개념 5) 조건식 truthy/falsy 판별
- 한 줄 요약: 값의 자료형/상태에 따라 조건문에서 참/거짓이 되는 규칙을 해석하는 유형입니다.
- 암기 규칙: `False`, `0`, `0.0`, `''`, `[]`, `{}`, `None`은 거짓이고, 그 외 대부분은 참이다.
- 풀이 3단계: 각 조건식 값을 자료형으로 분류 -> truthy/falsy 적용 -> 누적 문자열/카운트 변화를 기록한다.
- 함정 포인트: 문자열 내용이 `"False"`여도 비어 있지 않으면 참이라는 점을 자주 놓칩니다.

| 값 | 분류 | `if 값:` 평가 | 이유 |
| --- | --- | --- | --- |
| `0`, `0.0` | 숫자 0 | 거짓 | 0은 falsy |
| `''` | 빈 문자열 | 거짓 | 길이 0 |
| `[]`, `{}` | 빈 컨테이너 | 거짓 | 원소 0개 |
| `None` | 없음(null) | 거짓 | 파이썬 기본 falsy |
| `"0"`, `"False"` | 비어있지 않은 문자열 | 참 | 내용과 무관, 길이 > 0 |
| `[0]`, `-1`, `3.14` | 비어있지 않음/0 아님 | 참 | 값이 존재 |

**대표 예시**
```python
msg = ""
if "0":
    msg += "A"
if []:
    msg += "B"
if -2:
    msg += "C"
print(msg)
```
```io
input:
(없음)
output:
AC
```

**변형 예시**
```python
cnt = 0
for v in [0, "", "OK", None, 7]:
    if v:
        cnt += 1
print(cnt)
```
```io
input:
(없음)
output:
2
```

**함정 예시**
```python
if "False":
    print("T")
else:
    print("F")
```
```io
input:
(없음)
output:
T
```

## 초등 트랙 (ELEMENTARY)
<!-- audience:elementary -->
### 초등 포인트
- 긴 설명보다 "한 줄 추적"을 먼저 적용하는 방식이 효과적입니다.
- 함수 키워드와 조건식 참/거짓 규칙을 우선 고정하는 것이 중요합니다.

### 초등 이론 보강
- 연산은 순서대로 값만 바꿔 기록합니다.
- 포맷은 칸 수를 먼저 세고 값을 넣습니다.
- 조건식은 "비어 있는가"를 먼저 확인합니다.

초등 규칙 카드:
1. `%`는 파이썬 규칙으로 판단한다.
2. 포맷 숫자는 칸 수다.
3. 함수 선언은 `def`다.
4. `global`은 전역 대입에서 쓴다.
5. 빈 컨테이너와 0은 거짓이다.

### 초등 연계 실습 (핸즈온)
실습 목표:
- 설명 읽기에서 끝내지 않고, 직접 계산/출력 확인으로 규칙을 고정합니다.

실습 문제:
```python
b = -8
b %= 3
print(b)
print("|{:4s}|".format("A"))
print("T" if "" else "F")
```

예상 출력:
```io
input:
(없음)
output:
1
|A   |
F
```

체크포인트:
1. `%` 결과의 부호를 제수 기준으로 설명했는가?
2. 포맷 폭 `4`를 "값"이 아닌 "칸 수"로 설명했는가?
3. 빈 문자열이 falsy라는 근거를 한 줄로 적었는가?

### 초등 오답 패턴
- 나머지 연산에서 음수 규칙을 반대로 적용합니다.
- 공백을 출력 문자열 일부로 보지 않습니다.
- 비어 있지 않은 문자열을 거짓으로 착각합니다.

## 중등 트랙 (MIDDLE)
<!-- audience:middle -->
### 중등 포인트
- "문법 이름 문제"와 "코드 추적 문제"를 같은 규칙으로 연결하는 훈련이 필요합니다.
- 반올림 자리수와 포맷 폭을 동시에 다루는 복합 문항 대비가 중요합니다.

### 중등 이론 보강
- 연산/포맷/조건식을 각각 분리한 뒤 합치는 습관이 정확도를 높입니다.
- 전역 대입과 지역 대입을 식별하는 습관이 필요합니다.

중등 판별 루틴:
1. 연산자 우선순위와 대입 순서를 분리한다.
2. 포맷 문자열을 조각 단위로 해체한다.
3. 조건식은 truthy/falsy로만 판정한다.
4. 함수 변수는 대입 여부로 스코프를 판단한다.

### 중등 연계 실습 (핸즈온)
실습 목표:
- 전역/지역 대입, 반올림 자리수, truthy/falsy를 한 문제에서 함께 판별합니다.

실습 문제:
```python
k = 3

def f():
    global k
    k += 2

f()
print(k)
print(round(83.249, 1), round(83.249, 2), round(83.249, -1))
print(bool({}), bool("N"), bool(0.0))
```

### 고등 연계 실습 (핸즈온)
실습 목표:
