### 개념 1) 삼항 연산자 평가 순서
- 개념 정의: `A if cond else B` 형태에서 조건 참/거짓에 따라 하나의 식만 선택하는 유형입니다.
- 판별 규칙: 먼저 `cond`를 평가하고, 참이면 `A`, 거짓이면 `B`만 계산한다.
- 추적 절차: 조건값 계산 -> 선택된 식 확정 -> 산술 연산 수행 -> 출력 순으로 풀이합니다.
- 오답 포인트: `A`와 `B`를 동시에 계산한다고 가정하면 연산 결과를 잘못 냅니다.

![삼항 연산자 평가 흐름도](./data/theory/images/contest_w09_ternary_evaluation_flow.svg)

예시 (기본):
```python
x = 12
y = 15
print(x + y if x > y else x * y)
```
```io
input:
(없음)
output:
180
```

예시 (변형):
```python
a = 7
b = 3
print(a - b if a % 2 == 0 else a + b)
```
```io
input:
(없음)
output:
10
```

예시 (함정):
```python
x = 5
y = 2
print((x + y) if x > y else x * y)
print(x + (y if x > y else x) * y)
```
```io
input:
(없음)
output:
7
9
```

### 개념 2) 람다 함수 값 추적
- 개념 정의: 짧은 식으로 정의된 함수(`lambda`)를 실제 인자 대입으로 계산하는 유형입니다.
- 판별 규칙: `lambda x: expr`는 `def` 함수와 동일하게 인자 치환 후 `expr` 값을 반환한다.
- 추적 절차: 람다 식 확인 -> 인자 대입 -> 연산 우선순위 적용 -> 반환값 계산 순으로 진행합니다.
- 오답 포인트: `f(a)*f(a+1)`에서 두 호출을 같은 값으로 취급하면 오답이 됩니다.

예시 (기본):
```python
f = lambda x: x + 1
a = 4
print(f(a), f(a) * f(a + 1))
```
```io
input:
(없음)
output:
5 30
```

예시 (변형):
```python
g = lambda x, y: x if x > y else y
print(g(3, 9), g(11, 4))
```
```io
input:
(없음)
output:
9 11
```

예시 (함정):
```python
h = lambda x: x + 1
x = 4
print(h(x) * h(x) + 1)
print(h(x) * h(x + 1))
```
```io
input:
(없음)
output:
26
30
```

### 개념 3) 문자열 치환 + `eval` 식 전개
- 개념 정의: 문자열에서 특정 문자를 치환해 수식 문자열을 만든 뒤 `eval`로 계산하는 유형입니다.
- 판별 규칙: 치환은 문자열 단계에서 먼저 수행되고, 이후 완성된 문자열이 식으로 해석된다.
- 추적 절차: 원문자열 확인 -> `replace` 결과 작성 -> 문자열 결합 결과 확인 -> `eval` 계산 순으로 풀이합니다.
- 오답 포인트: 연산자 우선순위를 식이 아니라 문자열 수준에서 잘못 해석하면 결과가 어긋납니다.

예시 (기본):
```python
f = lambda x: eval((str(x).replace("q", "4") + "*" + str(x).replace("q", "4")))
print(f("q"))
```
```io
input:
(없음)
output:
16
```

예시 (변형):
```python
f = lambda x: eval(str(x).replace("q", "4") + "*" + str(x).replace("q", "4"))
print(f("q+1"))
print(f("q+q"))
```
```io
input:
(없음)
output:
9
24
```

예시 (함정):
```python
x = "q+1"
r = x.replace("q", "4")
print(r)
print(r + "*" + r)
```
```io
input:
(없음)
output:
4+1
4+1*4+1
```

### 개념 4) `sort(key=lambda ...)` 복합 정렬
- 개념 정의: 객체/튜플 리스트를 람다 key로 정렬하고 인접 원소 비교를 수행하는 유형입니다.
- 판별 규칙: `key=lambda a:(a.x, a.y)`는 x 우선, x 동률이면 y 기준으로 오름차순 정렬한다.
- 추적 절차: 정렬 전 데이터 목록화 -> key 값표 작성 -> 정렬 결과 확정 -> 인접 비교 로직 적용 순으로 진행합니다.
- 오답 포인트: key 튜플의 항목 순서를 바꾸면 정렬 기준 전체가 달라집니다.

![sort(key=(x,y)) 정렬 키 비교 과정 도식](./data/theory/images/contest_w09_sort_key_compare_diagram.svg)

예시 (기본):
```python
pts = [(3, 10), (2, 6), (3, 2), (1, 9)]
pts.sort(key=lambda p: (p[0], p[1]))
print(pts)
```
```io
input:
(없음)
output:
[(1, 9), (2, 6), (3, 2), (3, 10)]
```

예시 (변형):
```python
pts = [(3, 10), (2, 6), (3, 2), (1, 9)]
pts.sort(key=lambda p: (p[1], p[0]))
print(pts)
```
```io
input:
(없음)
output:
[(3, 2), (2, 6), (1, 9), (3, 10)]
```

예시 (함정):
```python
pts = [(2, 5), (2, 1), (1, 9)]
pts.sort(key=lambda p: p[0])
print(pts)
```
```io
input:
(없음)
output:
[(1, 9), (2, 5), (2, 1)]
```

### 개념 5) 람다 조합으로 누적값 계산
- 개념 정의: `F`(선택 함수), `G`(결합 함수) 같은 람다를 반복문과 결합해 누적 결과를 구하는 유형입니다.
- 판별 규칙: 반복 내부의 갱신식(`m = F(m, k[i])`, `p = G(p, value)`)을 순서대로 적용해야 한다.
- 추적 절차: 케이스별 `m` 계산 -> 후처리 식 계산 -> `p` 누적 -> 최종 출력 순으로 풀이합니다.
- 오답 포인트: `m` 초기값이나 반복 방향을 잘못 잡으면 최댓값/최솟값 결과가 달라집니다.

예시 (기본):
```python
F = lambda A, B: A if A > B else B
G = lambda A, B: A + B
k = [1200, 3500, 200]
m = 0
for i in range(len(k) - 1, -1, -1):
    m = F(m, k[i])
p = G(0, (m * 7 + 999) // 1000)
print(m, p)
```
```io
input:
(없음)
output:
3500 25
```

예시 (변형):
```python
F = lambda A, B: A if A < B else B
arr = [8, 3, 5]
m = 10**9
for v in arr:
    m = F(m, v)
print(m)
```
```io
input:
(없음)
output:
3
```

예시 (함정):
```python
F = lambda A, B: A if A > B else B
arr = [4, 9, 2]
m = 100
for v in arr:
    m = F(m, v)
print(m)
```
```io
input:
(없음)
output:
100
```

## 초등 트랙 (ELEMENTARY)
<!-- audience:elementary -->
### 초등 포인트
- 람다 결과 예측 기초

### 초등 이론 보강
- 람다는 `입력 -> 계산식 -> 출력` 표 3칸으로 먼저 해석합니다.
- 삼항식은 조건 참/거짓 두 경우를 나눠 한 줄씩 계산합니다.

초등 규칙 카드:
1. 조건식부터 계산한다.
2. 람다는 인자 대입 후 식을 계산한다.
3. 정렬은 key 값을 먼저 적는다.

### 초등 연계 연습
1. `lambda x: x+2`에 `x=5`를 대입해 출력값을 쓰시오.
2. `a if c else b` 형태에서 `c`가 False일 때 결과를 쓰시오.

### 초등 오답 패턴
- 람다 식을 보자마자 암산으로 처리해 대입 단계를 생략합니다.

## 중등 트랙 (MIDDLE)
<!-- audience:middle -->
### 중등 포인트
- 람다+정렬 복합

### 중등 이론 보강
- key 튜플 순서 변화에 따른 정렬 결과를 비교표로 작성합니다.
- 반복 누적 코드에서 매 단계 `m`, `p` 값을 추적표로 검산합니다.

중등 판별 루틴:
1. 람다 식을 일반 함수 형태로 바꿔 본다.
2. 정렬 key를 데이터 옆에 함께 적는다.
3. 누적 변수를 단계별로 기록한다.

### 중등 연계 연습
1. 동일 데이터에 대해 `(x,y)` 정렬과 `(y,x)` 정렬을 비교하시오.
2. `F`, `G` 정의를 바꿨을 때 누적 결과가 어떻게 달라지는지 계산하시오.

### 중등 오답 패턴
- 정렬은 맞췄지만 인접 비교 단계에서 인덱스 처리를 잘못합니다.

## 고등 트랙 (HIGH)
<!-- audience:high -->
### 고등 포인트
- 람다+클래스 정렬

### 고등 이론 보강
- 클래스 객체 리스트 정렬 후 인접 관계 기반 누적식을 분해해 계산합니다.
- 문자열 기반 식 생성 코드에서 중간 문자열과 최종 계산식을 분리해 검증합니다.

고등 판별 프레임:
1. key 함수가 만드는 정렬 키를 명시한다.
2. 정렬 후 인접 비교 구간을 표로 만든다.
3. 누적식과 예외 처리(동일 y 없음)를 분리한다.

### 고등 연계 연습
1. 클래스 점 집합을 정렬 후 인접 거리 누적 규칙을 직접 구현하시오.
2. `replace`/문자열 결합/`eval`을 포함한 람다를 안전한 계산 방식으로 재작성하시오.

### 고등 오답 패턴
- 정렬 결과를 눈대중으로 판단해 누적 근거를 설명하지 못합니다.
