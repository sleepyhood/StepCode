### 개념 1) 삼항 연산자 평가 순서
- 개념 정의: `A if cond else B`에서 조건 결과에 따라 하나의 식만 선택해 계산하는 개념입니다.
- 핵심 내용:
  - 먼저 조건 `cond`를 평가합니다.
  - 조건이 참이면 `A`, 거짓이면 `B`만 계산합니다.
  - 선택된 식 결과가 바깥 연산/출력에 사용됩니다.
- 오답 포인트: `A`와 `B`를 동시에 계산한다고 가정하면 결과가 어긋납니다.

| 단계 | 무엇을 평가하나 | 결과 |
| --- | --- | --- |
| 1 | `cond` 평가 | `True` 또는 `False` |
| 2 | `cond`가 참이면 `A` 선택 | `B`는 평가하지 않음 |
| 3 | `cond`가 거짓이면 `B` 선택 | `A`는 평가하지 않음 |
| 4 | 선택된 식 결과를 바깥 연산/출력에 사용 | 최종값 확정 |

![삼항 연산자 평가 흐름도](./data/theory/images/contest_w09_ternary_evaluation_flow.svg)

### 개념 2) 람다 함수 값 추적
- 개념 정의: `lambda` 식을 인자 대입으로 계산해 반환값을 추적하는 개념입니다.
- 핵심 내용:
  - `lambda`는 짧은 함수 정의이며 `def`와 같은 방식으로 계산됩니다.
  - 호출마다 인자가 다르면 결과도 독립적으로 계산해야 합니다.
  - 복합식은 각 호출 결과를 먼저 구한 뒤 결합합니다.
- 오답 포인트: 여러 호출을 같은 값으로 취급하면 결과가 틀립니다.

예시 (기본):
```python
f = lambda x: x + 1
a = 4
print(f(a), f(a) * f(a + 1))
```
```io
input:
(없음)
output:
5 30
```

예시 (변형):
```python
g = lambda x, y: x if x > y else y
print(g(3, 9), g(11, 4))
```
```io
input:
(없음)
output:
9 11
```

예시 (함정):
```python
h = lambda x: x + 1
x = 4
print(h(x) * h(x) + 1)
print(h(x) * h(x + 1))
```
```io
input:
(없음)
output:

30
```

### 개념 3) 문자열 치환 + `eval` 식 전개
- 개념 정의: 문자열 치환으로 수식 문자열을 만든 뒤 `eval`로 계산하는 전개 과정을 해석하는 개념입니다.
- 핵심 내용:
  - `replace`는 먼저 문자열 단계에서 적용됩니다.
  - 결합된 최종 문자열이 수식으로 해석되어 계산됩니다.
  - 중간 문자열을 먼저 확인하면 우선순위 해석 오류를 줄일 수 있습니다.
- 오답 포인트: 식이 아닌 문자열 단계에서 우선순위를 잘못 판단하면 결과가 틀립니다.

예시 (기본):
```python
f = lambda x: eval((str(x).replace("q", "4") + "*" + str(x).replace("q", "4")))
print(f("q"))
```

```io
16
```


### 개념 4) `sort(key=lambda ...)` 복합 정렬
- 개념 정의: `sort(key=lambda ...)`에서 key 값에 따라 단일/복합 정렬 순서를 결정하는 개념입니다.
- 핵심 내용:
  - key가 튜플이면 앞 항목부터 우선순위 비교를 수행합니다.
  - key 항목 순서를 바꾸면 정렬 기준 전체가 바뀝니다.
  - 정렬 후 인접 비교 로직은 정렬 결과를 기준으로 수행됩니다.
- 오답 포인트: key 순서를 잘못 읽으면 전체 순서를 반대로 해석할 수 있습니다.

| key 형태 | 1순위 | 2순위 | 정렬 예시 (`[(3,10),(2,6),(3,2),(1,9)]`) |
| --- | --- | --- | --- |
| `key=lambda p:(p[0], p[1])` | 첫 번째 값 `x` | 두 번째 값 `y` | `[(1,9),(2,6),(3,2),(3,10)]` |
| `key=lambda p:(p[1], p[0])` | 두 번째 값 `y` | 첫 번째 값 `x` | `[(3,2),(2,6),(1,9),(3,10)]` |
| `key=lambda p:p[0]` | `x`만 비교 | 동률은 기존 순서 유지 | `x` 동률 그룹 내부 상대 순서 유지 |

![sort(key=(x,y)) 정렬 키 비교 과정 도식](./data/theory/images/contest_w09_sort_key_compare_diagram.svg)

예시 (기본):
```python
pts = [(3, 10), (2, 6), (3, 2), (1, 9)]
pts.sort(key=lambda p: (p[0], p[1]))
print(pts)
```
```io
input:
(없음)
output:
[(1, 9), (2, 6), (3, 2), (3, 10)]
```

예시 (변형):
```python

```
```io
input:

output:

```

예시 (함정):
```python

pts.sort(key=lambda p: p[0])
print(pts)
```
```io
input:
(없음)
output:

```

### 개념 5) 람다 조합으로 누적값 계산
- 개념 정의: 람다 함수 조합을 반복문과 결합해 누적값을 계산하는 개념입니다.
- 핵심 내용:
  - 반복 내부 갱신식은 코드 순서대로 적용해야 합니다.
  - 초기값(`m`, `p`)과 반복 방향이 결과를 크게 좌우합니다.
  - 함수 조합은 단계별 중간값을 기록하면 검산이 쉬워집니다.
- 오답 포인트: 초기값/반복 방향을 잘못 두면 최댓값/최솟값 결과가 달라집니다.

예시 (기본):
```python
F = lambda A, B: A if A > B else B
G = lambda A, B: A + B
k = [1200, 3500, 200]
m = 0
for i in range(len(k) - 1, -1, -1):
    m = F(m, k[i])
p = G(0, (m * 7 + 999) // 1000)
print(m, p)
```
```io
input:
(없음)
output:
3500 25
```

예시 (변형):
```python
F = lambda A, B: A if A < B else B
arr = [8, 3, 5]
m = 10**9
for v in arr:
    m = F(m, v)
print(m)
```
```io
input:
(없음)
output:
3
```

예시 (함정):
```python
F = lambda A, B: A if A > B else B
arr = [4, 9, 2]
m = 100
for v in arr:
    m = F(m, v)
print(m)
```
```io
input:
(없음)
output:
100
```

### 고등 연계 실습 (핸즈온)
실습 목표:

```python
# W09 starter (고등): 람다 조합/삼항

    print(g(f(x)))

if __name__ == "__main__":
    solve()
```

과제:
1. 클래스 점 집합을 정렬 후 인접 거리 누적 규칙을 직접 구현하시오.
