주어진 연도가 윤년이면 1, 아니면 0을 반환하는 함수를 만든다고 할 때 빈 칸에 들어갈 코드로 알맞은 것을 고르시오 [초중고] 

```c
int leapYear(int y) {
    if([빈 칸]) return 0;  // 빈 칸
    else return 1;
}
```

⓵ (y % 4 == 0 && y % 100 != 0) && y % 400 == 0  
⓶ (y % 4 == 0 && y % 100 != 0) || y % 400 == 0  
⓷ (y % 4 != 0 && y % 100 == 0) || y % 400 != 0

#### 문제 6
6. 다음 프로그램의 실행 결과는 무엇인가? [초]
```c
#include <stdio.h>
int main()
{
    int a = 0;
    for(int i=2 ; i<15 ; i++) {
        if(i % 2 == 0 || i % 3 == 0 && i % 5 == 0) {
            a++;
        }
    }
    printf("%d", a);
    return 0;
}
```
① 6  ② 7  ③ 14  ④ 15  ⑤ 16

#### 문제 14
14. 다음 프로그램의 빈 칸에 값을 넣었을 때 실행 결과가 1인 것을 고르시오. [초, 중, 고]
```c
#include <stdio.h>
int main()
{
    int a[5] = {빈 칸};
    int b = 0;
    for(int i=0 ; i<5 ; i++) {
        b ^= a[i];
    }
    printf("%d\n", b);
    return 0;
}
```
① 0, 1, 2, 3, 4  
② 1, 2, 3, 4, 4  
③ 1, 3, 1, 3, 1  
④ 0, 0, 0, 1, 1  
⑤ 10, -10, 10, -10, 10
