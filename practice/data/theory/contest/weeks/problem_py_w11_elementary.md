## 문제 1
다음 중 아래 코드의 빈 칸에 넣었을 때 출력 결과가 다른 값을 고르시오.
```python
print([빈 칸])
```
⓵ 9 * 8
⓶ 37 ^ 109
⓷ 9 << 3
⓸ (2 ^ 3) * (3 ^ 2)
⓹ (36 if 7*3 else 21) * 2

## 문제 2
다음 프로그램의 실행 결과에서 제일 오른쪽에 연속으로 나타나는 0의 개수는 몇 개인지 고르시오.
```python
a = 1
for i in range(1, 11):
    a *= i
print('%o' % a)
```
⓵ 1개
⓶ 2개
⓷ 3개
⓸ 4개
⓹ 5개

## 문제 3
다음 코드의 실행 결과로 올바른 값을 고르시오.
```python
a = [7, 890, 1, 234, 5678, 901, 23, 45, 6]
cnt = 0
for i in a:
    b = (i & 1) | (i & 2)
    if b > 0:
        cnt += 1
print(cnt)
```
⓵ 6
⓶ 7
⓷ 8
⓸ 9
⓹ 10

## 문제 4
다음 프로그램의 실행 결과가 보기와 같을 때, 빈 칸에 들어갈 코드로 올바른 것을 고르시오.
```python
a = [[0, 1, 2], [3, 4, 5], [6, 7, 8]]
for i in range(3):
    for j in range(3):
        print(빈칸, end=' ')
    print()
```
```text
<보기>
6 3 0
7 4 1
8 5 2
```
⓵ a[2-i][j]
⓶ a[i][2-j]
⓷ a[j][2-i]
⓸ a[i][j]
⓹ a[2-j][i]
