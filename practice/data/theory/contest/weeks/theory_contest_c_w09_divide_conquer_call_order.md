## 공통 이론 (COMMON)
<!-- audience:common -->
### 개념 1) 절반 분할 조건
- 개념 정의: 구간 `[a,b]`를 분할할 때 종료조건과 분할점 계산식을 올바르게 적용하는 개념입니다.
- 판별 규칙: `a==b`가 되면 더 분할하지 않고 리프를 출력한다.
- 판별 규칙: `c=(a+b)/2`와 `c=a+(b-a)/4`는 분할 위치가 다르므로 출력 순서도 달라질 수 있다.
- 추적 절차: 종료조건 확인 -> 분할점 계산 -> 다음 구간 `(a,c)`, `(c+1,b)` 생성 순으로 푼다.
- 오답 포인트: 분할식의 정수 나눗셈을 실수처럼 계산하면 순서가 어긋납니다.

| 분할식 | 정수 계산 형태 | 구간 분할 결과 |
| --- | --- | --- |
| `c = (a+b)/2` | 합을 2로 나눈 몫 | 좌: `[a,c]`, 우: `[c+1,b]` |
| `c = a+(b-a)/2` | 길이 절반 이동 | 좌우 균형 분할 |
| `c = a+(b-a)/4` | 길이 1/4 이동 | 좌 구간이 상대적으로 짧음 |
| 종료 `a==b` | 리프 도달 | 추가 분할 없이 출력/반환 |

![분할 종료조건과 분할 절차 흐름도](./data/theory/images/contest_w09_split_condition_flow.svg)

예시 (기본):
```c
#include <stdio.h>
void f(int a,int b){
    if(a==b){ printf("%d ",a); return; }
    int c=(a+b)/2;
    f(a,c);
    f(c+1,b);
}
int main(void){ f(0,7); }
```
```io

(없음)
output:
0 1 2 3 4 5 6 7
```

예시 (변형):



### 개념 2) 호출 순서(전위/중위/후위)
- 개념 정의: 출력/계산 코드가 재귀 호출의 앞/사이/뒤 어디에 있는지에 따라 결과 순서가 바뀌는 개념입니다.
- 판별 규칙: 출력문이 리프에서만 실행되면 호출 순서가 곧 출력 순서를 결정한다.
- 판별 규칙: `f(left); f(right);` 구조는 좌측 구간이 항상 먼저 소진된다.
- 추적 절차: 호출 트리 작성 -> 방문 순서 표시 -> k번째 출력 위치 확인 순으로 푼다.
- 오답 포인트: DFS 방문 순서를 BFS처럼 세면 k번째 값을 틀립니다.

| 코드 배치 | 방문 순서 특징 | 출력 영향 |
| --- | --- | --- |
| `f(left); f(right);` | 좌측 DFS 우선 | 오름차순/좌측 우선 출력 경향 |
| `f(right); f(left);` | 우측 DFS 우선 | 내림차순/우측 우선 출력 경향 |
| 출력이 리프에서만 | 리프 방문 순서와 동일 | k번째 값 추적이 단순해짐 |
| 출력이 호출 전/후 | 전위/후위 방문 반영 | 동일 트리라도 순서 달라짐 |

![분할 호출 트리의 좌우 방문 순서 도식](./data/theory/images/contest_w09_call_order_tree.svg)

예시 (기본):
```c
#include <stdio.h>
void p(int a,int b){
    if(a==b){ printf("%d ",a); return; }
    int c=(a+b)/2;
    p(a,c);
    p(c+1,b);
}
int main(void){ p(0,15); }
```

```io
output:

```

예시 (변형):

### 개념 3) 호출 트리 깊이 추정
- 개념 정의: 반복적인 함수 합성 또는 재귀 깊이에 따라 값이 어떻게 누적/증폭되는지 추정하는 개념입니다.
- 판별 규칙: 함수 합성은 "한 회차 변환식"을 만든 뒤 반복 적용하면 빠르게 계산된다.
- 판별 규칙: `a=f(a,-i); a=f(a,i);`처럼 2회 합성되는 경우 회차별 순변화식을 정리한다.
- 추적 절차: 1회차 변환 유도 -> n회 반복 적용 -> 경계 회차 검산 순으로 푼다.
- 오답 포인트: 중간 변수 갱신 시점을 놓치면 부호가 반대로 누적될 수 있습니다.

| 추적 단계 | 할 일 | 검산 포인트 |
| --- | --- | --- |
| 1회차 전개 | `a -> f(a,-i) -> f(결과,i)` 전개 | 중간 `a` 갱신 시점 고정 |
| 순변화식 정리 | `a' = T(a,i)` 형태로 정리 | 부호/상수항 분리 확인 |
| 반복 적용 | `i=0..k` 순서로 누적 | 1~2회차는 원식으로 대조 |
| 경계 입력 점검 | 작은 `k`/초깃값으로 테스트 | 패턴 일치 여부 확인 |

![함수 합성 반복의 유도와 교차 검산 절차 도식](./data/theory/images/contest_w09_composition_repeat_check.svg)

예시 (기본):
```c
#include <stdio.h>
int f(int a,int b){ return b*2-a; }
int main(void){
    int a=1;
    for(int i=0;i<3;i++){
        a=f(a,-i);
        a=f(a,i);
    }
    printf("%d",a);
}
```
```io
input:
(없음)
output:
13
```

예시 (변형):
```c
#include <stdio.h>
int f(int a,int b){ return b*2-a; }
int main(void){
    int a=1;
    for(int i=0;i<1;i++){
        a=f(a,-i);

    }
    printf("%d",a);
}
```
```io

```

예시 (함정):
```text
한 회차에서 f를 두 번 적용하므로 단순히 "-a" 한 번으로 계산하면 오답이다.
```
