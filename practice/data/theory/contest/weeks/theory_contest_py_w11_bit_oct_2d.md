### 개념 1) 비트 연산과 값 판별
- 한 줄 요약: 정수의 하위 비트 패턴을 `&`, `|`, `^`, `<<`로 계산해 결과를 비교하는 유형입니다.
- 암기 규칙: `x & 1`은 최하위 1비트, `x & 2`는 두 번째 비트, `x << k`는 `x * 2^k`와 같다.
- 풀이 3단계: 정수를 이진수로 표현 -> 연산자별 규칙 적용 -> 십진수로 환산 -> 보기 비교 순으로 풀이합니다.
- 함정 포인트: `^`를 거듭제곱으로 오해하면 결과가 크게 달라집니다.

| 연산자 | 의미 | 예시 | 결과 | 주의점 |
| --- | --- | --- | --- | --- |
| `&` | 둘 다 1인 비트만 1 | `5 & 3` (`0101 & 0011`) | `1` | 마스킹에 자주 사용 |
| <code>&#124;</code> | 하나라도 1이면 1 | <code>5 &#124; 3</code> | `7` | 합집합 비트 |
| `^` | 다르면 1 | `5 ^ 3` | `6` | 거듭제곱 아님 |
| `<< k` | 왼쪽 시프트(`x * 2^k`) | `5 << 2` | `20` | 비트 자리수 증가 |

### 개념 2) XOR 누적과 소거 성질
- 한 줄 요약: `b ^= a[i]` 형태로 배열 전체를 XOR 누적해 최종값을 구하는 유형입니다.
- 암기 규칙: 같은 수를 짝수 번 XOR하면 0으로 소거되고, 홀수 번 남은 값만 결과에 남는다.
- 풀이 3단계: 빈도(짝/홀) 확인 -> 누적 XOR 수행 -> 최종값 확정 순으로 풀이합니다.
- 함정 포인트: 덧셈 누적처럼 처리하면 전혀 다른 값이 됩니다.

**대표 예시**

```python
b = 0
for v in a:

print(b)
```

### 개념 3) 팩토리얼 8진수 끝자리 0 개수
- 한 줄 요약: `n!`을 8진수로 표현했을 때 오른쪽 연속 0 개수를 묻는 유형입니다.
- 암기 규칙: 8진수 뒤 0 개수는 `n!` 안에 포함된 소인수 2의 개수를 3으로 나눈 몫이다.
- 풀이 3단계: `v2(n!)` 계산 -> `v2 // 3` 수행 -> 8진수 끝 0 개수 확정 순으로 풀이합니다.
- 함정 포인트: 10진수의 뒤 0 규칙(2와5 쌍)과 혼동하면 오답이 됩니다.

| 단계 | 계산식 | `n=10` 예시 | 결과 |
| --- | --- | --- | --- |
| `v2(n!)` 계산 | `sum(n // 2^k)` | `10//2 + 10//4 + 10//8 = 5+2+1` | `8` |
| 8진수 0 개수 | `v2 // 3` | `8 // 3` | `2` |
| 최종 해석 | 뒤쪽 연속 `0` 개수 | `10!`의 8진수 `15657400` | `2` |

**대표 예시**

### 개념 4) 2차원 인덱스 변환과 회전 출력
- 한 줄 요약: `a[r][c]`에서 인덱스를 변환해 회전/대칭 결과를 출력하는 유형입니다.
- 암기 규칙: 3x3에서 90도 시계 회전 출력은 `a[2-j][i]`로 읽는다.
- 풀이 3단계: 목표 출력의 행/열 의미 설정 -> 원본 인덱스 역매핑 -> 식 검증 순으로 풀이합니다.
- 함정 포인트: `a[j][2-i]`와 `a[2-j][i]`를 혼동하면 회전 방향이 바뀝니다.

| 목표 변환 | 출력식 | 방향 |
| --- | --- | --- |
| 원본 그대로 | `a[i][j]` | 회전 없음 |
| 90도 시계 회전 | `a[2-j][i]` | 오른쪽 회전 |
| 90도 반시계 회전 | `a[j][2-i]` | 왼쪽 회전 |

```python
a = [[0,1,2],[3,4,5],[6,7,8]]
for i in range(3):

        print(a[2-j][i], end=' ')
    print()
```

### 개념 5) 2차원 BFS/DFS 연결요소 탐색
- 한 줄 요약: 격자에서 상하좌우 이동으로 연결된 칸을 하나의 컴포넌트로 묶어 크기/개수를 계산하는 유형입니다.
- 암기 규칙: 범위 검사 -> 방문 여부 검사 -> 방문 표시 -> 큐/재귀 확장 순서를 고정한다.
- 풀이 3단계: 시작점 발견 -> 탐색으로 같은 컴포넌트 라벨링 -> 컴포넌트 크기 집계 -> 후처리 계산 순으로 풀이합니다.
- 함정 포인트: 방문 표시를 늦게 하면 같은 칸이 중복 삽입되어 결과가 깨집니다.

| 단계 | BFS/DFS 공통 동작 | 체크 포인트 |
| --- | --- | --- |
| 1 | 좌표가 격자 범위 안인지 검사 | `0 <= y < n`, `0 <= x < n` |
| 2 | 방문했는지/대상칸인지 검사 | `not vis[y][x]`, `grid[y][x] == 1` |
| 3 | 방문 표시를 먼저 수행 | 중복 삽입 방지 |
| 4 | 인접 4방향 확장 | `(-1,0),(1,0),(0,-1),(0,1)` |
| 5 | 컴포넌트 크기/개수 갱신 | 탐색 종료 시 집계 |

![2D BFS/DFS 탐색 순서 방문 번호 오버레이](./data/theory/images/contest_w11_bfs_dfs_visit_overlay.svg)

**대표 예시**
```python
from collections import deque

grid = [
    [1,0,0],
    [1,1,0],
    [0,0,1],
]
n = 3
vis = [[0]*n for _ in range(n)]
comp = 0
sizes = []
for i in range(n):
    for j in range(n):
        if grid[i][j] == 1 and not vis[i][j]:
            comp += 1
            q = deque([(i,j)])
            vis[i][j] = 1
            sz = 0
            while q:
                y, x = q.popleft()
                sz += 1
                for dy, dx in [(-1,0),(1,0),(0,-1),(0,1)]:
                    ny, nx = y+dy, x+dx
                    if 0 <= ny < n and 0 <= nx < n and grid[ny][nx] == 1 and not vis[ny][nx]:
                        vis[ny][nx] = 1
                        q.append((ny,nx))
            sizes.append(sz)
print(comp, sizes)
```
```io
input:
(없음)
output:
2 [3, 1]
```

### 개념 6) 중첩 반복 누적식 + 절댓값/나머지
- 한 줄 요약: 2차원 배열 곱 누적 후 `abs(det) % m` 형태 후처리를 수행하는 유형입니다.
- 암기 규칙: 누적 배열 초기화 위치와 반복 횟수(`n`번 반복)를 먼저 확인한다.
- 풀이 3단계: `t` 초기화 확인 -> 누적 루프 전개 -> 식 `abs(x) % 5` 계산 -> 출력값 확정 순으로 풀이합니다.
- 함정 포인트: `t`를 매 반복마다 초기화하는 것으로 잘못 가정하면 전혀 다른 결과가 나옵니다.

**대표 예시**
```python
def f(v):
    return v if v > 0 else -v

a = [[10, 2], [0, 5]]
t = [[0, 0], [0, 0]]
for _ in range(2):
    for i in range(2):
        for j in range(2):
            for k in range(2):
                t[i][j] += a[i][k] * a[k][j]
p = f(t[0][0] * t[0][1] - t[1][0] * t[1][1]) % 5
print(p)
```

```io
(없음)
output:
0
```

## 초등 트랙 (ELEMENTARY)

### 초등 포인트
- 비트 기초 연산/2차원 순회

### 초등 이론 보강
- 비트 연산은 작은 수(0~15) 이진수 표로 먼저 계산합니다.
- 2차원 배열은 행/열 인덱스를 종이에 표시한 뒤 코드와 대응합니다.

초등 규칙 카드:
1. 연산자 의미를 먼저 확정한다.
2. 인덱스 범위를 먼저 확인한다.
3. 누적 변수 초기값을 먼저 적는다.

### 초등 연계 실습 (핸즈온)
실습 목표:
- 핵심 규칙을 직접 계산/표기로 확인합니다.

### 중등 포인트

### 중등 이론 보강

- 중첩 루프에서는 초기화 위치를 먼저 표시하고 누적식을 단계별로 추적합니다.

중등 판별 루틴:

2. 반복 경계와 초기화 위치를 점검한다.
3. 최종 후처리(`abs`, `%`)를 마지막에 적용한다.

### 중등 연계 실습 (핸즈온)
실습 목표:

### 고등 연계 실습 (핸즈온)
실습 목표:
- 판별 근거를 먼저 세우고 결과를 검증합니다.

실습 문제 코드:
```python
# W11 starter (고등): 2차원 BFS 골격
from collections import deque

def solve():
    g = [
        [1, 1, 0],
        [0, 1, 0],
        [1, 0, 1],
    ]
    n, m = 3, 3
    vis = [[False] * m for _ in range(n)]
    dr = [1, -1, 0, 0]
    dc = [0, 0, 1, -1]

    q = deque([(0, 0)])
    vis[0][0] = True
    cnt = 0
    while q:
        r, c = q.popleft()
        cnt += 1
        for k in range(4):
            nr, nc = r + dr[k], c + dc[k]
            if 0 <= nr < n and 0 <= nc < m and not vis[nr][nc] and g[nr][nc] == 1:
                vis[nr][nc] = True
                q.append((nr, nc))
    print(cnt)

if __name__ == "__main__":
    solve()
```
