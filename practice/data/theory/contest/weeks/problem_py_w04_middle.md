## 문제 1
연계 개념: 개념 1) 리스트 메서드 기능 구분
다음 코드의 실행 결과로 올바른 것을 고르시오.
```python
a = [6, 1, 5, 0, 2, 3, 4]
for i in range(5):
    b = i
    for j in range(1, 30):
        b = a[b]
    print(b, end=' ')
```
⓵ 3 1 4 5 6
⓶ 6 2 3 4 1
⓷ 1 0 4 5 2
⓸ 5 0 2 3 1
⓹ 4 2 1 5 3

## 문제 3
연계 개념: 개념 2) 반복 인덱싱 상태 전이 (`b = a[b]`), 개념 3) 순환(cycle) 길이와 반복 횟수 관계
다음 코드의 실행 결과로 올바른 것을 고르시오.
```python
a = [3, 1, 4, 1, 5]
a.insert(3, 9)
a.pop(1)
print(a)
```
⓵ [3, 4, 1, 9, 5]
⓶ [3, 4, 9, 1, 5]
⓷ [3, 1, 9, 4, 5]
⓸ [3, 9, 4, 1, 5]
⓹ [3, 4, 9, 5]

## 문제 5
