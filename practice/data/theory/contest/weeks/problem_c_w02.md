#### 문제 4
4. 다음 코드의 실행 결과로 올바른 것을 고르시오 [중고]
```c
#include<stdio.h>
int main()
{
    int a = 0x32;
    int b = 030;
    printf("%d", a+b);
    return 0;
}
```

⓵ 44  
⓶ 56  
⓷ 62  
⓸ 74  
⓹ 80
