### 개념 1) 리스트 메서드 기능 구분
- 개념 정의: 리스트 조작 메서드가 "어디에", "무엇을", "몇 개" 변경하는지 구분하는 유형입니다.
- 판별 규칙: `append`는 끝에 1개, `insert`는 특정 위치에 1개, `extend`는 여러 개를 끝에 붙인다.
- 추적 절차: 변경 전 리스트 기록 -> 메서드 적용 위치/개수 확인 -> 변경 후 리스트를 비교한다.
- 오답 포인트: `insert`와 `append`, `remove`와 `pop`의 용도를 섞으면 오답이 발생하기 쉽습니다.

| 메서드 | 용도 | 반환값 | 리스트 변화 | 자주 하는 혼동 |
| --- | --- | --- | --- | --- |
| `append(x)` | 끝에 1개 추가 | `None` | 길이 +1 | 반환값이 추가 원소라고 오해 |
| `insert(i, x)` | 인덱스 `i`에 삽입 | `None` | 뒤 원소 밀림 | `append`와 위치 차이 혼동 |
| `pop([i])` | 원소 꺼내고 삭제 | 삭제된 원소 | 길이 -1 | `remove`와 혼동 |
| `remove(x)` | 값이 `x`인 첫 원소 삭제 | `None` | 길이 -1 | 인덱스가 아니라 "값" 기준 |
| `sort()` | 제자리 정렬 | `None` | 순서 재배열 | `sorted()`와 반환 방식 혼동 |

예시 (기본):
```python
a = [10, 20, 30]
a.insert(1, 99)
print(a)
```

### 개념 2) 반복 인덱싱 상태 전이 (`b = a[b]`)
- 개념 정의: 인덱스를 값으로 바꿔 다시 인덱스로 쓰는 반복 전이 구조를 해석하는 유형입니다.
- 판별 규칙: 한 번 반복할 때마다 `b`는 "현재 값"이 아니라 "다음 인덱스"로 바뀐다.
- 추적 절차: 시작값 지정 -> 반복 횟수만큼 `b = a[b]` 갱신 -> 각 단계 값을 표로 기록한다.
- 오답 포인트: `b`를 고정 인덱스로 착각하면 반복 결과가 전부 어긋납니다.

| step | `b` 이전 | 계산 `a[b]` | `b` 이후 |
| --- | --- | --- | --- |
| 시작 | `0` | - | `0` |
| 1 | `0` | `a[0]=2` | `2` |
| 2 | `2` | `a[2]=3` | `3` |
| 3 | `3` | `a[3]=1` | `1` |
| 4 | `1` | `a[1]=0` | `0` |

![b=a[b] 인덱스 점프 그래프](./data/theory/images/contest_w04_index_jump_graph.svg)

예시 (기본):
```python
a = [2, 0, 3, 1]
b = 0
for _ in range(4):
    b = a[b]
print(b)
```
```io
input:
(없음)
output:
0
```

예시 (변형):
```python
a = [1, 2, 3, 0]
b = 2
for _ in range(5):
    b = a[b]
print(b)
```
```io
input:
(없음)
output:
3
```

예시 (함정):
```python
a = [4, 0, 1, 2, 3]
b = 1
for _ in range(3):
    b = a[b]
print(b)
```
```io
input:
(없음)

3
```

### 개념 3) 순환(cycle) 길이와 반복 횟수 관계
- 개념 정의: 반복 인덱싱 결과가 주기적으로 반복될 때, 반복 횟수와 최종 상태를 연결하는 유형입니다.
- 판별 규칙: 순환 길이가 `L`이면 큰 반복 횟수는 `횟수 % L`로 줄여 판단한다.
- 추적 절차: 몇 단계 직접 추적해 순환 구간 확인 -> 순환 길이 계산 -> 나머지 횟수만 적용한다.
- 오답 포인트: 전체 횟수를 전부 손으로 추적하려다 계산 실수가 누적됩니다.

![사이클 길이와 모듈러 축약 다이어그램](./data/theory/images/contest_w04_cycle_modular_ring.svg)

## 초등 트랙 (ELEMENTARY)
<!-- audience:elementary -->
### 초등 포인트
- 리스트 조작 구현 4문항

### 초등 이론 보강
- 리스트 변화 전/후를 두 줄로 써서 비교합니다.
- 인덱스 추적은 단계 번호를 붙여 한 칸씩 이동합니다.

초등 규칙 카드:
1. `append`는 끝에 1개 추가다.
2. `insert(i, x)`는 i 위치에 1개 삽입이다.
3. 인덱스 추적은 현재 인덱스 -> 다음 인덱스 순서로 본다.

### 초등 연계 연습
1. 리스트 `[1, 3, 5]`에 `insert(1, 2)` 적용 결과를 쓰시오.
2. `a=[1,0]`, `b=0`에서 `b=a[b]`를 3회 적용한 결과를 쓰시오.

### 초등 오답 패턴
- `insert`가 끝에 붙는다고 착각합니다.

## 중등 트랙 (MIDDLE)
<!-- audience:middle -->
### 중등 포인트
- 인덱스 역추적 문제

### 중등 이론 보강
- 상태표(`step, b`)를 작성하면 긴 반복도 안정적으로 계산할 수 있습니다.
- 순환 구간을 찾으면 반복 횟수를 나머지로 축약할 수 있습니다.

중등 판별 루틴:
1. 시작 인덱스를 확정한다.
2. 1회 전이식 `b <- a[b]`를 반복 적용한다.
3. 순환이 보이면 반복 횟수를 축약한다.

### 중등 연계 연습
1. `b = a[b]` 반복 문제를 상태표 8행 이상으로 작성하시오.
2. 같은 전이식에서 시작 인덱스만 바꿨을 때 결과 차이를 설명하시오.

### 중등 오답 패턴
- 단계 수를 하나 덜/더 적용해 최종값이 틀립니다.

## 고등 트랙 (HIGH)
<!-- audience:high -->
### 고등 포인트
- 인덱스/슬라이싱 복합 문제

### 고등 이론 보강
- 전이 그래프 관점(노드=인덱스, 간선=다음 인덱스)으로 해석하면 일반화가 쉬워집니다.
- 순환 진입 전 구간과 순환 구간을 분리하면 대반복도 계산 가능합니다.

고등 판별 프레임:
1. 전이 함수를 정의한다. (`f(i)=a[i]`)
2. 시작점에서 궤적을 추적한다.
3. 순환 길이/진입 길이를 분리해 반복 결과를 계산한다.

### 고등 연계 연습
1. 전이 그래프를 직접 그리고 순환 길이를 구하시오.
2. 반복 횟수 `N`이 매우 큰 경우의 축약 계산식을 작성하시오.

### 고등 오답 패턴
- 그래프 구조는 맞게 보지만 반복 횟수 축약식을 잘못 세웁니다.
