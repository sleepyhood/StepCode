## 문제 2
연계 개념: 개념 2) 오버플로우/승격
다음 코드의 실행 결과로 올바른 것을 고르시오.
```c
#include <stdio.h>
int main() {
    short s = 32767;
    printf("%d ", s + 1);
    s = s + 1;
    printf("%d", s);
    return 0;
}
```
⓵ 32768 -32768
⓶ -32768 32768
⓷ -1 -32768
⓸ 32768 32768
⓹ 오류
