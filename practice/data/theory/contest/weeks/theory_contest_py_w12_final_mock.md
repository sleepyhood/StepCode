### 개념 1) 실전 시간 배분 전략
- 개념 정의: 제한 시간 내 최대 점수를 얻기 위해 문제를 선별하고 순서를 재배치하는 전략입니다.
- 판별 규칙: 쉬운 문제를 먼저 확정해 기본 점수를 확보하고, 중간 난도 문항으로 확장한다.
- 추적 절차: 1차 스캔(난도 라벨) -> 2차 풀이(확정 문항) -> 3차 도전(고난도) -> 4차 검토(실수 제거) 순으로 진행합니다.
- 오답 포인트: 어려운 문제에 초반 시간을 과투자하면 후반 확정 점수를 놓칩니다.

예시 (기본):
```python
# 난도 라벨 예시: E(쉬움), M(보통), H(어려움)
qs = ["E", "M", "E", "H", "M", "E"]
order = [i for i, d in enumerate(qs) if d == "E"] + \
        [i for i, d in enumerate(qs) if d == "M"] + \
        [i for i, d in enumerate(qs) if d == "H"]
print(order)
```
```io
input:
(없음)
output:
[0, 2, 5, 1, 4, 3]
```

예시 (변형):
```python
# 45분 시험: 10/20/10/5 분배
plan = {"scan": 10, "solve_main": 20, "challenge": 10, "review": 5}
print(sum(plan.values()))
```
```io
input:
(없음)
output:
45
```

예시 (함정):
```python
# 어려운 문제에 30분 사용

print(left)
```

### 개념 2) 문제 유형별 풀이 프로토콜
- 개념 정의: 문항을 유형으로 분류해 고정된 풀이 순서를 적용하는 방법입니다.
- 판별 규칙: 계산형/추적형/개념형을 먼저 구분하고, 유형별 체크리스트를 적용한다.
- 추적 절차: 유형 분류 -> 핵심 변수 표시 -> 중간 근거 작성 -> 최종 답 확정 순으로 풀이합니다.
- 오답 포인트: 유형 분류 없이 바로 계산하면 검증 포인트를 빠뜨립니다.

예시 (기본):
```python
qtype = "trace"
if qtype == "calc":
    steps = ["식 정리", "중간값", "최종값"]
elif qtype == "trace":
    steps = ["초기값", "반복/분기", "출력"]
else:
    steps = ["개념 키워드", "보기 대조", "정답"]
print(steps)
```
```io
input:
(없음)
output:
['초기값', '반복/분기', '출력']
```

예시 (변형):
```python
# 추적형 점검 항목 수
check = ["초기값", "루프범위", "분기조건", "갱신식", "출력"]
print(len(check))
```
```io

(없음)
output:
5
```

예시 (함정):
```python
# 출력만 보고 답을 확정하면 근거가 비어 있습니다.
```

### 개념 3) 검토 루틴(실수 제거)
- 개념 정의: 풀이 후 최종 제출 전에 오답 가능성이 높은 항목을 재점검하는 절차입니다.
- 판별 규칙: 검토는 계산 재수행이 아니라 실수 포인트를 압축 점검한다.
- 추적 절차: 정답 번호/단위/부호/경계값/들여쓰기 순서로 빠르게 확인합니다.
- 오답 포인트: 전체를 처음부터 다시 풀면 시간만 소모되고 핵심 실수는 놓칠 수 있습니다.

예시 (기본):
```python
checks = ["정답번호", "부호", "경계값", "들여쓰기", "출력형식"]
print(" -> ".join(checks))
```
```io
input:
(없음)
output:

```

예시 (변형):
```python
mistakes = {"번호": 0, "부호": 1, "경계": 0, "형식": 0}
print(sum(mistakes.values()))
```
```io
input:
(없음)
output:
1
```

예시 (함정):
```python
# 검토를 생략하면 잠재 오답이 남습니다.
review_done = False
print("risk" if not review_done else "safe")
```
```io
input:
(없음)
output:
risk
```

### 개념 4) 오답코드 분류 체계
- 개념 정의: 틀린 문제를 원인 코드로 분류해 재발 방지 학습으로 연결하는 체계입니다.
- 판별 규칙: 한 문항은 1차 원인 코드 1개를 우선 지정한다.
- 추적 절차: 오답 확인 -> 1차 원인 태깅 -> 보조 원인 기록 -> 수정 액션 작성 순으로 진행합니다.
- 오답 포인트: 원인 없이 정답만 고치면 같은 실수가 반복됩니다.

| 코드 | 의미 | 재발 방지 액션(예시) |
| --- | --- | --- |
| `IDX` | 인덱스/범위 실수 | 경계값 3개(최소/중간/최대) 수동 검산 |
| `COND` | 조건/분기 오해 | 참/거짓 케이스를 표로 분리 확인 |
| `OP` | 연산자/우선순위 실수 | 괄호로 식을 명시하고 단계별 계산 |
| `TYPE` | 형변환/자료형 혼동 | 입력 타입/중간 타입을 `type()`으로 점검 |
| `FLOW` | 흐름 제어 오류 | `break/continue/종료조건` 체크리스트 사용 |
| `READ` | 지문/선지 오독 | 키워드(단위/조건/출력형식) 밑줄 표시 |

오답코드 기준:
1. `IDX`: 인덱스/범위 실수
2. `COND`: 조건/분기 오해
3. `OP`: 연산자/우선순위 실수
4. `TYPE`: 형변환/자료형 혼동
5. `FLOW`: 흐름 제어(`break`/`continue`/재귀 종료) 오류
6. `READ`: 문제 지문/선지 오독

예시 (기본):
```python
wrong = {"q": 17, "code": "OP", "fix": "^와 ** 구분 재훈련"}
print(wrong["q"], wrong["code"])
```
```io
input:
(없음)
output:
17 OP
```

예시 (변형):
```python
logs = ["IDX", "READ", "IDX", "COND", "IDX"]
print(logs.count("IDX"))
```
```io
input:
(없음)
output:
3
```

예시 (함정):
```python
# 원인 코드 미기록
entry = {"q": 5, "answer_fix": True, "code": ""}
print(entry["code"] == "")
```
```io
input:
(없음)
output:
True
```

### 개념 5) 재풀이 루프 설계
- 개념 정의: 오답 문항을 일정 간격으로 재풀이해 장기 기억으로 전환하는 절차입니다.
- 판별 규칙: 재풀이는 1회 정답 확인으로 끝내지 않고 최소 3회 간격 반복한다.
- 추적 절차: D0(즉시) -> D2(2일 후) -> D7(1주 후) 재풀이 및 코드별 개선 여부를 기록합니다.
- 오답 포인트: 같은 날 반복만 하면 단기 기억 착시로 실제 실력 향상이 제한됩니다.

예시 (기본):
```python
schedule = ["D0", "D2", "D7"]
print(len(schedule), schedule[-1])
```
```io
input:
(없음)
output:
3 D7
```

예시 (변형):
```python
# 문항별 재풀이 완료 상태
status = {"q8": [1, 1, 0], "q17": [1, 0, 0]}
print(sum(status["q8"]), sum(status["q17"]))
```
```io
input:
(없음)
output:
2 1
```

예시 (함정):
```python
# D0만 수행한 경우
done = ["D0"]
print("insufficient" if len(done) < 3 else "ok")
```
```io
input:
(없음)
output:
insufficient
```

## 초등 트랙 (ELEMENTARY)
<!-- audience:elementary -->
### 초등 포인트
- 공통+초등 트랙 종합

### 초등 이론 보강
- 쉬운 문항 확정 능력을 우선 강화해 기본 점수를 안정화합니다.
- 계산형/개념형 구분을 빠르게 하여 문제 읽기 시간을 줄입니다.

초등 규칙 카드:
1. 쉬운 문제부터 확정한다.
2. 답을 고르면 근거 한 줄을 남긴다.
3. 제출 전 번호/부호를 다시 본다.

### 초등 연계 실습 (핸즈온)
실습 목표:
- 핵심 규칙을 직접 계산/표기로 확인합니다.

실습 문제 코드:
```python
# W12 starter (초등): 모의 점수 기록

def solve():
    scores = [1, 0, 1, 1, 0, 1]
    print(sum(scores))

if __name__ == "__main__":
    solve()
```

과제:
1. 10문항 모의에서 E/M/H 라벨을 붙이고 풀이 순서를 작성하시오.

체크포인트:
1. 과제별로 코드를 직접 실행해 결과를 확인했는가?
2. 정답과 함께 근거(판별 규칙/계산 과정)를 기록했는가?
3. 오답 가능 지점을 한 줄로 점검했는가?
### 초등 오답 패턴
- 근거를 남기지 않아 같은 실수를 다음 문제에서 반복합니다.

### 중등 연계 실습 (핸즈온)

```python
# W12 starter (중등): 오답코드 집계

def solve():
```

## 고등 트랙 (HIGH)
<!-- audience:high -->
### 고등 포인트
- 공통+고등 트랙 종합

### 고등 이론 보강
- 고난도 문항은 완전 해결보다 부분 점수 전략(핵심 근거 확보)을 병행합니다.
- 종합 모의 후 회차별 약점 분포를 수치화해 다음 학습 우선순위를 재설정합니다.

고등 판별 프레임:
1. 시간 대비 기대점수를 계산한다.
2. 고난도 문항은 제한 시간 내 중단 기준을 정한다.
3. 오답코드 통계를 다음 주 계획에 반영한다.

### 고등 연계 실습 (핸즈온)
실습 목표:
- 판별 근거를 먼저 세우고 결과를 검증합니다.

실습 문제 코드:
```python
# W12 starter (고등): 시간 배분/재풀이 계획

def solve():
    plan = {"scan": 10, "solve": 20, "challenge": 10, "review": 5}
    print(sum(plan.values()))

    retry = ["D0", "D2", "D7"]
    print(len(retry), retry[-1])

if __name__ == "__main__":
    solve()
```

과제:
1. 최근 3회 모의 오답코드 비율을 계산해 우선 보강 순위를 작성하시오.
2. 고난도 2문항에 대해 7분 제한 풀이 후 중단 기준 충족 여부를 평가하시오.

체크포인트:
1. 과제별로 코드를 직접 실행해 결과를 확인했는가?
2. 정답과 함께 근거(판별 규칙/계산 과정)를 기록했는가?
3. 오답 가능 지점을 한 줄로 점검했는가?
### 고등 오답 패턴
- 한 문항 집착으로 전체 점수 기대값을 낮춥니다.
