# Python Contest Week 01 Elementary Problem Set

## 범위
- 연산/대입/나머지
- 출력 포맷 `.format()`
- 함수 키워드(`def`, `global`)
- 반올림 `round`
- 조건식 truthy/falsy

## 문제 1
연계 개념: 개념 1) 연산/대입/나머지
다음 코드의 실행 결과로 올바른 것을 고르시오.
```python
v = -9
v %= 4
print(v)
```
⓵ -1
⓶ 0
⓷ 3
⓸ 4
⓹ 오류

⓶ define
⓷ def
⓸ func
⓹ global

## 문제 3
연계 개념: 개념 4) 반올림 `round`
다음 코드의 실행 결과로 올바른 것을 고르시오.
```python
x = 12.34
print(round(x, 1))
```
⓵ 12
⓶ 12.0
⓷ 12.3
⓸ 12.34
⓹ 12.4

## 문제 4
연계 개념: 개념 2) 출력 포맷 `.format()`
다음 코드의 실행 결과로 올바른 것을 고르시오.
(`·`는 공백)
```python
print("|{:4s}|".format("A"))
```
⓵ `|A|`
⓶ `|A··|`
⓷ `|··A|`
⓸ `|A···|`
⓹ `|···A|`
