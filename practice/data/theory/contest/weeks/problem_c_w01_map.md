# C Contest Week 01 분반 매핑표

## 목적
- `problem_c_w01_*`와 `answer_c_w01_*`의 문항 번호를 1:1로 동기화하기 위한 매핑표입니다.
- 운영 시 문항 누락/중복/번호 불일치를 빠르게 점검하기 위한 기준 문서입니다.

## 파일 대응
- 문제지(초등): `practice/data/theory/contest/weeks/problem_c_w01_elementary.md`
- 정답지(초등): `practice/data/theory/contest/weeks/answer_c_w01_elementary.md`
- 문제지(중등): `practice/data/theory/contest/weeks/problem_c_w01_middle.md`
- 정답지(중등): `practice/data/theory/contest/weeks/answer_c_w01_middle.md`
- 문제지(고등): `practice/data/theory/contest/weeks/problem_c_w01_high.md`
- 정답지(고등): `practice/data/theory/contest/weeks/answer_c_w01_high.md`

## 매핑 규칙
1. 같은 레벨에서는 문제 문항 번호와 정답 문항 번호를 동일하게 유지한다.
2. 같은 레벨 내에서는 한 문항을 중복 배치하지 않는다.
3. 원문 직접 대응이 필요한 경우 `원문 회차`와 `원문 문항`을 함께 기록한다.
4. 각 문항은 `해설` 칸에 핵심 풀이 근거를 1줄 이상 작성한다.
5. W01 핵심 주제는 `컴파일/헤더/자료형 범위`로 고정한다.

## 운영 체크
1. 각 레벨 문제 수와 정답 수가 동일한가
2. 같은 문항 번호가 문제/정답에 모두 존재하는가
3. 원문 대응이 필요한 경우 `원문 회차 + 원문 문항`이 함께 기록되었는가
4. 각 문항의 `해설` 칸이 비어 있지 않은가
5. W01 주제(컴파일/헤더/자료형 범위)가 유지되는가
