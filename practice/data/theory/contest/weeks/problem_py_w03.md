### PY_1회차
- 문항: 10, 13

#### 문제 10
10. 다음 코드의 실행 결과로 올바른 것을 고르시오. [초중]
```python
a = 88
b = 132
while b > 0:
    c = a % b
    a = b
    b = c
print(a)
```
⓵ 11
⓶ 22
⓷ 44
⓸ 66
⓹ 88

---

#### 문제 13
13. 다음 코드의 실행 결과로 올바른 것을 고르시오. [중고]
```python
n, m, k, a = 3, 10, 15, 1
while k > 0:
    if k % 2 == 1:
        a *= n
        a %= m
    n = (n * n) % m
    k //= 2
print(a)
```
⓵ 1
⓶ 3
⓷ 5
⓸ 7
⓹ 9
