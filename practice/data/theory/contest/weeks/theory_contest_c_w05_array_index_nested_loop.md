### 개념 1) 배열 인덱스 경계
- 개념 정의: 배열 접근에서 유효 범위를 벗어나지 않도록 반복 구간과 접근식을 맞추는 개념입니다.
- 핵심 내용:
  - 크기 `n` 배열의 유효 인덱스는 `0`부터 `n-1`입니다.
  - `a[i-1]`, `a[i+1]`를 함께 쓰면 보통 `i=1`부터 `i<n-1` 범위를 사용합니다.
  - 접근식과 반복 범위가 맞지 않으면 경계 오류가 발생합니다.
- 판별 규칙:
  - 먼저 접근식을 보고, 그다음 반복 시작/종료값이 안전한지 확인한다.
- 오답 포인트: 반복을 `i=0`부터 시작하면 `a[-1]` 접근이 생겨 조건식 자체가 잘못됩니다.

| 접근 형태 | 안전한 `i` 범위 | 확인 포인트 |
| --- | --- | --- |
| `a[i]`만 사용 | `0 <= i < n` | 기본 유효 인덱스 범위인지 확인 |
| `a[i-1]`, `a[i]` 사용 | `1 <= i < n` | 시작값이 1 이상인지 확인 |
| `a[i]`, `a[i+1]` 사용 | `0 <= i < n-1` | 종료값이 `n-2` 이하인지 확인 |
| `a[i-1]`, `a[i]`, `a[i+1]` 사용 | `1 <= i < n-1` | 양쪽 경계 접근이 동시에 안전한지 확인 |

![배열 인덱스 경계와 안전 반복 구간 다이어그램](./data/theory/images/contest_w05_index_boundary_window.svg)

예시 (기본):
```c
#include <stdio.h>
int main(void) {
    int a[6] = {1, 4, 2, 7, 3, 5};
    int cnt = 0;
    for (int i = 1; i < 5; i++) {
        if (a[i-1] < a[i] && a[i] > a[i+1]) cnt++;
    }
    printf("%d", cnt);
    return 0;
}
```


### 개념 2) 누적합/최댓값 추적
- 개념 정의: 조건을 만족할 때만 누적값을 갱신하거나, 기준값보다 크면 최대값을 갱신하는 개념입니다.
- 핵심 내용:
  - 누적 변수는 초기값에 따라 결과가 달라지므로 먼저 확인합니다.
  - `if`가 연속이면 같은 원소에 두 조건이 모두 적용될 수 있습니다.
  - 최댓값 갱신은 `candidate > best`일 때만 일어납니다.
- 판별 규칙:
  - 누적형과 최댓값형을 분리해서 기록하면 계산 실수가 줄어든다.
- 오답 포인트: `if ...; if ...;`를 `if ... else if ...`로 오해하면 값이 달라집니다.

| 갱신 유형 | 기본 형태 | 추적할 값 |
| --- | --- | --- |
| 누적합 | `s += value` / `s -= value` | 각 단계의 `s` 변화량과 최종값 |
| 조건 누적 | `if (cond) s += value` | `cond` 통과 여부와 반영 시점 |
| 최댓값 갱신 | `if (cand > best) best = cand` | `best`가 바뀐 단계만 표시 |
| 독립 조건 2개 | `if (c1) ...; if (c2) ...;` | 같은 원소에 두 조건이 모두 적용되는지 확인 |

![누적합과 최댓값 갱신을 함께 추적하는 다이어그램](./data/theory/images/contest_w05_accumulate_max_trace.svg)

예시 (기본):
```c
#include <stdio.h>
int main(void) {
    int a[] = {5, 2, 9, 4, 7};
    int s = 0;
    for (int i = 0; i < 5; i++) {
        if (a[i] % 2 == 1) s += a[i];
        if (a[i] % 3 == 1) s -= a[i];
    }
    printf("%d", s);
    return 0;
}
```
```io
input:
(없음)
output:
16
```

예시 (변형):
```c
#include <stdio.h>
int main(void) {
    int x[4] = {13, 8, 7, 11};
    int y[4] = {2, 15, 3, 12};
    int best = 0;
    for (int i = 0; i < 4; i++) {
        for (int j = 0; j < 4; j++) {
            int t = x[i] + y[j];
            if (t <= 16 && t > best) best = t;
        }
    }
    printf("%d", best);
    return 0;
}
```
```io
input:
(없음)
output:
16
```

예시 (함정):
```text
같은 원소가 +와 - 조건을 모두 만족할 수 있다.
따라서 두 if는 서로 독립적으로 계산해야 한다.
```

### 개념 3) 2차원 배열 순회
- 개념 정의: 2중/3중 반복문에서 인덱스 조합 전체를 순회하며 값을 누적하는 개념입니다.
- 핵심 내용:
  - 전체 조합 수는 각 루프 범위 길이의 곱으로 계산합니다.
  - 식이 분리 가능하면 항별로 나눠 계산해 검산할 수 있습니다.
  - 연산 우선순위를 유지해야 누적 결과가 맞습니다.
- 판별 규칙:
  - 중첩 반복은 기본 조합 수를 먼저 계산하고, 식을 나중에 적용한다.
- 오답 포인트: 조합 수를 한 단계 덜 곱하거나, 곱셈/덧셈 결합을 잘못하면 오답입니다.

| 점검 항목 | 계산 방법 | 빠른 검산 |
| --- | --- | --- |
| 전체 조합 수 | 각 루프 길이의 곱 | `cnt = n1 * n2 * n3` |
| 단순 누적식 | 조합마다 식 1회 더함 | 표본 1~2개 직접 대입 후 확장 |
| 항 분해 가능 식 | 항별로 분리 후 합산 | `sum(a[i])`, `sum(b[j])`, `sum(c[k])`를 분리 계산 |
| 우선순위 확인 | 곱셈 후 덧셈 적용 | `a[i] + (b[j] * c[k])` 형태 유지 |

![중첩 반복 조합 수와 항 분해 검산 다이어그램](./data/theory/images/contest_w05_nested_combination_sum.svg)

예시 (기본):
```c
#include <stdio.h>
int main(void) {
    int a[2] = {1, 2};
    int b[2] = {0, 3};
    int c[2] = {1, 4};
    int d = 0;
    for (int i = 0; i < 2; i++)
        for (int j = 0; j < 2; j++)
            for (int k = 0; k < 2; k++)
                d += a[i] + b[j] * c[k];
    printf("%d", d);
    return 0;
}
```

```io
(없음)
output:
38
```

예시 (변형):


### 중등 포인트

### 중등 연계 실습
실습 목표:
- 배열 쌍 합의 최대 조건값을 찾습니다.

실습 문제:
```c
#include <stdio.h>
int main(void) {
    int a[3] = {4, 9, 12};
    int b[3] = {1, 6, 8};
    int best = 0;
    for (int i = 0; i < 3; i++)
        for (int j = 0; j < 3; j++) {
            int t = a[i] + b[j];
            if (t <= 15 && t > best) best = t;
        }
    printf("%d", best);
    return 0;
}
```

체크포인트:
1. `t<=15` 통과/미통과를 분리 표시했는가?
2. `best` 갱신 시점만 따로 표시했는가?
