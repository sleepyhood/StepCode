### 개념 1) `while True` + `break` 종료 추적
- 한 줄 요약: 무한 루프 형태에서 실제 종료 시점과 실행 횟수를 계산하는 유형입니다.
- 암기 규칙: `break` 조건 검사가 "업데이트 전/후" 어디에 있는지 먼저 확인한다.
- 풀이 3단계: 초기값 기록 -> 조건 검사 시점 표시 -> 1회 반복 단위로 상태표를 작성한다.
- 함정 포인트: `break`를 만나는 줄까지 본문이 실행된다고 착각하면 반복 횟수를 잘못 셉니다.

| 단계 | 검사 시점 | 조건 참일 때 | 조건 거짓일 때 | 본문 실행 여부 |
| --- | --- | --- | --- | --- |
| 패턴 A | 루프 시작 직후 검사 | 즉시 `break` | 아래 본문 진행 | 거짓일 때만 실행 |
| 패턴 B | 본문 일부 실행 후 검사 | 그 시점에서 종료 | 다음 갱신 진행 | 검사 이전 코드는 실행됨 |
| 패턴 C | 카운터 증가 -> 검사 | 증가분 반영 후 종료 가능 | 누적/출력 코드 진행 | 검사 위치가 횟수를 결정 |

![while True에서 break 종료 흐름도](./data/theory/images/contest_w03_while_break_flow.svg)

**대표 예시**
```python
a = 0
i = 1
while True:
    if i > 7:
        break
    i += 2
    a += 4
print(a)
```



### 개념 2) 호제법(`a, b = b, a % b`) 종료 구조
- 한 줄 요약: `while b > 0` 형태로 최대공약수를 구하는 반복 구조를 해석하는 유형입니다.
- 암기 규칙: 매 반복에서 `(a, b)`가 `(b, a % b)`로 이동하고, `b == 0`에서 종료한다.
- 풀이 3단계: `(a, b)` 쌍을 행 단위로 기록 -> 나머지 계산 -> 다음 상태로 갱신한다.
- 함정 포인트: `a % b` 계산 전에 갱신 순서를 바꾸면 전체 흐름이 깨집니다.

| 반복 | 이전 `(a, b)` | 계산 `a % b` | 다음 `(a, b)` |
| --- | --- | --- | --- |
| 1 | `(84, 30)` | `24` | `(30, 24)` |
| 2 | `(30, 24)` | `6` | `(24, 6)` |
| 3 | `(24, 6)` | `0` | `(6, 0)` |
| 종료 | `b == 0` | - | gcd = `a` (`6`) |

![호제법 상태 전이 표](./data/theory/images/contest_w03_euclid_state_transition.svg)

**대표 예시**
```python
a = 84
b = 30
while b > 0:
    a, b = b, a % b
print(a)
```
```io
input:
(없음)
output:
6
```

**변형 예시**
```python
a = 96
b = 36
while b > 0:
    c = a % b
    a = b
    b = c
print(a)
```
```io
input:
(없음)
output:
12
```

**함정 예시**
```python

b = 12

    b = a % b
    a = b
print(a)
```
```io
input:
(없음)

0
```

### 개념 3) 반복 제곱(mod)에서 `k //= 2` 의미
- 한 줄 요약: 큰 지수를 빠르게 계산할 때 `while k > 0`로 지수를 절반씩 줄이는 구조를 해석하는 유형입니다.
- 암기 규칙: `k`가 홀수일 때만 결과 변수(`a`)에 현재 밑(`n`)을 반영한다.
- 풀이 3단계: `(n, k, a)`를 매 반복 기록 -> 홀수 분기 반영 -> `n=n*n mod m`, `k//=2` 갱신한다.
- 함정 포인트: 홀수 분기와 제곱 갱신의 순서를 바꿔 적용하면 결과가 달라집니다.

| `k` 상태 | 분기 | `a` 업데이트 | 공통 업데이트 |
| --- | --- | --- | --- |
| 홀수 (`k % 2 == 1`) | 곱 반영 필요 | `a = (a*n) % m` | `n = (n*n) % m`, `k //= 2` |
| 짝수 (`k % 2 == 0`) | 곱 반영 없음 | 그대로 유지 | `n = (n*n) % m`, `k //= 2` |
| 종료 (`k == 0`) | 루프 끝 | 최종 `a`가 결과 | 추가 갱신 없음 |

**대표 예시**
```python
n, m, k, a = 2, 7, 11, 1
while k > 0:
    if k % 2 == 1:
        a = (a * n) % m
    n = (n * n) % m
    k //= 2
print(a)
```
```io
input:
(없음)
output:
4
```

**변형 예시**
```python
n, m, k, a = 3, 10, 5, 1
while k > 0:
    if k % 2 == 1:
        a = (a * n) % m
    n = (n * n) % m
    k //= 2
print(a)
```
```io
input:
(없음)
output:
3
```

**함정 예시**
```python

        a = (a * n) % m
    n = (n * n) % m
    k //= 2
```

## 초등 트랙 (ELEMENTARY)
<!-- audience:elementary -->
### 초등 포인트
- while 추적 8문항

### 초등 이론 보강
- 매 반복에서 바뀌는 변수 2개만 먼저 기록합니다.
- `break`를 만나기 전까지 실행되는 줄을 화살표로 표시합니다.

초등 규칙 카드:
1. 종료 조건 줄을 먼저 찾는다.
2. 반복 1회 단위로 값 변화를 기록한다.
3. `break` 뒤 줄은 실행되지 않는다.

### 초등 연계 실습 (핸즈온)
실습 목표:
- 핵심 규칙을 직접 계산/표기로 확인합니다.

실습 문제 코드:
```python
# W03 starter (초등): while 종료조건 추적

def solve():
    n = 10
    cnt = 0
    while n > 0:
        n -= 3
        cnt += 1
    print(cnt, n)

if __name__ == "__main__":
    solve()
```

1. `while True` 예시에서 반복 횟수만 먼저 세어 보시오.
2. 같은 코드에서 초기값을 바꿨을 때 종료 시점이 어떻게 바뀌는지 설명하시오.

체크포인트:

## 중등 트랙 (MIDDLE)
<!-- audience:middle -->
### 중등 포인트
- while + 조건 누적

### 중등 이론 보강
- 상태표(`step, i, a`)를 작성해 누적 결과를 확인합니다.
- 분기(`if`)가 누적식에 미치는 영향을 분리해서 계산합니다.

중등 판별 루틴:
1. 종료 조건을 불리언으로 먼저 확인한다.
2. 본문 실행 줄을 순서대로 표시한다.
3. 반복 종료 직전 상태를 최종값과 비교한다.

### 중등 연계 실습 (핸즈온)
실습 목표:
- 판별 절차를 적용해 근거 중심으로 답안을 작성합니다.

실습 문제 코드:
```python
# W03 starter (중등): break 위치 영향 비교

def run(limit):
    i = 0
    s = 0
    while True:
        i += 1
        if i > limit:
            break
        s += i
    return s

def solve():
    print(run(5))

if __name__ == "__main__":
    solve()
```

과제:
1. 누적형 while 코드의 상태표를 5행 이상 작성하시오.
2. 종료 조건 연산자를 바꿨을 때(`>`, `>=`) 결과 차이를 설명하시오.

체크포인트:
1. 과제별로 코드를 직접 실행해 결과를 확인했는가?
2. 정답과 함께 근거(판별 규칙/계산 과정)를 기록했는가?
3. 오답 가능 지점을 한 줄로 점검했는가?
### 중등 오답 패턴

## 고등 트랙 (HIGH)
<!-- audience:high -->
### 고등 포인트
- while + 수학 로직(호제법)

### 고등 이론 보강
- 호제법과 반복 제곱은 "상태 전이"로 보면 빠르게 검증할 수 있습니다.
- 큰 수 계산도 mod를 중간에 적용하면 상태 크기를 제어할 수 있습니다.

고등 판별 프레임:
1. 상태 변수 집합을 정한다. (`a,b` 또는 `n,k,a`)
2. 반복 1회 전이식을 쓴다.
3. 종료 조건을 만족하는 마지막 상태를 출력값과 연결한다.

### 고등 연계 실습 (핸즈온)
실습 목표:
- 판별 근거를 먼저 세우고 결과를 검증합니다.

실습 문제 코드:
```python
# W03 starter (고등): 종료조건/불변식 점검

def gcd_like(a, b):
    while b != 0:
        a, b = b, a % b
    return a

def solve():
    print(gcd_like(84, 18))

if __name__ == "__main__":
    solve()
```

과제:
1. 호제법 코드의 상태 전이식을 일반화하시오.
2. 반복 제곱 코드에서 `k`를 2진수 관점으로 설명하시오.

체크포인트:
1. 과제별로 코드를 직접 실행해 결과를 확인했는가?
2. 정답과 함께 근거(판별 규칙/계산 과정)를 기록했는가?
3. 오답 가능 지점을 한 줄로 점검했는가?
### 고등 오답 패턴
- 수학식은 이해하지만 전이 순서를 코드 줄 순서와 다르게 적용합니다.
