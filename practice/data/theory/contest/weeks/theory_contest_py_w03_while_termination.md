### 개념 1) `while True` + `break` 종료 추적
- 개념 정의: 무한 루프 형태에서 실제 종료 시점과 실행 횟수를 계산하는 유형입니다.
- 판별 규칙: `break` 조건 검사가 "업데이트 전/후" 어디에 있는지 먼저 확인한다.
- 추적 절차: 초기값 기록 -> 조건 검사 시점 표시 -> 1회 반복 단위로 상태표를 작성한다.
- 오답 포인트: `break`를 만나는 줄까지 본문이 실행된다고 착각하면 반복 횟수를 잘못 셉니다.

![while True에서 break 종료 흐름도](./data/theory/images/contest_w03_while_break_flow.svg)

예시 (기본):
```python
a = 0
i = 1
while True:
    if i > 7:
        break
    i += 2
    a += 4
print(a)
```
```io
input:
(없음)
output:
16
```

예시 (변형):
```python
v = 1
j = 0
while True:
    if j >= 4:
        break
    j += 1
    v *= 2
print(v)
```
```io
input:
(없음)
output:
16
```

예시 (함정):
```python
x = 0
t = 0
while True:
    t += 1
    if t > 3:
        break
    x += 5
print(x)
```
```io
input:
(없음)
output:
15
```

### 개념 2) 호제법(`a, b = b, a % b`) 종료 구조
- 개념 정의: `while b > 0` 형태로 최대공약수를 구하는 반복 구조를 해석하는 유형입니다.
- 판별 규칙: 매 반복에서 `(a, b)`가 `(b, a % b)`로 이동하고, `b == 0`에서 종료한다.
- 추적 절차: `(a, b)` 쌍을 행 단위로 기록 -> 나머지 계산 -> 다음 상태로 갱신한다.
- 오답 포인트: `a % b` 계산 전에 갱신 순서를 바꾸면 전체 흐름이 깨집니다.

![호제법 상태 전이 표](./data/theory/images/contest_w03_euclid_state_transition.svg)

예시 (기본):
```python
a = 84
b = 30
while b > 0:
    a, b = b, a % b
print(a)
```
```io
input:
(없음)
output:
6
```

예시 (변형):
```python
a = 96
b = 36
while b > 0:
    c = a % b
    a = b
    b = c
print(a)
```
```io
input:
(없음)
output:
12
```

예시 (함정):
```python
a = 40
b = 12
while b > 0:
    b = a % b
    a = b
print(a)
```
```io
input:
(없음)
output:
0
```

### 개념 3) 반복 제곱(mod)에서 `k //= 2` 의미
- 개념 정의: 큰 지수를 빠르게 계산할 때 `while k > 0`로 지수를 절반씩 줄이는 구조를 해석하는 유형입니다.
- 판별 규칙: `k`가 홀수일 때만 결과 변수(`a`)에 현재 밑(`n`)을 반영한다.
- 추적 절차: `(n, k, a)`를 매 반복 기록 -> 홀수 분기 반영 -> `n=n*n mod m`, `k//=2` 갱신한다.
- 오답 포인트: 홀수 분기와 제곱 갱신의 순서를 바꿔 적용하면 결과가 달라집니다.

예시 (기본):
```python
n, m, k, a = 2, 7, 11, 1
while k > 0:
    if k % 2 == 1:
        a = (a * n) % m
    n = (n * n) % m
    k //= 2
print(a)
```
```io
input:
(없음)
output:
4
```

예시 (변형):
```python
n, m, k, a = 3, 10, 5, 1
while k > 0:
    if k % 2 == 1:
        a = (a * n) % m
    n = (n * n) % m
    k //= 2
print(a)
```
```io
input:
(없음)
output:
3
```

예시 (함정):
```python
n, m, k, a = 5, 9, 13, 1
while k > 0:
    if k % 2 == 1:
        a = (a * n) % m
    n = (n * n) % m
    k //= 2
print(a)
```
```io
input:
(없음)
output:
5
```

## 초등 트랙 (ELEMENTARY)
<!-- audience:elementary -->
### 초등 포인트
- while 추적 8문항

### 초등 이론 보강
- 매 반복에서 바뀌는 변수 2개만 먼저 기록합니다.
- `break`를 만나기 전까지 실행되는 줄을 화살표로 표시합니다.

초등 규칙 카드:
1. 종료 조건 줄을 먼저 찾는다.
2. 반복 1회 단위로 값 변화를 기록한다.
3. `break` 뒤 줄은 실행되지 않는다.

### 초등 연계 연습
1. `while True` 예시에서 반복 횟수만 먼저 세어 보시오.
2. 같은 코드에서 초기값을 바꿨을 때 종료 시점이 어떻게 바뀌는지 설명하시오.

### 초등 오답 패턴
- 조건 검사 시점(업데이트 전/후)을 구분하지 않습니다.

## 중등 트랙 (MIDDLE)
<!-- audience:middle -->
### 중등 포인트
- while + 조건 누적

### 중등 이론 보강
- 상태표(`step, i, a`)를 작성해 누적 결과를 확인합니다.
- 분기(`if`)가 누적식에 미치는 영향을 분리해서 계산합니다.

중등 판별 루틴:
1. 종료 조건을 불리언으로 먼저 확인한다.
2. 본문 실행 줄을 순서대로 표시한다.
3. 반복 종료 직전 상태를 최종값과 비교한다.

### 중등 연계 연습
1. 누적형 while 코드의 상태표를 5행 이상 작성하시오.
2. 종료 조건 연산자를 바꿨을 때(`>`, `>=`) 결과 차이를 설명하시오.

### 중등 오답 패턴
- 종료 조건은 맞게 읽지만 누적 줄 실행 횟수를 하나 적게 셉니다.

## 고등 트랙 (HIGH)
<!-- audience:high -->
### 고등 포인트
- while + 수학 로직(호제법)

### 고등 이론 보강
- 호제법과 반복 제곱은 "상태 전이"로 보면 빠르게 검증할 수 있습니다.
- 큰 수 계산도 mod를 중간에 적용하면 상태 크기를 제어할 수 있습니다.

고등 판별 프레임:
1. 상태 변수 집합을 정한다. (`a,b` 또는 `n,k,a`)
2. 반복 1회 전이식을 쓴다.
3. 종료 조건을 만족하는 마지막 상태를 출력값과 연결한다.

### 고등 연계 연습
1. 호제법 코드의 상태 전이식을 일반화하시오.
2. 반복 제곱 코드에서 `k`를 2진수 관점으로 설명하시오.

### 고등 오답 패턴
- 수학식은 이해하지만 전이 순서를 코드 줄 순서와 다르게 적용합니다.
