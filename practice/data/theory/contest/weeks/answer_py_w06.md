# Python Contest Week 06 Answer Sheet

## 작성 규칙
- 정답: 객관식은 보기 번호(예: ③), 주관식은 값/문자열/코드
- 해설 메모: 핵심 풀이 근거를 1~3줄로 작성

## PY_1회차

| 문항 | 정답 | 해설 메모 |
| --- | --- | --- |
| 19번 | ④ | 의도된 들여쓰기(내부 `for j`) 기준으로 각 단어의 연속 같은 모음 개수를 비교한다. `engineeriing`은 `ee`, `ii`로 카운트 2가 되어 최댓값이므로 출력은 `engineeriing`(④). |
| 22번 | 27 | 수정된 들여쓰기 기준으로 `<입력 1>` 결과는 18, `<입력 2>` 결과는 9가 나온다. 합은 `18+9=27`이다. |

## PY_2회차

| 문항 | 정답 | 해설 메모 |
| --- | --- | --- |
| 10번 | ② | `f(x)=x*x`, `a=4`이므로 `f(a)=16`, `f(a+1)=25`, 두 번째 값은 `16*25=400`. 출력은 `16 400`이므로 ②. |
| 20번 | append, endswith, zfill, pop | 1) 리스트 뒤 추가는 `append`, 2) 접미사 확인은 `endswith`, 3) 왼쪽 0 채우기는 `zfill`, 4) 딕셔너리의 키-값 쌍 제거는 `pop(key)`를 사용한다. |
