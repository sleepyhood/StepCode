### 개념 1) 행/열 인덱스와 경계
- 개념 정의: 2차원 배열에서 인덱스 유효 범위를 지키며 연산 대상을 정확히 선택하는 개념입니다.
- 핵심 내용:
  - 2차원 연산은 각 변수의 역할(행/열/누적축)을 먼저 고정해야 합니다.
  - 행렬 곱은 `i, j` 위치를 구할 때 `k`를 누적축으로 합산합니다.
  - 부분 구간 탐색은 시작점뿐 아니라 끝점이 경계를 넘지 않아야 합니다.
- 판별 규칙:
  - 인덱스 문항은 `변수 역할 -> 범위 -> 끝점` 순서로 확인한다.
- 오답 포인트: `i/j/k` 의미를 섞거나 경계 반복 범위를 하나라도 틀리면 결과가 크게 달라집니다.

| 항목 | 핵심 식/범위 | 검산 포인트 |
| --- | --- | --- |
| 행렬 곱 원소 | `c[i][j] = Σ(a[i][k]*b[k][j])` | `i`는 행, `j`는 열, `k`는 누적축 |
| 부분 정사각형 시작점 | `0 <= i <= n-k`, `0 <= j <= m-k` | `<=`로 마지막 시작점 포함 |
| 끝점 계산 | `(i+k-1, j+k-1)` | 끝점이 배열 경계 내인지 확인 |
| 반복 변수 역할 | `i/j/k` 역할 고정 | 변수 의미를 섞지 않기 |

![행열 인덱스 역할과 경계 범위 검산 흐름도](./data/theory/images/contest_w11_index_boundary_flow.svg)

예시 (기본):
```c
#include <stdio.h>
int main(void){
    int a[2][2]={{1,2},{3,4}};
    int b[2][2]={{2,0},{1,2}};
    int c = 0;
    for(int k=0;k<2;k++) c += a[0][k]*b[k][1];
    printf("%d", c);
    return 0;
}
```
```io
input:
(없음)
output:
4
```

예시 (변형):
```c
#include <stdio.h>
int main(void){
    int n=4,m=5,k=3,cnt=0;
    for(int i=0;i<=n-k;i++)
        for(int j=0;j<=m-k;j++)
            cnt++;
    printf("%d", cnt);
    return 0;
}
```
```io
input:
(없음)
output:
6
```

예시 (함정):
```text
for(i=0; i<n-k; i++) 처럼 '='를 빼면 마지막 시작점을 놓친다.
```

### 개념 2) 인접 방향 벡터
- 개념 정의: 격자에서 인접 칸을 방문할 때 방향 집합(4방향/8방향)을 체계적으로 적용하는 개념입니다.
- 핵심 내용:
  - 4방향은 상하좌우, 8방향은 대각선까지 포함한 탐색입니다.
  - 방향 집합을 먼저 고정하지 않으면 연결 기준이 문제마다 달라집니다.
  - 이웃 좌표는 경계 검사 후에만 확장해야 안전합니다.
- 판별 규칙:
  - 벡터 탐색은 `방향 확정 -> 경계 검사 -> 방문/값 검사 -> 확장` 순서로 처리한다.
- 오답 포인트: 방향 개수를 잘못 적용하면 연결요소 개수와 탐색 누적값이 달라집니다.

| 방향 집합 | 벡터 수 | 포함 이동 |
| --- | --- | --- |
| 4방향 | 4 | 상/하/좌/우 |
| 8방향 | 8 | 4방향 + 대각선 4개 |
| 루프 생성형(-1~1) | 9(원점 포함) | `(0,0)` 제외 처리 필요 |
| 검사 순서 | 경계 -> 값/방문 -> 확장 | 순서 고정으로 중복/오류 방지 |

![4방향과 8방향 벡터 적용 비교 도식](./data/theory/images/contest_w11_direction_vector_map.svg)

예시 (기본):
```c
#include <stdio.h>
int dx[4]={-1,1,0,0}, dy[4]={0,0,-1,1};
int main(void){
    int x=2,y=3;
    for(int t=0;t<4;t++) printf("%d,%d ", x+dx[t], y+dy[t]);
    return 0;
}
```

### 개념 3) 방문 체크와 중복 탐색 방지
- 개념 정의: 이미 처리한 칸을 다시 세지 않도록 상태를 바꾸며 탐색하는 개념입니다.
- 핵심 내용:
  - 방문 체크는 재방문 전에 해야 중복 탐색을 막을 수 있습니다.
  - 연결요소 개수는 새 시작점을 찾을 때만 증가합니다.
  - 한 요소를 모두 소거한 뒤 다음 시작점으로 넘어가야 카운트가 안정적입니다.
- 판별 규칙:
  - 연결요소 문제는 `시작점 증가 1회 + 요소 전체 소거` 패턴으로 계산한다.
- 오답 포인트: 방문 표시 시점이 늦으면 같은 요소를 여러 번 세게 됩니다.

| 단계 | 수행 동작 | 실수 방지 체크 |
| --- | --- | --- |
| 시작점 판정 | `if (grid[i][j])` 확인 | 새 요소에서만 카운트 증가 |
| 방문 표시 | 즉시 `grid[i][j]=0` 또는 `visited=1` | 재방문 전에 마킹 완료 |
| 이웃 확장 | 방향 벡터로 인접 칸 순회 | 경계/값 검사 후만 호출 |
| 요소 종료 | DFS/BFS 반환 후 다음 칸 탐색 | 같은 요소 재카운트 금지 |

![방문 체크와 중복 카운트 방지 순환 도식](./data/theory/images/contest_w11_visit_dedup_cycle.svg)

예시 (기본):
```c
#include <stdio.h>
int g[3][3]={{1,1,0},{0,1,0},{1,0,1}};
void sink(int x,int y){
    if(x<0||y<0||x>=3||y>=3) return;
    if(!g[x][y]) return;
    g[x][y]=0;
    sink(x-1,y); sink(x+1,y); sink(x,y-1); sink(x,y+1);
}
int main(void){
    int cc=0;
    for(int i=0;i<3;i++) for(int j=0;j<3;j++) if(g[i][j]){ cc++; sink(i,j); }
    printf("%d", cc);
    return 0;
}
```
```io
input:
(없음)
output:
3
```

예시 (변형):
```c

    int a[2][2]={{1,1},{1,1}}, cnt=0;
    for(int i=0;i<2;i++) for(int j=0;j<2;j++) if(a[i][j]) cnt++;
    printf("%d", cnt);

```

예시 (함정):
```text

```

### 실전 풀이 루틴 (W11 공통)

2. 탐색 방향이 4방향인지 8방향인지 먼저 고정한다.
3. 방문 표시 시점을 "재귀 호출 직전"으로 고정한다.

5. 행렬 곱/정사각형 문제는 인덱스 식을 한 줄로 검산한다.

```c
#include <stdio.h>
int g[3][3]={{1,0,1},{1,0,0},{0,1,1}};
void f(int x,int y){
  if(x<0||y<0||x>=3||y>=3||!g[x][y]) return;
  g[x][y]=0;
  f(x-1,y); f(x+1,y); f(x,y-1); f(x,y+1);
}
int main(void){
  int ans=0;
  for(int i=0;i<3;i++) for(int j=0;j<3;j++) if(g[i][j]){ ans++; f(i,j); }
  printf("%d", ans);
}
```

체크포인트:
1. 시작점 발견 시점에만 카운트했는가?
