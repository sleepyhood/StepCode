## 문제 1
연계 개념: 개념 1) 삼항 연산자 평가 순서
다음 프로그램의 실행 결과는 무엇인가?
```python
x = 12
y = 15
print(x + y if x > y else x * y)
```
⓵ 3
⓶ 12
⓷ 15
⓸ 27
⓹ 180

## 문제 2
연계 개념: 개념 1) 삼항 연산자 평가 순서
다음 프로그램의 실행 결과는 무엇인가?
```python
f = lambda x: x + 1
a = 4
print(f(a), f(a) * f(a + 1))
```
⓵ 4 16
⓶ 4 20
⓷ 4 24
⓸ 5 25
⓹ 5 30

## 문제 3
연계 개념: 개념 1) 삼항 연산자 평가 순서
다음 코드의 실행 결과로 올바른 것을 고르시오.
```python
f = lambda x: x * 2 if x % 2 == 0 else x + 1
print(f(5), f(6))
```
⓵ 5 6
⓶ 6 12
⓷ 10 7
⓸ 12 6
⓹ 6 6

## 문제 4
연계 개념: 개념 2) 람다 함수 값 추적
다음 코드의 실행 결과로 올바른 것을 고르시오.
```python
a = [3, 1, 2]
a.sort(key=lambda x: -x)
print(a)
```
⓵ [1, 2, 3]
⓶ [3, 2, 1]
⓷ [2, 1, 3]
⓸ [3, 1, 2]
⓹ [1, 3, 2]

## 문제 5
연계 개념: 개념 2) 람다 함수 값 추적
다음 코드의 실행 결과로 올바른 것을 고르시오.
```python
arr = [(2, 3), (1, 5), (2, 1)]
arr.sort(key=lambda p: (p[0], p[1]))
print(arr[0], arr[-1])
```
⓵ (1, 5) (2, 3)
⓶ (2, 1) (2, 3)
⓷ (1, 5) (2, 1)
⓸ (2, 3) (1, 5)
⓹ (2, 3) (2, 1)
