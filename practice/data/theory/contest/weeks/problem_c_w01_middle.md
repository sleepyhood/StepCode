# C Contest Week 01 Middle Problem Set

## 범위
- 표준 헤더 기능 판별
- `short` 오버플로우와 경계값
- 자료형 상수 해석
- 컴파일 단계 용어 구분

## 문제 1
연계 개념: 개념 1) 표준 헤더
다음 중 C 표준 헤더와 기능 연결이 올바르지 않은 것을 고르시오.
⓵ stdio.h: 입출력
⓶ time.h: 시간 처리
⓷ assert.h: 검증 매크로
⓸ stdarg.h: 예외 처리 전용 헤더
⓹ stddef.h: 공통 타입/매크로

## 문제 2
연계 개념: 개념 2) 오버플로우
다음 코드의 실행 결과로 올바른 것을 고르시오.
```c
#include <stdio.h>
int main() {
    short s = 32767;
    s = s + 1;
    printf("%d", s);
    return 0;
}
```
⓵ -32768
⓶ -1
⓷ 1
⓸ 32768
⓹ 오류

## 문제 3
연계 개념: 개념 2) 자료형 상수
다음 코드의 실행 결과로 올바른 것을 고르시오.
```c
#include <stdio.h>
#include <limits.h>
int main() {
    printf("%d", SHRT_MAX);
    return 0;
}
```
⓵ 127
⓶ 255
⓷ 32767
⓸ 65535
⓹ 2147483647

"고급 언어 코드를 기계가 실행 가능한 코드로 번역하는 과정"

⓸ 컴파일
