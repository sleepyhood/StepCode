# Python Contest Week 01 Answer Sheet

## 작성 규칙
- 정답: 객관식은 보기 번호(예: ③), 주관식은 값/문자열/코드
- 해설 메모: 핵심 풀이 근거를 1~3줄로 작성

## PY_1회차

| 문항 | 정답 | 해설 메모 |
| --- | --- | --- |
| 3번 | ③ | `s=-20 -> -19`, 파이썬에서 `-19 % 5`는 나머지를 양수로 맞춰 `1`이 된다. 따라서 ③. |
| 4번 | ⑤ | `A{:-7d}30{:6s}A`에서 `2023`은 폭 7로 우측 정렬되어 앞 공백 3칸, `KITPA`는 폭 6으로 앞 공백 1칸이 붙는다. 전체는 `A___202330_KITPAA` 형태. |
| 6번 | ③ | `round(a, 1)`은 소수 첫째 자리까지 반올림하므로 `87.362 -> 87.4`. 따라서 ③. |
| 7번 | ④ | `"False"`는 빈 문자열이 아니어서 참, `[]`와 `0`은 거짓, `-10`과 `3.14`는 참이므로 `1,3,5`가 붙어 `135`. 따라서 ④. |
