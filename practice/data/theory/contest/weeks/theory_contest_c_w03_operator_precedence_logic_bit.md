## 공통 이론 (COMMON)
<!-- audience:common -->
### 개념 1) 우선순위와 괄호 전략
- 개념 정의: 연산자 우선순위와 결합 방향을 기준으로 식을 단계적으로 계산하는 개념입니다.
- 판별 규칙: 괄호 -> 산술 -> 비교 -> 논리 -> 삼항 순으로 해석한다.
- 판별 규칙: `&&`가 `||`보다 먼저 계산된다.
- 판별 규칙: 삼항 `cond ? A : B`는 `cond`를 먼저 불린으로 판별한 뒤 한쪽만 계산한다.
- 추적 절차: 식 분해 -> 중간값 기록 -> 최종 출력 검산 순서로 푼다.
- 오답 포인트: 연산자 우선순위를 반대로 적용하거나 삼항 분기값을 동시에 계산하면 오답입니다.

우선순위 빠른 비교표:

| 단계 | 먼저 보는 항목 | 판단 포인트 |
| --- | --- | --- |
| 1 | 괄호 | 괄호 내부를 먼저 계산한다. |
| 2 | 산술/비교 | 숫자식을 중간값으로 줄인다. |
| 3 | 논리(`&&`, `||`) | `&&`를 `||`보다 먼저 계산한다. |
| 4 | 삼항(`?:`) | 조건 참/거짓 판정 후 한쪽 분기만 계산한다. |


![연산자 우선순위와 삼항 분기 평가 흐름 다이어그램](./data/theory/images/contest_w03_precedence_ternary_flow.svg)

### 개념 2) 논리 연산 단락 평가
- 개념 정의: 복합 조건식에서 참/거짓을 단계적으로 줄여 최종 판정을 내리는 개념입니다.
- 판별 규칙: `&&`는 하나라도 거짓이면 거짓, `||`는 하나라도 참이면 참이다.
- 판별 규칙: 단락 평가로 인해 결과가 확정되면 뒤 식은 평가되지 않을 수 있다.
- 추적 절차: 원자 조건 분리 -> 각 조건 T/F 판단 -> 결합 순서대로 합성한다.
- 오답 포인트: 윤년 조건처럼 예외(400의 배수)를 마지막에 덮어써야 하는 구조를 놓치면 오답입니다.

직관 모델:
- 기본 규칙 + 예외 규칙의 "필터"를 순서대로 통과시키는 방식으로 보면 됩니다.

형식 규칙(윤년 핵심):
- 윤년: `(y % 4 == 0 && y % 100 != 0) || (y % 400 == 0)`
- 윤년이 아닌 해: 위 식의 부정 형태

윤년 판정 체크표:

| 연도 | `%4==0` | `%100!=0` | `%400==0` | 최종 결과 |
| --- | --- | --- | --- | --- |
| 2024 | 참 | 참 | 거짓 | 윤년(1) |
| 1900 | 참 | 거짓 | 거짓 | 평년(0) |
| 2000 | 참 | 거짓 | 참 | 윤년(1) |


![윤년 논리식 필터 흐름 다이어그램](./data/theory/images/contest_w03_leap_logic_filter.svg)

예시 (기본):
```c
#include <stdio.h>
int main(void) {
    int y = 2024;
    int leap = (y % 4 == 0 && y % 100 != 0) || (y % 400 == 0);
    printf("%d", leap);
    return 0;
}
```
```io

(없음)
output:
1
```

예시 (변형):
```c
#include <stdio.h>

    int y = 1900;
    int leap = (y % 4 == 0 && y % 100 != 0) || (y % 400 == 0);
    printf("%d", leap);

}
```
```io

(없음)

```

예시 (함정):
```text

주의: 괄호를 생략해도 &&가 먼저 계산되지만, 검산 시 괄호로 명시하는 습관이 안전하다.
```

### 개념 3) 비트 연산 마스크
- 개념 정의: 비트 단위 연산(`&`, `^`) 결과를 십진수 값으로 다시 해석하는 개념입니다.
- 판별 규칙: `a & b`는 두 비트가 모두 1인 자리만 1이 된다.
- 판별 규칙: `a ^ b`는 두 비트가 다를 때 1이 된다.
- 판별 규칙: 같은 값을 XOR 두 번 하면 상쇄된다(`x ^ x = 0`).
- 추적 절차: 이진수 정렬 -> 자리별 연산 -> 필요 시 십진수 환산 순서로 푼다.
- 오답 포인트: XOR 누적에서 상쇄 규칙을 놓치면 배열 문항을 빠르게 못 풉니다.

비트 연산 핵심표:

| 연산 | 규칙 | 예시 | 결과 |
| --- | --- | --- | --- |
| `a & b` | 둘 다 1인 비트만 1 | `14 & 10` | `10` |
| `a ^ b` | 서로 다른 비트만 1 | `5 ^ 3` | `6` |
| 상쇄 | 같은 값 두 번 XOR 시 0 | `x ^ x` | `0` |


![비트 마스크와 XOR 상쇄 흐름 다이어그램](./data/theory/images/contest_w03_bitmask_xor_cancel.svg)

예시 (기본):
```c
#include <stdio.h>
int main(void) {
    int a = 14;  // 1110
    int b = 10;  // 1010
    printf("%d", a & b);
    return 0;
}
```
```io
input:
(없음)
output:
10
```

예시 (변형):
```c
#include <stdio.h>
int main(void) {
    int arr[5] = {2, 4, 2, 4, 7};
    int x = 0;
    for (int i = 0; i < 5; i++) x ^= arr[i];
    printf("%d", x);
    return 0;
}
```
```io
input:
(없음)
output:
7
```

예시 (함정):
```text
배열: 1, 3, 1, 3, 1
누적 XOR: (1^1)^(3^3)^1 = 1
```
