### 개념 1) `range` 반복 횟수 계산
- 한 줄 요약: `range(start, stop, step)`가 실제로 몇 번 도는지 판단하는 유형입니다.
- 암기 규칙: `stop`은 포함하지 않고, `step` 방향으로 도달 가능한 값만 센다.
- 풀이 3단계: 시작값 확인 -> 마지막 포함값 확인 -> 항 개수 계산한다.
- 함정 포인트: `stop` 값을 포함해서 세면 반복 횟수가 1회씩 어긋납니다.

| 형태 | start 포함 | stop 포함 | step 방향 | 값 예시 | 반복 횟수 |
| --- | --- | --- | --- | --- | --- |
| `range(n)` | `0` 포함 | `n` 미포함 | `+1` | `range(5) -> 0,1,2,3,4` | `5` |
| `range(a, b)` | `a` 포함 | `b` 미포함 | `+1` | `range(2, 6) -> 2,3,4,5` | `4` |
| `range(a, b, s)` (`s>0`) | `a` 포함 | `b` 미포함 | 증가 | `range(2,14,3) -> 2,5,8,11` | `4` |
| `range(a, b, s)` (`s<0`) | `a` 포함 | `b` 미포함 | 감소 | `range(5,0,-2) -> 5,3,1` | `3` |
| `step` 방향 불일치 | 보통 0회 | - | - | `range(1,10,-1)` | `0` |

![range 경계 시각화](./data/theory/images/contest_w02_range_boundary.svg)

```python
c = 0
for i in range(2, 14, 3):
    c += 1
print(c)
```

### 개념 2) 누적합/카운트 분리 계산
- 한 줄 요약: 반복문 안에서 더하기/빼기/카운트를 동시에 수행할 때 최종값을 계산하는 유형입니다.
- 암기 규칙: 조건마다 누적 항목을 분리해 부분합을 먼저 구한다.
- 풀이 3단계: 조건 A 합계 계산 -> 조건 B 합계 계산 -> 최종 식으로 결합한다.
- 함정 포인트: `if` 두 개가 서로 배타적이라고 착각하면 같은 원소가 두 번 반영되는 경우를 놓칩니다.

**대표 예시**
```python
v = 0
for x in [2, 3, 4, 5, 6, 7]:
    if x % 2 == 0:
        v += x
    if x % 3 == 1:
        v -= x
print(v)
```
```io
input:
(없음)
output:
5
```

**변형 예시**
```python
score = 0
for n in [1, 2, 3, 4, 5]:
    if n >= 3:
        score += 2
    if n % 2 == 1:
        score -= 1
print(score)
```
```io
input:
(없음)
output:
3
```

**함정 예시**
```python
acc = 0
for n in [1, 2, 3, 4]:
    if n % 2 == 0:
        acc += 10
    if n % 4 == 0:
        acc -= 3
print(acc)
```
```io
input:
(없음)
output:
17
```

### 개념 3) 중첩 반복의 총 실행 횟수
- 한 줄 요약: 2중 반복에서 내부 연산이 총 몇 번 실행되는지 계산하는 유형입니다.
- 암기 규칙: 바깥 반복 횟수 × 안쪽 반복 횟수로 총 실행 횟수를 계산한다.
- 풀이 3단계: 각 루프의 반복 횟수 산출 -> 곱셈으로 총 횟수 계산 -> 누적식 반영한다.
- 함정 포인트: 내부 반복 횟수를 바깥 인덱스와 혼동하면 곱셈 구조를 놓치기 쉽습니다.

| 바깥 루프 | 바깥 횟수 | 안쪽 루프 | 안쪽 횟수 | 총 실행 횟수 |
| --- | --- | --- | --- | --- |
| `for i in range(1, 9, 2)` | `4` | `for j in range(0, 6, 2)` | `3` | `4 x 3 = 12` |
| `for i in range(3)` | `3` | `for j in range(4)` | `4` | `3 x 4 = 12` |
| `for i in range(2, 11, 3)` | `3` (`2,5,8`) | `for j in range(i)` | `i`에 따라 가변 | `2+5+8=15` |

![중첩 반복 실행 횟수 격자](./data/theory/images/contest_w02_nested_count_grid.svg)

**대표 예시**
```python
a = 0
for i in range(1, 9, 2):
    for j in range(0, 6, 2):
        a += 1
print(a)
```
```io
input:
(없음)
output:
12
```

**변형 예시**
```python
s = 0
for i in range(3):
    for j in range(4):
        s += i + j
print(s)
```
```io
input:
(없음)
output:
30
```

**함정 예시**
```python
cnt = 0
for i in range(2, 11, 3):
    for j in range(i):
        cnt += 1
print(cnt)
```
```io
input:
(없음)
output:
15
```

## 초등 트랙 (ELEMENTARY)
<!-- audience:elementary -->
### 초등 포인트
- 단일 반복 결과 예측

### 초등 이론 보강
- `range`의 시작/끝/간격을 먼저 쓰고 반복 횟수를 셉니다.
- 누적 변수는 매 반복마다 어떻게 변하는지 한 줄 표로 기록합니다.

초등 규칙 카드:
1. `stop`은 포함하지 않는다.
2. 누적 변수는 "이전값 + 변화량"으로 기록한다.
3. 두 `if`는 동시에 실행될 수 있다.

### 초등 연계 연습
1. `range(1, 12, 2)`의 원소를 직접 써 보시오.
2. 누적 변수 초기값이 바뀌면 결과가 어떻게 달라지는지 설명하시오.

### 초등 오답 패턴
- 반복 횟수를 감으로 세다가 마지막 항을 잘못 포함합니다.

## 중등 트랙 (MIDDLE)
<!-- audience:middle -->
### 중등 포인트
- 반복문 상태표 작성

### 중등 이론 보강
- 조건별 부분합을 분리해 계산한 뒤 마지막에 합칩니다.
- 중첩 반복은 "루프별 횟수"를 먼저 계산하고 결과를 결합합니다.

중등 판별 루틴:
1. 반복 구간을 실제 값 목록으로 펼친다.
2. 조건 A/B 통과 집합을 분리한다.
3. 부분합을 구한 뒤 최종식을 계산한다.

### 중등 연계 연습
1. 조건이 2개인 누적 코드를 부분합 방식으로 풀이하시오.
2. 2중 반복의 총 실행 횟수를 식으로만 계산하시오.

### 중등 오답 패턴
- 조건식을 순차 실행이 아닌 `if-elif`처럼 해석합니다.

## 고등 트랙 (HIGH)
<!-- audience:high -->
### 고등 포인트
- 반복문 최적화 관점 설명

### 고등 이론 보강
- 반복 구간이 등차수열인 경우 합 공식으로 빠르게 계산할 수 있습니다.
- 중첩 반복은 곱셈 구조로 축약한 뒤 필요 시 세부 추적을 합니다.

고등 판별 프레임:
1. 반복 횟수를 수열 관점으로 계산한다.
2. 누적식을 부분합으로 분해한다.
3. 중첩 구조를 곱셈으로 축약해 검증한다.

### 고등 연계 연습
1. `range` 누적 문제를 등차수열 합으로 풀이하시오.
2. 같은 로직을 값만 바꾼 변형 문항을 직접 설계하시오.

### 고등 오답 패턴
- 계산은 맞지만 반복 횟수 산출 근거를 생략합니다.
