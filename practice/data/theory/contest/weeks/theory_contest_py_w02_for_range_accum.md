### 개념 1) `range` 반복 횟수 계산
- 개념 정의: `range(start, stop, step)`가 실제로 몇 번 반복되는지 정확히 계산하는 개념입니다.
- 핵심 내용:
  - `start`는 포함하고 `stop`은 포함하지 않습니다.
  - `step` 방향으로 도달 가능한 값만 반복됩니다.
  - `step` 방향이 구간과 맞지 않으면 반복 횟수는 0회가 될 수 있습니다.
- 오답 포인트: `stop`을 포함해서 세거나 방향을 무시하면 반복 횟수가 어긋납니다.

| 형태 | start 포함 | stop 포함 | step 방향 | 값 예시 | 반복 횟수 |
| --- | --- | --- | --- | --- | --- |
| `range(n)` | `0` 포함 | `n` 미포함 | `+1` | `range(5) -> 0,1,2,3,4` | `5` |
| `range(a, b)` | `a` 포함 | `b` 미포함 | `+1` | `range(2, 6) -> 2,3,4,5` | `4` |
| `range(a, b, s)` (`s>0`) | `a` 포함 | `b` 미포함 | 증가 | `range(2,14,3) -> 2,5,8,11` | `4` |
| `range(a, b, s)` (`s<0`) | `a` 포함 | `b` 미포함 | 감소 | `range(5,0,-2) -> 5,3,1` | `3` |
| `step` 방향 불일치 | 보통 0회 | - | - | `range(1,10,-1)` | `0` |

![range 경계 시각화](./data/theory/images/contest_w02_range_boundary.svg)

예시 (기본):
```python
c = 0
for i in range(2, 14, 3):
    c += 1
print(c)
```

### 개념 2) 누적합/카운트 분리 계산
- 개념 정의: 한 반복 안에서 여러 조건 누적이 동시에 일어날 때 항목을 분리해 계산하는 개념입니다.
- 핵심 내용:
  - 조건별 누적값을 분리하면 계산 실수를 줄일 수 있습니다.
  - `if`가 두 개면 한 원소가 두 조건을 모두 만족할 수 있습니다.
  - 최종값은 부분합을 합치거나 빼는 식으로 정리합니다.
- 오답 포인트: `if` 두 개를 `if-elif`처럼 해석하면 중복 반영을 놓칩니다.

예시 (기본):
```python
v = 0
for x in [2, 3, 4, 5, 6, 7]:
    if x % 2 == 0:
        v += x
    if x % 3 == 1:
        v -= x
print(v)
```
```io
input:
(없음)
output:
5
```

예시 (변형):
```python
score = 0
for n in [1, 2, 3, 4, 5]:
    if n >= 3:
        score += 2
    if n % 2 == 1:
        score -= 1
print(score)
```
```io
input:
(없음)
output:
3
```

예시 (함정):
```python
acc = 0
for n in [1, 2, 3, 4]:
    if n % 2 == 0:
        acc += 10
    if n % 4 == 0:
        acc -= 3
print(acc)
```
```io

(없음)
output:

```

### 개념 3) 중첩 반복의 총 실행 횟수
- 개념 정의: 중첩 반복에서 내부 연산이 총 몇 번 실행되는지 계산하는 개념입니다.
- 핵심 내용:
  - 고정 반복이면 `바깥 횟수 x 안쪽 횟수`로 계산합니다.
  - 안쪽 반복이 가변이면 바깥 값별 안쪽 횟수를 합산합니다.
  - 총 실행 횟수를 먼저 구한 뒤 누적식을 적용하면 안정적입니다.
- 오답 포인트: 안쪽 반복 횟수를 바깥 인덱스와 섞어 계산하면 총합이 틀립니다.

| 바깥 루프 | 바깥 횟수 | 안쪽 루프 | 안쪽 횟수 | 총 실행 횟수 |
| --- | --- | --- | --- | --- |
| `for i in range(1, 9, 2)` | `4` | `for j in range(0, 6, 2)` | `3` | `4 x 3 = 12` |
| `for i in range(3)` | `3` | `for j in range(4)` | `4` | `3 x 4 = 12` |
| `for i in range(2, 11, 3)` | `3` (`2,5,8`) | `for j in range(i)` | `i`에 따라 가변 | `2+5+8=15` |

![중첩 반복 실행 횟수 격자](./data/theory/images/contest_w02_nested_count_grid.svg)

예시 (기본):
```python
a = 0
for i in range(1, 9, 2):
    for j in range(0, 6, 2):
        a += 1
print(a)
```
```io
input:
(없음)
output:
12
```

예시 (변형):
```python
s = 0
for i in range(3):
    for j in range(4):
        s += i + j
print(s)
```
```io
input:
(없음)
output:
30
```

예시 (함정):
```python
cnt = 0
for i in range(2, 11, 3):
    for j in range(i):
        cnt += 1
print(cnt)
```
```io
input:
(없음)
output:
15
```

## 초등 트랙 (ELEMENTARY)

### 초등 포인트

### 초등 이론 보강
- `range`의 시작/끝/간격을 먼저 쓰고 반복 횟수를 셉니다.
- 누적 변수는 매 반복마다 어떻게 변하는지 한 줄 표로 기록합니다.

초등 규칙 카드:
1. `stop`은 포함하지 않는다.
2. 누적 변수는 "이전값 + 변화량"으로 기록한다.
3. 두 `if`는 동시에 실행될 수 있다.

### 초등 연계 실습 (핸즈온)
실습 목표:
- 핵심 규칙을 직접 계산/표기로 확인합니다.

실습 문제 코드:
```python
# W02 starter (초등): range 값/누적 확인

def solve():
    nums = list(range(1, 12, 2))
    print(nums)  # 과제 1: 값 목록 확인

    start = 0    # 과제 2: 초기값을 바꿔 결과 비교
    total = start
    for x in nums:
        total += x
    print(total)

if __name__ == "__main__":
    solve()
```

과제:
1. `range(1, 12, 2)`의 원소를 직접 써 보시오.
2. 누적 변수 초기값이 바뀌면 결과가 어떻게 달라지는지 설명하시오.

- 중첩 반복은 "루프별 횟수"를 먼저 계산하고 결과를 결합합니다.

중등 판별 루틴:

2. 조건 A/B 통과 집합을 분리한다.
3. 부분합을 구한 뒤 최종식을 계산한다.

### 중등 연계 실습 (핸즈온)
실습 목표:
- 판별 절차를 적용해 근거 중심으로 답안을 작성합니다.

실습 문제 코드:
```python
# W02 starter (중등): 조건 분리 + 부분합

def solve():
    s_all = 0
    s_a = 0
    s_b = 0
    for i in range(1, 31):
        s_all += i
        if i % 2 == 0:
            s_a += i
        if i % 3 == 0:
            s_b += i
    print(s_all, s_a, s_b)

if __name__ == "__main__":
    solve()
```

과제:
1. 조건이 2개인 누적 코드를 부분합 방식으로 풀이하시오.
2. 2중 반복의 총 실행 횟수를 식으로만 계산하시오.

## 고등 트랙 (HIGH)
<!-- audience:high -->
### 고등 포인트
- 반복문 최적화 관점 설명

### 고등 이론 보강
- 반복 구간이 등차수열인 경우 합 공식으로 빠르게 계산할 수 있습니다.
- 중첩 반복은 곱셈 구조로 축약한 뒤 필요 시 세부 추적을 합니다.

고등 판별 프레임:
1. 반복 횟수를 수열 관점으로 계산한다.
2. 누적식을 부분합으로 분해한다.
3. 중첩 구조를 곱셈으로 축약해 검증한다.

### 고등 연계 실습 (핸즈온)
실습 목표:
- 판별 근거를 먼저 세우고 결과를 검증합니다.

실습 문제 코드:
```python
# W02 starter (고등): 반복 횟수/부분합 검증

def solve():
    # 과제 1: 등차수열 합 공식과 반복 결과를 비교
    a, d, n = 4, 4, len(range(4, 25, 4))
    formula = n * (2 * a + (n - 1) * d) // 2

    loop_sum = 0
    for x in range(4, 25, 4):
        loop_sum += x

    print(n, formula, loop_sum)

if __name__ == "__main__":
    solve()
```

과제:
1. `range` 누적 문제를 등차수열 합으로 풀이하시오.
2. 같은 로직을 값만 바꾼 변형 문항을 직접 설계하시오.

체크포인트:
1. 과제별로 코드를 직접 실행해 결과를 확인했는가?
2. 정답과 함께 근거(판별 규칙/계산 과정)를 기록했는가?
3. 오답 가능 지점을 한 줄로 점검했는가?
### 고등 오답 패턴
