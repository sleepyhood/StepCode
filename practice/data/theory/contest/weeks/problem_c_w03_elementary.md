## 문제 1
연계 개념: 개념 1) 우선순위와 괄호 전략
다음 코드의 실행 결과로 올바른 것을 고르시오.

```c
#include<stdio.h>
int main()
{
    int x = 12;
    int y = 15;
    printf("%d", x>y?(x+y):(x*y));
    return 0;
}
```

⓵ 3  
⓶ 12  
⓷ 15  
⓸ 27  
⓹ 180

## 문제 3
연계 개념: 개념 2) 논리 연산 단락 평가
다음 조건식으로 빈 칸을 채울 때 올바른 것을 고르시오.

주어진 연도가 윤년이면 1, 아니면 0을 반환하는 함수를 만든다고 할 때 빈 칸에 들어갈 코드로 알맞은 것을 고르시오.

```c
int leapYear(int y) {
    if([빈 칸]) return 0;  // 빈 칸
    else return 1;
}
```

⓵ (y % 4 == 0 && y % 100 != 0) && y % 400 == 0  
⓶ (y % 4 == 0 && y % 100 != 0) || y % 400 == 0  
⓷ (y % 4 != 0 && y % 100 == 0) || y % 400 != 0  
⓸ (y % 4 != 0 || y % 100 == 0) || y % 400 != 0  
⓹ (y % 4 != 0 || y % 100 == 0) && y % 400 != 0  

## 문제 4
연계 개념: 개념 1) 우선순위와 괄호 전략, 개념 2) 논리 연산 단락 평가
다음 코드의 실행 결과로 올바른 것을 고르시오.

```c
#include <stdio.h>
int main()
{
    int a = 0;
    for(int i=2 ; i<15 ; i++) {
        if(i % 2 == 0 || i % 3 == 0 && i % 5 == 0) {
            a++;
        }
    }
    printf("%d", a);
    return 0;
}
```
① 6  ② 7  ③ 14  ④ 15  ⑤ 16

## 문제 5
연계 개념: 개념 1) 우선순위와 괄호 전략, 개념 3) 비트 연산 마스크

