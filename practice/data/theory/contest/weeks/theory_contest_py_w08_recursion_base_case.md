### 개념 1) 종료조건 우선 확인
- 한 줄 요약: 재귀 함수에서 가장 먼저 멈추는 조건을 읽고, 그때 반환값을 고정하는 유형입니다.
- 암기 규칙: 종료조건은 재귀 호출보다 앞에서 검사한다.
- 풀이 3단계: 종료조건 목록화 -> 종료 시 반환값 기록 -> 비종료 분기의 다음 인자 확인 -> 호출 깊이 추적 순으로 풀이합니다.
- 함정 포인트: 종료조건이 여러 개일 때 한 가지만 보고 나머지를 누락하면 경계값에서 오답이 됩니다.

![종료조건 우선 체크 플로우차트](./data/theory/images/contest_w08_base_case_first_flow.svg)

**대표 예시**
```python
def f(n):
    if n <= 1:
        return 1
    return n * f(n - 1)

print(f(4))
```

### 개념 2) 분할 재귀와 출력 순서
- 한 줄 요약: 구간을 반으로 나누는 재귀에서 출력이 어느 시점(호출 전/후)에 발생하는지 추적하는 유형입니다.
- 암기 규칙: `print`가 재귀 호출 앞에 있으면 전위, 뒤에 있으면 후위 순서다.
- 풀이 3단계: 현재 구간 기록 -> 중간값 계산 -> 왼쪽 호출 -> 오른쪽 호출 -> 출력 발생 시점 체크 순으로 진행합니다.
- 함정 포인트: 중간값 계산은 맞지만 출력 위치를 잘못 읽어 줄 순서를 틀리는 경우가 많습니다.

![분할 재귀 호출 트리와 출력 순서](./data/theory/images/contest_w08_divide_recursion_print_order.svg)

**대표 예시**
```python
def f(a, b):
    if a == b:
        print(a)
        return
    c = (a + b) // 2
    f(a, c)
    f(c + 1, b)

f(0, 3)
```

### 개념 3) 다중 초기값 점화식 계산
- 한 줄 요약: 여러 초기값을 갖는 재귀식 `f(n)=f(n-1)+f(n-3)` 형태를 표 계산으로 푸는 유형입니다.
- 암기 규칙: 초기값 개수만큼 먼저 채운 뒤 작은 n부터 순차 계산한다.
- 풀이 3단계: `f(0), f(1), f(2)` 기록 -> `f(3)`부터 증가 계산 -> 목표 인덱스 도달 -> 값 확정 순으로 풀이합니다.
- 함정 포인트: `f(n-2)`를 잘못 끼워 넣거나 초기값 인덱스를 한 칸 밀리게 쓰면 전체가 어긋납니다.

**대표 예시**
```python
def f(n):
    if n == 0:
        return 0
    if n == 1:
        return 1
    if n == 2:
        return 8
    return f(n - 1) + f(n - 3)

print(f(6))
```
```io
input:
(없음)
output:
25
```

**변형 예시**
```python
vals = [0, 1, 8]
for n in range(3, 7):
    vals.append(vals[n - 1] + vals[n - 3])
print(vals[6])
```
```io
input:
(없음)
output:
25
```

**함정 예시**
```python
vals = [0, 1, 8]
for n in range(3, 7):
    vals.append(vals[n - 1] + vals[n - 2])
print(vals[6])
```
```io
input:
(없음)
output:
48
```

### 개념 4) 후보 대입형 재귀 함수 비교
- 한 줄 요약: 빈칸에 들어갈 후보값을 각각 대입해 함수 결과를 비교해 최댓값을 찾는 유형입니다.
- 암기 규칙: 후보마다 독립 실행하고 이전 결과를 초기화한 뒤 비교한다.
- 풀이 3단계: 후보 리스트 준비 -> 각 후보로 함수 실행 -> 결과 기록표 작성 -> 최댓값과 보기 번호 매핑 순으로 처리합니다.
- 함정 포인트: 중간 캐시나 전역값을 초기화하지 않으면 후보 간 결과가 섞여 잘못 비교됩니다.

**대표 예시**
```python
def f(a):
    if a <= 0:
        return 0
    return (a % 5) * f(a // 5) + (a % 5)

cands = [14, 20, 26]
best = max(cands, key=f)
print(best, f(best))
```
```io
input:
(없음)
output:
26 6
```

**변형 예시**
```python
def g(a):
    if a <= 0:
        return 0
    return (a % 3) + g(a // 3)

for x in [8, 9, 10]:
    print(x, g(x))
```
```io
input:
(없음)
output:
8 4
9 1
10 2
```

**함정 예시**
```python
score = 0

def bad(a):
    global score
    if a <= 0:
        return score
    score += a % 3
    return bad(a // 3)

for x in [8, 10]:
    print(x, bad(x))
```
```io
input:
(없음)
output:
8 4
10 6
```

### 개념 5) 방문배열 재귀와 되돌리기
- 한 줄 요약: 격자/그래프 재귀에서 방문한 칸을 표시했다가 호출이 끝나면 다시 원복하는 유형입니다.
- 암기 규칙: 재귀 진입 전 `visited=1`, 복귀 직전 `visited=0`으로 되돌린다.
- 풀이 3단계: 범위 검사 -> 방문 검사 -> 목표 도달 검사 -> 방문 표시 -> 다음 칸 재귀 -> 방문 해제 순으로 진행합니다.
- 함정 포인트: 방문 해제를 빼먹으면 다른 경로 탐색이 막혀 경우의 수가 과소 계산됩니다.

**대표 예시**
```python
def f(x, y, v):
    if x < 0 or y < 0 or x >= 2 or y >= 2:
        return 0
    if v[x][y]:
        return 0
    if x == 1 and y == 1:
        return 1
    v[x][y] = 1
    k = f(x + 1, y, v) + f(x, y + 1, v)
    v[x][y] = 0
    return k

print(f(0, 0, [[0, 0], [0, 0]]))
```
```io
input:
(없음)
output:
2
```

**변형 예시**

## 초등 트랙 (ELEMENTARY)
<!-- audience:elementary -->
### 초등 포인트
- 재귀 호출 순서 그림화

### 초등 이론 보강
- 호출 트리를 깊이 2~3 단계까지만 그려 종료 시점을 눈으로 확인합니다.
- 기저 사례에 도달했을 때 바로 반환되는 값을 먼저 쓰고 나머지를 계산합니다.

초등 규칙 카드:
1. 종료조건을 먼저 읽는다.
2. 한 번의 호출에서 다음 호출 인자를 적는다.
3. 출력은 `print` 위치 기준으로 순서를 정한다.

### 초등 연계 연습
1. `f(a,b)` 구간 분할 재귀에서 `f(0,3)` 출력 순서를 적으시오.
2. 종료조건 2개가 있는 재귀를 만들고 각 조건의 반환값을 쓰시오.

### 초등 오답 패턴
- 종료조건을 읽지 않고 점화식만 계산해 불필요한 복잡도를 만듭니다.

## 중등 트랙 (MIDDLE)
<!-- audience:middle -->
### 중등 포인트
- 재귀 초기값 변형 문제

### 중등 이론 보강
- 다중 초기값 점화식을 표 계산(반복문)으로 병행해 검산합니다.
- 후보 대입형 문항에서 결과표를 작성해 최댓값 선택 실수를 줄입니다.

중등 판별 루틴:
1. 초기값과 종료조건을 먼저 고정한다.
2. 재귀식의 참조 인덱스를 확인한다.
3. 후보별 결과를 표로 비교한다.

### 중등 연계 연습
1. 초기값을 바꿨을 때 `f(8)` 값이 어떻게 변하는지 비교하시오.
2. 후보 4개를 함수에 대입해 최댓값 후보를 고르는 표를 작성하시오.

### 중등 오답 패턴
- 초기값 인덱스를 한 칸 밀려 적어 이후 계산이 모두 어긋납니다.

## 고등 트랙 (HIGH)
<!-- audience:high -->
### 고등 포인트
- 백트래킹 경로 수 계산

### 고등 이론 보강
- 방문표시/해제 구조를 템플릿화해 격자 재귀 문제에 재사용합니다.
- 동일 재귀 호출이 중복되는 코드에서 실제 유효 경로만 분리해 계산합니다.

고등 판별 프레임:
1. 경계/방문/목표 검사를 순서대로 고정한다.
2. 재귀 분기별 기여도를 분리한다.
3. 복귀 시 방문 해제를 확인한다.

### 고등 연계 연습
1. 3x3 격자에서 이동 규칙을 바꿔 경로 수 변화를 비교하시오.
2. 중복 호출이 있는 재귀 코드를 항별로 분해해 계산 근거를 제시하시오.

### 고등 오답 패턴
- 방문 해제를 생략해 경로 수를 과소 계산합니다.
