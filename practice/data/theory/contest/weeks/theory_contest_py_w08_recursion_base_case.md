### 개념 1) 종료조건 우선 확인
- 개념 정의: 재귀에서 멈추는 조건과 반환값을 먼저 고정해 호출 흐름을 안정화하는 개념입니다.
- 핵심 내용:
  - 종료조건은 재귀 호출보다 앞에서 검사해야 합니다.
  - 종료조건이 여러 개면 각각의 반환값을 분리해 확인해야 합니다.
  - 비종료 분기의 다음 인자 변화가 종료 도달 여부를 결정합니다.
- 오답 포인트: 종료조건 일부를 누락하면 경계 입력에서 무한 재귀나 오답이 발생합니다.

### 개념 2) 분할 재귀와 출력 순서
- 개념 정의: 구간 분할 재귀에서 출력문 위치에 따라 출력 순서가 달라지는 구조를 해석하는 개념입니다.
- 핵심 내용:
  - 출력 위치(호출 전/후)가 순서를 결정합니다.
  - 왼쪽/오른쪽 호출 순서가 바뀌면 전체 출력 순서도 바뀝니다.
  - 중간값 계산과 출력 시점을 분리해 추적해야 정확합니다.
- 오답 포인트: 출력 시점을 호출 순서와 섞어 읽으면 줄 순서가 틀립니다.

### 개념 3) 다중 초기값 점화식 계산
- 개념 정의: 다중 초기값 재귀식을 표 계산으로 변환해 값을 구하는 개념입니다.
- 핵심 내용:
  - 초기값 개수만큼 먼저 채운 뒤 작은 인덱스부터 순서대로 계산합니다.
  - 참조 인덱스(`n-1`, `n-3`)를 정확히 유지해야 합니다.
  - 재귀와 반복 표 계산을 함께 사용하면 검산이 쉬워집니다.
- 오답 포인트: 참조 인덱스나 초기값 위치가 한 칸만 어긋나도 전체 결과가 달라집니다.

예시 (기본):
```python
def f(n):
    if n == 0:
        return 0
    if n == 1:
        return 1
    if n == 2:
        return 8
    return f(n - 1) + f(n - 3)

print(f(6))
```
```io
input:
(없음)
output:
25
```

예시 (변형):
```python
vals = [0, 1, 8]
for n in range(3, 7):
    vals.append(vals[n - 1] + vals[n - 3])
print(vals[6])
```
```io

(없음)
output:
25
```

예시 (함정):

### 개념 4) 후보 대입형 재귀 함수 비교
- 개념 정의: 후보값별 재귀 결과를 독립적으로 계산해 최댓값/최솟값을 선택하는 개념입니다.
- 핵심 내용:
  - 후보마다 실행 상태를 독립적으로 유지해야 공정 비교가 됩니다.
  - 비교 전 초기화 여부를 먼저 확인해야 합니다.
  - 결과표로 정리하면 선택 실수를 줄일 수 있습니다.
- 오답 포인트: 전역값/캐시를 재사용하면 후보 결과가 섞여 비교가 무효가 됩니다.

예시 (기본):
```python
def f(a):
    if a <= 0:
        return 0
    return (a % 5) * f(a // 5) + (a % 5)

cands = [14, 20, 26]
best = max(cands, key=f)
print(best, f(best))
```
```io
input:
(없음)
output:
26 6
```

예시 (변형):
```python
def g(a):
    if a <= 0:
        return 0
    return (a % 3) + g(a // 3)

for x in [8, 9, 10]:
    print(x, g(x))
```
```io
input:
(없음)
output:

9 1
10 2
```

예시 (함정):
```python
score = 0

def bad(a):
    global score
    if a <= 0:
        return score
    score += a % 3
    return bad(a // 3)

    print(x, bad(x))
```

### 개념 5) 방문배열 재귀와 되돌리기
- 개념 정의: 격자/그래프 재귀에서 방문 표시와 방문 해제를 짝으로 관리하는 백트래킹 개념입니다.
- 핵심 내용:
  - 진입 시 방문 표시, 복귀 직전 방문 해제를 짝으로 둡니다.
  - 검사 순서는 보통 경계 -> 방문 -> 목표 순으로 고정합니다.
  - 방문 해제가 있어야 다른 경로 탐색이 가능합니다.
- 오답 포인트: 방문 해제를 생략하면 경로 수가 과소 계산됩니다.

예시 (기본):
```python
def f(x, y, v):
    if x < 0 or y < 0 or x >= 2 or y >= 2:
        return 0
    if v[x][y]:
        return 0
    if x == 1 and y == 1:
        return 1
    v[x][y] = 1
    k = f(x + 1, y, v) + f(x, y + 1, v)
    v[x][y] = 0
    return k

print(f(0, 0, [[0, 0], [0, 0]]))
```
```io
input:
(없음)
output:
2
```

예시 (변형):

## 초등 트랙 (ELEMENTARY)
<!-- audience:elementary -->
### 초등 포인트
- 재귀 호출 순서 그림화

### 초등 이론 보강
- 호출 트리를 깊이 2~3 단계까지만 그려 종료 시점을 눈으로 확인합니다.
- 기저 사례에 도달했을 때 바로 반환되는 값을 먼저 쓰고 나머지를 계산합니다.

초등 규칙 카드:
1. 종료조건을 먼저 읽는다.
2. 한 번의 호출에서 다음 호출 인자를 적는다.
3. 출력은 `print` 위치 기준으로 순서를 정한다.

### 초등 연계 실습 (핸즈온)
실습 목표:
- 핵심 규칙을 직접 계산/표기로 확인합니다.

실습 문제 코드:
```python
# W08 starter (초등): 재귀 종료조건 확인

def fact(n):
    if n <= 1:
        return 1
    return n * fact(n - 1)

def solve():
    print(fact(5))

if __name__ == "__main__":
    solve()
```

2. 종료조건 2개가 있는 재귀를 만들고 각 조건의 반환값을 쓰시오.

### 고등 이론 보강

고등 판별 프레임:

2. 재귀 분기별 기여도를 분리한다.
3. 복귀 시 방문 해제를 확인한다.

### 고등 연계 실습 (핸즈온)
실습 목표:
- 판별 근거를 먼저 세우고 결과를 검증합니다.

실습 문제 코드:
```python
# W08 starter (고등): 백트래킹 기본 골격

ans = []
used = [False] * 4

def bt(path):
    if len(path) == 3:
        ans.append(path[:])
        return
    for i in range(1, 4):
        if used[i]:
            continue
        used[i] = True
        path.append(i)
        bt(path)
        path.pop()
        used[i] = False

def solve():
    bt([])
    print(len(ans))

if __name__ == "__main__":
    solve()
```

과제:
1. 3x3 격자에서 이동 규칙을 바꿔 경로 수 변화를 비교하시오.
2. 중복 호출이 있는 재귀 코드를 항별로 분해해 계산 근거를 제시하시오.

체크포인트:
1. 과제별로 코드를 직접 실행해 결과를 확인했는가?
2. 정답과 함께 근거(판별 규칙/계산 과정)를 기록했는가?
3. 오답 가능 지점을 한 줄로 점검했는가?
