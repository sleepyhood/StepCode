## 범위
- 리스트 인덱싱

- pop/remove 기초

## 문제 1
다음 코드의 실행 결과로 올바른 것을 고르시오.
```python
a = [6, 1, 5, 0, 2, 3, 4]
for i in range(5):
    b = i
    for j in range(1, 30):
        b = a[b]
    print(b, end=' ')
```
⓵ 3 1 4 5 6
⓶ 6 2 3 4 1
⓷ 1 0 4 5 2
⓸ 5 0 2 3 1
⓹ 4 2 1 5 3

## 문제 3
다음 코드의 실행 결과로 올바른 것을 고르시오.
```python
a = [1, 2, 3, 4]
a.insert(2, 9)
print(a)
```
⓵ [1, 2, 3, 4, 9]
⓶ [1, 9, 2, 3, 4]
⓷ [1, 2, 9, 3, 4]
⓸ [9, 1, 2, 3, 4]
⓹ [1, 2, 3, 9, 4]

## 문제 4
다음 코드의 실행 결과로 올바른 것을 고르시오.
```python
a = [10, 20, 30, 40]
a.pop(1)
print(a)
```
⓵ [10, 20, 30]
⓶ [10, 30, 40]
⓷ [20, 30, 40]
⓸ [10, 40]
⓹ 오류
