## 매핑 규칙
1. 같은 레벨에서는 문제 문항 번호와 정답 문항 번호를 동일하게 유지한다.
2. 같은 레벨 내에서는 한 문항을 중복 배치하지 않는다.
3. 원문 직접 대응이 필요한 경우 원문 회차와 원문 문항을 함께 기록한다.
4. 각 문항은 해설 칸에 핵심 풀이 근거를 1줄 이상 작성한다.
5. W09 개념 1~3 범위를 벗어나는 문항은 비고에 이유를 명시한다.

1. 각 레벨 문제 수와 정답 수가 동일한가

5. W09 개념 1~3과 문항 연계가 일치하는가
