### 개념 1) 기저 조건 설정
- 개념 정의: 재귀가 멈추는 조건과 그때 반환할 값을 정확히 고정하는 개념입니다.
- 핵심 내용:
  - 기저 조건이 없으면 재귀가 끝나지 않을 수 있습니다.
  - 기저 조건의 반환값은 전체 계산의 출발점이 됩니다.
  - `a==1`, `a<=1`, `a==0`처럼 조건이 조금만 달라도 결과가 달라집니다.
- 판별 규칙:
  - 재귀 문제는 먼저 \"어디서 멈추는지\"를 확정하고 계산한다.
- 오답 포인트: `a<=1`, `a==1`, `a==0`의 차이를 무시하면 결과가 달라집니다.

| 기저 조건 형태 | 멈추는 입력 범위 | 반환값 영향 |
| --- | --- | --- |
| `if (a == 0)` | 정확히 0에서만 종료 | 0 도달 시 기준값 고정 |
| `if (a == 1)` | 정확히 1에서만 종료 | 0 입력 경로와 분리됨 |
| `if (a <= 1)` | 1 이하 전체에서 종료 | 음수/0 입력도 즉시 종료 |
| `if (a < 1)` | 0 이하에서 종료 | 1에서 한 단계 더 진행 |

![재귀 기저 조건과 종료 시점 다이어그램](./data/theory/images/contest_w08_base_condition_stop.svg)

예시 (기본):
```c
#include <stdio.h>
int f(int n){
    if(n==0) return 1;
    return f(n-1)+2;
}
int main(void){ printf("%d", f(3)); }
```
```io
input:
(없음)
output:
7
```

예시 (변형):
```c
#include <stdio.h>
int g(int n){
    if(n<=1) return 1;
    return g(n-2)*2;
}
int main(void){ printf("%d", g(5)); }
```
```io
input:
(없음)
output:
4
```

예시 (함정):
```text
if (a == 1) 과 if (a <= 1) 은 음수/0 입력에서 호출 경로가 달라진다.
```

### 개념 2) 호출-복귀 순서
- 개념 정의: 재귀 호출이 내려가는 순서와 반환이 올라오는 순서의 계산 시점을 분리하는 개념입니다.
- 핵심 내용:
  - 재귀는 먼저 하강(호출)하고, 그다음 복귀(반환)합니다.
  - 호출문 앞 연산과 호출문 뒤 연산은 실행 시점이 다릅니다.
  - 출력문이 호출 뒤에 있으면 복귀 순서로 출력되어 역순이 될 수 있습니다.
- 판별 규칙:
  - 식에 호출 앞/뒤 연산이 섞이면 하강 단계와 복귀 단계를 나눠서 본다.
- 오답 포인트: 호출 중 계산과 복귀 중 계산을 섞어 계산하면 값이 어긋납니다.

| 코드 위치 | 실행 시점 | 추적 메모 |
| --- | --- | --- |
| 재귀 호출 전 연산 | 하강 단계 | 호출마다 즉시 적용 |
| 재귀 호출문 | 하강 단계 | 기저 도달까지 반복 |
| `return f(...)+b`의 `+b` | 복귀 단계 | 프레임마다 1회 적용 |
| 호출 뒤 `printf` | 복귀 단계 | 역순 출력 가능성 확인 |

![분할 재귀 호출 트리와 리프 출력 순서 다이어그램](./data/theory/images/contest_w08_recursive_call_tree_leaf_order.svg)

예시 (기본):
```c
#include <stdio.h>
void p(int n){
    if(n>0) p(n-1);
    printf("%d ", n);
}
int main(void){ p(3); }
```
```io
input:
(없음)
output:
0 1 2 3
```

예시 (변형):
```c
#include <stdio.h>
int f(int a,int b){
    if(a<=0) return b;
    return f(a-2,b*2)+b;
}
int main(void){ printf("%d", f(6,1)); }
```
```io
input:
(없음)
output:
15
```

예시 (함정):
```text
return f(...)+b 에서 +b 는 복귀 단계마다 적용된다.
```

### 개념 3) 재귀-반복 치환 검산
- 개념 정의: 재귀 식을 반복/표 방식으로 바꿔 계산을 검증하는 개념입니다.
- 핵심 내용:
  - 자리수 분해 재귀는 while 반복으로 바꿔도 같은 결과가 나옵니다.
  - 점화 재귀는 작은 값부터 표를 채우면 계산이 안정적입니다.
  - 두 방법을 함께 쓰면 계산 실수를 줄일 수 있습니다.
- 판별 규칙:
  - 재귀 결과가 헷갈리면 반복식이나 표 계산으로 한 번 더 검산한다.
- 오답 포인트: 분기 재귀에서 같은 하위 문제를 누락하면 최종값이 작게 나옵니다.

| 검산 방식 | 적용 대상 | 확인 절차 |
| --- | --- | --- |
| 호출 체인 전개 | 단일 재귀(`f(n-1)`) | 기저까지 내려가며 반환 합산 |
| DP 표 채우기 | 점화 재귀(`f(n-1)+f(n-k)`) | `f(0)`부터 목표 n까지 순차 계산 |
| while 치환 | 자리수/나눗셈 재귀 | 재귀식과 반복식 결과 대조 |
| 샘플 입력 2개 비교 | 전 유형 공통 | 경계 입력 포함해 일치 확인 |

![재귀식과 반복식 교차 검산 다이어그램](./data/theory/images/contest_w08_recursion_iteration_check.svg)

예시 (기본):
```c
#include <stdio.h>
int sumd(int a){
    if(a==0) return 0;
    return sumd(a/10)+a%10;
}
int main(void){ printf("%d", sumd(512)); }
```
```io
input:
(없음)
output:
8
```

예시 (변형):
```c
#include <stdio.h>
int f(int n){
    if(n==0) return 1;
    if(n==1) return 4;
    if(n==2) return 9;
    return f(n-1)+f(n-3);
}
int main(void){ printf("%d", f(6)); }
```
```io
input:
(없음)
output:
30
```

예시 (함정):
```text
f(n-1)+f(n-3) 는 직전 항 하나만 보는 점화가 아니다.
```

## 중등 트랙 (MIDDLE)
<!-- audience:middle -->
### 중등 포인트
- 분기 재귀를 표로 환산해 누락 없이 계산합니다.

### 중등 연계 실습
실습 목표:
- 점화 재귀를 작은 n부터 채워 계산합니다.

실습 문제:
```c
#include <stdio.h>
int f(int n){
  if(n==0) return 1;
  if(n==1) return 3;
  return f(n-1)+f(n-2);
}
int main(void){ printf("%d", f(5)); }
```

체크포인트:
1. f(0)부터 f(5)까지 표를 작성했는가?
2. 각 항 계산 근거를 이전 항으로 설명했는가?
