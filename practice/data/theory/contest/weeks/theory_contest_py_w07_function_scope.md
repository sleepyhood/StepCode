### 개념 1) 함수 선언/전역 선언 키워드
- 한 줄 요약: 함수를 만들 때와 함수 내부에서 전역 변수를 수정할 때 사용하는 문법을 구분하는 유형입니다.
- 암기 규칙: 함수 정의는 `def`, 함수 내부 전역 수정 선언은 `global`이다.
- 풀이 3단계: 함수 헤더 확인 -> 내부에서 값 대입 여부 확인 -> 전역 선언 필요 여부 판단 순으로 진행합니다.
- 함정 포인트: `func`, `static`, `local` 같은 유사 단어를 문법 키워드로 착각하면 오답이 됩니다.

| 키워드 | 쓰는 위치 | 필요 상황 | 영향 범위 | 비고 |
| --- | --- | --- | --- | --- |
| `def` | 함수 정의 줄 | 함수를 선언할 때 | 함수 객체 생성 | 필수 문법 |
| `global x` | 함수 내부 | 전역 변수 `x`를 대입/증감할 때 | 전역 `x` 직접 변경 | 읽기만 할 때는 불필요 |
| `nonlocal x` | 중첩 함수 내부 | 바로 바깥 함수의 `x` 수정 시 | 바깥 함수 스코프 변경 | 중첩 함수에서만 사용 |

**대표 예시**
```python

def f():
    global a
    a += 5

f()
print(a)
```

### 개념 2) 지역/전역 스코프 충돌 추적
- 한 줄 요약: 같은 이름의 변수가 함수 안팎에 있을 때 실제 참조 대상을 판별하는 유형입니다.
- 암기 규칙: 함수 내부에서 대입이 발생하면 기본적으로 지역 변수로 취급한다.
- 풀이 3단계: 변수 이름 수집 -> 함수 내부 대입 유무 확인 -> 읽기/쓰기 스코프 분리 -> 출력 위치별 값 확정 순으로 추적합니다.
- 함정 포인트: 대입이 있는데 `global` 선언이 없으면 외부 값이 바뀐다고 오해하기 쉽습니다.

### 개념 3) 재귀 호출 횟수 누적(`a += 1`)
- 한 줄 요약: 재귀 함수 진입 시마다 카운터를 증가시키고 종료 조건까지 몇 번 호출되는지 계산하는 유형입니다.
- 암기 규칙: `a += 1`이 함수 첫 부분에 있으면 현재 호출도 횟수에 포함된다.
- 풀이 3단계: 시작값 기록 -> 매 단계에서 `a` 증가 -> 다음 인자 계산 -> 종료 조건 `x == 1` 도달 시 누적 횟수 확정 순으로 풀이합니다.
- 함정 포인트: 종료 호출(마지막 `x==1`)을 카운트에서 빼면 1 작게 계산됩니다.

![재귀 호출 스택과 호출 횟수 카운트](./data/theory/images/contest_w07_recursive_call_stack_counter.svg)

**대표 예시**
```python
a = 0

def f(x):
    global a
    a += 1
    if x == 1:
        return
    f(x - 1)

f(4)
print(a)
```
```io

(없음)

4
```

### 개념 4) 짝수/홀수 분기와 `x & 1 == 0`
- 한 줄 요약: 비트 연산으로 홀짝을 판정해 재귀 분기 경로를 선택하는 유형입니다.
- 암기 규칙: `x & 1 == 0`은 `(x & 1) == 0`으로 해석하며, 참이면 짝수다.
- 풀이 3단계: 현재 `x`의 최하위 비트 확인 -> 짝수/홀수 분기 선택 -> 다음 `x` 생성 -> 호출 경로 표 작성 순으로 진행합니다.
- 함정 포인트: 비교 우선순위를 잘못 이해하면 분기식을 다른 의미로 오해할 수 있습니다.

| 판별식 | 의미 | 짝수 예 (`x=10`) | 홀수 예 (`x=7`) | 장단점 |
| --- | --- | --- | --- | --- |
| `x % 2 == 0` | 2로 나눈 나머지 검사 | `True` | `False` | 가장 직관적 |
| `(x & 1) == 0` | 최하위 비트 검사 | `True` (`1010 & 1 = 0`) | `False` (`0111 & 1 = 1`) | 비트 관점 학습에 유리 |
| `x % 2` / `x & 1` | 홀짝 코드(0/1) | `0` | `1` | 조건식에 바로 사용 가능 |

**대표 예시**
```python
for x in [4, 7, 10]:
    if x & 1 == 0:
        print("E")
    else:
        print("O")
```

### 개념 5) 호출 경로 길이 비교 전략
- 한 줄 요약: 여러 시작값 중 재귀 경로가 가장 긴 후보를 선택하는 유형입니다.
- 암기 규칙: 동일 함수/규칙에서는 각 후보의 `a` 값을 독립적으로 측정해 최대값을 비교한다.
- 풀이 3단계: 후보별 초기화 -> 함수 실행 -> 호출 횟수 기록 -> 최댓값 비교 -> 대응 보기 번호 선택 순으로 처리합니다.
- 함정 포인트: 후보를 연속 실행하면서 `a`를 초기화하지 않으면 비교가 무효가 됩니다.

**대표 예시**
```python
def steps(n):
    c = 0
    while n != 1:
        c += 1
        if n % 2 == 0:
            n //= 2
        else:
            n = 3 * n + 1
    return c + 1

cands = [3, 5, 7]
best = max(cands, key=steps)
print(best)
```
```io
input:
(없음)
output:
7
```

**변형 예시**
```python
def chain_len(n):
    cnt = 1
    while n != 1:
        cnt += 1
        if n % 2 == 0:
            n //= 2
        else:
            n = 3 * n + 1
    return cnt

print(chain_len(9))
print(chain_len(11))
```
```io
input:
(없음)
output:
20
15
```

**함정 예시**
```python
a = 0

def f(x):
    global a
    a += 1
    if x == 1:
        return
    f(x - 1)

for n in [3, 4]:
    f(n)
print(a)
```
```io
input:
(없음)
output:

```

## 고등 트랙 (HIGH)

### 고등 이론 보강

### 고등 연계 실습 (핸즈온)
