### PY_1회차
- 문항: 9

#### 문제 9
9. 다음 코드의 실행 결과로 올바른 것을 고르시오. [초]
```python
p = 5
for i in range(3, 35, 2):
    p += 2
print(p)
```
⓵ 35
⓶ 36
⓷ 37
⓸ 38
⓹ 39

### PY_2회차
- 문항: 1, 2

#### 문제 1
1. 다음 프로그램의 실행 결과는 무엇인가? [고]
```python
a = 0
for i in range(100, 2024, 150):
    a += i
print(a)
```
⓵ 11500
⓶ 12000
⓷ 12500
⓸ 13000
⓹ 13500

---

#### 문제 2
2. 다음 프로그램의 실행 결과는 무엇인가? [초]
```python
b = 0
for i in [1, 2, 3, 4, 5, 6, 7]:
    if i % 2 == 1:
        b += i
    if i % 3 == 1:
        b -= i
print(b)
```
⓵ -9
⓶ -4
⓷ 0
⓸ 4
⓹ 9

### PY_3회차
