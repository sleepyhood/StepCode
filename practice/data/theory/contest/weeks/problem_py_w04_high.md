# Python Contest Week 04 High Problem Set

## 범위
- 인덱스 전이 추적
- 리스트 조작 연산 결합

## 문제 1
연계 개념: 개념 1) 리스트 메서드 기능 구분
다음 코드의 실행 결과로 올바른 것을 고르시오.
```python
a = [6, 1, 5, 0, 2, 3, 4]
for i in range(5):
    b = i
    for j in range(1, 30):
        b = a[b]
    print(b, end=' ')
```
⓵ 3 1 4 5 6
⓶ 6 2 3 4 1
⓷ 1 0 4 5 2
⓸ 5 0 2 3 1
⓹ 4 2 1 5 3

## 문제 2
연계 개념: 개념 2) 반복 인덱싱 상태 전이 (`b = a[b]`), 개념 3) 순환(cycle) 길이와 반복 횟수 관계
다음 코드의 실행 결과로 올바른 것을 고르시오.
```python
a = [9, 8, 7, 6, 5]
a.insert(2, 4)
a.remove(8)
a.pop(3)
print(a)
```
⓵ [9, 4, 7, 5]
⓶ [9, 7, 4, 5]
⓷ [9, 4, 6, 5]
⓸ [9, 4, 7, 6]
⓹ [9, 7, 6, 5]

## 문제 3
연계 개념: 개념 1) 리스트 메서드 기능 구분

⓸ [5, 7, 9, 11]

## 문제 4
연계 개념: 개념 3) 순환(cycle) 길이와 반복 횟수 관계
다음 코드의 실행 결과로 올바른 것을 고르시오.
```python
a = [0, 1, 2, 3, 4]
for i in range(3):
    a.insert(i, a.pop())
print(a)
```
⓵ [4, 3, 2, 0, 1]
⓶ [2, 3, 4, 0, 1]
⓷ [4, 2, 3, 0, 1]
⓸ [3, 4, 2, 0, 1]
⓹ [2, 4, 3, 0, 1]
