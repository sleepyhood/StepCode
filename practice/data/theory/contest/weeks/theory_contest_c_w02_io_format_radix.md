### 개념 1) `printf` 폭(width)·정렬·정밀도
- 개념 정의: 실수 출력에서 폭/정렬/정밀도와 리터럴 문자가 최종 문자열을 어떻게 바꾸는지 판단하는 개념입니다.
- 핵심 내용:
  - `%w.pf`에서 `w`는 전체 폭, `p`는 소수점 이하 자리수입니다.
  - `-`가 있으면 왼쪽 정렬, 없으면 오른쪽 정렬입니다.
  - 서식 뒤에 붙은 문자(예: `00`)는 숫자 포맷과 별개로 그대로 출력됩니다.
- 판별 규칙:
  - 폭은 "최소 너비"이므로 값이 더 길면 잘리지 않고 그대로 출력된다.
- 오답 포인트: 리터럴 문자를 무시하거나, 폭을 "숫자 길이 제한"으로 오해하면 틀립니다.

빠른 비교표:

| 요소 | 의미 | 예시 | 출력 영향 |
| --- | --- | --- | --- |
| `w` (폭) | 최소 전체 너비 | `%7.2f` | 자리 부족분을 공백으로 채움 |
| `p` (정밀도) | 소수점 이하 자리수 | `%.2f` | 반올림 후 소수점 자리 고정 |
| `-` (정렬) | 좌측 정렬 지정 | `%-7.2f` | 공백이 오른쪽에 붙음 |
| 리터럴 문자 | 서식 뒤 고정 출력 | `%6.2f00` | `00`이 그대로 출력됨 |

![printf 폭 정렬 정밀도 조립 흐름 다이어그램](./data/theory/images/contest_w02_printf_width_precision_flow.svg)

예시 (기본):
```c
#include <stdio.h>
int main(void) {
    printf("[%7.2f]", 3.14);
    return 0;
}
```
```io
input:
(없음)
output:
[   3.14]
```

예시 (변형):
```c
#include <stdio.h>
int main(void) {
    printf("[%-7.2fEND]", 3.14);
    return 0;
}
```
```io
input:
(없음)
output:
[3.14   END]
```

예시 (함정):
```c
#include <stdio.h>
int main(void) {
    printf("[%6.2f00]", 3.14);
    return 0;
}
```
```io
input:
(없음)
output:
[  3.1400]
```

### 개념 2) 진법 리터럴(`0x`, `0`) 해석
- 개념 정의: 정수 상수의 표기 형태를 10진수 값으로 변환해 계산하는 개념입니다.
- 핵심 내용:
  - `0x`/`0X`로 시작하면 16진수입니다.
  - 앞자리 `0`만 있고 `x`가 없으면 8진수입니다.
  - 계산 전에 먼저 10진수로 바꾸면 실수가 줄어듭니다.
- 판별 규칙:
  - 접두사가 다르면 같은 숫자 모양이어도 값이 달라진다.
- 오답 포인트: `030`을 30으로 읽거나 `0x32`를 32로 읽으면 오답입니다.

직관 모델:
- 숫자 앞 접두사는 "읽는 규칙"을 바꾸는 태그입니다.

형식 규칙:
- `0x32 = 3*16 + 2 = 50`
- `030 = 3*8 + 0 = 24`

접두사 변환표:

| 표기 | 해석 규칙 | 예시 | 10진 변환 |
| --- | --- | --- | --- |
| `0x...` / `0X...` | 16진수 | `0x1F` | `31` |
| `0...` (x 없음) | 8진수 | `021` | `17` |
| 접두사 없음 | 10진수 | `30` | `30` |

![진법 리터럴 접두사 판별과 10진 변환 흐름 다이어그램](./data/theory/images/contest_w02_radix_literal_conversion.svg)

예시 (기본):
```c
#include <stdio.h>
int main(void) {
    int a = 0x1F;
    int b = 021;
    printf("%d", a + b);
    return 0;
}
```
```io
input:
(없음)
output:
48
```

예시 (변형):
```c
#include <stdio.h>
int main(void) {
    int x = 0x20;   // 32
    int y = 010;    // 8
    printf("%d", x - y);
    return 0;
}
```
```io
input:
(없음)
output:
24
```

예시 (함정):
```text
식: 0x12 + 012
해석: 18 + 10 = 28
```

### 개념 3) `scanf` 공백/개행 처리
- 개념 정의: 연속 입력에서 버퍼에 남은 공백/개행이 다음 서식으로 넘어가는 동작을 판단하는 개념입니다.
- 핵심 내용:
  - `%d`는 앞 공백을 건너뛰고 숫자만 읽습니다.
  - `%c`는 공백도 문자로 읽어서, 직전 개행(`\n`)을 먼저 읽을 수 있습니다.
  - `" %c"`처럼 앞에 공백을 넣으면 남은 공백/개행을 먼저 버리고 다음 문자를 읽습니다.
- 판별 규칙:
  - `%d` 뒤에 바로 `%c`가 나오면 버퍼에 남은 개행이 들어올 가능성을 먼저 확인한다.
- 오답 포인트: `%c`도 자동으로 공백을 건너뛴다고 가정하면 틀립니다.

버퍼 소비 비교표:

| 서식 | 공백/개행 처리 | 대표 결과 |
| --- | --- | --- |
| `scanf("%d", &n)` | 앞 공백을 건너뛰고 정수 토큰만 소비 | 정수 입력 후 개행이 버퍼에 남을 수 있음 |
| `scanf("%c", &ch)` | 공백도 문자로 그대로 읽음 | 남은 `\n`을 먼저 읽을 수 있음 |
| `scanf(" %c", &ch)` | 앞 공백/개행을 먼저 소비한 뒤 문자 읽음 | 실제 다음 문자(`A` 등)를 읽음 |

![scanf에서 버퍼 공백 개행이 소비되는 흐름 다이어그램](./data/theory/images/contest_w02_scanf_buffer_flow.svg)

예시 (기본):
```c
#include <stdio.h>
int main(void) {
    int n;
    char ch;
    scanf("%d", &n);
    scanf("%c", &ch);
    printf("%d", ch);
    return 0;
}
```
```io
input:
7
A
output:
10
```

예시 (변형):
```c
#include <stdio.h>
int main(void) {
    int n;
    char ch;
    scanf("%d", &n);
    scanf(" %c", &ch);
    printf("%c", ch);
    return 0;
}
```
```io
input:
7
A
output:
A
```

예시 (함정):
```text
입력: 12_B  (_는 공백)
서식: "%d%c"
결과: 정수=12, 문자=' ' (공백)
```

### 실전 풀이 루틴 (W02 공통)
1. 문항이 서식 비교형/진법 계산형/입력 버퍼형 중 무엇인지 먼저 분류한다.
2. 진법 계산형이면 접두사부터 변환하고 연산한다.
3. 서식 비교형이면 폭, 정렬, 정밀도, 리터럴 문자 순서로 분해한다.
4. 입력 버퍼형이면 각 `scanf` 직후 버퍼 상태를 한 줄로 기록한다.
5. 마지막에 출력 타입(`%d`, `%c`, `%f`)을 확인해 최종 검산한다.
