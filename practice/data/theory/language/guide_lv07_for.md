# for

## 공통 원칙 (언어 무관)

### 리뉴얼 목표
1. “정답 맞히기”보다 **반복 흐름과 상태 변화 이해**를 우선한다.
2. Python/C를 **동일한 문항 유형**으로 구성하고, 언어별 차이는 문법만 바꾼다.
3. MCQ는 보조로 최소화하고, 핵심 검증은 `Trace(Grid)`, `Reverse`, `Short`, `Code`로 수행한다.

### 학습 개념(필수)
1. for문의 흐름: 초기화 → 조건 확인 → 본문 → 증감.
2. 종료 직후 값(조건이 깨진 순간의 변수 값).
3. 누적 변수(`sum`, `count`)의 초기화/갱신 위치.
4. 반복문 안 조건문(if)으로 분기되는 상태 변화.
5. step/증감식이 반복 횟수와 출력에 주는 영향.
6. 입력과 반복의 결합(`n`개 처리, 인덱스/입력값 구분).

### 문항 구성 규칙
1. 세트당 `Trace(Grid)` 2문항.
2. 세트당 `Reverse` 1문항.
3. 세트당 `Short` 1문항.
4. 세트당 `Code` 1문항 이상.
5. 세트당 `MCQ` 0~1문항(찍기 불가 비교형만).
6. 반복/추적형 문제는 가능하면 `grid` 사용, 시점은 “각 반복 직후”로 명시.

### Code 문항 고정 규칙 (for 단원)
1. `Code` 문항은 가능한 한 **한 줄 작성**으로 출제한다.
2. 초보자 혼란을 줄이기 위해 제어문 전체 한 줄 압축은 지양한다.
   - 지양: `if (...) sum += i;`
3. 제어문이 필요한 경우는 골격을 주고 한 요소만 쓰게 한다.
   - 예: `for ( ____ )` 헤더 작성
   - 예: `if ( ____ )` 조건식 작성
4. 한 문항에서 한 기능만 검증한다.
   - 입력 한 줄 / 출력 한 줄 / 누적 한 줄 / 조건식 한 줄

### 언어별 변환 규칙
1. **유형/의도/정답 논리 동일**: 같은 세트 번호(b01~c01)는 같은 사고를 검증한다.
2. **문법만 변경**:
   - C: `for (int i = ...; ...; ...)`, `scanf/printf`
   - Python: `for i in range(...)`, `input/print`
3. 출력 형식/줄바꿈/경계 조건은 두 언어에서 같은 의미로 맞춘다.

## 세트 골격 (공통 템플릿)

### b01 (기초)
1. Trace(Grid): 기본 반복 흐름(`i`, `output`).
2. Trace(Grid): 누적 합(`i`, `sum`).
3. Short: 종료 직후 반복 변수 값.
4. Reverse: 출력 패턴으로 끝값/횟수 추론.
5. Code: 기본 반복문 한 줄 또는 본문 한 줄 작성.

### b02 (기초)
1. Trace(Grid): step 변화(증가/감소).
2. Trace(Grid): 중간 상태 복원(예: 3회 반복 직후).
3. Reverse: 시작값/step 추론.
4. Short: 경계 조건(<, <=) 비교.
5. Code: `if` 조건식 한 줄 작성(본문은 골격 제공).

### b03 (기초)
1. Trace(Grid): 입력 포함 반복(`i`, `num`, `count/sum`).
2. Trace(Grid): 조건 누적(짝수/양수 등).
3. Reverse: 최종 `count/sum`으로 입력/조건 만족 횟수 추론.
4. Short: 종료 직후 `i` 또는 누적 변수 값.
5. Code: `if` 조건식 한 줄 작성(누적 본문은 골격 제공).

### b04 (기초)
1. Trace(Grid): 입력 위치와 누적 순서 확인.
2. Trace(Grid): 경계값(0 포함 여부, <= vs <) 비교.
3. Reverse: 최종 결과로 `n` 또는 조건 역추론.
4. Short: step 방향/종료 조건 판단.
5. Code: 루프 안 입력/갱신 위치 작성.

### c01 (챌린지)
1. Trace(Grid): 조건 2개 이상 결합.
2. Reverse: 출력/최종 상태에서 초기값/범위 추론.
3. Trace(Grid): 중간 상태 복원(필요 시 break/continue 포함).
4. Code: 복합 조건식 한 줄 작성(`if` 골격 제공).
5. Short: 종료 직후 값 + 분기 횟수 요약.

## C / Python 매핑 가이드

- 위 공통 골격을 `c_lv07_for_b01~c01`에 그대로 적용한다.
- 코드 예시는 `for (...)`, `printf`, `scanf` 기준으로 작성한다.

### Python
- 위 공통 골격을 `py_lv07_for_b01~c01`에 그대로 적용한다.
- 코드 예시는 `range(...)`, `input`, `print` 기준으로 작성한다.

## 체크리스트
1. 같은 번호 세트(b01, b02...)가 언어별로 **동형 문제 구조**인지 확인.
2. 세트마다 `Code` 문항이 최소 1개 포함됐는지 확인.
3. `Trace/Reverse` 문항에서 grid가 필요한 경우 누락이 없는지 확인.
4. Reverse가 단순 숫자 맞히기가 아니라 상태/흐름 추론을 요구하는지 확인.
5. MCQ는 보조용이며, 없거나 1개인지 확인.
