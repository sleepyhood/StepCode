# Canva 기반 MD 가이드 목차 (스켈레톤)

## 트랙 정의
- 이 트랙은 `문제지 없이 md 중심`으로 운영한다.
- 성격: 개념 정리, 흐름 시각화, 빠른 체크.
- 분류: `언어 수업`, `유니티 수업`, `경시대회 수업`과 별도.

## 운영 원칙
1. 각 단원은 `핵심 개념 + 시각 자료 + 미니 체크` 3축으로 구성한다.
2. Canva는 제작 도구로만 쓰고, 최종 산출물은 저장소에 이미지/문서로 보관한다.
3. 단원마다 템플릿을 동일하게 유지해 학습 밀도를 일정하게 맞춘다.

## 목차
1. OT: Canva 기반 학습법과 문서 읽는 법
2. 시각화 규칙: 흐름도/표/요약 카드 기준
3. 배열/반복 추적 읽기
4. 조건/분기 추적 읽기
5. 함수 호출 흐름 읽기
6. 디버깅 관찰 포인트 정리
7. 실수 패턴 모음(오답 중심)
8. 시험 전 1페이지 요약 만드는 법
