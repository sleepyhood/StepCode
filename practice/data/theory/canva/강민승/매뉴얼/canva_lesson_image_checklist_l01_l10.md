# Canva 회차별 필수 이미지 체크리스트 (L01~L10)

## 목적
- 90분 수업에서 데모와 실습이 멈추지 않도록, 차시별 필수 이미지 자산을 사전 준비한다.
- 이론 문서(`theory_canva_lXX.md`)와 과제지(`student_assignment_lXX.md`)를 이미지 기준으로 연결한다.

## 공통 규칙
- 저장 경로: `practice/data/theory/images/`
- 파일명 규칙: `canva_lXX_<category>_<index>.png` 또는 `.svg`
- 권장 규격:
  - SNS: `1080x1080`, `1080x1920`
  - 썸네일: `1280x720`
  - 슬라이드: `1920x1080`
- 권장 최소 세트(매 차시 공통):
  - 데모용 원본 4개
  - 강사용 정답 예시 2개
  - 학생 실습 시작 템플릿 2개
  - 전/후 비교 샘플 2개

## 차시 시작 전 점검
1. 필수 이미지 파일명이 규칙(`canva_lXX_*`)을 지키는가
2. 수업 PC와 학생 PC에서 이미지가 모두 열리는가
3. 라이선스/출처 확인이 끝난 자산만 포함했는가
4. 실습 난이도별(쉬움/보통/도전) 템플릿이 각각 있는가

## 운영 팁
- 데모용과 학생 배포용을 분리해서 준비한다.
- 전/후 비교 이미지는 같은 구도와 주제로 짝을 맞춘다.
- 수업 종료 후 우수 결과물을 다음 차시 데모 자산으로 재사용한다.
