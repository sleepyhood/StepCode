# Canva 3권 통합 목차 및 수업 구성안

## 문서 목적
- 3권의 내용을 중복 없이 재구성해 `수업용 목차`로 통합한다.
- 1회 90분 수업 기준으로, 수업 후 숙제가 가능한 운영안을 함께 제시한다.

## 통합 목차 (3권 기반)
## Module 1. 시작과 작업 환경
1. Canva 개요, 계정/요금제, 저작권과 라이선스
2. 홈 화면 구조, 템플릿 탐색, 폴더 관리
3. 에디터 구조, 기본 툴바, 파일/공유 메뉴

## Module 2. 디자인 기본기
1. 텍스트/요소/배경/색상 기본 편집
2. 레이어, 정렬, 그룹화, 가이드라인
3. 페이지 관리, 스타일 복사, 기본 애니메이션

## Module 3. Canva AI 핵심
1. Visual Suite와 Magic Studio 이해
2. Magic Switch, Magic Write, Magic Design
3. Magic Media, 사진 편집 AI(Eraser/Edit/Expand)

## Module 4. 채널별 콘텐츠 제작
1. 인스타그램: 피드/스토리/릴스 디자인
2. 블로그/유튜브: 썸네일, 배너, 카드뉴스
3. 쇼핑몰/인쇄물: 상세페이지, 명함, 브로슈어

## Module 5. 영상/발표/웹
1. 영상 컷 편집, 전환/타이밍, 오디오 편집
2. 프레젠테이션(목차, 연혁, 차트, 후기 페이지)
3. Canva 웹사이트 제작 및 배포

## Module 6. 운영/브랜딩/수익화
1. 브랜드 키트, 비주얼 시스템, 템플릿 체계
2. 콘텐츠 플래너, Sheets, Bulk Create 자동화
3. 수익화 파이프라인(템플릿/외주/POD/교육)

## 90분 수업 운영 틀 (권장)
1. 0~10분: 지난 숙제 리뷰 + 오늘 결과물 기준 안내
2. 10~25분: 핵심 개념 데모(강사 라이브 편집)
3. 25~70분: 실습(개별 제작 + 중간 피드백 2회)
4. 70~85분: 결과 공유, 수정 포인트 체크
5. 85~90분: 숙제 브리핑(제출 규격, 마감, 평가 기준)

## 차시별 구성 (총 10차시, 차시당 90분)
## 1차시. Canva 시작 + 저작권/라이선스
- 수업: 계정/요금제/라이선스, 홈/에디터 구조, 템플릿 시작법
- 산출물: 자기소개 카드 1장 + 공용 템플릿 1개 리디자인
- 숙제: 동일 주제로 정사각형/세로형 2가지 버전 제작

## 2차시. 디자인 기본 편집
- 수업: 텍스트/요소/배경/색상, 정렬/그룹화, 가이드라인
- 산출물: 브랜드 무드 카드 2장
- 숙제: 같은 레이아웃으로 색상 3안 비교본 제출

## 3차시. 레이어와 페이지 운영
- 수업: 레이어 구조, 페이지 복제/이동, 일관성 유지
- 산출물: 4페이지 카드뉴스 초안
- 숙제: 카드뉴스를 6페이지로 확장 + 표지/마지막 페이지 개선

## 4차시. Canva AI 1
- 수업: Magic Switch/Write/Design, 프롬프트 작성 원칙
- 산출물: AI 초안 2종 + 수동 개선본 1종
- 숙제: 동일 주제로 AI 초안과 수동본 차이 리포트(짧은 메모)

## 5차시. Canva AI 2 + 이미지 편집
- 수업: Magic Media, Eraser/Edit/Expand, 이미지 보정
- 산출물: 전/후 비교 이미지 3세트
- 숙제: 개인 프로젝트용 핵심 비주얼 5개 제작

## 6차시. SNS 콘텐츠 실전
- 수업: 인스타 피드/스토리/릴스 구성, CTA 설계
- 산출물: 피드 2장 + 스토리 2장 + 릴스 커버 1장
- 숙제: 주간 업로드용 콘텐츠 묶음(최소 5개)

## 7차시. 유튜브/블로그/썸네일
- 수업: 썸네일 가독성, 배너 구성, 카드뉴스 적용
- 산출물: 썸네일 2안 + 배너 1안
- 숙제: 실제 업로드 가능한 썸네일 패키지 3개

## 8차시. 영상 편집 + 프레젠테이션
- 수업: 컷 편집, 전환/속도/타이밍, 오디오, 발표 슬라이드
- 산출물: 20~40초 홍보 영상 1개 + 6p 발표 자료
- 숙제: 영상 자막/오디오 보정 후 최종본 제출

## 9차시. 웹/브랜드/자동화
- 수업: Canva 웹사이트, 브랜드 키트, 플래너/Sheets/Bulk Create
- 산출물: 랜딩페이지 1개 + 브랜드 키트 초안
- 숙제: 동일 브랜드로 포스트 10개 대량 생성 실습

## 10차시. 수익화/포트폴리오 완성
- 수업: 템플릿 판매/외주/POD/강의형 수익화, 가격 전략
- 산출물: 포트폴리오 보드 1개 + 상품/서비스 제안서 1장
- 숙제: 최종 포트폴리오 패키지 제출(표지/작품/가격/소개)

## 평가 및 숙제 운영 기준
1. 매 차시 숙제는 `실제 게시/납품 가능한 결과물` 기준으로 낸다.
2. 제출 규격 예시: PNG 1080x1080, PDF, Canva 공유 링크.
3. 평가지표 4개를 고정한다: 가독성, 일관성, 목적 적합성, 완성도.
4. 숙제는 다음 차시 시작 10분 리뷰에 반드시 재활용한다.

## 3권 매핑 기준 (요약)
- 1권: AI/수익화/브랜딩/생산성 축을 담당
- 2권: 기능 실습(요소, 편집, 영상, 고급 기능) 축을 담당
- 3권: 채널별 실전 과제(인스타/블로그/유튜브/쇼핑몰/인쇄물) 축을 담당
