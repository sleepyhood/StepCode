# Canva 5차시 학생 과제지


## 연계 이론
- [theory_canva_l05.md](./theory_canva_l05.md)

## 오늘 목표
1. 이미지 생성/보정/확장의 차이를 이해하고 적용할 수 있다.
2. 전/후 비교가 가능한 편집 세트를 만들 수 있다.
3. 개인 프로젝트에 쓸 핵심 비주얼을 확보할 수 있다.

## 준비물
- 편집할 원본 이미지 3장 이상
- 주제 키워드 5개
- 브랜드 톤(예: 밝음/차분함/프리미엄) 1개

## 90분 수업 활동
1. 0~10분: 숙제 리뷰
- AI 초안과 수동 개선본 차이 피드백

2. 10~25분: 핵심 데모
- Magic Media로 비주얼 초안 생성
- Magic Eraser/Edit/Expand 실제 적용
- 보정 시 과편집 방지 기준 설명

3. 25~55분: 실습 A (개인)
- 미션: 전/후 비교 3세트 제작
- 세트 구성:
  - Set 1: 불필요 요소 제거(Eraser)
  - Set 2: 오브젝트 교체/추가(Edit)
  - Set 3: 배경/프레임 확장(Expand)

4. 55~70분: 실습 B (개인)
- 미션: 개인 프로젝트용 핵심 비주얼 2개 완성
- 조건:
  - 서로 다른 용도(썸네일/피드 등)
  - 동일 브랜드 톤 유지

5. 70~85분: 결과 공유
- 편집 전/후 비교와 의도 설명

6. 85~90분: 숙제 안내

## 수업 내 제출물
1. 전/후 비교 3세트
2. 프로젝트용 핵심 비주얼 2개

## 숙제
## 과제명: 핵심 비주얼 패키지 제작
1. 개인 프로젝트 주제로 핵심 비주얼 5개를 제작한다.
2. 최소 2개는 AI 편집 기능(Eraser/Edit/Expand) 사용 근거를 남긴다.
3. 각 비주얼 용도(피드/배너/썸네일 등)를 표기한다.

## 숙제 제출 형식
- 파일: `이름_l05_v01.png` ~ `이름_l05_v05.png`
- 설명: `이름_l05_usage.md` (각 이미지 용도 1줄 + 편집 이유 1줄)
- Canva 공유 링크 1개

## 평가 기준 (10점)
1. 편집 정확성(3점): 전/후 품질이 자연스럽고 목적에 맞는가
2. 활용성(3점): 실제 콘텐츠에 바로 사용 가능한가
3. 톤 일관성(2점): 5개 비주얼의 스타일이 통일되는가
4. 제출 정확성(2점): 파일/설명/링크가 완비됐는가

## 체크리스트
- 편집 흔적이 부자연스럽지 않은가
- 용도별 크기/구성이 맞는가
- 브랜드 톤이 유지되는가
- 5개 모두 목적이 명확한가
