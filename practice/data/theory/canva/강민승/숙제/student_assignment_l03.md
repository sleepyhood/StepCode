# Canva 3차시 학생 과제지


## 연계 이론
- [theory_canva_l03.md](./theory_canva_l03.md)

## 오늘 목표
1. 레이어 순서와 잠금/숨김을 사용해 편집 충돌을 줄일 수 있다.
2. 4~6페이지 콘텐츠를 일관된 스타일로 구성할 수 있다.
3. 표지-본문-마무리 흐름이 있는 카드뉴스를 완성할 수 있다.

## 준비물
- 2차시 결과물(색상안 포함)
- 카드뉴스 주제 1개(예: 공지, 안내, 튜토리얼, 홍보)
- 핵심 문장 6개 이상

## 90분 수업 활동
1. 0~10분: 숙제 리뷰
- 색상안 비교에서 가독성 우수 사례 공유

2. 10~25분: 핵심 데모
- 레이어 잠금/해제, 전후 배치
- 페이지 복제/이동/삭제
- 공통 컴포넌트(제목 바, 페이지 번호, CTA) 재사용

3. 25~55분: 실습 A (개인)
- 미션: 4페이지 카드뉴스 초안 제작
- 필수 구조:
  - p1: 표지(주제 + 핵심 한 줄)
  - p2~p3: 본문(핵심 정보 2개 이상)
  - p4: 마무리(요약 + 행동 유도 문구)

4. 55~70분: 실습 B (개인)
- 미션: 4페이지를 6페이지로 확장
- 조건:
  - p5: 사례 또는 부가 정보
  - p6: Q&A 또는 체크리스트
  - 페이지 간 시각 톤 일관성 유지

5. 70~85분: 결과 공유
- 발표 내용:
  - 레이어를 어떻게 관리했는지
  - 페이지 확장 시 무엇을 추가했는지

6. 85~90분: 숙제 안내

## 수업 내 제출물
1. 4페이지 카드뉴스 초안
2. 6페이지 확장본

## 숙제
## 과제명: 카드뉴스 최종 패키지 완성
1. 오늘 만든 6페이지 카드뉴스를 최종 보정한다.
2. 아래 2개 버전을 제출한다.
- 버전 A: 정보 전달 중심
- 버전 B: 감성 표현 중심
3. 각 버전에 대해 "개선한 점 3가지"를 작성한다.

## 숙제 제출 형식
- 파일: `이름_l03_info.pdf`, `이름_l03_emotion.pdf`
- 설명: `이름_l03_revision.md` (버전별 3줄 이상)
- Canva 공유 링크 1개

## 평가 기준 (10점)
1. 페이지 흐름(3점): 표지-본문-마무리 연결이 자연스러운가
2. 일관성(3점): 폰트/색/정렬/요소 규칙이 유지되는가
3. 확장 완성도(2점): 6페이지 확장이 억지 없이 읽히는가
4. 개선 기록(2점): 수정 근거를 명확히 설명했는가

## 체크리스트
- 표지에서 주제가 즉시 이해되는가
- 본문 페이지에 정보 과밀이 없는가
- 마지막 페이지에 행동 유도 문구가 있는가
- 버전 A/B가 의도 차이를 보여주는가
