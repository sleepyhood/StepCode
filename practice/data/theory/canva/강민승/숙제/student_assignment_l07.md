# Canva 7차시 학생 과제지


## 연계 이론
- [theory_canva_l07.md](./theory_canva_l07.md)

## 오늘 목표
1. 썸네일 가독성과 클릭 유도 요소를 적용할 수 있다.
2. 배너와 썸네일의 역할 차이를 설명할 수 있다.
3. 실제 업로드 가능한 썸네일 패키지를 완성할 수 있다.

## 준비물
- 6차시 콘텐츠 결과물
- 유튜브/블로그 주제 1개
- 핵심 키워드 5개

## 90분 수업 활동
1. 0~10분: 숙제 리뷰
- 주간 콘텐츠 패키지 흐름 점검

2. 10~25분: 핵심 데모
- 썸네일: 제목 길이, 강조 포인트, 시선 흐름
- 배너: 채널 정체성/업로드 주기 정보 배치
- 카드뉴스 내용을 썸네일로 압축하는 방법

3. 25~55분: 실습 A (개인)
- 미션: 썸네일 2안 제작
- 조건:
  - 같은 주제, 다른 디자인 컨셉
  - 제목 12자 내외 버전 1개 포함
  - 인물/오브젝트 강조 포인트 1개 이상

4. 55~70분: 실습 B (개인)
- 미션: 배너 1안 제작
- 조건:
  - 채널명 + 핵심 주제 + CTA 포함
  - 모바일 잘림 영역 고려

5. 70~85분: 결과 공유
- A/B 썸네일 중 선택 근거 발표

6. 85~90분: 숙제 안내

## 수업 내 제출물
1. 썸네일 2안
2. 배너 1안

## 숙제
## 과제명: 업로드 가능 썸네일 패키지
1. 실제 업로드 가능한 썸네일 3개를 제작한다.
2. 각 썸네일의 타깃/주제/CTA를 1줄씩 작성한다.
3. 선택 썸네일 1개에 대해 배너와 스타일을 맞춘 버전을 추가 제작한다.

## 숙제 제출 형식
- 파일: `이름_l07_thumb01.png` ~ `이름_l07_thumb03.png`, `이름_l07_banner.png`
- 설명: `이름_l07_strategy.md` (썸네일별 2줄 이상)
- Canva 공유 링크 1개

## 평가 기준 (10점)
1. 가독성(3점): 작은 화면에서도 제목이 읽히는가
2. 클릭 유도력(3점): 핵심 포인트가 즉시 눈에 띄는가
3. 브랜드 일관성(2점): 배너/썸네일 톤이 통일되는가
4. 제출 정확성(2점): 파일/설명/링크가 완비됐는가

## 체크리스트
- 제목이 과도하게 길지 않은가
- 시선이 핵심 요소로 자연스럽게 이동하는가
- 배너에서 채널 정보가 분명한가
- 썸네일 3개가 서로 목적을 가지는가
