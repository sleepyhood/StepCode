# Canva 3권 통합 커리큘럼 (목차 기반 보강안)

## 문서 목적
- 이미지 기준 목차(Chapter 1~7, Lesson 단위)를 우선 반영해 수업용 커리큘럼으로 재구성한다.
- 모든 차시는 `90분(1시간 30분)`으로 고정하며, 차시 내 완료 가능한 산출물을 반드시 만든다.
- 별도 과제(숙제)와 발표형 수업 없이, `수업 내 제작 중심`으로 운영한다.

## 90분 수업 운영 틀 (공통)
1. 0~10분: 차시 목표와 산출물 기준 확인
2. 10~25분: 핵심 기능 데모
3. 25~80분: 실습 제작(중간 피드백 2회)
4. 80~90분: 산출물 마감 및 체크리스트 검수

## 차시별 구성 (총 8차시, 차시당 90분)

### 1차시. CH01-L1~L6 캔바 첫 세팅 완성 (분량 보강)
- 수업 내용: 캔바 개요, 저작권/사용권, 요금제 판단, 계정 설정, 홈/에디터 핵심 동선
- 진행 포인트: 개념 설명보다 `즉시 적용` 중심으로 온보딩 완료
- 산출물: 개인 작업공간 세팅본(폴더/브랜드 기본값) + 저작권 체크 카드 1장 + 템플릿 리디자인 1종

### 2차시. CH02-L1~L4 디자인 시작과 텍스트 구조
- 수업 내용: 작업영역 조작, 도구 구조, 텍스트 계층/가독성 설계
- 산출물: 텍스트 중심 카드뉴스 3페이지

### 3차시. CH02-L5~L9 요소/색상/레이어/페이지/공유
- 수업 내용: 요소 조합, 배경/색상 시스템, 정렬/그룹화, 페이지 운영, 내보내기
- 산출물: 5페이지 콘텐츠 세트 + 공유 링크/PNG 납품본

### 4차시. CH03-L1~L5 AI 창작 워크플로 통합
- 수업 내용: Visual Suite, Magic Studio, 직업 맞춤 AI 전략
- 산출물: 동일 주제 AI 초안 2종 + 개선본 1종 + 직무별 AI 활용 플로우 1장

### 5차시. CH04-L1~L4 업종 실전 디자인 1
- 수업 내용: 실전 원칙, 베이커리/필라테스/동물병원 케이스 적용
- 산출물: 업종별 SNS 패키지 6종(피드 3, 스토리 3)

### 6차시. CH04-L5~L7 + CH05-L1~L3 업종 실전 디자인 2 + 수익화 기초
- 수업 내용: 강사 상세페이지, 기업 문서형 디자인, 자산화, 판매/외주 구조
- 산출물: 상세페이지 1종 + 기업용 제안 슬라이드 5페이지 + 판매용 템플릿 1종

### 7차시. CH05-L4~L7 + CH06-L1~L3 수익화 고도화 + 브랜드 기초
- 수업 내용: POD/교육형 상품/가격 전략, 브랜드 정체성/비주얼 시스템
- 산출물: 서비스 가격표 1장 + 브랜드 키트 1세트

### 8차시. CH06-L4~L6 + CH07-L1~L6 포트폴리오와 생산성 자동화
- 수업 내용: 웹 포트폴리오, 채널 운영, 플래너/시트/Bulk/차트/인사이트/뉴스레터/AI 루틴
- 산출물: 웹 포트폴리오 랜딩 1페이지 + 자동 발행용 콘텐츠 DB 1세트

## 산출물 운영 기준
1. 모든 차시는 수업 종료 전 산출물 제출을 완료한다.
2. 제출 형식은 Canva 링크 + 내보내기 파일(PNG/PDF/MP4 중 해당 형식)로 통일한다.
3. 평가지표는 `가독성`, `일관성`, `목적 적합성`, `완성도` 4개로 고정한다.

## 3권 매핑 기준 (요약)
- 1권: AI 활용, 수익화, 브랜딩, 생산성 파트 중심
- 2권: 편집 기능, 디자인 기본기, 실전 제작 기능 중심
- 3권: 업종별/채널별 실무 적용 과제 중심
