# Canva 9차시 학생 과제지


## 연계 이론
- [theory_canva_l09.md](./theory_canva_l09.md)

## 오늘 목표
1. 기본 랜딩페이지 구조를 설계하고 제작할 수 있다.
2. 브랜드 키트(색/폰트/요소)를 정리해 일관성을 유지할 수 있다.
3. 템플릿 기반 대량 제작(Bulk Create) 흐름을 적용할 수 있다.

## 준비물
- 8차시 발표자료 핵심 문구
- 제품/서비스 소개 문장 5개
- 브랜드 색상 2~3개, 폰트 1~2개

## 90분 수업 활동
1. 0~10분: 숙제 리뷰
- 영상/슬라이드 일관성 체크

2. 10~25분: 핵심 데모
- Canva 웹사이트 섹션 구성
- 브랜드 키트 등록 및 적용
- Sheets/Bulk Create로 카드 대량 생성

3. 25~55분: 실습 A (개인)
- 미션: 랜딩페이지 1개 제작
- 필수 섹션:
  - 히어로(제목 + CTA)
  - 소개(핵심 가치)
  - 사례/결과
  - 문의/연결

4. 55~70분: 실습 B (개인)
- 미션: 동일 템플릿으로 포스트 10개 대량 생성
- 조건:
  - 제목/보조문구 데이터 분리
  - 브랜드 키트 스타일 일괄 적용

5. 70~85분: 결과 공유
- 랜딩페이지 1분 데모 + 대량 생성 결과 확인

6. 85~90분: 숙제 안내

## 수업 내 제출물
1. 랜딩페이지 1개
2. 대량 생성 포스트 10개

## 숙제
## 과제명: 브랜드 일관성 자동화 실습
1. 동일 브랜드로 포스트 10개를 재생성한다.
2. 포스트를 목적별로 분류한다(홍보/정보/신뢰/행동 유도).
3. 랜딩페이지 문구를 1회 이상 개선해 수정본 제출한다.

## 숙제 제출 형식
- 파일: `이름_l09_post01.png` ~ `이름_l09_post10.png`
- 페이지: `이름_l09_landing.pdf` 또는 공개 링크
- 설명: `이름_l09_map.md` (콘텐츠 분류표 + 수정 이유)
- Canva 공유 링크 1개

## 평가 기준 (10점)
1. 구조 설계(3점): 랜딩페이지 흐름이 명확한가
2. 자동화 활용(3점): 10개 콘텐츠가 규칙적으로 생성됐는가
3. 브랜드 일관성(2점): 키트 적용이 안정적인가
4. 제출 정확성(2점): 파일/설명/링크가 완비됐는가

## 체크리스트
- CTA가 페이지 상단에 명확히 있는가
- 포스트 10개가 중복 없이 역할을 가지는가
- 브랜드 색/폰트가 흔들리지 않는가
- 수정본에서 개선 포인트가 드러나는가
