# Canva 1차시 학생 과제지


## 연계 이론
- [theory_canva_l01.md](./theory_canva_l01.md)

## 오늘 목표
1. Canva 작업 흐름(홈 -> 템플릿 -> 에디터 -> 공유)을 설명할 수 있다.
2. 무료/유료 요소와 라이선스 주의점을 구분할 수 있다.
3. 템플릿 1개를 목적에 맞게 수정해 결과물을 완성할 수 있다.

## 준비물
- Canva 계정 로그인 완료
- 노트북 또는 PC
- 제출용 폴더(본인 이름)

## 90분 수업 활동
1. 0~10분: 오리엔테이션
- 오늘 산출물/숙제/평가 기준 확인
- 제출 형식 확인(PNG + 링크)

2. 10~25분: 핵심 데모
- 홈 화면 메뉴, 템플릿 검색, 프로젝트 정리
- 에디터 화면(요소, 텍스트, 업로드, 공유) 기본 사용
- 라이선스 확인 위치와 체크 방법

3. 25~55분: 실습 A (개인)
- 미션: "자기소개 카드" 1장 제작
- 필수 요소:
  - 이름/한 줄 소개/연락 채널(가상 가능)
  - 텍스트 2종 이상, 요소 2개 이상
  - 배경색 1개, 강조색 1개

4. 55~70분: 실습 B (개인)
- 미션: 제공 템플릿 1개 리디자인
- 필수 수정:
  - 제목/본문 텍스트 교체
  - 색상 팔레트 교체
  - 요소 2개 교체

5. 70~85분: 결과 공유
- 1인 1분 발표: 바꾼 이유 2가지 설명
- 동료 피드백 1개씩 작성

6. 85~90분: 숙제 안내

## 수업 내 제출물
1. 자기소개 카드 1장
2. 리디자인 템플릿 1장

## 숙제
## 과제명: 동일 주제 2포맷 변환
1. 오늘 만든 리디자인 결과를 아래 2개 규격으로 재제작한다.
- 1080x1080 (정사각형)
- 1080x1920 (세로형/스토리)
2. 각 결과물에 대해 "무엇을 왜 바꿨는지" 3줄 메모를 작성한다.

## 숙제 제출 형식
- 파일: `이름_l01_square.png`, `이름_l01_vertical.png`
- 메모: `이름_l01_note.md` (3~5줄)
- Canva 공유 링크 1개

## 평가 기준 (10점)
1. 가독성(3점): 제목/본문이 한눈에 읽히는가
2. 목적 적합성(3점): 자기소개/안내 목적이 분명한가
3. 일관성(2점): 색/폰트/정렬이 통일되어 있는가
4. 완성도(2점): 규격/파일명/제출 형식이 맞는가

## 체크리스트
- 라이선스 확인 없이 요소를 사용하지 않았는가
- 제목/본문 대비가 충분한가
- 모바일에서 봐도 글자가 읽히는가
- 제출 파일명 규칙을 지켰는가
