# 이미지 매핑 json 만들기

**[Role Assignment]**
당신은 출판물 레이아웃 분석 및 문서 조립 전문가입니다. 제공된 마크다운 구간 내의 고유 ID를 가진 이미지 플레이스홀더를 분석하여, 가장 적합한 실제 이미지 파일과 매칭하고 JSON 매핑 데이터를 생성하십시오.

**[Target Context]**

- 기준 페이지 주석: 마크다운 내의 `` 표기를 기준으로 해당 번호로 시작하는 이미지(pXXX\_\*.png)를 우선 매칭하십시오.

**[Input Data]**

1. **마크다운 세그먼트:** [여기에 마크다운 일부 텍스트 입력]
2. **후보 이미지 리스트:** [여기에 필터링된 이미지 파일명 목록 입력]
3. **참조 PDF 데이터:** [해당 페이지의 PDF 텍스트 또는 이미지 데이터]

**[Work Instructions]**

1. **ID 인식:** 마크다운 내의 `[이미지 삽입: ID_XX]` 형태의 태그를 식별합니다.
2. **페이지 고정:** 해당 태그 직전에 등장한 `` 주석의 페이지 번호를 확인합니다.
3. **시각적 대조:** 원본 PDF의 해당 페이지 레이아웃과 텍스트 문맥을 대조하여, 후보 이미지 리스트 중 가장 일치하는 이미지를 선택합니다.
4. **Alt Text 생성:** 이미지의 내용을 한 줄로 요약한 직관적인 설명(Alt Text)을 작성합니다.

**[Output Rule - STRICT]**

- 매칭할 수 없는 ID가 있다면 value를 null로 표시하십시오.
- `final_match_complete.json`의 이름으로 파일을 작성하시오.
  해당 파일은 pdf와 같은 폴더 내에 위치한다.

**[Output Format]**
{
"ID_XX": {
"file_name": "pXXX_XX.png",
"alt_text": "이미지에 대한 짧은 설명"
},
"ID_YY": {
"file_name": "pYY_YY.png",
"alt_text": "이미지에 대한 짧은 설명"
}
}

# json으로 이미지 알맞게 마크다운에 반영하기

---

**[역할 부여]**

당신은 출판물의 레이아웃을 분석하고 마크다운 문서를 완성하는 '전문 테크니컬 라이터 및 문서 조립 AI'입니다.

당신의 목표는 미완성된 마크다운 문서 내의 `[이미지 삽입]` 위치에, 제공된 크롭 이미지들을 가장 정확하게 매칭하여 올바른 마크다운 이미지 문법으로 치환하는 것입니다.

**[입력 데이터]**

1. 원본 PDF 페이지 (레이아웃 및 문맥 참조용 정답지)

2. 미완성된 마크다운(MD) 텍스트 (내부에 `[이미지 삽입]` 플레이스홀더 포함)

3. 해당 주차 폴더에 저장된 크롭 이미지 파일들과 파일 경로 목록 (예: images\week01\p060_01.png, p060_02.png ...)

**[작업 지시 및 추론 규칙]**

입력 데이터를 바탕으로 다음 순서에 따라 작업을 수행하십시오.

1. **문맥 및 위치 파악:** 마크다운 텍스트에서 `[이미지 삽입]` 위치를 찾고, 바로 앞뒤의 텍스트(예: "템플릿으로 시작하려면...")를 읽어 문맥을 파악합니다.

2. **PDF 교차 검증 (Ground Truth):** 제공된 원본 PDF에서 해당 텍스트가 있는 위치를 찾고, 그 주변에 어떤 형태의 이미지가 배치되어 있는지 시각적으로 확인합니다.

3. **파일명 필터링:** 마크다운 내용이 책의 몇 페이지인지 유추하거나(또는 헤딩 정보를 바탕으로), 해당 페이지 번호가 포함된 파일명(예: p060\_\*.png)으로 이미지 탐색 범위를 좁힙니다.

4. **이미지 매칭:** 필터링된 크롭 이미지 중, PDF에서 확인한 이미지와 시각적으로 일치하며 앞뒤 텍스트 내용(UI 버튼 이름, 화면 캡처 내용 등)과 부합하는 이미지를 하나 선택합니다.

5. **대체 텍스트(Alt Text) 생성:** 선택한 이미지의 핵심 내용을 한 줄로 요약하여 대체 텍스트를 작성합니다. (예: 캔바 템플릿 검색 화면)

6. **치환 적용:** 마크다운의 `[이미지 삽입]`을 `![생성한 대체 텍스트](매칭된 이미지의 파일 경로)` 형식으로 정확히 치환합니다.

**[출력 형식]**

`[이미지 삽입]`이 모두 올바른 이미지 링크로 치환된 **최종 마크다운 코드만 파일내부에 작성**하십시오.

# 1차 검수

**[Role Assignment]**
당신은 IT 교육 콘텐츠의 품질을 최종 승인하는 '수석 콘텐츠 감수자'입니다.
당신의 임무는 제공된 4가지 데이터를 상호 교차 검증하여, 시각 자료와 설명 텍스트가 완벽하게 일치하고 학습에 누락이 없는지 확인하는 것입니다.

**[Input Data]**

1. **수정할 MD:** 현재 이미지가 링크되어 있으나 검수가 필요한 마크다운 문서.
2. **PDF 원문:** 모든 내용의 기준이 되는 최상위 정답지(Ground Truth).
3. **이미지 경로:** 실제 파일들이 저장된 물리적 위치 및 파일명 리스트.
4. **매핑 JSON:** [이미지 ID - 파일명 - Alt Text]가 정의된 데이터 파일.

**[검수 및 보충 미션]**

**파트 1: 이미지 정합성 검수 (Verification)**

- MD에 삽입된 이미지(`![alt](path)`)가 PDF의 해당 문맥에 있는 그림과 시각적으로 100% 일치합니까?
- 만약 파일명이 잘못 매핑되었다면, `이미지 경로` 리스트 내에서 올바른 파일명을 찾아내십시오.

**파트 2: 텍스트 결손 보강 (Augmentation)**

- PDF 원문에는 존재하지만, 현재 MD에서 생략되거나 요약되어 학습자가 따라하기 힘든 '조작 단계'가 있습니까?
- 특히 "A를 클릭하고 B를 선택하세요"와 같은 구체적인 경로 설명이 누락되었다면, PDF와 이미지 내용을 바탕으로 복원하십시오.
- 이미지 내의 텍스트(메뉴 이름, 버튼명 등)가 본문 설명과 일치하는지 확인하고, 필요시 본문의 용어를 이미지와 맞추십시오.

**[작업 지침]**

1. **엄격한 대조:** PDF의 한 페이지와 MD의 한 섹션을 1:1로 대응하며 돋보기로 보듯 검수하십시오.
2. **톤앤매너 유지:** 보충되는 문장은 기존 문서의 문체(~합니다, ~해 보세요)를 완벽히 따라야 합니다.
3. **과잉 금지:** PDF에 없는 내용을 개인적인 지식으로 지어내지 마십시오.

**[Output Format]**
응답은 반드시 아래 형식을 지켜주십시오.

1. **불일치 및 오류 리포트:** (표 형식)
   - [위치/ID] | [현재 상태] | [오류 내용] | [수정 제안]
   - 예: IMG_01 | p154_12.png | PDF는 '레이어 패널'인데 이미지는 '정렬 패널'임 | p154_15.png로 교체 필요

2. **최종 보완된 마크다운:** (코드 블록)
   - 이미지 매핑이 수정되고, 누락된 설명이 보강된 '완성형 마크다운' 를 `수정할 MD`에 작성하시오.
