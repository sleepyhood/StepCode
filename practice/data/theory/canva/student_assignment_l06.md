# Canva 6차시 학생 과제지


## 연계 이론
- [theory_canva_l06.md](./theory_canva_l06.md)

## 오늘 목표
1. 채널별 포맷 차이에 맞게 콘텐츠를 설계할 수 있다.
2. CTA(행동 유도) 문구를 포함한 실전 게시물 묶음을 만들 수 있다.
3. 주간 업로드 가능한 콘텐츠 패키지를 완성할 수 있다.

## 준비물
- 5차시 핵심 비주얼 5개
- 주간 콘텐츠 주제 1개
- 핵심 CTA 문구 3개

## 90분 수업 활동
1. 0~10분: 숙제 리뷰
- 비주얼 패키지의 활용성 점검

2. 10~25분: 핵심 데모
- 피드/스토리/릴스 커버 권장 구성
- CTA 배치 위치와 문구 톤
- 시리즈 콘텐츠의 통일감 유지법

3. 25~55분: 실습 A (개인)
- 미션: 콘텐츠 5개 제작
- 구성:
  - 피드 2개(정보형 1, 홍보형 1)
  - 스토리 2개(공지형 1, 참여유도형 1)
  - 릴스 커버 1개

4. 55~70분: 실습 B (개인)
- 미션: 업로드 순서 설계
- 조건:
  - 5개 콘텐츠 발행 순서 작성
  - 각 콘텐츠 목적(인지/관심/행동) 태그 부여

5. 70~85분: 결과 공유
- 1인 1분: "왜 이 순서로 배치했는가" 설명

6. 85~90분: 숙제 안내

## 수업 내 제출물
1. 피드 2개 + 스토리 2개 + 릴스 커버 1개
2. 업로드 순서표 1개

## 숙제
## 과제명: 주간 업로드 패키지 완성
1. 주제 1개로 주간용 콘텐츠 최소 5개를 완성한다.
2. 각 콘텐츠에 CTA 문구를 1개 이상 포함한다.
3. 콘텐츠 캡션 초안을 각 2줄 이상 작성한다.

## 숙제 제출 형식
- 파일: `이름_l06_post01.png` ~ `이름_l06_post05.png`
- 캡션: `이름_l06_caption.md` (콘텐츠별 2줄 이상)
- 순서표: `이름_l06_schedule.md` (업로드 날짜/목적 포함)
- Canva 공유 링크 1개

## 평가 기준 (10점)
1. 채널 적합성(3점): 피드/스토리/릴스 형식이 적절한가
2. 메시지 설계(3점): CTA와 캡션이 목적에 맞는가
3. 시리즈 일관성(2점): 5개 콘텐츠가 한 브랜드로 보이는가
4. 제출 정확성(2점): 파일/캡션/순서표/링크가 모두 있는가

## 체크리스트
- 콘텐츠별 목적(인지/관심/행동)이 분명한가
- CTA가 자연스럽고 구체적인가
- 캡션이 이미지 내용과 연결되는가
- 발행 순서가 흐름을 만드는가
