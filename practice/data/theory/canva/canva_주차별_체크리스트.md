## 캔바(Canva) 실전 마스터 과정: 수강생용 자가 점검표

### 1차시: 캔바 첫 세팅과 작업 영역 적응

- [ ] 캔바 계정 생성이 완료되었으며, 기본 언어 및 계정 설정이 끝났는가?
- [ ] 저작권 가이드라인을 확인하고 무료/유료 요소의 상업적 이용 범위를 이해했는가?
- [ ] 홈 화면에서 디자인 목적에 맞는 템플릿 탐색 및 검색 기능을 활용해 보았는가?
- [ ] **[산출물]** 업무 효율을 위해 3개 이상의 프로젝트 관리 폴더를 생성했는가?

### 2차시: 디자인 기초 다지기 - 텍스트와 요소

- [ ] 주제에 맞는 폰트(가독성 고려)를 선택하고 텍스트 스타일을 적용했는가?
- [ ] 그래픽 요소를 활용해 레이아웃을 풍성하게 구성했는가?
- [ ] 배경색과 요소 컬러의 조화가 디자인 목적에 부합하는가?
- [ ] **[산출물]** 텍스트와 요소로만 구성된 안내문 혹은 카드뉴스 2페이지를 완성했는가?

### 3차시: 디자인 정돈 및 AI 창작 워크플로 체험

- [ ] 레이어 순서 조정 및 '정렬' 기능을 사용하여 모든 요소가 깔끔하게 정돈되었는가?
- [ ] 수정이 용이하도록 관련 요소들을 '그룹화' 처리했는가?
- [ ] Magic Studio(AI 도구)를 활용해 이미지를 편집하거나 생성해 보았는가?
- [ ] **[산출물]** 정렬이 완벽한 SNS 배너 1종을 완성하고 공유 링크를 추출했는가?

### 4차시: 실전 디자인 1 - SNS와 포스터 제작

- [ ] 업종(베이커리/필라테스/동물병원 중 택 1)의 분위기에 맞는 템플릿을 선택했는가?
- [ ] 템플릿의 기존 요소를 유지하되 나만의 독창적인 요소를 추가/수정했는가?
- [ ] 홍보 목적에 맞는 핵심 문구(카피)가 눈에 잘 띄도록 배치되었는가?
- [ ] **[산출물]** SNS 피드와 스토리를 포함한 홍보물 3종 세트를 제작했는가?

### 5차시: 실전 디자인 2 - 기업형 디자인과 자산 관리

- [ ] 프레젠테이션의 논리적 흐름(표지-목차-본문-종료)이 구성되었는가?
- [ ] 슬라이드 간의 통일성을 위해 일관된 컬러와 폰트를 유지했는가?
- [ ] 상세페이지의 경우, 고객의 시선을 끄는 상단 배너와 정보 전달이 명확한가?
- [ ] **[산출물]** 기업 제안서 또는 강의용 슬라이드 3페이지 이상을 완성했는가?

### 6차시: 브랜드 정체성과 비주얼 시스템 구축

- [ ] 나만의 브랜드를 정의하는 핵심 키워드와 테마 컬러 3가지를 선정했는가?
- [ ] 브랜드의 성격(신뢰, 친근함 등)을 대변하는 폰트 조합을 결정했는가?
- [ ] 캔바 내 '브랜드 키트' 기능을 활용해 로고, 색상, 글꼴을 설정했는가?
- [ ] **[산출물]** 한눈에 보는 브랜드 아이덴티티 보드 1세트를 구성했는가?

### 7차시: 브랜드를 뽐내는 웹 포트폴리오 제작

- [ ] 캔바 웹사이트 기능을 활용해 모바일과 PC에서 모두 잘 보이는지 확인했는가?
- [ ] 외부 링크(SNS, 이메일 등) 연결을 위한 버튼이 정상적으로 작동하는가?
- [ ] 6차시에서 설정한 브랜드 비주얼 시스템이 웹 페이지 전체에 잘 녹아있는가?
- [ ] **[산출물]** 캔바 호스팅을 이용해 배포된 웹 포트폴리오 1페이지 링크를 제출했는가?

### 8차시: 업무 효율 200% 올리는 대량 제작 실무

- [ ] 구글 스프레드시트 또는 캔바 시트(CSV)에 데이터를 구조에 맞게 입력했는가?
- [ ] '대량 제작' 도구를 통해 시트의 데이터와 디자인 요소를 정확히 연결했는가?
- [ ] 자동 생성된 콘텐츠 중 레이아웃이 깨진 부분이 없는지 최종 검토했는가?
- [ ] **[산출물]** 대량 제작 기능을 활용한 정보성 콘텐츠 최소 5장 이상을 생성했는가?
