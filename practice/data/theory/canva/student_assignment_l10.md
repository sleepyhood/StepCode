# Canva 10차시 학생 과제지


## 연계 이론
- [theory_canva_l10.md](./theory_canva_l10.md)

## 오늘 목표
1. 본인 작업에 맞는 수익화 방식(템플릿/외주/POD/교육)을 선택할 수 있다.
2. 가격/제안 기준을 문서화할 수 있다.
3. 최종 포트폴리오 패키지를 제출 가능한 형태로 완성할 수 있다.

## 준비물
- 1~9차시 대표 결과물 6개 이상
- 관심 수익화 방식 1~2개
- 자기소개 문장 3줄

## 90분 수업 활동
1. 0~10분: 숙제 리뷰
- 랜딩/자동화 결과 우수 사례 확인

2. 10~25분: 핵심 데모
- 수익화 모델 비교(템플릿/외주/POD/강의)
- 가격 책정 기본 프레임(난이도/시간/가치)
- 포트폴리오 보드 구조

3. 25~55분: 실습 A (개인)
- 미션: 포트폴리오 보드 1개 제작
- 필수 구성:
  - 자기소개
  - 대표 작업 6개
  - 역할/성과 설명
  - 연락 방법

4. 55~70분: 실습 B (개인)
- 미션: 상품/서비스 제안서 1장 제작
- 필수 항목:
  - 제공 범위
  - 납기
  - 가격(기본/옵션)
  - 수정 정책

5. 70~85분: 최종 공유
- 1인 1분 피칭(대상 고객 + 제공 가치)

6. 85~90분: 숙제 안내

## 수업 내 제출물
1. 포트폴리오 보드 1개
2. 제안서 1장

## 숙제
## 과제명: 최종 포트폴리오 패키지 제출
1. 포트폴리오 보드를 최종 보정한다.
2. 제안서를 실제 전달 가능한 문구로 수정한다.
3. 아래 구성으로 최종 패키지를 제출한다.
- 표지 1장
- 작품 6장 이상
- 가격/제안 1장
- 자기소개 1장

## 숙제 제출 형식
- 파일: `이름_l10_portfolio.pdf`, `이름_l10_offer.pdf`
- 요약: `이름_l10_summary.md` (타깃 고객, 강점, 다음 계획)
- Canva 공유 링크 1개

## 평가 기준 (10점)
1. 실무성(3점): 실제 판매/제안에 바로 쓸 수 있는가
2. 구성 완성도(3점): 포트폴리오 흐름이 명확한가
3. 설득력(2점): 가격/범위/가치 설명이 타당한가
4. 제출 정확성(2점): 파일/요약/링크가 모두 있는가

## 체크리스트
- 대표 작업이 목적별로 균형 있게 포함됐는가
- 가격과 범위가 모순되지 않는가
- 연락/제안 정보가 누락되지 않았는가
- 다음 실행 계획이 구체적인가
