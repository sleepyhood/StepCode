# Canva 2차시 학생 과제지


## 연계 이론
- [theory_canva_l02.md](./theory_canva_l02.md)

## 오늘 목표
1. 텍스트 계층(제목/본문/강조)을 의도적으로 구성할 수 있다.
2. 정렬/간격/그룹화를 사용해 레이아웃을 안정화할 수 있다.
3. 동일 레이아웃에서 색상 변주 3안을 만들 수 있다.

## 준비물
- 1차시 제출본 1개
- Canva 브랜드 색상 후보 3개(직접 선정)
- 배포용 이미지 2장 이상(직접 촬영 또는 무료 소스)

## 90분 수업 활동
1. 0~10분: 숙제 리뷰
- 우수 사례 2개, 개선 사례 2개 비교

2. 10~25분: 핵심 데모
- 텍스트 효과, 자간/행간, 대비 조정
- 요소/도형 스타일 복사
- 가이드라인, 정렬, 그룹화로 정돈하기

3. 25~50분: 실습 A (개인)
- 미션: "브랜드 무드 카드" 2장 제작
- 카드 1: 정보형(텍스트 중심)
- 카드 2: 감성형(이미지 중심)
- 공통 필수:
  - 제목 1개, 본문 2블록 이상
  - 요소 3개 이상
  - 정렬 도구 사용

4. 50~70분: 실습 B (개인)
- 미션: 동일 레이아웃으로 색상 3안 만들기
- 조건:
  - 레이아웃/텍스트는 동일 유지
  - 색상 팔레트만 바꿔 3가지 버전 생성

5. 70~85분: 피드백 라운드
- 2인 1조 상호 피드백
- 항목: 가독성, 집중 포인트, 색상 일관성

6. 85~90분: 숙제 안내

## 수업 내 제출물
1. 브랜드 무드 카드 2장
2. 동일 레이아웃 색상 3안

## 숙제
## 과제명: 색상/타이포 변주 실험
1. 오늘 제작한 카드 중 1개를 선택한다.
2. 아래 변주를 만든다.
- A안: 현재 기준
- B안: 대비 강화(강조색 중심)
- C안: 미니멀 버전(색상 2개 이하)
3. 각 안마다 "대상 독자"를 1줄로 지정한다.

## 숙제 제출 형식
- 파일: `이름_l02_A.png`, `이름_l02_B.png`, `이름_l02_C.png`
- 설명: `이름_l02_compare.md` (각 안 2~3줄)
- Canva 공유 링크 1개

## 평가 기준 (10점)
1. 계층 구조(3점): 제목/본문/강조가 구분되는가
2. 정돈도(3점): 정렬/간격/그룹화가 안정적인가
3. 변주 완성도(2점): 3안의 차이가 분명한가
4. 제출 정확성(2점): 파일/설명/링크가 모두 있는가

## 체크리스트
- 텍스트가 배경에 묻히지 않는가
- 요소 간 간격이 규칙적으로 보이는가
- 색상 3안이 서로 다른 의도를 가지는가
- 설명 파일에 대상 독자를 명시했는가
