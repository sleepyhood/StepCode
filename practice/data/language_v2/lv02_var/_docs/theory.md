# 변수 핵심 이론

## 1) 변수가 하는 일

변수는 값을 저장하는 이름입니다.

- 계산 결과를 나중에 다시 사용하기 위해 값을 보관합니다.
- 같은 변수에 새 값을 넣으면 이전 값은 덮어써집니다.
- 초급 단계에서는 "지금 이 변수에 무엇이 들어 있는가"를 계속 확인하는 습관이 중요합니다.

---

## 2) 실행 흐름

변수 코드는 아래 순서로 읽으면 이해가 쉬워집니다.

1. 변수 준비(선언/이름 정하기)
2. 초기값 저장
3. 새 값으로 갱신(필요 시)
4. 마지막 값 출력/사용

핵심은 "**코드는 위에서 아래로 실행되고, 변수 값은 단계마다 바뀐다**"는 점입니다.

---

## 3) 가장 자주 쓰는 패턴

### 패턴 A: 대입과 재대입(덮어쓰기)

{lang:python}
```python
x = 10
x = x + 3
print("%d" % x)
```

{lang:c}
```c
int x = 10;
x = x + 3;
printf("%d\n", x);
```

{lang:java}
```java
int x = 10;
x = x + 3;
System.out.printf("%d\n", x);
```

```io
input:
(없음)
output:
13
```

아래 표는 **각 대입문이 실행된 직후 상태**를 기록한 것입니다.

```tracegrid
title: Trace 1. 대입과 재대입
lang: python,c,java
columns: 단계, 실행문, x 값
rows:
1 | x = 10 | 10
2 | x = x + 3 | 13
```

### 패턴 B: 두 변수 사용

{lang:python}
```python
a = 4
b = 7
sumv = a + b
print("%d" % sumv)
```

{lang:c}
```c
int a = 4;
int b = 7;
int sumv = a + b;
printf("%d\n", sumv);
```

{lang:java}
```java
int a = 4;
int b = 7;
int sumv = a + b;
System.out.printf("%d\n", sumv);
```

```io
input:
(없음)

```

아래 표는 **각 대입문이 실행된 직후 상태**를 기록한 것입니다.


## 4) 값 갱신 포인트 (변수 단원 핵심)

변수 단원에서 중요한 포인트는 "같은 이름이라도 시점마다 값이 다르다"는 점입니다.

- `x = 10` 직후의 `x`와 `x = x + 3` 직후의 `x`는 다릅니다.
- 식 오른쪽은 "이전 값"으로 계산한 뒤, 결과를 왼쪽 변수에 저장합니다.
- 그래서 실행 순서를 따라가며 값 변화를 확인해야 합니다.

---

## 5) 자주 틀리는 포인트

1. 선언/초기화 순서 혼동 (C/Java)
   선언 전에 변수를 사용하면 오류가 납니다.

2. 문자열과 숫자 혼동
   `"10"`과 `10`은 다릅니다.

3. 갱신 결과 오해
   `x = x + 1`은 "같다" 비교가 아니라 "새 값 저장"입니다.

4. 변수명 남용
   의미 없는 이름(`a1`, `x2`)을 남발하면 추적이 어려워집니다.

---

## 5-1) 언어별 실전 팁

{lang:python} Python은 선언 키워드 없이 바로 대입합니다. (`x = 10`)

{lang:c} C는 타입을 먼저 선언합니다. (`int x = 10;`)

{lang:java} Java도 타입 선언이 필요합니다. (`int x = 10;`)

{lang:python,c,java} 초급 단원에서는 출력 형식을 서식문자 기반(`%d`, `%.1f`)으로 통일해 연습합니다.
