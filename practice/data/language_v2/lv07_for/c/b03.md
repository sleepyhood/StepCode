# C for문 기초 3회차

### Q1. Trace 1. 입력 포함 count

각 반복 직후 i, num, count를 표에 채우세요.

```c
int n = 4;
int count = 0;
for (int i = 0; i < n; i++) {
    int num;
    scanf("%d", &num);
    if (num > 0) count++;
}
```
