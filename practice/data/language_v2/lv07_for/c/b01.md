# C for문 기초 1회차

### Q1. Trace 1. 기본 반복 흐름

각 반복 직후 i와 output을 표에 채우세요.

```c
#include <stdio.h>

int main(void) {
    for (int i = 0; i < 3; i++) {
        printf("%d\n", i);
    }
    return 0;
}
```

### Q2. Trace 2. 누적 합

각 반복 직후 i와 sum을 표에 채우세요.

```c

int main(void) {
    int sum = 0;

    return 0;
}
```
