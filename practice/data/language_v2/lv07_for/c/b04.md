# C for문 기초 4회차

### Q1. Trace 1. 입력 위치와 누적

각 반복 직후 i, num, sum을 표에 채우세요.

```c
int n = 3;
int sum = 0;
for (int i = 0; i < n; i++) {
    int num;
    scanf("%d", &num);
    sum += num;
}
```

### Q3. Reverse 1. n 추론

```c

for (int i = 1; i <= n; i++) {
    if (i % 2 == 1) sum += i;
}
printf("%d\n", sum);
```
