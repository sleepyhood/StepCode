# [P101v0711번] 11. [반복-for 기초1] 1부터 n까지 짝수 평균 구하기

## 1. 문제 설명
정수 n이 주어졌을 때, 1부터 n까지 중 짝수의 평균을 정수로 출력하는 프로그램을 작성해 주세요.

단, 평균은 소수점 이하는 버리고 정수 부분만 출력해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다. (1 ≤ n ≤ 10,000)

* **출력:**
1부터 n까지 짝수들의 평균을 한 줄에 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
6
```

### 예시 출력 1
```text
4
```

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력 단위 구분을 명확히 하기 위해 Python 코드를 기준(Ground Truth)으로 삼습니다.

```python
n = int(input())
total = 0
count = 0

for i in range(1, n + 1):
    if i % 2 == 0:
        total += i
        count += 1

print("%d" % (total // count))
```
