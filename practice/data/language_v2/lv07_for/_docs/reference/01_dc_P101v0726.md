# [P101v0726번] 26. [반복-for 분기] 홀수 3번 나오면 종료, 짝수만 출력

## 1. 문제 설명
정수 n이 주어졌을 때, n개의 숫자를 차례대로 입력받아 짝수만 출력하되,

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다. (1 ≤ n ≤ 100)

* **출력:**
홀수가 3번 나오기 전까지 입력된 짝수만 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
8  
2  
3  
4  
5  
7  
6  
8  
10
```

### 예시 출력 1
```text
2  
4
```

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력과 출력의 흐름이 보이도록 for문과 조건문을 사용해 문제를 그대로 구현합니다.

```python
n = int(input())
odd_count = 0

for _ in range(n):
    number = int(input())
    if number % 2 == 1:
        odd_count += 1
        if odd_count == 3:
            break
    else:
        print("%d" % number)
```

### 추가 해설
반복을 진행하다가 문제에서 정한 종료 조건을 만나면 바로 멈추도록 구현했습니다.
