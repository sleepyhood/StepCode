# [P101v0721번] 21. [반복-for 분기] 짝수만 출력, 0이면 멈추기

## 1. 문제 설명
정수 n이 주어졌을 때, n개의 정수를 차례대로 입력받고, 짝수만 출력하되 수가 0이면 출력을 멈추는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다. (1 ≤ n ≤ 100)

* **출력:**
입력된 수 중 짝수만 출력하며, 수가 0인 경우에는 출력하지 않고 프로그램을 종료합니다.

---

## 3. 예시

### 예시 입력 1
```text
6  
1  
2  
3  
4  
0  
6
```

### 예시 출력 1
```text
2  
4
```

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력과 출력의 흐름이 보이도록 for문과 조건문을 사용해 문제를 그대로 구현합니다.

```python
n = int(input())

for _ in range(n):
    number = int(input())
    if number == 0:
        break
    if number % 2 == 0:
        print("%d" % number)
```

### 추가 해설
반복을 진행하다가 문제에서 정한 종료 조건을 만나면 바로 멈추도록 구현했습니다.
