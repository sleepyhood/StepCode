# [P101v0707번] 07. [반복-for 기초1] 1부터 n까지 합 구하기

## 1. 문제 설명
정수 n이 주어졌을 때, 1부터 n까지의 합을 출력하는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다. (1 ≤ n ≤ 10,000)

* **출력:**
1부터 n까지의 정수 합을 한 줄에 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
5
```

### 예시 출력 1
```text
15
```

---

## 4. 힌트
합을 저장할 변수를 선언한 후, for문을 통해 값을 누적해서 계산해 주세요.

---

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력 단위 구분을 명확히 하기 위해 Python 코드를 기준(Ground Truth)으로 삼습니다.

```python
n = int(input())
result = 0

for i in range(1, n + 1):
    result += i

print("%d" % result)
```

반복문과 조건문을 이용해 문제에서 요구한 순서대로 값을 처리하면 됩니다.
