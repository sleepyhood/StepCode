# [SP101v0703번] 03. [반복-for 기초1] 1부터 n까지 출력하기

## 1. 문제 설명
1부터 입력받은 수까지 모두 출력해주세요.

---

## 2. 입출력 설명

* **입력:**
정수 하나가 입력됩니다.

* **출력:**
1부터 입력받은 수까지 연속해서 출력해주세요.

---

## 3. 예시

### 예시 입력 1
```text
5
```

### 예시 출력 1
```text
1 2 3 4 5
```

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력과 출력의 흐름이 보이도록 for문과 조건문을 사용해 문제를 그대로 구현합니다.

```python
n = int(input())
result = []

for i in range(1, n + 1):
    result.append("%d" % i)

print(" ".join(result))
```

### 추가 해설
