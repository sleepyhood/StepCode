# [P101v0725번] 25. [반복-for 분기] 홀수만 출력하고 음수 만나면 종료

## 1. 문제 설명
정수 n이 주어졌을 때, n개의 정수를 차례대로 입력받고,

입력된 수 중 홀수만 출력하되 음수가 입력되면 그 즉시 종료하는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다. (1 ≤ n ≤ 100)

그 다음 줄부터 n개의 줄에 걸쳐 정수 하나씩 주어집니다.

* **출력:**
음수가 입력되기 전까지 입력된 홀수를 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
6  
5  
4  
3  
-1  
7  
9
```

### 예시 출력 1
```text
5  
3
```

---

## 4. 힌트
입력값이 음수면 break, 홀수면 출력하는 두 조건을 함께 처리해 주세요.

---

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력 단위 구분을 명확히 하기 위해 Python 코드를 기준(Ground Truth)으로 삼습니다.

```python
n = int(input())

for _ in range(n):
    number = int(input())
    if number < 0:
        break
    if number % 2 == 1:
        print("%d" % number)
```

### 추가 해설
반복 중 종료 조건을 만나면 즉시 멈추도록 `break`를 사용했습니다.
