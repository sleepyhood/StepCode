# [P101v0725번] 25. [반복-for 분기] 홀수만 출력하고 음수 만나면 종료

## 1. 문제 설명
정수 n이 주어졌을 때, n개의 정수를 차례대로 입력받고,

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다. (1 ≤ n ≤ 100)

* **출력:**
음수가 입력되기 전까지 입력된 홀수를 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
6  
5  
4  
3  
-1  
7  
9
```

### 예시 출력 1
```text
5  
3
```

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력과 출력의 흐름이 보이도록 for문과 조건문을 사용해 문제를 그대로 구현합니다.

```python
n = int(input())

for _ in range(n):
    number = int(input())
    if number < 0:
        break
    if number % 2 == 1:
        print("%d" % number)
```
