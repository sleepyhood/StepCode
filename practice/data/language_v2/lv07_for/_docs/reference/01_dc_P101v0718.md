# [P101v0718번] 18. [반복-for 분기] 1부터 n까지 출력하다가 5에서 멈추기

## 1. 문제 설명
정수 n이 주어졌을 때, 1부터 n까지 출력하되 숫자 5를 출력한 뒤 반복을 멈추는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다. (5 ≤ n ≤ 100)

* **출력:**
1부터 시작하여 5까지 출력한 후 멈춥니다.

---

## 3. 예시

### 예시 입력 1
```text
8
```

### 예시 출력 1
```text
1  
2  
3  
4  
5
```

---

## 4. 힌트
for문을 사용하고, i가 5일 때 break를 사용하여 반복을 종료해 주세요.

---

<!-- ANSWER_START -->
## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력 단위 구분을 명확히 하기 위해 Python 코드를 기준(Ground Truth)으로 삼습니다.

```python
n = int(input())

for i in range(1, n + 1):
    print("%d" % i)
    if i == 5:
        break
```

### 추가 해설
반복 중 종료 조건을 만나면 즉시 멈추도록 `break`를 사용했습니다.
