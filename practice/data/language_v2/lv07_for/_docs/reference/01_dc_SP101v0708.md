# [SP101v0708번] 08. [반복-for 기초1] 1부터 n까지 3의 배수의 합 구하기

## 1. 문제 설명
정수 n이 주어졌을 때, 1부터 n까지 중 3의 배수만 더한 합을 출력하는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다. (1 ≤ n ≤ 10,000)

* **출력:**
1부터 n까지 중 3의 배수의 합을 한 줄에 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
10
```

### 예시 출력 1
```text
18
```

---

## 4. 힌트
변수를 선언하여 짝수를 발견할 때마다 1씩 증가시켜 주세요.

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력 단위 구분을 명확히 하기 위해 Python 코드를 기준(Ground Truth)으로 삼습니다.

```python
n = int(input())
result = 0

for i in range(1, n + 1):
    if i % 3 == 0:
        result += i

print("%d" % result)
```
