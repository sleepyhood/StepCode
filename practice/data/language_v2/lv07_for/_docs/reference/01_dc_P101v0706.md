# [P101v0706번] 06. [반복-for 기초1] 1부터 n까지 3의 배수 출력하기

## 1. 문제 설명
정수 n이 주어졌을 때, 1부터 n까지 중 3의 배수만 출력하는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다. (1 ≤ n ≤ 100)

* **출력:**
1부터 n까지 중 3의 배수만 한 줄에 하나씩 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
10
```

### 예시 출력 1
```text
3  
6  
9
```

---

## 4. 힌트
if문을 사용하여 현재 수가 3의 배수인지 검사한 후 출력해 주세요.

---

<!-- ANSWER_START -->
## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력 단위 구분을 명확히 하기 위해 Python 코드를 기준(Ground Truth)으로 삼습니다.

```python
n = int(input())

for i in range(1, n + 1):
    if i % 3 == 0:
        print("%d" % i)
```

### 추가 해설
반복문과 조건문을 이용해 문제에서 요구한 순서대로 값을 처리하면 됩니다.
