# [SP101v0723번] 23. [반복-for 응용] 나머지가 1이 되는 수 찾기

## 1. 문제 설명
자연수 n이 주어집니다. n을 어떤 자연수 x로 나누었을 때 나머지가 1이 되도록 하는 가장 작은 자연수 x를 구하세요.

답은 항상 존재하며, 가장 작은 값을 출력하면 됩니다.

---

## 2. 입출력 설명

* **입력:**
자연수 n이 한 줄에 입력됩니다. (3 ≤ n ≤ 1,000,000)

* **출력:**
n을 x로 나눴을 때 나머지가 1이 되는 가장 작은 자연수 x를 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
10
```

### 예시 출력 1
```text
3
```

---

## 4. 힌트
x = 1부터 시작하여 n % x == 1이 되는 가장 작은 값을 찾으면 됩니다.

---

<!-- ANSWER_START -->
## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력 단위 구분을 명확히 하기 위해 Python 코드를 기준(Ground Truth)으로 삼습니다.

```python
n = int(input())

for x in range(2, n + 1):
    if n % x == 1:
        print("%d" % x)
        break
```

### 추가 해설
반복 중 종료 조건을 만나면 즉시 멈추도록 `break`를 사용했습니다.
