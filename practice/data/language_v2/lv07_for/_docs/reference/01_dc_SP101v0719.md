# [SP101v0719번] 19. [반복-for 응용] 홀수는 더하고 짝수는 빼고

## 1. 문제 설명
두 정수가 입력됩니다.

---

## 2. 입출력 설명

* **입력:**
정수 두개가 입력됩니다. 처음 입력된 수가 두 번째 입력된 수 이하입니다.

* **출력:**
두 정수 사이의 수 중 홀수는 더하고 짝수는 뺀 결과를 출력해주세요.

---

## 3. 예시

### 예시 입력 1
```text
14 27
```

### 예시 출력 1
```text
7
```

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력과 출력의 흐름이 보이도록 for문과 조건문을 사용해 문제를 그대로 구현합니다.

```python
a, b = map(int, input().split())
result = 0

for i in range(a, b + 1):
    if i % 2 == 1:
        result += i
    else:
        result -= i

print("%d" % result)
```

### 추가 해설
반복문을 순서대로 실행하면서 문제에서 요구한 값만 출력하거나 계산하면 됩니다.
