# [SP101v0719번] 19. [반복-for 응용] 홀수는 더하고 짝수는 빼고

## 1. 문제 설명
두 정수가 입력됩니다.

두 정수를 포함한 사이의 구간에 대해서 홀수는 더하고 짝수는 뺀 합을 출력하세요.

ex)

입력한 값이 5와 10

5 - 6 + 7 - 8 + 9 - 10 = -3

---

## 2. 입출력 설명

* **입력:**
정수 두개가 입력됩니다. 처음 입력된 수가 두 번째 입력된 수 이하입니다.

* **출력:**
두 정수 사이의 수 중 홀수는 더하고 짝수는 뺀 결과를 출력해주세요.

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력 단위 구분을 명확히 하기 위해 Python 코드를 기준(Ground Truth)으로 삼습니다.

```python
a, b = map(int, input().split())
result = 0

for i in range(a, b + 1):
    if i % 2 == 1:
        result += i
    else:
        result -= i

print("%d" % result)
```
