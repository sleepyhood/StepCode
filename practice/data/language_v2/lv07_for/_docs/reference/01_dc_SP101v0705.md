# [SP101v0705번] 05. [반복-for 기초1] 1부터 n까지 홀수 출력하기

## 1. 문제 설명
정수 n이 주어졌을 때, 1부터 n까지 중 홀수만 출력하는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다. (1 ≤ n ≤ 100)

* **출력:**
1부터 n까지 중 홀수만 한 줄에 하나씩 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
7
```

### 예시 출력 1
```text
1  
3  
5  
7
```

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력과 출력의 흐름이 보이도록 for문과 조건문을 사용해 문제를 그대로 구현합니다.

```python
n = int(input())

for i in range(1, n + 1):
    if i % 2 == 1:
        print("%d" % i)
```

### 추가 해설
반복문을 순서대로 실행하면서 문제에서 요구한 값만 출력하거나 계산하면 됩니다.
