# [P101v0732번] 32. [반복-for 응용] 2의 n 제곱 구하기

## 1. 문제 설명
정수가 하나 입력됩니다.

---

## 2. 입출력 설명

* **입력:**
정수 하나가 입력됩니다.

* **출력:**
2를 입력받은 수 만큽 곱하여 출력해주세요.

---

## 3. 예시

### 예시 입력 1
```text
10
```

### 예시 출력 1
```text
1024
```

---

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력과 출력의 흐름이 보이도록 for문과 조건문을 사용해 문제를 그대로 구현합니다.

```python
n = int(input())
result = 1

for _ in range(n):
    result *= 2

print("%d" % result)
```

### 추가 해설
반복문을 순서대로 실행하면서 문제에서 요구한 값만 출력하거나 계산하면 됩니다.
