# [P101v0735번] 35. [반복-for 응용] 부족한 금액 계산하기

## 1. 문제 설명
놀이기구의 원래 이용료는 price원인데, 이 놀이기구를 N번째 이용할 때는 price의 N배를 받습니다.

---

## 2. 입출력 설명

* **입력:**
세 정수 price, money, count가 한 줄에 공백으로 구분되어 입력됩니다.

* **출력:**
놀이기구를 count번 타기 위해 부족한 금액을 출력합니다. 부족하지 않으면 0을 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
3 20 4
```

### 예시 출력 1
```text
10
```

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력과 출력의 흐름이 보이도록 for문과 조건문을 사용해 문제를 그대로 구현합니다.

```python
price, money, count = map(int, input().split())
total = 0

for i in range(1, count + 1):
    total += price * i

if total > money:
    print("%d" % (total - money))
else:
    print("%d" % 0)
```

### 추가 해설
반복문을 순서대로 실행하면서 문제에서 요구한 값만 출력하거나 계산하면 됩니다.
