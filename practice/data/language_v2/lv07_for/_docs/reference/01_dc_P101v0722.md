# [P101v0722번] 22. [반복-for 분기] 2와 3의 배수는 건너뛰기

## 1. 문제 설명
정수 n이 주어졌을 때, 1부터 n까지 출력하되, 2의 배수 또는 3의 배수는 출력하지 않는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다. (1 ≤ n ≤ 100)

* **출력:**
1부터 n까지 중 2 또는 3의 배수가 아닌 수만 한 줄에 하나씩 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
10
```

### 예시 출력 1
```text
1  
5  
7
```

---

## 4. 힌트
if문으로 i가 2 또는 3의 배수인지 판단하여 continue를 사용해 건너뛰어 주세요.

---

<!-- ANSWER_START -->
## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력 단위 구분을 명확히 하기 위해 Python 코드를 기준(Ground Truth)으로 삼습니다.

```python
n = int(input())

for i in range(1, n + 1):
    if i % 2 == 0 or i % 3 == 0:
        continue
    print("%d" % i)
```

### 추가 해설
제외해야 하는 값은 `continue`로 건너뛰고, 필요한 값만 출력하도록 구현했습니다.
