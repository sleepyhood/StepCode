# [SP101v0711번] 11. [반복-for 기초1] 처음 입력받은 수 부터 두번째 입력 받은 수 까지 출력

## 1. 문제 설명
두개의 정수가 입력됩니다.

---

## 2. 입출력 설명

* **입력:**
정수 두개가 입력됩니다.

* **출력:**
첫번째 입력받은 수부터 두번째 입력받은 수 까지 출력해주세요.

---

## 3. 예시

### 예시 입력 1
```text
5
8
```

### 예시 출력 1
```text
5 6 7 8
```

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력과 출력의 흐름이 보이도록 for문과 조건문을 사용해 문제를 그대로 구현합니다.

```python
a = int(input())
b = int(input())
result = []

for i in range(a, b + 1):
    result.append("%d" % i)

print(" ".join(result))
```

### 추가 해설
반복문을 순서대로 실행하면서 문제에서 요구한 값만 출력하거나 계산하면 됩니다.
