# [P101v0727번] 27. [반복-for 분기] 누적합이 k를 넘으면 멈추기

## 1. 문제 설명
정수 n과 k가 주어졌을 때, n개의 정수를 입력받아 누적합이 k를 초과하면 멈추는 프로그램을 작성해 주세요.

입력된 숫자를 누적합이 초과되기 전까지 출력해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 두 정수 n, k가 주어집니다. (1 ≤ n ≤ 100, 1 ≤ k ≤ 1000)

그 다음 줄부터 n개의 줄에 걸쳐 정수 하나씩 입력됩니다.

* **출력:**
누적합이 k를 넘기 전까지 입력된 수를 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
6 15  
3  
5  
4  
2  
10  
6
```

### 예시 출력 1
```text
3  
5  
4  
2
```

---

## 4. 힌트
누적합을 계속 더하면서, 누적합이 k를 초과하는 순간 break를 사용하세요.

---

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력 단위 구분을 명확히 하기 위해 Python 코드를 기준(Ground Truth)으로 삼습니다.

```python
n, k = map(int, input().split())
total = 0

for _ in range(n):
    number = int(input())
    if total + number > k:
        break
    total += number
    print("%d" % number)
```

### 추가 해설
반복 중 종료 조건을 만나면 즉시 멈추도록 `break`를 사용했습니다.
