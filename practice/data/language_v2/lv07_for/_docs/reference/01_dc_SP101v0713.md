# [SP101v0713번] 13. [반복-for 기초2] n개의 숫자 중 짝수만 출력하기

## 1. 문제 설명
정수 n이 주어졌을 때, n개의 숫자를 각각 입력받고, 입력된 수 중 짝수만 출력하는 프로그램을 작성해 주세요.

출력은 입력된 순서를 유지하여 출력해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다. (1 ≤ n ≤ 100)

그 다음 줄부터 n개의 줄에 걸쳐 정수 하나씩 입력됩니다.

* **출력:**
입력된 숫자 중 짝수만 한 줄에 하나씩 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
5  
10  
7  
12  
9  
8
```

### 예시 출력 1
```text
10  
12  
8
```

---

## 4. 힌트
각 숫자를 입력받은 뒤, 2로 나누어 떨어지는 경우만 출력해 주세요.

---

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력 단위 구분을 명확히 하기 위해 Python 코드를 기준(Ground Truth)으로 삼습니다.

```python
n = int(input())

for _ in range(n):
    number = int(input())
    if number % 2 == 0:
        print("%d" % number)
```

반복문과 조건문을 이용해 문제에서 요구한 순서대로 값을 처리하면 됩니다.
