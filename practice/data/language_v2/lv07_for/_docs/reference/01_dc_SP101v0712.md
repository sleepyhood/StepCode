# [SP101v0712번] 12. [반복-for 기초1] 두 수 사이의 짝수의 합과 홀수의 평균 출력

## 1. 문제 설명
두 정수가 입력됩니다.

---

## 2. 입출력 설명

* **입력:**
정수 두개가 입력됩니다.

* **출력:**
입력받은 두 수 사이의 짝수의 합과 홀수의 평균(정수)를 출력해주세요.

---

## 3. 예시

### 예시 입력 1
```text
1 10
```

### 예시 출력 1
```text
even sum : 30
odd avg : 5
```

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력과 출력의 흐름이 보이도록 for문과 조건문을 사용해 문제를 그대로 구현합니다.

```python
a, b = map(int, input().split())

even_sum = 0
odd_sum = 0
odd_count = 0

start = a
end = b
if start > end:
    start, end = end, start

for i in range(start, end + 1):
    if i % 2 == 0:
        even_sum += i
    else:
        odd_sum += i
        odd_count += 1

odd_avg = odd_sum // odd_count
print("even sum : %d" % even_sum)
print("odd avg : %d" % odd_avg)
```

### 추가 해설
출력 조건을 맞춘 뒤 `%` 서식문자로 예시와 같은 형식을 맞춰 주면 됩니다.
