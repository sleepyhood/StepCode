# [SP101v0712번] 12. [반복-for 기초1] 두 수 사이의 짝수의 합과 홀수의 평균 출력

## 1. 문제 설명
두 정수가 입력됩니다.

두 정수 사이의 구간에 대해서 짝수의 합과 홀수의 평균을 출력하세요.

---

## 2. 입출력 설명

* **입력:**
정수 두개가 입력됩니다.

* **출력:**
입력받은 두 수 사이의 짝수의 합과 홀수의 평균(정수)를 출력해주세요.

---

## 3. 예시

### 예시 입력 1
```text
1 10
```

### 예시 출력 1
```text
even sum : 30
odd avg : 5
```

### 예시 입력 2
```text
10 1
```

### 예시 출력 2
```text
even sum : 30
odd avg : 5
```

### 예시 입력 3

5 20
```

### 예시 출력 3

```

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력 단위 구분을 명확히 하기 위해 Python 코드를 기준(Ground Truth)으로 삼습니다.

```python
a, b = map(int, input().split())

even_sum = 0
odd_sum = 0
odd_count = 0

start = a
end = b
if start > end:
    start, end = end, start

for i in range(start, end + 1):
    if i % 2 == 0:
        even_sum += i
    else:
        odd_sum += i
        odd_count += 1

print("even sum : %d" % even_sum)
print("odd avg : %d" % (odd_sum // odd_count))
```

### 추가 해설
출력하는 값은 `%` 서식문자를 사용해 예시의 형식에 맞춰 표현합니다.
