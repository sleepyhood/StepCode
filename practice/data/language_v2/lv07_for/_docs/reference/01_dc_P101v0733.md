# [P101v0733번] 33. [반복-for 응용] 같이 만나는 날은?

## 1. 문제 설명
3명의 알바생이 있습니다.

---

## 2. 입출력 설명

* **입력:**
정수 3개가 입력됩니다.

* **출력:**
처음 같이 만나는 날을 출력해주세요

---

## 3. 예시

### 예시 입력 1
```text
15
6
23
```

### 예시 출력 1
```text
690
```

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력과 출력의 흐름이 보이도록 for문과 조건문을 사용해 문제를 그대로 구현합니다.

```python
a = int(input())
b = int(input())
c = int(input())

for day in range(1, a * b * c + 1):
    if day % a == 0 and day % b == 0 and day % c == 0:
        print("%d" % day)
        break
```

### 추가 해설
반복을 진행하다가 문제에서 정한 종료 조건을 만나면 바로 멈추도록 구현했습니다.
