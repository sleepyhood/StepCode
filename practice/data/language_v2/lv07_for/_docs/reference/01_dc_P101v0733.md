# [P101v0733번] 33. [반복-for 응용] 같이 만나는 날은?

## 1. 문제 설명
3명의 알바생이 있습니다.

각 알바생은 n일 마다 한번씩 아르바이트에 나오고 있습니다.

다같이 만나서 일하는 날은 언제일까요?

---

## 2. 입출력 설명

* **입력:**
정수 3개가 입력됩니다.


( 1 <= n <= 30 )

* **출력:**
처음 같이 만나는 날을 출력해주세요

---

## 3. 예시

### 예시 입력 1
```text
15
6
23
```

### 예시 출력 1
```text
690
```

### 예시 입력 2
```text
6
10
12
```

### 예시 출력 2
```text
60
```

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력 단위 구분을 명확히 하기 위해 Python 코드를 기준(Ground Truth)으로 삼습니다.

```python
a = int(input())
b = int(input())
c = int(input())

for day in range(1, a * b * c + 1):
    if day % a == 0 and day % b == 0 and day % c == 0:
        print("%d" % day)
        break
```

### 추가 해설
반복 중 종료 조건을 만나면 즉시 멈추도록 `break`를 사용했습니다.
