# [SP101v0718번] 18. [반복-for 분기] 최대값과 최소값 출력

## 1. 문제 설명
최대 정수가 20개까지 입력됩니다.

---

## 2. 입출력 설명

* **입력:**
정수 20개 ( 0 이상 500 이하) 가 입력되며, 중간에 0이 입력될 수도 있습니다.

* **출력:**
0이 입력되기 전까지의 수들 중에서 가장 큰 수와 가장 작은 수를 출력해주세요.

---

## 3. 예시

### 예시 입력 1
```text
5 430 103 39 204 396 305 492 474 257 494 94 113 172 366 116 0 164 212 228
```

### 예시 출력 1
```text
max : 494
min : 5
```

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력과 출력의 흐름이 보이도록 for문과 조건문을 사용해 문제를 그대로 구현합니다.

```python
numbers = list(map(int, input().split()))
max_value = None
min_value = None

for number in numbers:
    if number == 0:
        break
    if max_value is None or number > max_value:
        max_value = number
    if min_value is None or number < min_value:
        min_value = number

print("max : %d" % max_value)
print("min : %d" % min_value)
```

### 추가 해설
출력 조건을 맞춘 뒤 `%` 서식문자로 예시와 같은 형식을 맞춰 주면 됩니다.
