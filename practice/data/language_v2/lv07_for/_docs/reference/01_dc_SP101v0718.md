# [SP101v0718번] 18. [반복-for 분기] 최대값과 최소값 출력

## 1. 문제 설명
최대 정수가 20개까지 입력됩니다.

중간에 0이 입력되면 입력을 멈추고 입력된 수들중에서

가장 큰 값과 작은 값을 출력해주세요.

Python으로 푸시는 분들은 넘어가셔도 괜찮습니다.

---

## 2. 입출력 설명

* **입력:**
정수 20개 ( 0 이상 500 이하) 가 입력되며, 중간에 0이 입력될 수도 있습니다.

* **출력:**
0이 입력되기 전까지의 수들 중에서 가장 큰 수와 가장 작은 수를 출력해주세요.

---

max : 494

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력 단위 구분을 명확히 하기 위해 Python 코드를 기준(Ground Truth)으로 삼습니다.

```python
max_value = 0
min_value = 0
first = 1

for number in map(int, input().split()):
    if number == 0:
        break
    if first == 1:
        max_value = number
        min_value = number
        first = 0
    else:
        if number > max_value:
            max_value = number
        if number < min_value:
            min_value = number

print("max : %d" % max_value)
print("min : %d" % min_value)
```

### 추가 해설
출력하는 값은 `%` 서식문자를 사용해 예시의 형식에 맞춰 표현합니다.
