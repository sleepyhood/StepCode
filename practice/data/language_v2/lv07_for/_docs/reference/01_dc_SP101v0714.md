# [SP101v0714번] 14. [반복-for 기초2] n개의 숫자 중 최대값 찾기

## 1. 문제 설명
정수 n이 주어졌을 때, n개의 정수를 입력받아 그 중 가장 큰 수를 출력하는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다. (1 ≤ n ≤ 100)

그 다음 줄부터 n개의 줄에 걸쳐 정수 a가 하나씩 입력됩니다. (-100 ≤ a ≤ 100)

* **출력:**
입력된 정수 중 가장 큰 값을 한 줄에 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
3  
10  
-5  
7
```

### 예시 출력 1
```text
10
```

---

## 4. 힌트
최대값을 저장할 변수를 선언하고, 입력받을 때마다 비교하여 큰 값을 갱신해 주세요.

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력 단위 구분을 명확히 하기 위해 Python 코드를 기준(Ground Truth)으로 삼습니다.

```python
n = int(input())
max_value = int(input())

for _ in range(n - 1):
    number = int(input())
    if number > max_value:
        max_value = number

print("%d" % max_value)
```

### 추가 해설
반복문과 조건문을 이용해 문제에서 요구한 순서대로 값을 처리하면 됩니다.
