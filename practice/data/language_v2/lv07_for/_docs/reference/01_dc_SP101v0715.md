# [SP101v0715번] 15. [반복-for 기초2] 입력된 n개의 합계와 평균을 출력

## 1. 문제 설명
정수 하나(N)가 입력된 후

N 개 만큼 추가로 입력이 됩니다.

짝수의 합계와 홀수의 평균을 출력해주세요.

Python으로 푸시는 분들은 넘어가셔도 괜찮습니다.

---

## 2. 입출력 설명

* **입력:**
정수 하나(N)가 입력된 후

N 개 만큼 정수가 추가로 입력이 됩니다.

* **출력:**
두번째 이후부터 입력된 값의

짝수의 합과 홀수의 평균(소수 둘째자리)를 출력해주세요.

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력 단위 구분을 명확히 하기 위해 Python 코드를 기준(Ground Truth)으로 삼습니다.

```python
n = int(input())
even_sum = 0
odd_sum = 0
odd_count = 0

for number in map(int, input().split()):
    if number % 2 == 0:
        even_sum += number
    else:
        odd_sum += number
        odd_count += 1

print("even sum : %d" % even_sum)
print("odd avg : %.2f" % (odd_sum / odd_count))
```

### 추가 해설
출력하는 값은 `%` 서식문자를 사용해 예시의 형식에 맞춰 표현합니다.
