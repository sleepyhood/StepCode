## 2. 입출력 설명

정수 하나(N)가 입력된 후

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력과 출력의 흐름이 보이도록 for문과 조건문을 사용해 문제를 그대로 구현합니다.

```python
n = int(input())
numbers = list(map(int, input().split()))

even_sum = 0
odd_sum = 0
odd_count = 0

for i in range(n):
    if numbers[i] % 2 == 0:
        even_sum += numbers[i]
    else:
        odd_sum += numbers[i]
        odd_count += 1

odd_avg = odd_sum / odd_count
print("even sum : %d" % even_sum)
print("odd avg : %.2f" % odd_avg)
```

### 추가 해설
출력 조건을 맞춘 뒤 `%` 서식문자로 예시와 같은 형식을 맞춰 주면 됩니다.
