# [P101v0719번] 19. [반복-for 분기] 1부터 n까지 출력 중 3은 건너뛰기

## 1. 문제 설명
정수 n이 주어졌을 때, 1부터 n까지 출력하되 숫자 3은 출력하지 않는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다. (1 ≤ n ≤ 100)

* **출력:**
1부터 n까지 중 숫자 3을 제외한 수를 한 줄에 하나씩 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
5
```

### 예시 출력 1
```text
1
2
4
5
```

---

## 4. 힌트
if문으로 i가 3인 경우 continue를 사용하여 출력하지 않고 건너뛰어 주세요.

---

<!-- ANSWER_START -->
## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력 단위 구분을 명확히 하기 위해 Python 코드를 기준(Ground Truth)으로 삼습니다.

```python
n = int(input())

for i in range(1, n + 1):
    if i == 3:
        continue
    print("%d" % i)
```

### 추가 해설
제외해야 하는 값은 `continue`로 건너뛰고, 필요한 값만 출력하도록 구현했습니다.
