# [SP101v0722번] 22. [반복-for 응용] 팩토리얼 구하기

## 1. 문제 설명
1부터 입력된 값까지 모두 곱한것을 펙토리얼이라고 합니다.

입력된 값의 n! 펙토리얼을 출력해주세요.

---

## 2. 입출력 설명

* **입력:**
정수 하나가 입력됩니다.


(1<= n <= 7)

* **출력:**
1부터 입력받은 수까지 모두 곱한 값을 출력해주세요.

---

## 3. 예시

### 예시 입력 1
```text
3
```

### 예시 출력 1
```text
6
```

### 예시 입력 2
```text
7
```

### 예시 출력 2
```text
5040
```

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력 단위 구분을 명확히 하기 위해 Python 코드를 기준(Ground Truth)으로 삼습니다.

```python
n = int(input())
result = 1

for i in range(1, n + 1):
    result *= i

print("%d" % result)
```
