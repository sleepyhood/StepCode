# [SP101v0722번] 22. [반복-for 응용] 팩토리얼 구하기

## 1. 문제 설명
1부터 입력된 값까지 모두 곱한것을 펙토리얼이라고 합니다.

---

## 2. 입출력 설명

* **입력:**
정수 하나가 입력됩니다.

* **출력:**
1부터 입력받은 수까지 모두 곱한 값을 출력해주세요.

---

## 3. 예시

### 예시 입력 1
```text
3
```

### 예시 출력 1
```text
6
```

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력과 출력의 흐름이 보이도록 for문과 조건문을 사용해 문제를 그대로 구현합니다.

```python
n = int(input())
result = 1

for i in range(1, n + 1):
    result *= i

print("%d" % result)
```

### 추가 해설
반복문을 순서대로 실행하면서 문제에서 요구한 값만 출력하거나 계산하면 됩니다.
