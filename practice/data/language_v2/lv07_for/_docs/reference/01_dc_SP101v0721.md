# [SP101v0721번] 21. [반복-for 응용] 1차 배열 좌표 출력

## 1. 문제 설명
정수 한개의 입력으로

---

## 2. 입출력 설명

* **입력:**
하나의 정수가 입력됩니다.

* **출력:**
배열의 순서에 맞게 출력예시와 같이 출력해주세요

---

## 3. 예시

### 예시 입력 1
```text
2
```

### 예시 출력 1
```text
N[0] N[1]
```

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력과 출력의 흐름이 보이도록 for문과 조건문을 사용해 문제를 그대로 구현합니다.

```python
n = int(input())
result = []

for i in range(n):
    result.append("N[%d]" % i)

print(" ".join(result))
```

### 추가 해설
반복문을 순서대로 실행하면서 문제에서 요구한 값만 출력하거나 계산하면 됩니다.
