# [SP101v0721번] 21. [반복-for 응용] 1차 배열 좌표 출력

## 1. 문제 설명
정수 한개의 입력으로

몇번째 칸인지를 순서대로 출력해주세요.

---

## 2. 입출력 설명

* **입력:**
하나의 정수가 입력됩니다.

* **출력:**
배열의 순서에 맞게 출력예시와 같이 출력해주세요

---

## 3. 예시

### 예시 입력 1
```text
2
```

### 예시 출력 1
```text
N[0] N[1]
```

### 예시 입력 2
```text
6
```

### 예시 출력 2
```text
N[0] N[1] N[2] N[3] N[4] N[5]
```

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력 단위 구분을 명확히 하기 위해 Python 코드를 기준(Ground Truth)으로 삼습니다.

```python
n = int(input())

for i in range(n):
    if i < n - 1:
        print("N[%d] " % i, end="")
    else:
        print("N[%d]" % i)
```

### 추가 해설
