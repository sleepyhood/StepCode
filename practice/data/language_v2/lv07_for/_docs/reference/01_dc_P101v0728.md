# [P101v0728번] 28. [반복-for 분기] 0나오기 전까지 최대값 찾기

## 1. 문제 설명
최대 정수가 10개까지 입력됩니다.

---

## 2. 입출력 설명

* **입력:**
정수 10개가 입력되며, 중간에 0이 입력될 수도 있습니다. 입력되는 정수는 0 이상입니다.

* **출력:**
0이 입력되기 전까지의 수들 중에서 가장 큰 수를 출력해주세요.

---

## 3. 예시

### 예시 입력 1
```text
3
12
45
38
5
15
15
7
54
234
```

### 예시 출력 1
```text
234
```

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력과 출력의 흐름이 보이도록 for문과 조건문을 사용해 문제를 그대로 구현합니다.

```python
max_value = 0

for _ in range(10):
    number = int(input())
    if number == 0:
        break
    if number > max_value:
        max_value = number

print("%d" % max_value)
```
