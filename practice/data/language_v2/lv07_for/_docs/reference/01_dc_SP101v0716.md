# [SP101v0716번] 16. [반복-for 분기] 1부터 n까지 7의 배수 만나면 멈추기

## 1. 문제 설명
정수 n이 주어졌을 때, 1부터 n까지 7의 배수를 처음 만나면 그 수를 출력하고 종료하는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다. (7 ≤ n ≤ 100)

* **출력:**
7의 배수를 처음 발견한 순간 그 수를 출력하고 종료합니다.

---

## 3. 예시

### 예시 입력 1
```text
20
```

### 예시 출력 1
```text
7
```

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력과 출력의 흐름이 보이도록 for문과 조건문을 사용해 문제를 그대로 구현합니다.

```python
n = int(input())

for i in range(1, n + 1):
    if i % 7 == 0:
        print("%d" % i)
        break
```

### 추가 해설
반복을 진행하다가 문제에서 정한 종료 조건을 만나면 바로 멈추도록 구현했습니다.
