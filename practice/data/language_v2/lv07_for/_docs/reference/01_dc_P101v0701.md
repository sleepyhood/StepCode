# [P101v0701번] 01. [반복-for 기초1] 1부터 5까지 출력하기

## 1. 문제 설명
for문을 사용하여 1부터 5까지의 정수를 한 줄에 하나씩 출력하는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
입력은 없습니다.

* **출력:**
1부터 5까지의 수를 순서대로 한 줄에 하나씩 출력합니다.

### 예시 입력 1
```text

```

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력과 출력의 흐름이 보이도록 for문과 조건문을 사용해 문제를 그대로 구현합니다.

```python
for i in range(1, 6):
    print("%d" % i)
```
