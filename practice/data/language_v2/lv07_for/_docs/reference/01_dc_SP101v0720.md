# [SP101v0720번] 20. [반복-for 응용] 두 수 사이 수 들중 1의자리가 1인값은 몇 개일까?

## 1. 문제 설명
두 정수가 입력됩니다.

---

## 2. 입출력 설명

* **입력:**
두개의 정수가 입력됩니다.

* **출력:**
두 정수 사이의 구간에 중에서 1의자리가 1인값을 모두 출력하고 다음줄에 몇개인지 출력하세요.

---

## 3. 예시

### 예시 입력 1
```text
26 51
```

### 예시 출력 1
```text
31 41 51 
3
```

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력과 출력의 흐름이 보이도록 for문과 조건문을 사용해 문제를 그대로 구현합니다.

```python
a, b = map(int, input().split())
result = []
count = 0

for i in range(a, b + 1):
    if i % 10 == 1:
        result.append("%d" % i)
        count += 1

print(" ".join(result))
print("%d" % count)
```

### 추가 해설
반복문을 순서대로 실행하면서 문제에서 요구한 값만 출력하거나 계산하면 됩니다.
