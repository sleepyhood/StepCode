# [P101v0730번] 30. [반복-for 응용] 약수의 개수 출력

## 1. 문제 설명
정수 하나가 입력됩니다.

약수개수를 출력해주세요.

약수란 나누어 떨어지는 수를 약수라고 합니다.

ex) 10의 약수의 수

4개 (1, 2, 5, 10)

---

## 2. 입출력 설명

* **입력:**
정수(1이상 ~ 1000이하)하나가 입력됩니다.

* **출력:**
입력된 수의 약수 개수를 출력해주세요.

---

## 3. 예시

### 예시 입력 1
```text
10
```

### 예시 출력 1
```text
4
```

### 예시 입력 2
```text
370
```

### 예시 출력 2
```text
8
```

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력 단위 구분을 명확히 하기 위해 Python 코드를 기준(Ground Truth)으로 삼습니다.

```python
n = int(input())
count = 0

for i in range(1, n + 1):
    if n % i == 0:
        count += 1

print("%d" % count)
```
