# [P101v0730번] 30. [반복-for 응용] 약수의 개수 출력

## 1. 문제 설명
정수 하나가 입력됩니다.

---

## 2. 입출력 설명

* **입력:**
정수(1이상 ~ 1000이하)하나가 입력됩니다.

* **출력:**
입력된 수의 약수 개수를 출력해주세요.

---

## 3. 예시

### 예시 입력 1
```text
10
```

### 예시 출력 1
```text
4
```

## [정답 및 해설 (Ground Truth)]

### 모범 코드 (Python)
입력과 출력의 흐름이 보이도록 for문과 조건문을 사용해 문제를 그대로 구현합니다.

```python
n = int(input())
count = 0

for i in range(1, n + 1):
    if n % i == 0:
        count += 1

print("%d" % count)
```

### 추가 해설
반복문을 순서대로 실행하면서 문제에서 요구한 값만 출력하거나 계산하면 됩니다.
