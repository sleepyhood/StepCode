# [P101v0720번] 20. [반복-for 분기] 음수를 만나면 출력 중단하기

## 1. 문제 설명
정수 n이 주어졌을 때, n개의 정수를 차례대로 입력받고, 음수가 나타나기 전까지 입력된 수를 그대로 출력하는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다. (1 ≤ n ≤ 100)

* **출력:**
입력된 수를 한 줄씩 출력하다가 음수를 만나면 출력하지 않고 종료합니다.

---

## 3. 예시

### 예시 입력 1
```text
6  
3  
7  
0  
-1  
8  
9
```

### 예시 출력 1
```text
3  
7  
0
```
