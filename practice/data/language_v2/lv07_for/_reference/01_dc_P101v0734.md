# [P101v0734번] 34. [반복-for 응용] 칠판 개표 결과 출력하기

## 1. 문제 설명
투표가 끝난 뒤에는 칠판에 선을 그어 개표를 표시합니다.

---

## 2. 입출력 설명

* **입력:**
정수 n이 한 줄에 입력됩니다. (1 ≤ n ≤ 100)

* **출력:**
n표를 받은 경우 칠판에 그려지는 결과를 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
13
```

### 예시 출력 1
```text

```
