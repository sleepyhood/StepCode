# [P101v0717번] 17. [반복-for 기초2] n개의 숫자 중 최소값 찾기

## 1. 문제 설명
정수 n이 주어졌을 때, n개의 정수를 입력받아 그 중 가장 작은 수를 출력하는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다. (1 ≤ n ≤ 100)

그 다음 줄부터 n개의 줄에 걸쳐 정수 a가 하나씩 입력됩니다. (-100 ≤ a ≤ 100)

* **출력:**
입력된 정수 중 가장 작은 값을 한 줄에 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
4  
15  
22  
-7  
0
```

### 예시 출력 1
```text
-7
```
