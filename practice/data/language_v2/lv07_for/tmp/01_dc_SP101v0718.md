# [SP101v0718번] 18. [반복-for 분기] 최대값과 최소값 출력

## 1. 문제 설명
최대 정수가 20개까지 입력됩니다.

중간에 0이 입력되면 입력을 멈추고 입력된 수들중에서

가장 큰 값과 작은 값을 출력해주세요.

Python으로 푸시는 분들은 넘어가셔도 괜찮습니다.

---

## 2. 입출력 설명

* **입력:**
정수 20개 ( 0 이상 500 이하) 가 입력되며, 중간에 0이 입력될 수도 있습니다.

* **출력:**
0이 입력되기 전까지의 수들 중에서 가장 큰 수와 가장 작은 수를 출력해주세요.

---

## 3. 예시

### 예시 입력 1
```text
5 430 103 39 204 396 305 492 474 257 494 94 113 172 366 116 0 164 212 228
```

### 예시 출력 1
```text
max : 494
min : 5
```

### 예시 입력 2
```text
295 165 448 128 323 345 87 459 49 361 234 118 279 250 135 66 0 401 185 265
```

### 예시 출력 2
```text
max : 459
min : 49
```

### 예시 입력 3
```text
394 242 428 252 227 268 294 230 229 147 81 36 313 178 342 392 214 239 23 481
```

### 예시 출력 3
```text
max : 481
min : 23
```
