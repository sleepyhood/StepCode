# [P101v0732번] 32. [반복-for 응용] 2의 n 제곱 구하기

## 1. 문제 설명
정수가 하나 입력됩니다.

2의 n제곱의 값을 출력해주세요

n 제곱이란 같은 값을 n번 곱한다는 말입니다.

ex) 2의 10제곱

2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 = 1024

---

## 2. 입출력 설명

* **입력:**
정수 하나가 입력됩니다.


(0 <= n <= 10)

* **출력:**
2를 입력받은 수 만큽 곱하여 출력해주세요.

---

## 3. 예시

### 예시 입력 1
```text
10
```

### 예시 출력 1
```text
1024
```
