# [P101v0718번] 18. [반복-for 분기] 1부터 n까지 출력하다가 5에서 멈추기

## 1. 문제 설명
정수 n이 주어졌을 때, 1부터 n까지 출력하되 숫자 5를 출력한 뒤 반복을 멈추는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 n이 주어집니다. (5 ≤ n ≤ 100)

* **출력:**
1부터 시작하여 5까지 출력한 후 멈춥니다.

---

## 3. 예시

### 예시 입력 1
```text
8
```

### 예시 출력 1
```text
1  
2  
3  
4  
5
```
