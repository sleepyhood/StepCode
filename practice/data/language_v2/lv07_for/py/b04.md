### Q1. Trace 1. 입력 위치와 누적

각 반복 직후 i, num, sum을 표에 채우세요.

```c
n = 3
sumv = 0
for i in range(n):
    num = int(input())
    sumv += num
```

### Q3. Reverse 1. n 추론

```c

for i in range(1, n + 1):
    if i % 2 == 1:
        sumv += i
print('%d' % sumv)
```
