# [P101v0402번] 02. [연산자-산술2] 나눈 몫을 출력

## 1. 문제 설명
정수 2개 입력받아 앞의 수에서 뒤의 수로 나눈 몫을 출력하세요

---

## 2. 입출력 설명

* **입력:**
정수 2개가 입력됩니다.

* **출력:**
입력한 앞정수에서 뒤 정수로 나눈 몫을 출력예시와 같이 출력하세요

---

## 3. 예시

### 예시 입력 1
```text
7 3
```

### 예시 출력 1
```text
2
```

---

## 4. 힌트
정수 나누기와 정수는 소수가 아닌 정수부분만 나타납니다.

즉 나누기는 몫을 나타내는 연산자 입니다.
