# [P101v0412번] 12. [연산자-논리1] 두가지 조건이 모두(&&) 성립되는지 출력

## 1. 문제 설명
A학생과 B학생의 코딩점수와 수학점수를 입력하였습니다.

앞의 학생이 뒤의 학생보다 코딩점수도 수학점수도 높으면(초과) 참(1)을 하나라도 낮으면 거짓(0)을 출력하세요(둘다 높으면)

(처음 입력 받은 숫자가 세번째 입력 받은 숫자 보다 크고, 두번째 입력 받은 숫자가 네번째 입력 받은 숫자보다 크면)

---

## 2. 입출력 설명

* **입력:**
정수 4개가 입력됩니다.

입력되는 값은

A학생의 코딩점수와 수학점수(예 : 80 85)

B학생의 코딩점수와 수학점수(예 : 85 90)입니다.

* **출력:**
입력한 4개의 정수를 2개씩 비교하여 출력예시와 같이 출력하세요.

(예)

A의 코딩점수 80 > B의 코딩점수 85

A의 수학점수 85 > B의 수학점수 90

첫번째 질문은 거짓이고, 두번째 질문도 거짓이므로 0이 출력됩니다.
