# [P101v0404번] 04. [연산자-산술4] 나눈 값의 몫과 나머지 출력

## 1. 문제 설명
정수 2개 입력받아 앞의 수에서 뒤의 수로 나눈 몫과 나머지를 출력하세요

---

## 2. 입출력 설명

* **입력:**
정수 2개가 입력됩니다.

* **출력:**
입력한 두 정수의 값과 몫과 나머지을 출력예시와 같이 출력하세요

---

## 3. 예시

### 예시 입력 1
```text
7 3
```

### 예시 출력 1
```text
7 / 3 = 2 ... 1
```

---

## 4. 힌트
정수 나누기와 정수는 소수가 아닌 정수부분만 나타납니다.

몫은 / 를 사용합니다.

나머지는 구하는 연산자는 % 입니다.

두가지를 적절하게 섞어서 출력예시와 같이 출력하세요
