# [P101v0414번] 14. [연산자-논리3] 한가지라도(||) 성립되는지 출력

## 1. 문제 설명
자격증 시험을 보았습니다.

자격증에는 3가지의 과목이 있는데

한 과목이라도 40점 밑이면 불합격(1) 입니다.

3과목 점수를 입력 후 합격(0) 불합격(1)을 출력하세요

---

## 2. 입출력 설명

* **입력:**
3개의 과목 점수로 이루어진 정수 3개가 입력됩니다.

* **출력:**
입력한 3개의 정수를 각각 비교하여 출력예시와 같이 출력하세요

---

## 3. 예시

### 예시 입력 1
```text
95 90 100
```

### 예시 출력 1
```text
0
```

### 예시 입력 2
```text
39 60 80
```

### 예시 출력 2
```text
1
```

### 예시 입력 3
```text
30 32 36
```

### 예시 출력 3
```text
1
```
