# [P101v0418번] [후치 연산(Post-Increment, Post-Decrement)]

## 1. 문제 설명
[후치 연산(Post-Increment, Post-Decrement)]

변수를 증가(++) 또는 감소(--)할 때, 연산이 수행된 후에변수의 원래 값이 먼저 사용되는 방식입니다.

a++→a값을 먼저 사용하고 나서 증가한다.a--→a값을 먼저 사용하고 나서 감소한다.

[C언어]

변수 뒤에다가 증가 감소 기호를 2번씩 적으면,변수의 값을가져온 다음에 적용됩니다.

---

## 2. 입출력 설명

* **입력:**
2개의 정수가 주어집니다.

* **출력:**
첫번째 줄에는 첫번째 입력한 값을 후치증가한 값을 출력해주세요.

두번째 줄에는 두번째 입력한 값을 후치감소한 값을 출력해주세요.

세번째 줄에는 2개의 정수를 출력합니다. (후치 연산의 결과가 반영되어야 합니다.)

---

## 3. 예시

### 예시 입력 1
```text
3
7
```

### 예시 출력 1
```text
3
7
4 6
```
