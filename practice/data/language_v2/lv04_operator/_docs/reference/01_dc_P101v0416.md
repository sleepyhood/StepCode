# [P101v0416번] 16. [연산자-증가, 감소1] 전치 증가, 감소 연산자

## 1. 문제 설명
변수가 가지고 있는 값을 증가시키거나, 감소하려면 다음과 같이 표현이 가능합니다.

예를 들어 정수 변수가 있을 때:

n = n + 1 // n의 값을 1만큼 증가하기

n = n - 1 // n의 값을 1만큼 감소하기

하지만, 이 부분을 축약형태로 표현이 가능한데, 이를전치연산, 후치연산으로 표현합니다.

[전치 연산(Pre-Increment, Pre-Decrement)]

변수를 증가(++) 또는 감소(--)할 때, 연산이 먼저 수행된 후에 해당 변수가 사용되는 방식입니다.

++a→a값을 먼저 증가시키고 나서 사용한다.--a→a값을 먼저 감소시키고 나서 사용한다.

[C언어]

변수 앞에다가 증가 감소 기호를 2번씩 적으면, 연산이적용된 다음에변수의 값을 가져오게 됩니다.

---

## 2. 입출력 설명

* **입력:**
2개의 정수가 주어집니다.

* **출력:**
첫번째 줄에는 첫번째 입력한 값을 전치증가한 값을 출력해주세요.

두번째 줄에는 두번째 입력한 값을 전치감소한 값을 출력해주세요.
