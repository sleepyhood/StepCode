# [P101v0417번] 17. [연산자-증가, 감소2] 전치 증가, 감소 연산자 문제

## 1. 문제 설명
이번 실험에서는 AI 로봇이 입력된 숫자를 특정 규칙에 따라 조작하는 능력을 테스트해야 합니다.

연구원이 로봇에게 아래의 규칙을 따라 변수를 변경하도록 지시합니다.

x의 값을 먼저 1 증가시킨 후a에 저장한다.ex) a = ++x; // a에 저장할껀데 x를 먼저 1을 증가 시키고(전치증가연산자)a의 값을 먼저 1 증가시킨 후b에 저장한다.b의 값을 먼저 1 증가시킨 후c에 저장한다.c의 값을 먼저 1 감소시킨 후d에 저장한다.d의 값을 먼저 1 감소시킨 후e에 저장한다.최종적으로 입력과 모든 변수들의값을 출력해야 한다.

x가 입력으로 주어지며, 각 규칙에 따라 변수들의 값을 출력해야 합니다.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수x가 주어집니다. (1 ≤ x ≤ 100)

* **출력:**
첫번째 줄에는 입력된 정수x를,

두번째 줄에는 연산에 사용된a,b,c,d,e변수의 값들을 출력합니다.

(단, 로봇에게 입력한 규칙이 모두 끝난 다음에 출력해야 합니다.)

---

## 3. 예시

### 예시 입력 1
```text
5
```

### 예시 출력 1
```text
6
7 8 7 6 6
```
