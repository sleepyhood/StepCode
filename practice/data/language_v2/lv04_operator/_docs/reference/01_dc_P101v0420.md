# [P101v0420번] 20. [연산자-증가, 감소5] 증감 문제

## 1. 문제 설명
AI 시스템은 정수 `x`를 입력받아 특정 연산을 수행한 뒤, `x`, `y`, `z`의 값을 출력해야 합니다.

이번 실험에서는 전치 증가(++x)와 후치 증가(x++)를 구분할 수 있는지를 확인합니다.

주어진 연산은 다음과 같이 진행됩니다:

(1) y = ++x + x++;

(2) z = ++x + ++y;

최종적으로 `x`, `y`, `z`의 값을 출력하는 프로그램을 작성하세요.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수 x가 주어집니다. (1 ≤ x ≤ 100)

* **출력:**
연산이 끝난 후, 최종적으로 x, y, z의 값을 공백으로 구분하여 출력하세요.

---

## 3. 예시

### 예시 입력 1
```text
5
```

### 예시 출력 1
```text
8 13 21
```

---

## 4. 힌트
초기 x = 5

1️⃣ ++x → x = 6, 사용된 값 = 6

2️⃣ x++ → 사용된 값 = 6, 이후 x = 7

→ y = 6 + 6 = 12

3️⃣ ++x → x = 8, 사용된 값 = 8

4️⃣ ++y → y = 13, 사용된 값 = 13

→ z = 8 + 13 = 21

그러나 y는 12에서 시작하므로 ++y는 13 → z = 8 + 13 = 21

그러나 출력은 x, y, z = 8 13 21
