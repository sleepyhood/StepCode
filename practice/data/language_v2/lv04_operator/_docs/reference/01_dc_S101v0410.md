# [S101v0410번] 10. [self-연산자-논리1] 게임 레벨과 경험치의 승리

## 1. 문제 설명
두 친구의 케릭터의 래벨과 경험치를 입력하였습니다.

앞의 친구가 뒤의 학생보다 레벨도 경험치도 높으면(초과) 참(1)을 그렇지 않으면 거짓(0)을 출력하세요

---

## 2. 입출력 설명

* **입력:**
2명의 게임 케릭터 레벨과 경험치가 입력됩니다.

입력되는 값은

앞의 친구의 케릭터 레벨과 경험치 점수

뒤의 친구의 케릭터 레벨과 경험치 점수 입니다.

* **출력:**
입력한 4개의 정수를 2개씩 비교하여 출력예시와 같이 출력하세요

---

## 3. 예시

### 예시 입력 1
```text
8 250 5 100
```

### 예시 출력 1
```text
1
```

### 예시 입력 2

```text
0
```

### 예시 입력 4
```text
5 300 8 600
```

### 예시 출력 4
```text
0
```
