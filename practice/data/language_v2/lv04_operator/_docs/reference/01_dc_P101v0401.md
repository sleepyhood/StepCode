# [P101v0401번] 01. [연산자-산술1] 사칙연산 출력

## 1. 문제 설명
정수 2개 입력받아 사칙연산(+ - * /)한 값을 출력하세요

---

## 2. 입출력 설명

* **입력:**
정수 2개가 입력됩니다.

* **출력:**
입력한 두 정수의 4칙연산인 + - * /를 출력예시와 같이 출력하세요

---

## 3. 예시

### 예시 입력 1
```text
8 2
```

### 예시 출력 1
```text
8 + 2 = 10
8 - 2 = 6
8 * 2 = 16
8 / 2 = 4
```
