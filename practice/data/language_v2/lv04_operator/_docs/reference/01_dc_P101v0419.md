# [P101v0419번] 19. [연산자-증가, 감소4] 후치 증가, 감소 연산자 문제

## 1. 문제 설명
AI로봇은 숫자를 기억하고 조작하는 능력을 가지고 있습니다.

아래의 연산을 정확하게 수행하도록 프로그래밍해야 합니다.

x의 값을p에 저장한 후,x의 값을 1 증가시킨다.p의 값을q에 저장한 후,p의 값을 1 증가시킨다.q의 값을r에 저장한 후,q의 값을 1 감소시킨다.r의 값을s에 저장한 후,r의 값을 1 감소시킨다.최종적으로 입력과 모든 변수들의값을 출력해야 한다.

x가 입력으로 주어지며, 각 규칙에 따라 변수들의 값을 출력해야 합니다.

---

## 2. 입출력 설명

* **입력:**
첫 번째 줄에 정수x가 주어집니다. (1 ≤ x ≤ 100)

* **출력:**
첫번째 줄에는 입력된 정수x를,

두번째 줄에는 연산에 사용된p,q,r,s변수의 값들을 출력합니다.

(단, 로봇에게 입력한 규칙이 모두 끝난 다음에 출력해야 합니다.)

---

## 3. 예시

### 예시 입력 1
```text
5
```

### 예시 출력 1
```text
6
6 4 4 5
```
