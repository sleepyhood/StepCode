### Q2. MCQ 2. and / or / not

다음 코드의 출력으로 올바른 것을 고르세요.

- 출력은 서식문자(%)를 사용한다.

```c
a = 2
b = 0
print('%s' % ((a > 0) and (b > 0)))
print('%s' % ((a > 0) or (b > 0)))
print('%s' % (not (a > 0)))
```

- **A**: True True False
- **B**: False True False
- **C**: False False True
- **D**: True False True
