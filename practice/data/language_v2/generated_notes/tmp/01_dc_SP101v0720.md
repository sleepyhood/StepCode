# [SP101v0720번] 20. [반복-for 응용] 두 수 사이 수 들중 1의자리가 1인값은 몇 개일까?

## 1. 문제 설명
두 정수가 입력됩니다.

두 정수 사이의 구간에 중에서 1의자리가 1인값은 모두 몇개일지 출력하세요.

ex)

입력 : 1 50

출력 : 1 11 21 31 41

5

---

## 2. 입출력 설명

* **입력:**
두개의 정수가 입력됩니다.

* **출력:**
두 정수 사이의 구간에 중에서 1의자리가 1인값을 모두 출력하고 다음줄에 몇개인지 출력하세요.

---

## 3. 예시

### 예시 입력 1
```text
26 51
```

### 예시 출력 1
```text
31 41 51 
3
```

### 예시 입력 2
```text
38 100
```

### 예시 출력 2
```text
41 51 61 71 81 91 
6
```

### 예시 입력 3
```text
85 87
```

### 예시 출력 3
```text
0
```
