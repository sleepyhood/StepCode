**핵심 문제**
현재 `doingcoding` 관리자 로그인 흐름은 `csrftoken` 확보까지는 성공했습니다. 로그 기준:

- `[관리자 로그인 준비] /api/profile 접속`
- `[접속] http://edu.doingcoding.com/api/profile (시도 1/3, 상태: 200)`
- `[관리자 로그인 준비] /api/profile 상태: 200`
- `[관리자 로그인 준비] csrftoken 확보 성공`

그 다음 바로 아래 에러가 납니다.

- `Locator.click: Timeout 30000ms exceeded.`
- `waiting for locator("//*[@id=\"app\"]/form/div[1]/div/div/input")`

이 뜻은 명확합니다.

- `ensure_doingcoding_admin_csrf()`가 `/api/profile`에서 CSRF를 확보한 뒤,
- 브라우저가 여전히 `/api/profile` 상태에 머물러 있음
- 그런데 `login_doingcoding_admin()`가 곧바로 로그인 폼 XPath를 찾으려 함
- 즉, **로그인 페이지로 돌아가지 않고 API 응답 페이지에서 로그인 input을 찾고 있음**

**즉시 수정해야 하는 부분**
가장 먼저 고쳐야 하는 것은 이것입니다.

- **`login_doingcoding_admin()`에서 `ensure_doingcoding_admin_csrf()` 호출 후, 반드시 `http://edu.doingcoding.com/admin/login`으로 다시 이동해야 함**
- 그리고 그 다음에만 로그인 input selector를 찾고 ID/PW 입력을 시작해야 함

이 부분이 지금 가장 중요합니다.  
**강조: CSRF seed page와 로그인 form page를 분리해야 합니다.**

현재는 이 둘이 섞여 있습니다.

- CSRF 확보용 페이지: `/api/profile`
- 실제 로그인 폼 페이지: `/admin/login`

이 두 URL의 역할이 다르므로, CSRF 확보 후 로그인 폼으로 재진입하는 단계가 반드시 필요합니다.

**수정해야 할 구체 흐름**
`login_doingcoding_admin(page, username, password, logger=None)` 내부 흐름을 아래처럼 바꿔야 합니다.

1. `ensure_doingcoding_admin_csrf(page, logger)` 호출
2. `csrftoken` 확보 성공
3. **즉시 `http://edu.doingcoding.com/admin/login`으로 `goto`**
4. 로그인 폼 selector 대기
   - `//*[@id="app"]/form/div[1]/div/div/input`
   - `//*[@id="app"]/form/div[2]/div/div/input`
5. 그 다음에만 ID/PW 입력
6. 이후 submit fallback 체인 수행
   - locator Enter
   - keyboard Enter
   - form requestSubmit/submit
   - GO 버튼 force click
   - 로그인 버튼 force click
   - JS click
7. 성공 시 `/admin/problems` 이동

**중요한 설계 원칙**
다음 세션에서 이걸 건드릴 때 아래 원칙을 유지해야 합니다.

1. `ensure_doingcoding_admin_csrf()`는 CSRF 확보만 책임져야 함
- `/api/profile`
- `/api/website`
- `/admin/login`
이 중 어디서 토큰을 얻든 상관없이, 반환값은 `csrftoken`만 주면 됨
- 로그인 폼 입력을 시작하면 안 됨

2. `login_doingcoding_admin()`는 폼 입력 전에 로그인 페이지 상태를 보장해야 함
- 즉, `ensure_doingcoding_admin_csrf()` 호출 후 현재 URL이 무엇이든 상관없이
- **반드시 `/admin/login`으로 재이동**
- 폼이 실제로 보이는지 확인 후 진행

3. 로그도 같이 강화해야 함
다음 로그가 있으면 디버깅이 쉬워집니다.
- `[관리자 로그인] csrf 확보 후 /admin/login 재진입`
- `[관리자 로그인] 로그인 폼 확인 완료`
- 실패 시 현재 URL 출력
