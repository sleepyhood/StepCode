# [P101v0306번] 06. [입력-정수6] 연봉을 입력하여 월급계산 출력

## 1. 문제 설명
월급계산기를 만들어봅니다.

---

## 2. 입출력 설명

* **입력:**
연봉(정수)이 입력됩니다.

입력되는 범위는 20,000,000~210,000,000입니다. 그 이외의 값은 신경쓰지 않으셔도 됩니다.

* **출력:**
입력받은 연봉의 월급을 계산하여 출력해주세요.

---

## 3. 예시

### 예시 입력 1
```text
30000000
```

### 예시 출력 1
```text
2500000
```

### 예시 입력 2
```text
120000000
```

### 예시 출력 2
```text
10000000
```
