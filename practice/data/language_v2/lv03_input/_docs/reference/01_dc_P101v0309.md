# [P101v0309번] 09. [입력-정수9] 정수 3개를 입력하여 평균을 출력

## 1. 문제 설명

---

## 2. 입출력 설명

* **입력:**
정수 3개가 입력됩니다.

입력되는 범위는 0~100입니다. 그 이외의 값은 신경쓰지 않으셔도 됩니다.

* **출력:**
입력받은 수의 평균(몫)을 출력해주세요.


```text

```

### 예시 출력 2
