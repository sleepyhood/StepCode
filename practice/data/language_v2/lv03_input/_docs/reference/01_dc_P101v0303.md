# [P101v0303번] 03. [입력-정수3] 입력한 정수의 다음수와 다다음수 출력

## 1. 문제 설명
정수 하나 입력받아 다음 숫자와 다다음 숫자를 출력하세요.

---

## 2. 입출력 설명

* **입력:**
정수 1개 입력됩니다.

입력되는 범위는 0~1000입니다. 그 이외의 값은 신경쓰지 않으셔도 됩니다.

* **출력:**
입력한 정수 다음수와, 다다음수를 출력하세요.

---

## 3. 예시

### 예시 입력 1
```text
0
```

### 예시 출력 1
```text
1 2
```

### 예시 입력 2
```text
24
```

### 예시 출력 2
```text
25 26
```
