# [S101v0311번] 11. [self-입력-문자3] 문자 이전 글자 출력

## 1. 문제 설명
문자 1개 입력받아 그 이전글자를 출력하세요.

---

## 2. 입출력 설명

* **입력:**
문자 1개 입력됩니다.

알파벳 대소문자 상관없이 B ~ Z까지만 입력됩니다. 그 이외의 입력값은 신경쓰지 않으셔도 됩니다.

* **출력:**
입력한 문자의 이전 문자를 출력하세요.

---

### 예시 입력 1

### 예시 출력 1
```text
O
```

### 예시 입력 2
```text

```
