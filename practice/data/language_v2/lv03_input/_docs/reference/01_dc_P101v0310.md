# [P101v0310번] 10. [입력-실수1] 입력한 실수 출력

## 1. 문제 설명
실수 하나를 입력받아 소수점 6자리까지 출력하세요.

---

## 2. 입출력 설명

* **입력:**
실수 1개 입력됩니다.

입력되는 범위는 0~10입니다. 그 이외의 값은 신경쓰지 않으셔도 됩니다.

* **출력:**
입력한 실수를 그대로 출력하세요.

---

## 3. 예시

### 예시 입력 1
```text
3.14
```

### 예시 출력 1
```text
3.140000
```

### 예시 입력 2
```text
2.4357579
```

### 예시 출력 2
```text
2.435758
```
