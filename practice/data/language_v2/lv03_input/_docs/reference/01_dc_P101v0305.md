# [P101v0305번] 05. [입력-정수5] 월급을 입력하여 연봉계산 출력

## 1. 문제 설명
연봉계산기를 만들어봅니다.

---

## 2. 입출력 설명

* **입력:**
월급(정수)이 입력됩니다.

입력되는 범위는 2,000,000~10,000,000입니다. 그 이외의 값은 신경쓰지 않으셔도 됩니다.

* **출력:**
연봉은 1년간 받은 월급의 총액을 의미합니다.

총액을 계산해 출력해주세요.

---

## 3. 예시

### 예시 입력 1
```text
2000000
```

### 예시 출력 1
```text
24000000
```

### 예시 입력 2
```text
3000000
```

### 예시 출력 2
```text
36000000
```
