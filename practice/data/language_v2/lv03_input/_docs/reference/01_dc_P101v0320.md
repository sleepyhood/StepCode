# [P101v0320번] 20. [입력-문자5] 소문자를 대문자로 출력

## 1. 문제 설명
소문자를 1개 입력받아 대문자로 변경하여 출력하세요.

---

## 2. 입출력 설명

* **입력:**
문자 1개 입력됩니다.

알파벳 소문자만 입력됩니다. 그 이외의 입력값은 신경쓰지 않으셔도 됩니다.

* **출력:**
입력한 소문자를 대문자로 바꿔서 출력하세요.

---

## 3. 예시

### 예시 입력 1
```text
c
```

### 예시 출력 1
```text
C
```

### 예시 입력 2
```text
o
```

### 예시 출력 2
```text
O
```

### 예시 입력 3
```text
d
```

### 예시 출력 3
```text
D
```
