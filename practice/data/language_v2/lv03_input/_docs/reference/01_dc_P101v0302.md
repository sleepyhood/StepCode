# [P101v0302번] 02. [입력-정수2] 입력한 정수 + 100 출력

## 1. 문제 설명
정수 하나 입력받아 +100한 값을 구하세요.

---

## 2. 입출력 설명

* **입력:**
정수 1개 입력됩니다.

입력되는 범위는 0~100입니다. 그 이외의 값은 신경쓰지 않으셔도 됩니다.

* **출력:**
입력한 정수에 100을 더한 값을 출력하세요.

---

## 3. 예시

### 예시 입력 1
```text
10
```

### 예시 출력 1
```text
110
```

### 예시 입력 2
```text
50
```

### 예시 출력 2
```text
150
```
