# [P101v0314번] 14. [입력-실수5] 예금액(정수)과 이자율(실수)을 입력하여 이자를 출력

## 1. 문제 설명
1년간 예금을 하려고합니다.

예금할 예금액(정수)과 받고싶은 이자율(실수)를 입력받아 1년 후 받을 이자를 구해주는 계산기를 만들어 봅니다.

---

## 2. 입출력 설명

* **입력:**
예금액과 이자율이 입력됩니다.

입력되는 예금액은 0~100,000,000과 이자율은 0.0(0%) ~ 1.0(100%) 입니다. 그이외의 값은 신경쓰지 않으셔도 됩니다.

* **출력:**
입력한 예금액의 이자율에대한 이자금액을 계산하여 정수부분만 출력하세요

소수 이하자리는 표시하지 않습니다.

---

## 3. 예시

### 예시 입력 1
```text
1000000 0.03
```

### 예시 출력 1
```text
30000
```

### 예시 입력 2
```text
12000000 0.123
```

### 예시 출력 2
```text
1476000
```
