## 1. 문제 설명
대문자를 1개 입력받아 다음 알파벳의 소문자로 변경하여 출력하세요.

---

## 2. 입출력 설명

* **입력:**
문자 1개 입력됩니다.

알파벳 대문자 A ~ Y까지만 입력됩니다. 그 이외의 입력값은 신경쓰지 않으셔도 됩니다.

* **출력:**
입력한 대문자를 소문자로 바꿔서 다음 문자로 출력하세요.
