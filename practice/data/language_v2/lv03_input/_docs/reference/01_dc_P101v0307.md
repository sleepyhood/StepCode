# [P101v0307번] 07. [입력-정수7] 가로와 세로를 입력하여 사각형 넓이 출력

## 1. 문제 설명
가로의 크기와 세로의 크기를 입력받아 사각형의 넓이를 구하는 프로그램을 만들어 봅니다.

---

## 2. 입출력 설명

* **입력:**
가로크기(정수)와 세로크기(정수) 2개가 입력됩니다.

입력되는 범위는 0~100입니다. 그 이외의 값은 신경쓰지 않으셔도 됩니다.

* **출력:**
사각형의 넓이를 출력해주세요.

---

## 3. 예시

### 예시 입력 1
```text
10 10
```

### 예시 출력 1
```text
100
```

### 예시 입력 2
```text
35 48
```

### 예시 출력 2
```text
1680
```
