# [S101v0302번] 02. [self-입력-정수2] 정수 2개의 사칙연산 출력

## 1. 문제 설명
정수를 2개 입력받고, 해당 정수 2개를 사칙연산(+ - * /)한 값을 출력하세요.

---

## 2. 입출력 설명

* **입력:**
정수 A, 정수 B가 입력됩니다.

입력되는 범위는 0~100입니다. 그 이외의 값은 신경쓰지 않으셔도 됩니다.

* **출력:**
입력한 정수의 4칙연산인 + - * /를 출력예시와 같이 출력하세요.

---

## 3. 예시

### 예시 입력 1
```text
2
8
```

### 예시 출력 1
```text
2 + 8 = 10
2 - 8 = -6
2 * 8 = 16
2 / 8 = 0
```

### 예시 입력 2
```text
6
5
```

### 예시 출력 2
```text
6 + 5 = 11
6 - 5 = 1
6 * 5 = 30
6 / 5 = 1
```
