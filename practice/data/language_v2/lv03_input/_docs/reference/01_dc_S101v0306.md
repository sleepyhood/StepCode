# [S101v0306번] 06. [self-입력-실수1] 입력한 실수 출력

## 1. 문제 설명

---

## 2. 입출력 설명

* **입력:**
실수 1개 입력됩니다.

입력되는 범위는 0~100.0입니다. 그 이외의 값은 신경쓰지 않으셔도 됩니다.

* **출력:**
입력한 실수를 그대로 출력하세요.
