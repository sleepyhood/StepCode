# [P101v0311번] 11. [입력-실수2] 입력한 실수의 2배 출력

## 1. 문제 설명
실수 하나를 입력하여 2배되는 값을 출력하세요.

---

## 2. 입출력 설명

* **입력:**
실수 1개 입력됩니다.

입력되는 범위는 0~100.0입니다. 그 이외의 값은 신경쓰지 않으셔도 됩니다.

* **출력:**
입력한 실수의 2배를 출력하세요.

---

## 3. 예시

### 예시 입력 1
```text
3.14
```

### 예시 출력 1
```text
6.280000
```

### 예시 입력 2
```text
2.4357579
```

### 예시 출력 2
```text
4.871516
```
