# [P101v0304번] 04. [입력-정수4] 입력한 수의 구구단 출력

## 1. 문제 설명
정수 하나 입력받아 구구단을 출력하세요.

---

## 2. 입출력 설명

* **입력:**
정수 1개 입력됩니다.

입력되는 범위는 2~9입니다. 그 이외의 값은 신경쓰지 않으셔도 됩니다.

* **출력:**
입력한 수의 구구단을 출력합니다. 구구단의 결과는 2자리로 오른쪽 정렬을 합니다.

---

## 3. 예시

### 예시 입력 1
```text
3
```

### 예시 출력 1
```text
3 * 1 = 3
3 * 2 = 6
3 * 3 = 9
3 * 4 = 12
3 * 5 = 15
3 * 6 = 18
3 * 7 = 21
3 * 8 = 24
3 * 9 = 27
```

### 예시 입력 2
```text
8
```

### 예시 출력 2
```text
8 * 1 = 8
8 * 2 = 16
8 * 3 = 24
8 * 4 = 32
8 * 5 = 40
8 * 6 = 48
8 * 7 = 56
8 * 8 = 64
8 * 9 = 72
```
