# [S101v0308번] 08. [self-입력-실수3] 판매수익 출력

## 1. 문제 설명
판매되는 물품의 금액, 수익률, 판매수량에 대한 오늘의 순 수익금액을 출력하세요

---

## 2. 입출력 설명

* **입력:**
물품의 금액(정수)과 수익율(실수) 오늘 판매된 수량(정수)이 입력됩니다.

* **출력:**
입력된 자료를 이용하여 오늘의 총 수익금액을 출력하세요.
