# [P101v0313번] 13. [입력-실수4] 실수 3개를 입력하여 소수 3자리까지 출력

## 1. 문제 설명
실수 세개를 입력받아 각각 소수 3자리까지 출력하세요.

---

## 2. 입출력 설명

* **입력:**
실수 3개가 입력됩니다.

입력되는 범위는 0~100.0입니다. 그 이외의 값은 신경쓰지 않으셔도 됩니다.

* **출력:**
입력한 실수 3개를 각각 소수 3자리까지 출력해주세요.

---

## 3. 예시

### 예시 입력 1
```text
3.141592 14.2879 24.8486
```

### 예시 출력 1
```text
3.142 14.288 24.849
```

### 예시 입력 2
```text
10.0 20.0 30.0
```

### 예시 출력 2
```text
10.000 20.000 30.000
```
