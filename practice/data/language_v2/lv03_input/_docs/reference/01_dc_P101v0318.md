# [P101v0318번] 18. [입력-문자3] 문자 다음 글자 출력

## 1. 문제 설명
문자 1개 입력받아 그 다음글자를 출력하세요.

---

## 2. 입출력 설명

* **입력:**
문자 1개 입력됩니다.

알파벳 대소문자 상관없이 A ~ Y까지만 입력됩니다. 그 이외의 입력값은 신경쓰지 않으셔도 됩니다.

* **출력:**
입력한 문자의 다음 문자를 출력하세요.

---

## 3. 예시

### 예시 입력 1
```text
Y
```

### 예시 출력 1
```text
Z
```

### 예시 입력 2
```text
c
```

### 예시 출력 2
```text
d
```
