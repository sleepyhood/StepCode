# [S101v0304번] 04. [self-입력-정수4] 삼각형 넓이 출력

## 1. 문제 설명
가로의 크기와 세로의 크기를 입력받아 삼각형의 넓이를 출력하세요.

---

## 2. 입출력 설명

* **입력:**
가로크기(정수)와 세로크기(정수) 2개가 입력됩니다.

입력되는 범위는 0~100입니다. 그 이외의 값은 신경쓰지 않으셔도 됩니다.

* **출력:**
삼각형의 넓이를 출력해주세요.

---

## 3. 예시

### 예시 입력 1
```text
12 24
```

### 예시 출력 1
```text
144
```

### 예시 입력 2
```text
35 48
```

### 예시 출력 2
```text
840
```
