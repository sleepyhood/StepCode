# [S101v0310번] 10. [self-입력-문자2] 문자 2개를 입력하여 차이를 출력

## 1. 문제 설명
문자 2개를 입력받아 두 문자의 차이를 출력하세요.

---

## 2. 입출력 설명

* **입력:**
문자 2개 입력됩니다.

첫번째 입력되는 문자는 두번째 입력되는 문자보다 알파벳 순서상 앞에 있는 문자가 입력됩니다.

입력될때는 항상 같은 대문자 또는 같은 소문자가 입력됩니다.

그 이외의 입력값은 신경쓰지 않으셔도 됩니다.

* **출력:**
입력한 문자 2개의 차이를 출력하세요.

---

## 3. 예시

### 예시 입력 1
```text
D o
```

### 예시 출력 1
```text
-43
```

### 예시 입력 2
```text
i n
```

### 예시 출력 2
```text
-5
```

### 예시 입력 3
```text
a A
```

### 예시 출력 3
```text
32
```
