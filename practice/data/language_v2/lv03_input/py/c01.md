# Python 입력 챌린지 1회차

### Q1. Trace 1. 이름과 점수(두 줄)

1줄째에는 이름, 2줄째에는 정수 두 개가 추가 공백과 함께 주어져요.
요구사항:
- 점수 합을 계산해요.
- 이름과 합을 함께 출력해요.
- name, s1, s2, output을 표에 채워요.

예시 표:
| name | s1 | s2 | output |
| --- | --- | --- | --- |
| Lee | 70 | 80 | 0 |

```c
name = input().strip()
s1, s2 = map(int, input().split())
print(name, s1 + s2)
```
