### Q6. Trace 1. 평균으로 Pass/Fail 분기

두 점수의 평균에 따라 분기되는 결과를 표에 채우세요.

입력 케이스 예시:
- case1: s1=80, s2=70
- case2: s1=50, s2=40
- case3: s1=60, s2=60

```c
s1, s2 = map(int, input().split())
avg = (s1 + s2) // 2
if avg >= 60:
    print('%s' % 'PASS')
else:
    print('%s' % 'FAIL')
```

### Q10. Code 2. 두 조건을 모두 만족해야 Pass

- score가 60 이상이고

```c
score = int(input())

else:
    print('%s' % 'Fail')
```
