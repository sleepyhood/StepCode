### Q5. MCQ 5. elif 조건식: 범위 분리에서 단순화

아래 코드에서
- age가 0~13이면 "Child"
- age가 14~19이면 "Teen"
- age가 20 이상이면 "Adult"
가 출력되도록 하려 합니다.

앞의 if가 거짓일 때만 elif를 검사한다는 점을 이용하여,
elif 줄에 들어갈 조건식을 고르세요.
(반드시 '<'만 사용하세요. 즉, <= 는 쓰지 마세요.)

```c
age = int(input())
if age < 14:
    print('%s' % 'Child')
elif  # 여기에 조건식을 작성하세요:
    print('%s' % 'Teen')
else:
    print('%s' % 'Adult')
```

- **A**: age <= 19
- **B**: age >= 14 and age <= 19
- **C**: age < 20
- **D**: 14 <= age < 20

### Q6. Trace 1. 경계값 등급 분기

- case1: score=89, bonus=1
- case2: score=80, bonus=0
- case3: score=79, bonus=0

total = score + bonus
if total >= 90:
    print('%s' % 'A')
