```c
import java.util.*;

        }
    }
}
```

- **A**: 0, 1, 10

### Q4. MCQ 4. 항상 Minus가 나오는 이유

다음 프로그램은 음수일 때만 "Minus"를 출력하려고 했지만,
입력 값과 상관없이 항상 "Minus"가 출력됩니다.
가장 중요한 원인은 무엇인가요?

```c
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        if (n < 0);
        {
            System.out.println("Minus");
        }
    }
}
```

- **A**: 변수 n의 자료형이 잘못되었다.
- **B**: 조건식이 n <= 0 이어야 한다.
- **C**: if (n < 0) 뒤의 세미콜론(;) 때문에 if가 의미가 없어진다.
- **D**: System.out.println 대신 System.out.printf를 사용해야 한다.
