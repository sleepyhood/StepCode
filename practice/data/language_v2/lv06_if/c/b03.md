### Q5. MCQ 5. elif 조건식: 범위 분리에서 단순화

아래 코드에서
- age가 0~13이면 "Child"
- age가 14~19이면 "Teen"
- age가 20 이상이면 "Adult"
가 출력되도록 하려 합니다.

앞의 if가 거짓일 때만 else if를 검사한다는 점을 이용하여,
else if 줄에 들어갈 조건식을 고르세요.
(반드시 '<'만 사용하세요. 즉, <= 는 쓰지 마세요.)

```c
int age;
scanf("%d", &age);
if (age < 14) {
    printf("Child\n");
}
else if (/* 여기에 조건식을 작성하세요 */) {
    printf("Teen\n");
}
else {
    printf("Adult\n");
}
```

- **A**: age <= 19
- **B**: age >= 14 && age <= 19
- **C**: age < 20
- **D**: 14 <= age && age < 20
