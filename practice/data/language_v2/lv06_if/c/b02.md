### Q3. MCQ 3. 0으로 나누기 방지

다음 설명에 맞는 C 코드를 고르세요.

- b가 0이 아니고, a가 b의 배수이면 "YES"를 출력한다.

- **D**: int a; scanf("%d", &a); int b; scanf("%d", &b); if (b != 0 || a % b == 0) {     printf("YES\n"); } else {     printf("NO\n"); }

### Q6. Trace 1. 범위 밖 판정(not)

n과 limit를 넣었을 때 not 범위 조건의 결과를 표에 채우세요.

입력 케이스 예시:
- case1: n=5, limit=10
- case2: n=0, limit=10
- case3: n=11, limit=10

```c
int n, limit;
scanf("%d %d", &n, &limit);
if (!(1 <= n && n <= limit)) {
    printf("OUT\n");
}
else {
    printf("IN\n");
}
```

### Q9. Code 1. 3의 배수 또는 5의 배수 조건식

정수 n이 3의 배수 또는 5의 배수일 때만 "YES"가 출력되도록, if 뒤의 조건식을 작성하세요.

if 뒤에 들어갈 조건식을 한 줄로 쓰세요.
(반드시 ||를 사용하세요.)

```c
int n;
scanf("%d", &n);
if (/* 여기에 조건식을 작성하세요 */) {
    printf("YES\n");
}
else {
    printf("NO\n");
}
```

---

### [답안 및 해설]
- **모범 코드:**
```c
n % 3 == 0 || n % 5 == 0
```
