- **D**: int price; scanf("%d", &price); char is_remote; scanf(" %c", &is_remote); char is_vip; scanf(" %c", &is_vip); if (is_vip == 'Y' || price >= 50000) {     printf("%d\n", 0); } else if (is_remote == 'Y') {     printf("%d\n", 5000); } else {     printf("%d\n", 3000); }

- VIP가 아니고 도서산간이면 5000

- 그 외 3000

다음 중 **이 코드의 버그를 확실히 드러내는 입력**을 고르세요.

```c
    printf("%d\n", 5000);
}
else {

}
```
