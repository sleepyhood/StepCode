# [18831번] 문제를 푸는 문제

## 1. 문제 설명
이 문제는 다섯 개의 서로 다른 문제로 이루어져 있다. 각 문제의 입력이 차례대로 주어질 때, 각 문제의 출력을 차례대로 출력하는 프로그램을 작성해야 한다.

* 문제 1: Dequery
* 문제 2: 박승원
* 문제 3: 미니 앨범
* 문제 4: 주령구
* 문제 5: 잘못 구현한 오일러 회로

---

## 2. 입출력 설명

* **입력:**
각 문제의 입력이 차례대로 주어진다.

* **출력:**
각 문제의 정답을 차례대로 출력한다.
