# [P101v0502번] 02. [자료형변환2] 정수를 소수 둘째자리까지 출력

## 1. 문제 설명
하나의 정수를 입력받아 소수로 둘째자리까지 출력해주세요

---

## 2. 입출력 설명

* **입력:**
정수 1개가 입력됩니다.

* **출력:**
소수로 변환하여 소수 둘째자리(이하반올림)까지 출력하세요.

---

## 3. 예시

### 예시 입력 1
```text
5
```

### 예시 출력 1
```text
5.00
```

---

## 4. 힌트
필요한 순간에 자료의 형태를 변경하여 사용할 수 있습니다.

정수형태변수(val)를 소수로 변경하여 사용하기 위한 방법은

(double)val 로 변수 앞에 소수 형태로 (double)를 작성해주면 변경하여 사용할 수 있습니다.
