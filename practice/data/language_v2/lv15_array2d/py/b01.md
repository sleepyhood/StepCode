### Q8. Code 3. 특정 값 개수 세기

아래 코드에서 주석 위치에 들어갈 **한 줄**을 작성하세요.
(`a[i][j]`가 0보다 크면 `cnt`를 1 증가)

```c
a = [
    [0, -1, 2],
    [3, 0, -4]
]
cnt = 0
for i in range(len(a)):
    for j in range(len(a[0])):
        # TODO: a[i][j]가 0보다 크면 cnt를 1 증가
print('%d' % cnt)
```

---
<!-- ANSWER_START -->
### [답안 및 해설]
- **모범 코드:**
```c
if a[i][j] > 0: cnt += 1
```
