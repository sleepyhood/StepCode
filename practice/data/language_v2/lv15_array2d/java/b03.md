```c
}
```

### Q5. Code 2. 테두리 합


### Q8. Code 3. 행 뒤집기(가로 반전)

아래 코드에서 주석 위치에 들어갈 **swap 3줄**을 작성하세요.
(배열 row를 좌우로 뒤집어야 합니다.)

```c
int[] row = {1, 2, 3, 4, 5};
int l = 0, r = row.length - 1;
while (l < r) {
    // TODO: row[l]과 row[r]을 교환하는 3줄
    l++; r--;
}
System.out.println(row[0] + " " + row[row.length-1]);
```

---
<!-- ANSWER_START -->
### [답안 및 해설]
- **모범 코드:**
```c
int tmp = row[l];
row[l] = row[r];
row[r] = tmp;
```
