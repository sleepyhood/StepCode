### Q5. Code 2. 전체 합 구하기

```c

    {3, 1},
    {2, 5}
};

        // TODO: a의 모든 원소를 sum에 더하는 한 줄
    }
}
System.out.println(sum);
```

### Q8. Code 3. 특정 값 개수 세기

아래 코드에서 주석 위치에 들어갈 **조건 + 증가 한 줄**을 작성하세요.
(값이 0보다 큰 칸의 개수를 `cnt`에 세어야 합니다.)

```c
int[][] a = {
    {0, 2, -1},
    {3, 0, 4}
};
int cnt = 0;
for (int i = 0; i < a.length; i++) {
    for (int j = 0; j < a[0].length; j++) {
        // TODO: a[i][j]가 0보다 크면 cnt를 1 증가
    }
}
System.out.println(cnt);
```

### [답안 및 해설]
- **모범 코드:**

### Q9. MCQ 4. 중첩 반복문 실행 횟수

```java
    }
}
```
