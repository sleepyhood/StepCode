# Java 2차원 배열 LV15 챌린지 1회차

### Q1. MCQ 1. Ragged 배열에서 열 길이

다음 `int[][] a`는 **ragged 배열(행마다 길이가 다름)**입니다.

```java
int[][] a = {
    {1, 2, 3},
    {4, 5},
    {6, 7, 8, 9}
};
int sum = 0;
for (int i = 0; i < a.length; i++) {
    for (int j = 0; j < a[0].length; j++) {
        sum += a[i][j];
    }
}
```
위 코드가 런타임 에러가 날 수 있는 이유와, 가장 좋은 수정 방법을 고르세요.

- **A**: 문제 없음. `a[0].length`는 항상 열 개수이므로 안전하다.
- **B**: 두 번째 행이 더 짧아서 `a[i][j]`에서 예외가 날 수 있다. 안쪽 반복문 조건을 `j < a[i].length`로 바꾼다.
- **C**: `a.length`가 잘못되었다. 바깥 반복문을 `i < a[0].length`로 바꾼다.
- **D**: 2차원 배열은 항상 직사각형이므로 ragged 배열이 될 수 없다.

### Q8. Code 3. 최댓값 갱신 + tie-break(3줄)

아래 코드에서 주석 위치에 들어갈 코드를 작성하세요.

- 더 큰 값이면 갱신
- 값이 같으면 **행 인덱스가 작은 쪽**
- 행도 같으면 **열 인덱스가 작은 쪽**

(주석 위치에 들어갈 코드는 **if문 포함 3줄**로 작성해도 됩니다.)

```c
int[][] a = {
    {5, 7, 7},
    {7, 7, 1},
    {6, 7, 7}
};

int best = a[0][0];
int br = 0, bc = 0;

for (int i = 0; i < a.length; i++) {
    for (int j = 0; j < a[0].length; j++) {
        // TODO: best, br, bc 갱신
    }
}
System.out.println(best + " @(" + br + "," + bc + ")");
```
