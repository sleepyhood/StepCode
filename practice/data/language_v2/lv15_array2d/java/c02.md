### Q1. MCQ 1. 행 교환의 의미

다음 코드 실행 후, `a[0][0]`의 값은 무엇이 될까요?

```java
int[][] a = {
    {1, 2},
    {3, 4},
    {5, 6}
};
int r1 = 0, r2 = 2;
int[] tmp = a[r1];
a[r1] = a[r2];
a[r2] = tmp;
System.out.println(a[0][0]);
```


- **A**: 1
- **B**: 3
- **C**: 5
- **D**: 컴파일 에러
