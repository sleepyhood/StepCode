### Q6. Short 2. 최댓값 동점 처리

아래 코드는 최댓값의 좌표를 찾습니다. 출력 결과를 쓰세요. (한 줄)
(동점이면 더 먼저 나온 좌표를 유지합니다.)

```c
int[][] a = {
    {5, 7},
    {7, 1}
};
int max = a[0][0];
int mr = 0, mc = 0;
for (int i = 0; i < a.length; i++) {
    for (int j = 0; j < a[0].length; j++) {
        if (a[i][j] > max) { max = a[i][j]; mr = i; mc = j; }
    }
}
System.out.println(mr + " " + mc);
```
