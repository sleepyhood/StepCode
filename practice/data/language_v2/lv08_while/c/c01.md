# C while문 챌린지 1회차

### Q1. MCQ 1. 무한 루프가 되는 이유(갱신 누락)

아래 코드가 무한 루프가 되는 이유로 가장 알맞은 것을 고르세요.

```c
int n;
scanf("%d", &n);
while (n > 0) {
    printf("%d\n", n);
    // n을 변화시키는 코드가 없다
}
```

- **A**: 조건식이 항상 거짓이다
- **B**: n이 0이 될 수 없기 때문에 무한 루프가 된다
- **C**: 반복문 안에서 n이 변하지 않아 n > 0이 계속 참이 된다
- **D**: printf에 서식문자를 사용했기 때문에 무한 루프가 된다

### Q2. MCQ 2. off-by-one (n개 입력)

입력이 n개일 때 이 코드는 몇 개를 더하려고 시도하나요?

```c

int i = 1;
int s = 0;
while (i <= n + 1) {
    int x;
    scanf("%d", &x);
    s = s + x;
    i = i + 1;
}
printf("%d\n", s);
```

- **A**: n-1개
- **B**: n개
- **C**: n+1개

### Q5. MCQ 5. continue와 갱신 순서

```c
int n;
scanf("%d", &n);
int i = 0;
int s = 0;
while (i < n) {
    i = i + 1;
    if (i % 2 == 0) {
        continue;
    }
    s = s + i;
}
printf("%d\n", s);
```

- **A**: 4
