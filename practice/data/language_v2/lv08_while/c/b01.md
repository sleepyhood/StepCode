### Q1. MCQ 1. 1부터 5까지 출력하는 while문

다음 요구사항을 만족하는 C while 코드를 고르세요.

- 정수 1부터 5까지를 순서대로 한 줄에 하나씩 출력한다.
- 각 줄에는 숫자 하나만 출력한다.
- printf 서식문자를 사용해 출력한다.

- **A**: int i = 1; while (i < 5) {     printf("%d\n", i);     i = i + 1; }

- **C**: int i = 0; while (i <= 5) {     printf("%d\n", i); }

### Q4. MCQ 4. 무한 루프가 되는 이유

다음 프로그램의 문제점에 대한 설명으로 가장 알맞은 것을 고르세요.

```c
int n;
scanf("%d", &n);
while (n != 0) {
    printf("%d\n", n);
}
```

- **A**: n이 음수일 때는 while문이 한 번도 실행되지 않는다.
- **B**: while 안에서 n의 값이 바뀌지 않아서, n이 0이 아니면 무한 반복된다.
- **C**: printf에서 서식문자를 사용하지 않아 오류가 발생한다.
- **D**: scanf를 int로 받지 않아 문자열 덧셈이 일어난다.

### Q7. Short 2. 0이 나올 때까지 짝수 개수 세기

```c

    int x;
    scanf("%d", &x);
    if (x == 0) {
        break;
    }
    if (x % 2 == 0) {

}
printf("%d\n", cnt);
```
