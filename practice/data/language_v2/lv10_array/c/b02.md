### Q1. MCQ 1. n개 입력을 배열에 저장

다음 중 정수 n을 입력받고, 이어서 n개의 정수를 입력받아 배열 arr에 저장하는 코드로 올바른 것을 고르세요.
(각 정수는 한 줄에 하나씩 입력된다고 가정합니다.)

- **A**: int n; scanf("%d", &n); int *arr = (int*)calloc(n, sizeof(int)); for (int i = 0; i <= n; i++)     scanf("%d", &arr[i]);
