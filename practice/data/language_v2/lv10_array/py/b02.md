### Q1. Trace 1. 합과 개수 추적

코드를 실행해 각 반복 직후의 i, x, s, count를 표에 채우세요.

```c
lst = [3, -1, 4, 0]
s = 0
cnt = 0
for i in range(len(lst)):
    x = lst[i]
    s += x
    if x > 0:
        cnt += 1
print(s, cnt)
```

### Q8. Short 2. 최댓값 인덱스(동점)

```c
idx = 0

        idx = i
print(idx)
```
