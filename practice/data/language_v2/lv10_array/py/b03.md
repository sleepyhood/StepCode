### Q1. Trace 1. 탐색 상태 추적

코드를 실행하며 표를 채우세요. 각 반복에서 i, lst[i], idx 변화를 적으세요.

```c
lst = [4, 7, 2, 7]
target = 7
idx = -1
for i in range(len(lst)):
    if lst[i] == target:
        idx = i
        break
print(idx)
```
