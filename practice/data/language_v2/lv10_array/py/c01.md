### Q1. Trace 1. 최댓값 인덱스 추적

코드를 실행해 각 반복 직후의 값을 표에 채우세요. 동점일 때는 기존 인덱스를 유지합니다.

```c

mx = lst[0]
idx = 0
for i in range(1, len(lst)):

        idx = i
print(idx)
```
