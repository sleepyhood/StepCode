### Q6. Short 2. 버그가 있는 최솟값 코드의 출력

```c
int[] arr = {5, 1, 4};
int min = arr[0];
for (int i = 1; i < arr.length; i++) {
    if (arr[i] > min) {
        min = arr[i];

}
```
