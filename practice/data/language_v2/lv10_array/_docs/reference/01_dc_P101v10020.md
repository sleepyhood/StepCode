# [P101v10020번] 임시. 20. [배열+인덱스] 짝수 인덱스 위치만 출력하기

## 1. 문제 설명
정수 8개를 입력받고, 인덱스가 짝수인 위치(0, 2, 4, 6)의 값을 출력하세요.

---

## 2. 입출력 설명

* **입력:**
정수 8개를 공백으로 입력합니다.

* **출력:**
짝수 인덱스 위치의 값들을 한 줄에 하나씩 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
1 2 3 4 5 6 7 8
```

### 예시 출력 1
```text
1
3
5
7
```

---

0부터 시작하는 인덱스를 이용해 짝수 번째 값만 출력해보세요. range(0, len(arr), 2) 형태를 사용해도 좋아요.
