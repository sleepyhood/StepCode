# [P101v10029번] 임시. 29. [배열+정렬] 세 수를 내림차순 정렬하기

## 1. 문제 설명
정수 3개를 입력받고, 그 숫자들을 내림차순(큰 수부터 작은 수)으로 정렬하여 출력하는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:**
정수 3개를 공백으로 입력합니다.

* **출력:**
정렬된 3개의 수를 한 줄에 공백으로 출력합니다.


첫째줄 마지막에는 띄어쓰기가 포함되어야 합니다.

---

## 3. 예시

### 예시 입력 1
```text
5 9 3
```

### 예시 출력 1
```text
9 5 3
```
