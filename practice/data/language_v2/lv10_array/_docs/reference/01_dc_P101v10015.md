# [P101v10015번] 임시. 15. [배열+조건] 홀수만 출력하기

## 1. 문제 설명
정수 6개를 입력받고, 그 중 홀수만 출력하는 프로그램을 작성하세요.

---

## 2. 입출력 설명

* **입력:**
정수 6개를 공백으로 입력합니다.

* **출력:**
홀수만 한 줄에 하나씩 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
2 3 4 5 6 7
```

### 예시 출력 1
```text
3
5
7
```

---

## 4. 힌트
2로 나누어 나머지가 1인 수만 출력하면 됩니다.
