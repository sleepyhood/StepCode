# [P101v10032번] 임시. 32. [배열-응용2] 음계 판별하기

## 1. 문제 설명
다장조는 c d e f g a b C의 8개 음으로 이루어져 있으며, 각각 숫자 1부터 8로 표현됩니다.

이 8개의 숫자가 어떤 순서로 배열되어 있는지 보고 ascending(오름차순), descending(내림차순), mixed(섞임) 중 하나를 판단하세요.

---

## 2. 입출력 설명

* **입력:**
첫째 줄에 1부터 8까지의 숫자들이 공백으로 구분되어 주어집니다.

숫자는 한 번씩만 등장합니다.

* **출력:**
"ascending", "descending", "mixed" 중 하나를 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
1 2 3 4 5 6 7 8
```

### 예시 출력 1
```text
ascending
```

### 예시 입력 2
```text
8 7 6 5 4 3 2 1
```

### 예시 출력 2
```text
descending
```

### 예시 입력 3
```text
4 5 6 7 8 1 2 3
```

### 예시 출력 3
```text
mixed
```
