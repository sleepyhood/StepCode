# [P101v10017번] 임시. 17. [배열+조건] 음수가 몇 개 있는지 세기

## 1. 문제 설명
정수 7개를 입력받고, 그 중 음수(-)인 수의 개수를 출력하세요.

---

## 2. 입출력 설명

* **입력:**
정수 7개를 공백으로 입력합니다.

* **출력:**
음수의 개수를 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
-1 3 0 -2 4 -5 2
```

### 예시 출력 1
```text
3
```

---

## 4. 힌트
0보다 작은 수를 찾아 조건문으로 개수를 세어보세요.
