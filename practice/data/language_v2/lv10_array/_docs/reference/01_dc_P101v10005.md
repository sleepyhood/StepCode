# [P101v10005번] 임시. 05. [배열 입력] 숫자 3개 입력받고 출력하기

## 1. 문제 설명
정수 3개를 입력받아 배열에 저장한 뒤, 입력된 순서대로 출력하세요.

반복문 없이 작성하세요.

---

## 2. 입출력 설명

* **입력:**
정수 3개를 공백으로 나누어 입력합니다.

* **출력:**
입력된 순서대로 한 줄에 하나씩 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
7 3 9
```

### 예시 출력 1
```text
7
3
9
```
