# [P101v10013번] 임시. 13. [배열+조건] 숫자 0이 몇 번 나왔는지 세기

## 1. 문제 설명

---

## 2. 입출력 설명

* **입력:**
정수 8개를 공백으로 입력합니다.

* **출력:**
숫자 0의 개수를 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
0 1 0 3 4 0 6 0
```

### 예시 출력 1
```text
4
```
