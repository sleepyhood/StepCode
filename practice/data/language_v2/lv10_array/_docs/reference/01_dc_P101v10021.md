# [P101v10021번] 임시. 21. [문자+조건] 대문자만 출력하기

## 1. 문제 설명
문자 6개를 입력받고, 그 중 대문자만 출력하는 프로그램을 작성하세요.

---

## 2. 입출력 설명

* **입력:**
문자 6개를 공백으로 입력합니다.

* **출력:**
대문자만 한 줄에 하나씩 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
A b C d e F
```

### 예시 출력 1
```text
A
C
F
```

각 문자가 대문자인지 확인하려면 아스키 코드 조건문이 필요합니다.
