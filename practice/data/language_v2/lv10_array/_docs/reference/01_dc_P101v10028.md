# [P101v10028번] 임시. 28. [배열+탐색] 최대값의 위치 출력하기

## 1. 문제 설명
정수 7개를 입력받고, 그 중 가장 큰 값이 저장된 인덱스를 출력하는 프로그램을 작성해 주세요.

(인덱스는 0부터 시작합니다.)

---

## 2. 입출력 설명

* **입력:**
정수 7개를 공백으로 입력합니다.

* **출력:**
가장 큰 값의 인덱스를 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
12 33 7 55 28 9 42
```

### 예시 출력 1
```text
3
```

---

최대값을 찾고, 해당 값이 위치한 인덱스를 함께 저장해 출력해보세요.
