# [P101v10008번] 임시. 08. [배열+반복문] 시험 점수 5개 입력 후 출력하기

## 1. 문제 설명
5과목의 시험 점수를 입력받고, 입력한 순서대로 한 줄에 하나씩 출력하는 프로그램을 작성하세요.

---

## 2. 입출력 설명

* **입력:**
5개의 정수를 공백으로 입력합니다.

* **출력:**
입력한 점수를 한 줄에 하나씩 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
80 95 70 85 90
```

### 예시 출력 1
```text
80  
95  
70  
85  
90
```
