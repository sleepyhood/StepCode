# [P101v10026번] 임시. 26. [배열+인덱스] 짝수 인덱스와 짝수 값 조건 출력

## 1. 문제 설명
정수 8개를 입력받고, 인덱스가 짝수이고 값도 짝수인 경우만 출력하는 프로그램을 작성해 주세요.

인덱스는 0부터 시작합니다.

---

## 2. 입출력 설명

* **입력:**
정수 8개를 공백으로 입력합니다.

* **출력:**
조건을 만족하는 값만 한 줄에 하나씩 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
1 2 4 5 6 7 8 9
```

### 예시 출력 1
```text
4
6
8
```

---

## 4. 힌트
반복문에서 인덱스를 활용하고, i가 짝수이고 arr[i]도 짝수인 경우만 출력해보세요.
