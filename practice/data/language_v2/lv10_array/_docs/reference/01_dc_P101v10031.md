# [P101v10031번] 임시. 31. [배열-응용1] 부호 반영하여 합 구하기

## 1. 문제 설명
정수들의 절댓값을 담은 배열 absolutes와 이들의 부호를 나타내는 배열 signs가 주어집니다.

signs는 1이면 양수, 0이면 음수를 의미합니다.

주어진 정수들의 실제 합을 구하여 출력하세요.

---

## 2. 입출력 설명

* **입력:**
첫째 줄에 입력할 정수의 개수 N이 주어집니다. (1 ≤ N ≤ 10)

둘째 줄에 N개의 정수로 이루어진 absolutes 배열이 공백으로 구분되어 주어집니다. (각 정수는 1 이상 1000 이하)

셋째 줄에 N개의 정수로 이루어진 signs 배열이 공백으로 구분되어 주어집니다. (각 원소는 1 또는 0입니다)

* **출력:**
실제 수들의 합을 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
3
4 7 12
1 0 1
```

### 예시 출력 1
```text
9
```

---

## 4. 힌트
absolutes와 signs의 인덱스를 대응시켜 signs가 1이면 양수, 0이면 음수로 간주하여 합산하세요.
