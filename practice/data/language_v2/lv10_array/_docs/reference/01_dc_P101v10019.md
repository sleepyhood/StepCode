# [P101v10019번] 임시. 19. [배열+탐색] 입력된 숫자 중에서 7이 있는지 찾기

## 1. 문제 설명
정수 6개를 입력받고, 그 중 숫자 7이 존재하는지 출력하세요.

(존재하면 YES, 없으면 NO)

---

## 2. 입출력 설명

* **입력:**
정수 6개를 공백으로 입력합니다.

* **출력:**
"YES" 또는 "NO"를 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
1 2 3 4 5 7
```

### 예시 출력 1
```text
YES
```
