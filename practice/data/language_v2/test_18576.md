# [18576번] Humongous String

## 1. 문제 설명
Consider the alphabet Σ = {s<sub>0</sub>, . . . , s<sub>k−1</sub>} of size k. Define the sequence of strings {T<sub>i</sub>} as follows:

* T<sub>0</sub> = s<sub>0</sub>;
* T<sub>i</sub> = T<sub>i−1</sub>s<sub>i</sub> mod k for all integers i ≥ 1.

Let S = T<sub>0</sub>T<sub>1</sub>T<sub>2</sub> . . . be an infinite string which is a concatenation of all strings {T<sub>i</sub>} in ascending order of their indices. For example, if k = 3, s<sub>0</sub> = “a”, s<sub>1</sub> = “b”, and s<sub>2</sub> = “c”, then T0 = “a”, T<sub>1</sub> = “ab”, T<sub>2</sub> = “abc”, T<sub>3</sub> = “abca”, T<sub>7</sub> = “abcabcab” (and so on), and S = “aababcabcaabcab. . . ”.

Denote the prefix of string S of length n by S<sub>n</sub>. Given numbers n and k, count the number of distinct non-empty substrings of string S<sub>n</sub> provided that |Σ| = k.

---

## 2. 입출력 설명

* **입력:**
The first line contains a single integer T (1 ≤ T ≤ 10<sup>5</sup>), the number of test cases.

Then T lines follow. The i-th of these lines contains two integers n<sub>i</sub> and k<sub>i</sub> (1 ≤ n<sub>i</sub> ≤ 10<sup>9</sup>, 1 ≤ k<sub>i</sub> ≤ 10<sup>9</sup>) separated by a single space: the length of string S<sub>ni</sub> and the size of alphabet Σ in the i-th test case.

* **출력:**
Print T lines. The i-th of them should contain a single integer: the answer for the i-th test case.
