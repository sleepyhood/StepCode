# Reference(기출/원본) 마크다운 작성 통합 가이드

이 문서는 학원 현장, 기출문제, 알고리즘 사이트 등에서 가져온 '원본 문제'를 `_docs/reference/` 폴더에 아카이빙할 때 사용하는 **표준 마크다운(MD) 템플릿 및 가이드라인**입니다.

## 📌 [핵심 원칙 3가지]

1. **1문제 = 1파일 (모듈화 보호):** 여러 문제가 한 파일에 뭉쳐 있으면 검색과 조립이 어렵습니다. 반드시 1개의 문제는 1개의 MD 파일(`01_name.md`)로 쪼개어 보관합니다.
2. **단일 파일 내 정답 코드 포함 (Single Source of Truth):** 문제 내용과 정답 코드(`<!-- ANSWER_START -->` 이하 구역)를 같은 파일 안에 두어, 문제가 바뀌었을 때 정답 갱신 누락을 방지합니다.
3. **기준 정답(Ground Truth)은 'Python' 권장:** 입력 형식(공백, 줄바꿈)이 가장 엄격하고 명시적인 Python 코드를 최우선 정답 코드로 수집합니다. C, Java 등 다른 언어로의 번환은 AI/스크립트에 맡깁니다.

---

## 📑 파일명 규칙 (Naming Convention)

파일이 많아졌을 때 관리가 쉽도록 **번호(Index) + 의미망(Keyword)** 형태로 구성합니다.
* ❌ `1.md` / `for_munje.md`
* ✅ `01_print_1_to_5.md`
* ✅ `02_gugudan.md`
* ✅ `03_even_sum.md`

---

# [반복-for 기초1] 1부터 5까지 출력하기

## 1. 문제 설명
for문을 사용하여 1부터 5까지의 정수를 한 줄에 하나씩 출력하는 프로그램을 작성해 주세요.

---

## 2. 입출력 설명

* **입력:** 없습니다.
* **출력:** 1부터 5까지의 수를 순서대로 한 줄에 하나씩 출력합니다.

---

## 3. 예시

### 예시 입력 1
```text
(없음)
```

### 예시 출력 1
```text
1
2
3
4
5
```

---

## 4. 힌트 및 뼈대 (선택 사항)

for문의 초기값은 1부터 시작하고, 5까지 반복하여 출력해 주세요.

```c
// C언어 뼈대
for (초기식; 조건식; 증감식) { ... }
```
