# 컴파일/전처리/표준 라이브러리

### 컴파일이란?
```text
컴퓨터는 사실 c언어를 알아볼 수 없습니다. c언어를 컴퓨터가 알아볼 수 있는 기계어 형태로 바꿔줘야 합니다. 
컴퓨터가 알아볼 수 있게 바꾸는 작업을 컴파일이라 하고 컴파일 기능을 하는 프로그램을 컴파일러라 합니다.
c언어와 같은 언어들을 고급언어, 기계어와 같은 언어를 저급언어라 부릅니다.
(사람이 알아보기 쉬울수록 고급, 컴퓨터가 알아보기 쉬울수록 저급입니다.)
```

### format?
```text
우리가 사용해 온 printf, scanf에서 f는 format의 줄임말입니다. 
format = 형식이라는 뜻입니다. %d는 정수라는 형식, %lf는 실수라는 형식, %c는 문자라는 형식. 
형식에 맞게 사용해라! 라는 뜻으로 뒤에 f라고 이름이 붙었습니다.
```

# 자료형/상수/진법


### 오버플로우?
```text
우리는 그동안 정수형 변수를 선언할 때 int를 사용해왔습니다. 당연하게도? 컴퓨터는 무한한 용량을 가진게 아니기 때문에 int에 무한한 값을 넣을 수는 없습니다.
int형 변수에 넣을 수 있는 값의 범위는 -2147483648 ~ 2147483647 입니다. 이 범위를 벗어나면 이상한 값이 됩니다! 이를 오버플로우라고 부릅니다. 
예를 들어 int a = 2147483647; 인 상황에서 a에 1을 더하면 a에는 -2147483648이라는 값이 들어가게 됩니다. 
int의 최대값에서 1을 더하면 한 바퀴를 돌아서 최소값으로 간다고 생각하면 편합니다. 

int보다 조금 더 작은 용량을 갖는 정수형 변수 short가 있습니다. short의 범위는 -32768 ~ 32767입니다. 
마찬가지로 short형 변수에 32767이 있는 상태에서 1을 더하면 -32768이 됩니다.

이걸 외우기 싫어서 #include <limist.h>를 코드에 작성해주면 SHRT_MAX와 같은 변수(정확히는 상수)를 사용할 수 있습니다.
SHRT_MAX는 그 이름 답게 short형 변수의 최대값인 32767이 저장되어 있습니다. 
INT_MAX에는 2147483647이 저장되어 있습니다.
```

### 진법
```text
우리가 평소에 사용하는 진법은 10진법입니다. 10진법이라는 건 정확하게 무슨 의미일까요? 
예를 들어, 532 라는 숫자는 (5 x 10²) + (3 x 10¹) + (2 x 10⁰) 라고 표현할 수 있습니다. 
즉, 10진법에서 각 자리의 숫자는 뒤에 10의 거듭제곱이 곱해진 수들의 합이라고 할 수 있습니다. 
가장 오른쪽의 숫자에는 10의 0제곱이 곱해져있고 왼쪽으로 한 칸씩 갈수록 1제곱, 2제곱, 3제곱..이 되는겁니다.

2진법은 각 자리의 숫자 뒤에 2의 거듭제곱이, 8진법은 각 자리의 숫자 뒤에 8의 거듭제곱이 곱해진 겁니다. 
10진법 5를 2진법으로 바꾸면 어떻게 될까요? 5 = (1 x 2²) + (0 x 2¹) + (1 x 2⁰) 이므로 101 로 표현합니다.
2진법에서는 2 이상의 숫자는 등장하지 않겠죠? 오른쪽에서 왼쪽으로 갈 때마다 2가 곱해지니 2라는 값은 한 칸 왼쪽에서 1로 표현이 될겁니다.
그래서 2진법에는 0과 1밖에 없습니다.

8진법에서 13을 표현하면 어떻게 될까요? 13 = (1 x 8¹) + (5 x 8⁰)이므로 15로 표현합니다.
16진법은 어떨까요? 16진법도 똑같은 방식이지만 한 가지 더 알아야 할 게 있습니다. 
10진법에서는 10미만의 값을 하나의 숫자로, 8진법에서는 8미만의 값을 하나의 숫자로 표현했습니다.
마찬가지로 16진법에서는 16미만의 값을 하나의 숫자로 표현해야 됩니다. 그런데 10, 11, 12 ..같은 숫자들은 이미 두 개의 숫자로 표현되어 있네요.
그래서 16진법은 두 자리의 숫자를 하나의 문자로 표현하기 위해 알파벳을 가져와서 사용합니다. 
10 = A, 11 = B, 12 = C, 13 = D, 14 = E, 15 = F 입니다(소문자로 표현해도 상관없습니다)
28을 16진법으로 표현하면 28 = (1 x 16¹) + (12 x 16⁰) 이므로 1C로 표현할 수 있습니다. 16진법에서 12는 C로 표기하기로 했으니까요.

C언어에서 진법을 구분하는 방식은 숫자앞에 추가로 기호를 작성해서 구분해줍니다.
숫자 앞에 
0b를 붙이면 2진법
0을 붙이면 8진법
0x를 붙이면 16진법입니다.
```

### 2진법의 음수 표기법 (안 나올 거 같은데 그냥 뺄까?)
```text
2진법으로 음수를 표현하려면 어떻게 해야할까요? 사람이라면 그냥 앞에 -를 붙여주면 되겠지만
안타깝게도 컴퓨터한테는 - 같은건 없습니다. 컴퓨터는 0과1밖에 없죠. 하지만 다행히도 아주 쉬운 방법이 있습니다.
결론부터 말하자면 일단 양수와 같은 방식으로 표현한 다음 0은 1로, 1은 0으로 바꾼 뒤 1을 더해주면 됩니다. 
하지만 그 전에 한 가지 습관이 필요합니다.
10진법 2를 2진법으로 바꾸면 10입니다. 이걸 음수로 표현하기 위해 위의 방식을 적용해볼까요? 
10 -> 0과 1을 바꾸기 -> 01 -> 1 더하기 -> 10
음수로 바꿨는데 똑같은 값이 나오네요. 이번에는 10앞에 0을 한 개 붙여서 해봅시다.
010이나 10이나 똑같잖아요? 
010 -> 0과 1을 바꾸기 -> 101 -> 1 더하기 -> 110
이번에는 -2가 이진법으로 잘 바뀌었습니다. 
110에 동일한 방식을 적용하면 010이 나옵니다. 부호를 바꿀 때에는 위와 같은 방식을 활용하면 됩니다. 
중요한 점은 변환을 한 값이 양수라면 제일 앞자리가 0이어야 하고 음수라면 1이어야 합니다.
그렇지 않다면 위에서 배운 오버플로우가 발생한 겁니다.
오버플로우가 발생하지 않게 하려면 앞에 0을 하나 붙여주면 됩니다. 
```

# 입출력/서식 지정

### 서식지정자
```text
우리가 그동안 사용했던 %d, %lf, %s, %c.. 이런 친구들을 서식지정자라고 부릅니다.
여기서 %와 문자 사이에 뭔가를 추가해서 표현 방식을 바꿀 수 있습니다.
%와 문자 사이에 양수를 집어넣으면 "왼쪽"부터 그 값만큼의 공간을 확보합니다.
printf("%8d", 100); 을 출력하면 띄어쓰기를 5칸 하고 100이 나올겁니다.
만약 8자리보다 큰 값을 출력하려고 하면 그냥 %d와 동일하게됩니다. 
양수가 아니라 음수를 넣으면 어떻게 될까요?
"오른쪽"부터 그 값만큼의 공간을 확보합니다.
printf("%-8d", 100);을 하면 그냥 100이 출력된 것 처럼 보이지만 사실은 뒤에 5칸의 띄어쓰기가 있습니다.
printf("%-8d", 100);을 한 뒤에 곧바로 다른 값을 출력해보면 5칸의 띄어쓰기가 있다는 걸 확인할 수 있습니다.
마찬가지로 8자리보다 더 큰 값을 출력할 때에는 그냥 %d와 동일하게 됩니다.
%lf의 경우 %와 lf 사이에 .3이라고 적으면 소수점 넷째자리에서 반올림해서 셋째자리까지 표현합니다.
(%lf는 기본적으로 소수점 여섯째자리까지 나옵니다.)
위에서 말한 것과 합쳐서 %8.3lf라고 하면 왼쪽부터 8칸의 공간을 확보하면서 소수점 셋째자리까지 표현한다는 뜻입니다.
(이 경우에도 마찬가지로 8자리를 넘어가면 %.3lf와 같아집니다.) 
주의할 부분은 .도 한 칸으로 인식됩니다. 123.456을 %8.3lf로 출력하면 띄어쓰기를 2칸 하고 123.456이 나오는게 아니라
띄어쓰기 1칸 하고 123.456이 나옵니다. 
```

# 비트연산

### 비트연산
```text
조건문에서 배웠던 and, or과 비슷한 방식입니다. 
c언어에서는 거짓 = 0, 참 = 1로 표현했습니다. 그러고보니 2진법도 0과 1밖에 없네요. 
비트는 2진법이라는 의미이고 0과1을 이용해서 연산을 하겠다는 뜻입니다. 
and는 둘 다 참(1)일 때 결과가 1이 됩니다. 즉 1 and 1 = 1 이라고 할 수 있습니다. 
그럼 1001 and 0011은 어떻게 계산할까요? 각 자리끼리 and 연산을 해주면 됩니다.
그럼 0001이 되겠네요. and는 둘 다 1인 자리만 1이고 나머지는 다 0을 적어주면 끝입니다! 
or은 둘 중에 하나만 1이면 결과가 1이었죠.
1001 or 0011 = 1011이 됩니다. or은 둘 다 0인 자리만 0이고 나머지는 다 1을 적어주면 끝입니다!
논리연산에서 not은 !로 표현했습니다. !는 결과를 반대로 바꿔줍니다. !0 = 1, !1 = 0입니다. 
비트연산에서 not은 ~로 표현합니다. ~0011 = 1100입니다. 0은 1로 1은 0으로 바꾸면 끝!

추가로 xor이라는게 있습니다. xor은 둘이 값이 다르면 1이고 같으면 0입니다.
1 xor 1 과 0 xor 0의 결과는 0입니다. 1 xor 0과 0 xor 1의 결과는 1입니다. 
1001 xor 0011 = 1010이 되겠네요.
10진법으로 표현된 숫자로 xor 연산을 하려면 어떻게 해야 할까요? 2진법으로 바꾼뒤에 해야할까요?
물론.. 그렇게 해야겠지만 xor의 특징을 이용해서 쉽게 풀 수 있는 몇 가지 팁이 있습니다.

1. xor은 같은 것끼리 만나면 전부 0이 된다. 
3 xor 3 = 0
100 xor 100 = 0
1234567 xor 1234567 = 0
똑같은 애들끼리 xor로 만나면 결과가 다 0입니다.

5 xor 5 xor 5은 답이 뭘까요? 0이라고 답했다면 틀렸습니다.
5 xor 5 = 0이니까 5 xor 5 xor 5 = 0 xor 5과 같습니다. 답은 5겠네요. 
!!앞에서부터 차근차근 계산해야 실수하지 않습니다!!
이 부분을 한 번 더 단순화 하자면 숫자 n 홀수개가 xor로 만나면 n이고 짝수개가 만난다면 0이라고 할 수 있겠네요 

2. 0과 xor연산을 하면 그 값이 그대로 나온다.
0 xor 1 = 1
0 xor 0 = 0 
0 xor A = A

3. xor 연산은 순서가 바뀌어도 결과가 동일하다. 
1 xor 3 xor 0 xor 3 = 3 xor 3 xor 1 xor 0과 같습니다.
위에 있는 두 가지 성질을 활용하기 편하게 순서를 바꿔주면 좋습니다.
3 xor 3 = 0이고 1 xor 0 = 1이니 결과적으로 0 xor 1과 같습니다. 답은 1이겠네요.

이 3가지 방식을 다 활용했는데도 계산이 끝나지 않았다 혹은 잊어버렸다.. 그럼 이제 2진법으로 바꿔서 계산합시다.
0 xor 01010을 계산해야 되는데 2번 팁이 떠오르지 않는다면 01010의 자리수에 맞게 0을 00000로 바꿔서 계산을 해주면 됩니다. 
00000 xor 01010 이므로 각 자리끼리 xor 연산을 해서 01010이 됩니다.
```

## 24. 아래 프로그램에 <입력>을 입력했을 때 출력되는 값을 작성하시오 [초중고] 

<입력>
```text
8
4 6
8 1
4 1
2 3
4 7
5 6
1 3
```

```c
#include<stdio.h>
int n;
int *link[10];
int size[10], check[10], ans;

void search(int c, int p) {
    int count = 0;
    check[c] = 1;
    for(int i=0; i<size[c]; i++) {
        if(!check[ link[c][i] ]) {
            search(link[c][i], p+1);
            count++;
        }
    }
    if(count == 0) ans += p;
}

int main()
{
    scanf("%d", &n);

    for(int i=1; i<=n; i++) {
        link[i] = (int*)malloc(sizeof(int));
        link[i][0] = 0;
    }

    int p, q;
    for(int i=0; i<n-1; i++) {
        scanf("%d %d", &p, &q);

        link[p] = realloc(link[p], sizeof(int)*(size[p] + 1));
        link[p][size[p]] = q;
        size[p]++;

        link[q] = realloc(link[q], sizeof(int)*(size[q] + 1));
        link[q][size[q]] = p;
        size[q]++;
    }

    search(1, 0);
    printf("%d", ans);
    return 0;
}
```

## 25. 아래 프로그램에 <입력1>과 <입력2>를 입력했을 때 출력되는 값의 합을 작성하시오 [중고] 

<입력 1> 
```text
8 3
3 4 5 6 7 8 9 10
```

<입력 2>
```text
12 4
10 20 30 40 30 40 20 30 40 50 10 20
```

```c
#include<stdio.h>
int main()
{
    int n, m, a[20];
    int s = 0;
    scanf("%d %d", &n, &m);
    for(int i=0; i<n; i++) {
        scanf("%d", &a[i]);
        s += a[i];
    }

    int l = 0, r = s;
    int ans = -1;
    while(l <= r) {
        int c = (l + r) / 2;
        int cnt = 1, t = 0, flg = 0;
        for(int i=0; i<n; i++) {
            if(t + a[i] <= c) {
                t += a[i];
            } else {
                if(a[i] <= c) {
                    t = a[i];
                    cnt++;
                } else {
                    flg = 1;
                    break;
                }
            }
        }
        if(flg || cnt > m) {
            l = c + 1;
        } else {
            r = c - 1;
            ans = c;
        }
    }
    printf("%d", ans);
    return 0;
}
```
